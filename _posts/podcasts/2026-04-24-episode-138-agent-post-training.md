## 300 字摘要

罗福莉把 2026 年描述为从 Chat 转向 Agent 的第二场模型战争。OpenClaw 给她的冲击不只来自界面，而是持久 Memory、多模型调度、主动任务、消息通道、Skills 与开放源码共同形成的 Agent 框架。模型决定能力上限，框架则补足行动、Context 和成本短板；二者还可能通过用户反馈和训练共同进化。

MiMo-V2 围绕长上下文和 Agent 效率设计：Pro 负责理解与复杂任务，Omni 负责感知，TTS 负责表达，由框架按任务编排。Flash/Pro 采用 Hybrid Attention 和 MTP，试图平衡 KV Cache、推理速度和长上下文成本。罗福莉认为 Agent 范式显著抬高 Post-train 与 RL Infra 的重要性，研究、Pre-train、Post-train 的合理用卡比例可能从 Chat 时代的 `3:5:1` 变成 `3:1:1`。

组织上，她主张无固定小组、无职级、弱 Deadline 和跨角色流动，以平权、热爱和多样性保护创造力。她同时作出非常激进的预测：1T 基座是接近 Claude Opus 4.6 的入场券，两年内可能实现 AGI。此类参数门槛、代差、进度百分比和时间表都属于个人判断，而非已验证结论。

### 五个核心结论

1. **Agent 框架是厚中间层。** 它组织 Context、Memory、模型路由、主动任务、工具、评估和成本，而不只是前端 UI。
2. **模型与框架需要共同进化。** 顶尖模型提高框架上限，开放框架又把人的经验、Skills 和使用反馈带回训练。
3. **Agent 范式很吃 Post-train。** 长程任务、多轮环境交互和框架变化，使后训练从短周期附属环节变成核心战场。
4. **效率是智能落地的组成部分。** Long Context、KV Cache、TPS、MTP、模型路由和端云混合共同决定生产力价值。
5. **组织敏捷性与技术敏捷性耦合。** 预训练需要提前半年到一年下注，后训练则需要容忍模糊、快速重写 Infra 和跨角色协作。

## 分章笔记

### 00:02:16–00:41:31 OpenClaw 与群体智能

- 罗福莉最初把 OpenClaw 看成 Claude Code 加 IM/UI、本地化和 24 小时在线，并因产品运营风格而排斥。
- 春节深夜安装后，她连续使用到天亮。第一天感受到“温度”和主动性，第二天用它讨论团队与组织，第三天共同构建 User Agent，用于生成多轮 Agent 场景数据。
- 她把认知变化概括为：有灵魂的产品体验、替代生活和工作的一部分、最终促进研究。
- OpenClaw 的优势来自多个普通机制的高完成度整合：分层 Memory、多模型调度、Message Channels、Heartbeat、定时任务和开放源码。
- 好框架应补“行动缺陷”：把模型自己拿不到的环境 Context 提供给它，并根据模型长短板调度不同能力。
- 产品是人能直接感受到的交互和价值层；Harness 还定义模型通信、Context、Workflow、路由和成本。两者边界仍然模糊。
- 顶尖模型可帮助改造开放框架，改好的框架又能让 Sonnet、国内模型甚至小模型完成更复杂任务。这不等于小模型在裸能力上追平顶尖模型。
- 团队内部通过共享部署、飞书群和共同修改形成群体探索。“不足 100 轮就辞职”是推动采用的夸张口号，罗福莉明确表示没有实际考核或解雇。
- 她称团队借助 Agent 在三四周完成过去三四十周的部分工作。这是个人估计，没有任务定义、样本和对照实验。
- OpenClaw 开源使使用者可以修改 Memory 和 Multi-Agent 架构，保留“群体进化”的可能；闭源框架则更难被外部共同改进。

**回顾问题：** 框架提升的是模型真实能力、任务成功率，还是对模型弱点的工程补偿？

### 00:41:31–01:19:39 生产力变革与 Agent 自进化

- Code 是高泛化训练环境，因为软件工程任务长、文件关联密集、结果可运行、可验证、可回滚。
- 书籍也有长上下文，但监督信号更发散；代码和工程轨迹更适合训练长程任务状态与反馈闭环。
- 罗福莉提出“Code 拉上限，其他领域保下限”：Coding 能力可迁移，但非 Code 场景仍需专门数据保证稳定性。
- Skills 将互联网之外的企业规则、组织惯例和个人经验变成可执行规范。人提供目标、环境与纠错，Agent 可整理和复用这些经验。
- Skill 改善运行时不等于知识已经写入模型参数；它更像外部 Memory、Workflow 和过程数据。
- OpenClaw 在中国更热被归因于开发者效率需求、便宜模型供给和较高的成本替换比。这是观察性判断，不是地区采用率统计。
- 罗福莉用“10 美元 API 完成 1000 美元工作”说明 ROI，但这是启发式例子，不是普遍价格数据。
- 她将自进化拆为模型、框架和人三层：模型通过训练进步，框架调整 Memory/路由/Workflow，人则持续发现任务和贡献 Skills。
- “AI 训练 AI”在当前更准确地说，是 Agent 加速代码、实验、评估和数据构造，仍由人类选择目标与判断结果。
- 她对 Multi-Agent 较谨慎：目前更确定的是并行、速度和成本收益，尚未看到稳定提升任务能力上限。
- 隐私方向是端云混合：本地小模型处理简单、隐私敏感任务，云端模型处理高难度和创造性任务；框架负责路由与权限。
- 她认为端侧模型会持续进步，但 2026 主旋律仍是高生产力、长程任务和 Agent 协作。

**回顾问题：** Skills、外部 Memory 和 RL 更新应怎样分工，才能既积累经验又避免隐私与错误固化？

### 01:19:39–01:52:33 MiMo-V2、Long Context 与算力分配

- MiMo-V2-Pro、Omni、TTS 分别承担理解/认知、感知和语音表达。它们不是一个万能模型，而是由 Agent 框架协调的模型生态。
- 分开模型的原因包括成本、速度和任务差异。语音生成不必使用 1T 级推理模型，但跨模型交接仍需明确 Context、状态、置信度和错误恢复协议。
- V2-Flash 与 Pro 围绕 Long Context 的效果、成本和速度设计。Agent 需要更长 Context，也需要更小 KV Cache 和更高响应速度。
- Hybrid Attention 用 Sliding Window 层降低 KV Cache，并保留部分 Full Attention。Pro 将比例进一步做得更稀疏，访谈口径为约 `7:1`。
- MTP 在预训练中被用于提升基座能力，在推理中则可一次提出多个 Token、由主模型 Verify，以利用剩余计算并提高 TPS。
- 罗福莉认为 MLA 在特定硬件和 Chat 时代是优秀结构，但可能已接近 Compute/Memory Balance，叠加 MTP 的空间较小。这是她的架构判断，不是 MLA 的普遍缺陷证明。
- 精细匹配单一芯片和固定场景的结构可获得最高效率，但 Agent Post-train 周期拉长后，原先假设的 Context、硬件和使用场景可能失效；更简洁、留有余量的结构更灵活。
- 访谈中 Flash/Pro 速度、API 价格和 MTP 收益均缺少统一硬件、Batch、Context 和并发口径，不能直接横向比较。
- 罗福莉提出研究、Pre-train、Post-train 的合理用卡比例约为 `3:1:1`，而 Chat 时代约为 `3:5:1`。这是其团队规划经验，不是行业标准。
- 她称 Agent 时代 Pre-train 与 Post-train 算力可能接近 `1:1`，研究实验还需要额外资源，因为想法实现更快后，GPU 反而成为瓶颈。

**回顾问题：** 模型结构应该极致适配当前芯片，还是为半年后的 Post-train 和 Agent 场景保留灵活性？

### 01:52:33–02:22:32 1T 训练、组织平权与另类架构

- 罗福莉把 1T 总参数基座视为接近 Claude Opus 4.6 Agent 水平的“入场券”。她也强调激活参数和 Context 共同决定效果与成本。
- MiMo-V2-Pro 训练的主要挑战是数值稳定：Loss Spike、激活异常、Expert 负载失衡、通信算子或 Norm 问题等。
- 团队倾向在问题出现时停下数天甚至一两周查根因，而不是为 Deadline 继续训练。她称停一天大几千卡可能意味着一两百万元级成本，数字应按卡型和利用率核验。
- 训练需要严密监控每层输入输出、激活值、Expert 分布和 QK Logits；必要时使用 Clip 或 Norm 稳住训练，但这些操作可能影响效果。
- 团队没有严格小组和职级，约 100 人覆盖数据、Infra、算法、产品和多模态链路，真正集中投入单代模型的约二三十到三四十人。均为内部口径。
- 固定分组会限制跨 Pre-train/Post-train/Infra 的迁移。做预训练的人有数据多样性视角，进入后训练可能带来不同贡献。
- “平权有利于创新”是团队价值观：项目推动者可以存在，但不对参与者拥有绝对控制权。
- 无 Deadline 和弱层级有利于研究探索，也可能带来责任、优先级、冲突处理和规模化管理风险；不能直接推广到所有公司。
- Omni/TTS 尝试把音频等模态离散 Token 化，并以 RVQ 等机制提高重建质量。优雅统一不是最高目标，效果和 Agent 可用性优先。
- 罗福莉对“多模态是否促进智能”保持保留：主观上看到感知和世界知识改善，但 Benchmark 没有明确证据；在可编排多模型的 Agent 时代，这个问题也未必关键。

**回顾问题：** 无职级和弱 Deadline 如何在团队扩大后维持问责、资源优先级与研究质量？

### 02:22:32–02:48:34 AGI 路线、价值观与自我否定

- 罗福莉认为人类与 AI 的进化环境不同。人类受生存压力塑造，大模型则从人类知识、算力和外部帮助的高起点开始。
- Coding 的下一步是进入真实复杂项目，完成不一定代码量大、但验证链很长的工程任务；之后再向更广泛生产力场景扩展。
- 机器人是 Agent 从屏幕进入物理空间的接口，但硬件、电池、传感器和灵巧手可能比语言 Agent 进化更慢。
- 她用“当前 20%、年内 60%–70%、两年内 AGI”表达极激进预测，但 AGI 没有操作性定义，这组百分比也无法直接检验。
- AI 训练 AI 被视为自迭代标志：模型能参与设计任务、实验、训练和新研究。但当前仍是分阶段走向该目标，不是已经实现自主闭环。
- 她认为开源可连接分散芯片、模型、Agent 框架和能源生态，从终局上加速 AGI；公司是否开源还取决于是否拥有模型之外的战略生态位。
- 她称国内具备 1T 以上基座的公司可能只落后当代 Claude 两三个月。这里不是追上同期未来 Claude，而且仍是个人概率判断。
- 推理需求“立即增长几倍到十倍”、两年 AGI、国内代差等都属于预测，不应当作事实。
- 罗福莉描述自己每天都在否定昨天的判断。在 Reward 模糊的大模型研究中，她更依靠价值观：选择对更多人有益、有意义的方向。
- 如果 AI 替代研究，她仍希望支持基础研究、建立公益性组织并继续做有益的事；这体现个人价值取向，不是技术路线结论。

**回顾问题：** 没有明确 AGI 定义时，百分比和两年时间表究竟在预测什么可观察能力？

### 02:48:34–03:19:45 三年技术史与 Agent 第二幕

- 罗福莉把 2022 年 ChatGPT 理解为把大规模预训练能力通过 Chat 交互释放出来。
- 2023 年开源团队追赶预训练：Llama 提供可复现起点；Qwen 强调规模、全尺寸生态和社区价值；DeepSeek 更关注资源受限下的架构创新。
- 她将 Qwen 与 DeepSeek 视为两种都重要的开源路径：生态规模与研究高度相互促进。
- DeepSeek 的 MoE 和 MLA 旨在降低训练与推理成本；相关芯片和算力背景应结合论文与官方报告理解。
- o1/R1 被视为 2024 年意外转折。罗福莉自述离开 DeepSeek 时已看到 Code/Math Reasoning 走通，却低估了它向通用场景泛化的范式意义。
- 2025 年是 Chat Reasoning 与 Agent 路线交错的一年。只优化 BrowseComp、SWE-bench 或 Terminal-Bench 不一定产生工业可用 Agent。
- 她认为正确方向是在复杂、多样的 Agent 框架中端到端完成高复杂任务，并以此重构 Post-train，而非为单一 Benchmark 定制简化框架。
- Anthropic 被视为更早走上正确路径；国内 Pre-train 代差已缩小，竞争核心转向 Agent Post-train 和 RL Scaling。
- Code 在 Pre-train、Reasoning 和 Agent 三个阶段都具备优势：数据丰富、可验证、环境明确、任务可长程，并可能向通用任务迁移。
- 后训练更新可按月发生，使竞争维度和速度同时增加；Context、推理芯片、Agent 框架和模型结构需要联合决策。

**回顾问题：** Benchmark 提升在什么条件下才可推断为真实 Agent 任务成功率提升？

### 03:19:45–03:35:19 环境、经验与 RL Infra

- 罗福莉认为 Frontier Lab 既要顺应可 Scaling 的主流，又要在架构和工业模型中做可规模化原创，而非只追求孤立 Paper。
- 她更相信团队自己的大规模实验结果，而非未经复现的论文结论；这种立场能强调工程真实性，也有信息闭环和忽视外部证据的风险。
- 约 100 人团队中，只有部分成员此前训过小模型。她认为大模型能力可在一至四个月内通过高标准环境快速习得，因此“环境比经验更重要”。
- 招聘更看重技术基础、好奇心、热爱、适应性和多样性，并开始吸纳更多本科生。节目提到博士及在读博士约占 55%，为团队内部统计口径。
- 管理依靠热爱、体验、使命和共享信息环境；钱是 Baseline，但意义感与价值感同样重要。
- 预训练需要战略前置，Post-train 则更重敏捷和模糊性。Agent RL Infra 从“以 Rollout 推理引擎为中心”转向“以 Agent 为中心”的异构复杂系统。
- RL Infra 必须容忍超时、中断、训练推理不一致和部分失败，并同时调度 GPU、CPU 与存储。它对算法与工程跨界理解要求更高。
- 罗福莉认为真正将 Agent RL Scaling 到接近 Pre-train 量级的团队仍很少；这属于观察判断。
- 有效访谈在约 `03:35:19` 结束，之后为节目片尾。

## 十五项高风险主张

以下内容必须带归因，并建议独立核验：

1. OpenClaw 已被 OpenAI 收购或团队立场发生变化的具体交易结构。
2. Anthropic 已停止支持 OpenClaw 调用的范围和时间。
3. OpenClaw 框架可让中层模型在约 85% 任务上接近 Claude Sonnet。
4. 第一天高强度使用 Claude Opus 4.6 花费接近 1000 美元。
5. Agent 使三四周完成过去三四十周的研究工作。
6. `10B` 模型一年后可达到当前 Claude Opus 4.6 水平。
7. MiMo-V2 Flash/Pro 的 TPS、API 成本和相对竞品速度。
8. `1T+` 基座是达到 Claude Opus 4.6 Agent 水平的入场券。
