## 300 字摘要

这期节目是戴雨森对上期“2026 Year of R”判断的复盘。他用“Strong Opinions, Weakly Held”解释投资人的纠错机制：需要明确表达判断，也要在 Claude Code、Codex、Anthropic 收入和 Agentic Coding 快速变化后更新观点与仓位。他的核心追问是，模型公司的收入增长并不等于 AI 的 Return 已兑现；Token 是客户投入，真正结果应体现在终端企业的新收入、降本、利润和组织效率。

戴雨森认为 Harness 不再只是“套壳”。模型决定能力上限，但 Harness 持有 Context、Memory、工具、Agentic Loop、Runtime、工作流和反馈数据，可能更像操作系统，模型更像处理器。它既能提高模型可用性，也可能形成数据飞轮与用户粘性。

创业部分强调，新机会不能只复刻字节时代的信息流、DAU、投放和商业化逻辑。Agent 产品应关注高价值任务、长期自主执行、Agent 间协作和 AI 原生基础设施；组织也会转向更小、更全栈的人机团队。需要注意，嘉宾披露了二级市场仓位变化，真格也投资了模型、Agent、世界模型和机器人公司，因此具体公司评价、估值与赛道判断均带有投资立场。

## 一页回顾

### 这期在回答什么

1. 投资人怎样面对公开预测被现实推翻？
2. Anthropic 和 Agentic Coding 的增长是否证明 AI Return 已成立？
3. Harness 为什么可能成为 AI 时代的 OS？
4. 模型会不会向下吞并应用和 Harness？
5. AI 产品是否还应该用 DAU 与使用时长衡量？
6. 下一个字节级公司为什么可能完全不像字节？
7. 中美 AI 创业机会和组织形态会如何分化？

### 五个核心结论

1. **复盘能力比单次预测准确更重要。** 强观点只有在前提改变时愿意更新，才不是固执。
2. **Return 问题仍未真正解决。** 模型收入是客户支出，最终回报必须落到客户利润和新价值创造。
3. **Harness 是模型能力进入现实工作的承载层。** 它组织 Context、Memory、工具、Runtime 和反馈数据，并可能拥有工作流粘性。
4. **Agent 时代的指标从注意力转向任务价值。** 低 DAU 但能独立完成高价值任务的产品，可能比高频 Chatbot 更有商业价值。
5. **原生机会不会长得像上一代冠军。** 复制信息流、买量和商业化打法，往往是在最强 incumbent 的规则下竞争。

### 最值得记住的两条链

AI 商业回报链：

`Token / CapEx 投入 -> 软件与内容产出 -> 新收入或降本 -> 企业利润`

Agent 产品栈：

`Model -> Context / Memory -> Tools -> Agentic Loop -> Runtime / Sandbox -> Harness / Product`

前一条解释为什么模型收入暴涨不等于客户 Return 已完成；后一条解释为什么“壳”可能拥有独立价值。

### 00:23:17–01:04:03 Return 问题与 Harness 价值重估

- Token、算力和 AI 订阅只是投入；代码、报告和软件是产出；最终结果必须是新增收入、降低成本或提高利润。
- AI Coding 可以让代码产量提高，但企业未必缺程序员，可能更缺“做什么”的产品判断。产能增加不自动创造需求。
- 自动驾驶类比说明，解决 80%–90% 的常规工作并不等于移除人类，因为协调、信任、责任和长尾异常仍需有人承担。
- 小公司和个人更可能率先获得 Return：他们过去有想法却缺执行能力，Agent 直接消除了生产门槛；大公司的瓶颈往往是组织和方向。
- 戴雨森把 Harness 定义为让模型在约束中长期工作的系统，包含 Context、工具、Agentic Loop、权限、Sandbox、持久 Runtime 和 Memory。
- ChatGPT 也可以被理解为 GPT API 的早期 Harness。用户体验的是产品和工作流，而不是裸模型接口。
- Coding Harness 能沉淀高价值任务轨迹：修改了什么、哪里失败、怎样修复。这些数据可能反哺模型训练，形成产品与模型飞轮。
- 模型与 Harness 并非二选一：模型决定上限，Harness 决定可用性、上下文、反馈、长期记忆和粘性。
- 用户可能频繁切换底层模型，却不愿离开保存自己 Memory、配置和项目 Context 的 Harness。
- 戴雨森认为 Harness 更像 OS，模型更像处理器；未来用户可能通过 GUI、Skill 和应用使用 Claude Code/Codex/OpenClaw Runtime，而不直接接触 CLI。
- 反方风险是模型公司持续向下吞并 Harness。应对方式可能是拥有产品数据、自训模型、工作流粘性或成为有价值的收购对象。
- “AGI 在缩水”指 AGI 的社会定义从奇点、重大科学突破，逐步缩到替代常规程序员。戴雨森认为当前 AI 仍主要擅长分布内任务，真正 OOD 创新尚未解决。
- 他预测 Agent 会因各自积累不同 Context 和 Skill 而分化，并可能形成 Agent-to-Agent 服务市场。这仍是长期推演。

**回顾问题：** Harness 的数据和 Memory 是长期护城河，还是模型平台尚未整合完成的临时窗口？

### 01:04:03–01:28:51 应用创业、估值和指标变化

- 戴雨森认为 AI 应用机会正在增加，实际融资项目更多、估值更高；这既说明市场认可，也可能代表资本过热。
- 创业机会经常存在于大厂看见却不愿做的领域：太小、太累、太低端、不合规、责任过重或过于超前。
- 早期技术浪潮中，他更鼓励 Horizontal 产品。成熟 SaaS 时代适合深耕垂直，而 AI 能力和场景尚在快速扩张，过早垂直可能限制上限。
- 真格仍强调“投人”：学习力、创造力、领导力和意志力等长期特征不变，但 AI 创始人还要有一手技术理解和非共识判断。
- 戴雨森用真格已投的年轻具身/世界模型创始人说明“好创始人与好方向共振”。这也是组合公司宣传，估值变化需独立核验。
- 模型训练越来越工业化，个人英雄主义空间减少；产品经理和创始人仍可能通过对未来的独特偏见创造产品。
- 移动互联网的 `DAU × 时长 × 变现效率` 不一定适合 Agent。若产品替用户节省注意力，访问频率降低反而可能是成功。
- 更合适的指标包括：自主运行时长、完成高价值任务数量、任务成功率、节省的人类时间和每项任务收入。
- 旧护城河可能变成软肋。封闭超级 App 若阻止用户 Agent 访问数据，可能把公司自己困住；开放工作流反而更易进入 Agent 时代。

**回顾问题：** 一个 Agent 产品的北极星指标，应该是用户数、在线时长、Token 消耗、任务价值还是利润？

### 01:28:51–01:48:01 AI 像外星人、组织变革与下一个字节

- 戴雨森把 AI 比作进入人类数字世界的外星人，并划分三阶段：给人类更多 Agent；让 Agent 适应 GUI、验证码、支付和账户；建设 Agent 原生的接口、支付和市场。
- 当 Coding 变得便宜，软件可以更个性化、临时化和低频化。约束从工程人力转向问题发现、想象力和数据访问。
- AI 工具装进公司不等于生产率提升。组织内部 Context 若对模型不可见，部门墙和责任流程不改变，技术收益难以兑现。
- 他用蒸汽机到电动机的工厂布局类比：新动力只有在组织结构和生产流程随之重构后，才会释放完整效率。
- AI 原生团队可能更小、更全栈。一个人或小队可调度 Agent 完成前端、后端、设计、测试和运营，传统瀑布式分工会减弱。
- “下一个字节可能不像字节”意味着，时代级公司应创造新交互和新生产方式，而不是把 AI 塞进信息流、买量和广告商业化。
- 字节背景创业者很优秀，但必须主动颠覆从信息流、DAU、分发和投放中学到的成功范式，否则是在字节最擅长的规则里挑战字节。
- 戴雨森把 AI 原生机会分成两阶段：先用新技术解决写代码、翻译、创作等旧问题；再出现 Agent 间协作、市场、协议、组织和商业模式等原生新需求。
- 如果软件主要由 Agent 使用，人类 GUI、Excel 和网页可能不再是最佳接口，底层 API、数据库和机器可读协议会更重要。

**回顾问题：** 今天看似奇怪、没有现成市场名称的哪些需求，可能是 Agent 原生时代的基础设施？

### 01:48:01–02:01:30 中美创业端、世界模型与硬件

- 戴雨森认为硅谷热点包括 Coding、世界模型和 Auto Research；New Labs 很热，但 Vertical SaaS 和产品公司仍占重要位置。
- 中国创投更“硬”，机器人、机器人大脑、世界模型、AI 硬件、硬科技和生产力应用更受关注。这是概括性判断，两边都有大量例外。
- 世界模型概念尚未收敛。预测下一世界状态、VLA、视频生成和机器人模型之间的边界仍有争议。
- 他对许多 AI 消费硬件持谨慎态度：旧硬件增加 Chatbot、感知或录音功能，不一定创造新需求；硬件还有供应链、开模、库存和慢迭代成本。
- 手机和云在较长时间内仍可能是最有效的 AI 载体。可穿戴设备需要证明持续使用习惯和不可替代价值。
- 真格基本没有投资录音类可穿戴 AI 硬件，也没有参与当前人形机器人整机热潮；但投资了模型、世界模型和机器人组件。这种组合暴露与其观点相关。
- 他认为人形机器人仍早期、估值高，真正有用取决于 Manipulation、灵巧手、机械臂、结构和模型共同成熟。
- 对跟风项目保持谨慎。更偏好“出题家”：提出不同问题、创造新类别，而非在已有赛道名称中做小幅优化。

**回顾问题：** 一个硬件产品的价值来自“用了 AI”，还是来自解决了过去无法解决的真实问题？

### 02:01:30–02:16:59 思考、创新与 Agency

- 戴雨森会优先阅读播客文字稿，并用 Claude Code 构建工具，将播客、Newsletter、会议记录和投资信息同步到 Notion。
- 他认为 AI 显著改善信息收集，却担心把思考外包给 AI 会让人只得到答案，没有更新自己的“权重”。
- 轮椅类比：长期不用腿，肌肉会萎缩；长期不独立形成论点、证据和反驳，思考能力也可能退化。
- “思想健身房”包括主动写观点、准备播客、明确论据、接受公开反驳，并用 AI 帮助检查而不是替代思考。
- 创新也需刻意练习。先做简单工具，再逐步扩大复杂度；拥有 AI 程序员并不等于知道该做什么。
- AI 可能在短期摧毁旧价值快于创造新价值，岗位变化也可能快于人类再培训；长期则可能像蒸汽机、电气化和化工扩散一样产生意料之外的新职业。
- 人类与 AI 的关系会从聊天转向协作，可靠完成任务后，人会自然给予更多权限、信任和依赖。
- 戴雨森认为 Agency 仍重要：决定要做什么、提出什么问题、改变什么现状。Taste 也可能被更强模型追上，因此并非永久护城河。
- 当前 AI 强于分布内重组，真正创造从未出现过的 OOD 内容仍较弱。能提出新问题和创造新范式的人相对更难替代。
- 节目以继续公开表达、继续被现实纠正作结，将“被打脸”视为投资人与行业共同进化的一部分。

**回顾问题：** 如何让 AI 扩大自己的思考和 Agency，而不是逐步替代它们？
