> **所属部分**：第 2 部分“个人领域的成功：从依赖到独立”  
> **英文标题**：Habit 2: Begin with the End in Mind  
> **副标题**：自我领导的原则  
> **本章任务**：说明人应先依据原则明确希望成为什么人、作出什么贡献，再用这一终点指导当下选择；并通过使命宣言、角色和目标，把人生的“第一次创造”掌握在自己手中。

## 一、本章核心结论

本章的中心命题是：

> 在行动之前，先明确真正重要的终点、原则和评价标准，再以此设计和校准当下生活，避免高效率地奔向错误方向。

“以终为始”不是一般意义上的“先定目标”，而是依次回答四个层次的问题：

1. **终点**：我希望一生最终体现什么品德、贡献与关系？
2. **原则**：哪些不因环境和情绪变化而改变的标准应指导选择？
3. **角色**：我在哪些重要关系和责任中实践这些原则？
4. **行动**：今天和近期的决策是否把我带向那个终点？

全章可以压缩为以下路径：

```text
想象人生终点
      ↓
澄清品德、贡献与核心价值
      ↓
用原则校准生活中心
      ↓
形成个人使命宣言
      ↓
分解为重要角色与长期目标
      ↓
在项目和日常生活中进行第一次创造
      ↓
由习惯三完成第二次创造
```

习惯一回答“谁对人生负责”：我是选择者和创造者。习惯二回答“要创造什么”：我要主动完成第一次创造。习惯三则回答“如何落实”：把重要的事安排进现实生活。

## 二、为什么本章从“自己的葬礼”开始

### 1. 心灵实验

作者邀请读者想象参加自己的葬礼，并分别听到亲人、朋友、同事和社团伙伴对自己一生的评价。核心问题包括：

- 他们会怎样描述我的人格？
- 我在家庭中是怎样的伴侣、父母、子女或亲人？
- 我给朋友和同事留下了什么影响？
- 我完成了哪些真正有意义的贡献？
- 哪些成就值得在生命终点被记住？

### 2. 练习的真正作用

死亡视角暂时移除了许多短期噪音：名利比较、琐碎争执、即时欲望和外界评价。它迫使人用更长时间尺度判断现在的生活。

普通决策常问：

- 今天怎样更舒服？
- 怎样得到认可？
- 怎样完成更多任务？

终点视角则问：

- 这件事最终塑造我成为什么人？
- 它对重要关系留下什么影响？
- 它是否构成我愿意承认的一生？

### 3. 为什么评价者分为不同关系

亲人、朋友、同事和公共社群分别观察人的不同侧面。若只想象职业评价，容易继续把人生压缩为工作成就；加入多种关系后，成功被扩展为品德、爱、信任、贡献和专业成果的整体。

### 4. 终点视角不是制造死亡焦虑

练习目的不是让人恐惧死亡，而是用有限性澄清优先级。死亡使以下事实更明显：

- 人无法带走财富和地位；
- 当前紧迫之事未必长期重要；
- 关系中的伤害和关爱会留下记忆；
- 时间一旦使用就无法重来；
- 忙碌不能自动证明方向正确。

### 5. 一个可操作的记录表

| 社交圈 | 希望体现的品德 | 希望作出的贡献 | 希望留下的成就或影响 |
| --- | --- | --- | --- |
| 家庭 |  |  |  |
| 朋友 |  |  |  |
| 工作 |  |  |  |
| 社区或公共服务 |  |  |  |

这张表不是写给别人看的形象设计，而是用“希望被怎样真实经历过”反推当下生活。

## 三、“以终为始”的准确含义

### 1. 用人生目标衡量当下

习惯二最基本的应用，是把人生使命和真正重视的价值作为日常判断标准：

```text
我希望最终成为什么人
          ↓
我应遵循哪些原则
          ↓
当前选择是否与之一致
```

终点不是只在重大决定时出现。每一次说话、工作、消费、冲突和承诺，都可能让人更接近或更偏离所选择的品德与关系。

### 2. 梯子搭错墙

作者用梯子比喻忙碌与方向的差异：

- 爬得快，表示效率高；
- 梯子是否靠在正确的墙上，表示方向正确；
- 如果墙错了，爬得越快，离真正目标越远。

因此：

$$
\text{高效率}\not\Rightarrow\text{高效能}
$$

效率回答“怎样更快完成”，效能还要回答“这件事是否值得完成，以及是否服务于正确终点”。

### 3. 为什么成功后仍会空虚

很多人以财富、权力、声望或职位作为默认终点。达成后感到空虚，可能不是执行失败，而是第一次创造失败：

- 目标来自社会脚本而非内在原则；
- 只描述“拥有什么”，没有说明“成为什么”；
- 只衡量可见成就，忽略关系和品德代价；
- 为手段牺牲了比目标更重要的事物。

所以，习惯二关注的不是更强的目标达成能力，而是目标选择能力。

### 4. “盖棺定论”作为成功检验

作者提出，希望生命终点获得的真实评价，往往比短期欲望更接近内心对成功的定义。这不是要求为他人评价而活，而是借他人的长期经验检验：自己的价值是否真正进入关系和贡献。

## 四、两次创造：一切先在头脑中产生

### 1. 两次创造的定义

作者认为，任何事物通常都经过两次创造：

| 阶段 | 名称 | 内容 |
| --- | --- | --- |
| 第一次创造 | 智力或精神创造 | 愿景、设计、目标、原则和计划 |
| 第二次创造 | 体力或现实创造 | 执行、建造、行动和交付 |

可以表示为：

$$
\text{现实成果}=\text{第一次创造的方向}\times\text{第二次创造的执行}
$$

这不是数值公式，而是强调：方向错误时，强化执行只会扩大偏差；方向正确但没有执行，也不会产生现实成果。

### 2. 建筑案例

建筑在施工前需要构思、设计图和施工计划。若第一次创造存在重大缺陷，施工后再修改会付出更高成本。

对应关系是：

| 建筑 | 人生或项目 |
| --- | --- |
| 设计目标 | 使命与理想结果 |
| 建筑图纸 | 角色、原则和计划 |
| 施工 | 日常行动与资源投入 |
| 验收标准 | 是否实现预定价值与结果 |

### 3. 企业案例

创办企业需要先明确服务对象、价值和目标，再组织资金、研发、生产、营销与人力。企业常见失败原因包括：

- 目标不清；
- 资源规划不足；
- 错误理解市场；
- 各部门执行没有共同方向。

这些问题即使发生在第二次创造中，根源也可能在第一次创造。

### 4. 教育子女案例

如果父母希望孩子最终自律、负责并有自尊，日常教育就不能只追求立即服从。每次命令、惩罚或包办，都应接受终点检验：这种做法是在培养责任，还是削弱责任？

这与第二章的产出/产能平衡相连：眼前秩序是产出，孩子的品德和能力是产能；终点帮助父母在两者之间判断。

### 5. 第一次创造不等于详细预测一切

“以终为始”不要求准确预知未来，也不要求计划不可改变。第一次创造的核心是：

- 明确方向；
- 确立原则；
- 定义成功标准；
- 预想关键后果；
- 在新信息出现时修订路径。

愿景提供罗盘，不是把未来写成无法调整的剧本。

## 五、主动设计还是被动接受

### 1. 第一次创造总会发生

即使一个人从不主动规划人生，也会存在第一次创造，只是它可能来自：

- 家庭期待；
- 教育与文化脚本；
- 同伴和组织压力；
- 对归属和认可的渴望；
- 过去经验形成的习惯；
- 广告、媒体和社会成功标准。

因此，问题不是“人生有没有剧本”，而是“谁在写剧本、剧本依据什么”。

### 2. 被动剧本为何容易被接受

人需要安全感、爱、接纳和价值确认。若内在安全感不足，就容易通过服从外部脚本换取认可：

- 选择社会认为体面的职业；
- 用收入和职位证明价值；
- 为避免冲突放弃个人原则；
- 按家庭期待重复不适合自己的生活方式。

这些选择未必都错，问题在于它们是否经过自觉检验。

### 3. 习惯一与习惯二的关系

| 习惯一 | 习惯二 |
| --- | --- |
| 我是选择者 | 我要选择什么方向 |
| 我是创造者 | 我要完成第一次创造 |
| 我能改写回应 | 我能改写人生剧本 |
| 关注影响圈 | 在影响圈核心确立愿景和价值 |

若没有习惯一，人会认为剧本无法改变；若没有习惯二，人虽主动，却可能没有方向。

## 六、自我领导与自我管理

### 1. 两者的区别

| 自我领导（Leadership） | 自我管理（Management） |
| --- | --- |
| 做正确的事 | 正确地做事 |
| 判断目的地 | 优化抵达路径 |
| 第一次创造 | 第二次创造 |
| 关注方向、原则和意义 | 关注计划、效率和执行 |
| 判断梯子靠哪面墙 | 更快、更稳地爬梯子 |

领导必须先于管理，因为执行能力无法补救根本方向错误。

### 2. 丛林案例

工人在丛林中高效砍伐，管理者负责政策、工具、进度和激励；领导者爬到高处观察后发现“不是这片丛林”。若团队只顾埋头工作，可能会回答：“别打扰，我们干得正起劲。”

这个案例揭示一种常见陷阱：紧迫任务持续提供即时成就感，使人没有时间检查任务是否服务于真正目标。

### 3. 地图与罗盘

环境变化快时，精确路线图可能很快过时。比固定路线更重要的是：

- 明确目的地；
- 拥有原则罗盘；
- 根据现实持续判断路径。

原则提供方向一致性，策略则可以灵活改变。

### 4. 石油公司总裁案例

一位总裁发现自己长期忙于管理，没有真正领导。他把部分管理工作交给他人，转向思考公司方向、文化、机会和深层问题。

这一转变困难在于：

- 紧急事务更容易带来完成感；
- 战略思考的结果延迟且不确定；
- 下属习惯把问题上交；
- 授权会暴露组织能力缺口。

但坚持后，公司适应环境的能力和经营成果显著提升。案例说明，自我领导需要主动为“不紧急但重要”的方向判断保留空间。

### 5. 家庭中的管理误区

父母也可能只关心规则、秩序、效率和控制，却忘记家庭希望培养怎样的人、建立怎样的关系。家庭管理当然必要，但应服从家庭愿景，而不能成为目的本身。

### 6. 领导不应取代管理

本章强调领导优先，不意味着管理不重要。正确关系是：

```text
领导决定方向 → 管理组织执行 → 结果反馈并修正方向
```

只有愿景没有执行，会停留在愿望；只有执行没有愿景，则可能高效地浪费生命。

## 七、改写人生剧本

### 1. 为什么是“改写”而非从零编写

每个人成长时都已继承家庭、文化和经历形成的剧本。自我领导不是假装这些影响不存在，而是：

1. 看见已有脚本；
2. 判断它是否符合现实与原则；
3. 保留有价值部分；
4. 改写低效、矛盾或有害部分；
5. 用新行为完成第二次创造。

### 2. 改写所需的三种天赋

| 天赋 | 在第一次创造中的作用 |
| --- | --- |
| 自我意识 | 看见旧脚本及现实行为 |
| 想象力 | 构造尚未实现的未来和不同回应 |
| 良知 | 用原则判断什么值得追求 |

独立意志则在习惯三中负责把新剧本落实为行动。

### 3. 萨达特案例

埃及总统萨达特成长于仇恨以色列的民族主义脚本中。入狱后，他通过旁观自我、冥想、阅读和祷告检查原有剧本，重新理解成功与自我，并最终改写对冲突和互赖的看法。

案例的论证作用是：

- 强烈的集体脚本也可以被审视；
- 独立不等于固守敌对；
- 战胜自己比占有权力更接近内在成功；
- 个人剧本改变可能扩大到社会影响。

### 4. 严厉父亲案例

父亲在孩子行为不当时发怒，使用权威迫使孩子服从。眼前冲突看似获胜，长期亲子关系却受损。

若父亲从葬礼终点反思，他真正希望留下的是爱、共同经历和尊重，而不是孩子记住恐惧与冲突。这揭示了两个版本的剧本：

| 旧剧本 | 新剧本 |
| --- | --- |
| 孩子不服从就是挑战权威 | 孩子的行为是教育与关系机会 |
| 目标是立即压服 | 目标是长期培养责任和信任 |
| 由愤怒和面子驱动 | 由爱、原则和父亲角色驱动 |
| 以当下输赢衡量 | 以终身关系和成长衡量 |

### 5. 按理想而非记忆生活

作者提出，人可以把未来理想与有限过去区分开：过去解释自动反应从何而来，理想则决定下一次要练习什么。

“按理想生活”不是否认过去创伤，而是不让记忆垄断未来脚本。

## 八、个人使命宣言：人生的书面宪法

### 1. 定义

个人使命宣言是一份关于人生哲学和基本信念的书面陈述，主要回答：

- **品德**：我想成为怎样的人？
- **贡献**：我想为家庭、工作和社会创造什么？
- **成就**：哪些结果值得投入生命？
- **原则**：哪些标准不可因短期压力而放弃？

### 2. 为什么称为“个人宪法”

宪法不是每天事务的详细操作手册，而是判断规则、决策和行为是否正当的上位标准。个人使命宣言同样用于：

- 评估机会是否值得追求；
- 在角色冲突中确定优先级；
- 在情绪波动时保持方向；
- 判断目标是否服务于真正价值；
- 根据环境变化灵活调整方法。

### 3. 稳定核心如何增强适应性

使命宣言并非让人僵化。恰恰因为核心原则稳定，方法才可以灵活：

```text
原则和使命稳定
      ↓
不必用固定做法维持身份安全
      ↓
能够根据事实调整路径
      ↓
在变化中仍保持方向一致
```

### 4. 使命宣言与目标的区别

| 使命宣言 | 目标 |
| --- | --- |
| 描述长期品德、贡献和原则 | 描述特定结果 |
| 相对稳定 | 可完成、替换或调整 |
| 用来筛选目标 | 用来落实使命 |
| 跨越多个角色 | 常属于特定角色或时期 |

例如，“帮助他人成长并保持诚信”属于使命；“今年指导两名新人完成独立项目”属于目标。

### 5. 两份示例的共同结构

书中示例虽然风格不同，却都包含：

- 不妥协的品德标准；
- 家庭和工作责任；
- 学习与能力更新；
- 财务和生活秩序；
- 服务与公共贡献；
- 具体决策准则。

这说明使命宣言既可以是简洁条款，也可以是完整叙述，重点是它能否真实指导选择。

## 九、使命感为什么能够对抗空虚

作者联系弗兰克尔的意义疗法指出，一部分心理空虚来自失去方向和意义。使命感能提供：

- 对生命的整体解释；
- 值得承受困难的理由；
- 连接长期与短期目标的框架；
- 使用时间、精力和才能的标准；
- 超越即时得失的贡献方向。

但使命宣言不是心理疾病的万能治疗，也不能替代必要的医疗和心理支持。它的作用是为生活组织意义，而不是否认疾病、创伤或现实困境。

## 十、影响圈的核心：愿景与价值从哪里产生

作者认为，使命宣言应从影响圈核心开始。这里是基本思维方式所在，也是最能由自己负责的部分。

四种能力在这里协作：

| 能力 | 作用 |
| --- | --- |
| 自我意识 | 检查当前地图、行为和价值是否一致 |
| 良知 | 用原则辨别方向和独特贡献 |
| 想象力 | 形成希望的人生终点和未来图景 |
| 独立意志 | 在后续行动中兑现第一次创造 |

在核心区投入，是一种高水平产能建设：它不一定立刻产生外部成果，却会提高生活各领域的判断与行动质量。

---

## 十一、核心提供的四种人生支撑

生活中心会影响安全感、人生方向、智慧与力量。

### 1. 安全感（Security）

安全感包括：

- 自我价值和身份认同；
- 情感归属；
- 自尊与自我接纳；
- 对基本能力的信心。

安全感从极度依赖变化无常的外界，到清楚认识自身价值，存在不同成熟程度。

### 2. 人生方向（Guidance）

人生方向是理解世界、作出决策和选择行为的内在准绳，相当于地图与罗盘。

它可能来自社会之镜和外界期待，也可能来自清楚、稳定的原则。

### 3. 智慧（Wisdom）

智慧是对生命、平衡和事物联系的整体理解，包含判断力、洞察力和理解力。

它从扭曲、片面的地图，发展到能把目标、关系、原则和后果适当联系起来的地图。

### 4. 力量（Power）

力量是选择、行动、达成目标和改变习惯的能力。

最低状态是成为外界操纵的对象；较高状态是能够依据价值行动，并承担自然后果。

### 5. 四者的相互关系

```text
稳定安全感 + 明确方向
          ↓
更全面的智慧
          ↓
更坚定且合乎原则的行动力量
          ↓
行动结果进一步验证或修正核心
```

若四者失衡，例如有力量却无智慧，行动能力可能被错误中心利用；有方向却无力量，则使命停留在纸面。

---

## 十二、各种生活中心的共同问题

“生活中心”是一个人获得价值、安全、方向和行动依据的主要来源。作者列举配偶、家庭、金钱、工作、名利、享乐、朋友、敌人、宗教和自我等中心。

这些对象本身大多不是坏事。问题在于：当它们成为最终价值来源时，人的四种支撑就会依赖变化、失去平衡。

共同机制是：

```text
把某个对象当作最终价值来源
            ↓
自我评价取决于该对象的状态
            ↓
害怕失去，判断开始偏斜
            ↓
用其他角色和原则保护该中心
            ↓
生活整体失衡
```

## 十三、以配偶和家庭为中心

### 1. 以配偶为中心

婚姻是重要且亲密的关系，但若全部情感价值都来自配偶：

- 对方的情绪会决定自己的安全感；
- 分歧会被体验为自我价值威胁；
- 容易在依附、控制、退缩和指责间循环；
- 为证明自己正确而调用过去证据；
- 失去独立判断和有效互赖的基础。

健康的婚姻需要重视配偶，却不把配偶变成唯一内在支柱。两个以原则建立独立安全感的人，更有能力选择互赖。

### 2. 以家庭为中心

家庭能够提供归属和共同生活，但若家族传统、名誉和外在和谐成为终极中心：

- 父母可能用孩子表现证明家庭价值；
- 对失礼和失败反应过度；
- 对子女的尊重需求超过对子女成长的投入；
- 爱变成以符合家族期待为条件；
- 孩子可能更依赖，也可能通过叛逆争取自我。

原则中心并不降低家庭重要性，而是帮助家庭以孩子长期幸福、尊严和成长为标准。

## 十四、以金钱、工作和名利为中心

### 1. 以金钱为中心

经济安全是现实需要，但若工资、资产或收入成为自我价值来源：

- 市场变化会严重动摇安全感；
- 决策只按经济收益排序；
- 家庭、健康和诚信容易被工具化；
- 财富减少被体验为人格贬值。

作者用父亲拒绝临时加班、坚持与孩子出游的例子说明：“工作还会再来，童年只有一次。”这不是主张永远拒绝工作，而是说明金钱不能自动压倒不可重复的关系时刻。

### 2. 以工作为中心

工作可以承载使命和贡献，但工作身份若等同于全部自我：

- 无法工作时便失去意义；
- 健康、婚姻和友谊被持续牺牲；
- 人生方向完全由岗位需要决定；
- 智慧和能力只在职业领域发展。

工作应成为实践使命的角色之一，而不是吞没所有角色。

### 3. 以名利为中心

财产、声望、荣誉和社会地位受外部比较影响：

- 面对更优者自卑；
- 面对稍逊者傲慢；
- 为维护形象隐瞒错误；
- 自我评价随市场和舆论剧烈波动。

名利可以是贡献的副产品，却不适合作为稳定核心。

---

## 十五、以享乐、朋友和敌人为中心

### 1. 以享乐为中心

适度娱乐有恢复作用，但把刺激和舒适作为判断一切的标准，会导致：

- 对已有刺激迅速适应；
- 需要更强刺激才能满足；
- 学习、责任和关系投入被视为妨碍；
- 长期空虚与能力停滞。

享乐是生活组成，不是足以组织整个人生的终点。

### 2. 以朋友为中心

朋友关系十分重要，但若安全感完全取决于同伴接纳：

- 容易照单全收群体价值；
- 难以表达不同意见；
- 自我评价随朋友态度变化；
- 为避免排斥牺牲原则。

### 3. 以敌人为中心

一个人若持续围绕某个主管、前任伴侣、父母或竞争者组织情绪和行动，即使表现为反对，也是在让敌人决定生活方向。

典型表现是：

- 反复证明对方错误和自己无辜；
- 决策以报复或超越对方为目标；
- 家庭和工作都被怨恨侵占；
- 离开对方后，心理中心仍未改变。

反对一个人并不等于不受其控制。若每个选择都围绕对方，敌人仍是中心。

## 十六、以宗教和自我为中心

### 1. 以宗教组织为中心

作者区分宗教组织与宗教所倡导的原则。若人只关注出席、身份和外在虔诚：

- 安全感来自群体标签；
- 容易用派别给人分类；
- 礼拜日与工作日人格分裂；
- 宗教活动取代真正服务和品德。

宗教可以传递原则、提供共同体和实践，但组织本身不应代替原则成为最终中心。

### 2. 以自我为中心

以自我利益为唯一标准，看似强化个人，实际会削弱安全感和智慧：

- 只索取，不贡献；
- 关系被视为满足需要的工具；
- 无法建立深度互赖；
- 成长缺少超越自我的意义。

作者用死海比喻只有流入、没有流出的状态。自我成长只有连接服务和贡献，才可能形成更完整的力量。

### 3. 健康自我关怀与自我中心的区别

原则中心不要求忽视个人需要。健康自我关怀会维护身体、边界和尊严，以便长期生活与贡献；自我中心则把他人价值完全从属于自己的利益。

## 十七、如何识别自己的生活中心

### 1. 生活中心通常是混合且摇摆的

大多数人并非只有一个中心，可能在不同情境中切换：工作受挫时以名利为中心，关系冲突时以配偶为中心，休息时又以享乐为中心。

中心摇摆会导致：

- 情绪随外界起伏；
- 决策标准前后不一；
- 角色之间不断冲突；
- 自我评价缺少稳定基础；
- 有时强势、有时完全无力。

### 2. 通过压力情境识别中心

可以观察：

- 什么一旦受威胁，我就觉得自己毫无价值？
- 我首先用什么衡量一天是否成功？
- 冲突时，我最害怕失去什么？
- 我的空闲思绪最常围绕谁或什么？
- 我愿意为哪件事反复牺牲其他重要角色？
- 哪种外部评价最能控制我的情绪？

### 3. 通过四种支撑识别中心

| 维度 | 诊断问题 |
| --- | --- |
| 安全感 | 我的价值主要依赖谁或什么？ |
| 人生方向 | 我依据什么作重大决定？ |
| 智慧 | 我是否能看到整体关系和长期后果？ |
| 力量 | 哪些变化会让我完全失去行动能力？ |

### 4. 不要只看口头价值

真实中心更多体现在：

- 时间和金钱流向；
- 压力下的第一反应；
- 愿意牺牲什么；
- 对成功和失败的定义；
- 长期反复出现的选择。

宣称“家庭最重要”，却持续把所有优质时间给工作，说明实际中心可能不同。

## 十八、以原则为中心

### 1. 为什么原则适合作为中心

作者认为，原则不同于配偶、工作、财富或声望，它们不会因他人态度、市场或职位变化而消失。诚信、公平、责任、尊严、服务和成长等原则可以跨角色提供稳定判断。

### 2. 原则中心如何提供安全感

安全感不再完全取决于：

- 配偶是否满意；
- 工作是否顺利；
- 账户数字是否上升；
- 朋友是否接纳；
- 敌人是否失败。

它更多来自：自己是否依照经过检验的原则生活，以及能否承担和修正选择。

### 3. 原则中心如何提供方向

原则是罗盘，而不是固定路线。例如诚信原则不会自动告诉人某次加班是否正确，却会排除欺骗配偶或老板的做法，并要求如实沟通和承担承诺。

### 4. 原则中心如何产生智慧

以原则为中心，可以把其他生活要素放回适当位置：

- 配偶值得爱，但不能成为情感控制者；
- 家庭重要，但不能以家族名誉伤害成员；
- 金钱必要，但应服务于生活而非支配生活；
- 工作承载贡献，但不能吞没全部身份；
- 娱乐用于恢复，不应取代成长；
- 自我需要照顾，也需要服务他人。

### 5. 原则中心如何产生力量

当选择依据不再完全依附外界，人更能：

- 在压力下保持判断；
- 拒绝短期诱惑；
- 承担不受欢迎但正确的决定；
- 根据新事实调整方法；
- 接受原则所带来的自然后果。

### 6. 原则与对原则的理解

作者认为原则稳定，但人的理解有限且可以进步。这一点很重要：以原则为中心不等于宣称自己永远正确。

更成熟的态度是：

- 相信存在值得遵循的原则；
- 承认自己可能误解或片面应用；
- 用事实、后果、对话和经验持续校准；
- 不把个人偏好包装成永恒原则。

## 十九、音乐会与加班：同一选择为何意义不同

### 1. 冲突情境

一个人已经答应与配偶听音乐会，老板却临时要求为次日重要会议加班。同一事件会因生活中心不同而被不同解释：

| 生活中心 | 主要判断依据 |
| --- | --- |
| 配偶/家庭 | 对方是否失望、家庭关系是否受损 |
| 金钱 | 加班费、调薪和经济收益 |
| 工作 | 表现、经验和晋升机会 |
| 名利 | 牺牲形象或可换来的物质声望 |
| 享乐 | 自己是否需要放松和娱乐 |
| 朋友 | 同伴如何选择 |
| 敌人 | 是否能借此超过或打击对手 |
| 宗教组织 | 群体身份和活动规则如何评价 |
| 自我 | 哪个选项对自己更有利 |

### 2. 原则中心不预设唯一答案

以原则为中心的人可能选择加班，也可能选择赴约。不同事实会导致不同方案：

- 工作是否真正紧急；
- 是否曾对配偶反复失约；
- 是否能授权或调整；
- 双方需求和长期后果是什么；
- 原先承诺如何处理。

原则中心的优势不是给出统一答案，而是改善决策过程。

### 3. 原则中心选择的特征

1. **主动**：不是被内疚、恐惧或讨好推动；
2. **整体**：考虑工作、家庭、承诺和长期后果；
3. **合乎原则**：不靠欺骗、报复或纯粹自利；
4. **利用互赖**：与配偶和老板沟通，考虑授权或替代安排；
5. **内在一致**：选择后能专注执行并承担结果。

### 4. 行为相同，意义可能不同

两个人都留下加班，一个为了报复竞争者，一个为了履行真实责任。表面产出相同，背后的品德、关系影响和长期习惯却不同。

因此，效能评估不能只看动作，还要看动机、原则、过程与后果。

## 二十、使命是发现还是发明

弗兰克尔认为，人更像是在发现而非任意发明使命。作者据此强调：

- 每个人具有独特经历、能力和关系；
- 生命情境会提出具体责任；
- 使命不是挑选一句漂亮口号；
- 它需要倾听良知，识别自己能作出的独特贡献。

“发现”并不表示使命早已以完整文字隐藏在内心，而是说使命受到现实能力、关系责任和原则约束，不能完全凭任性创造。

重要的问题从“生命能给我什么”转为：

> 当前生命和责任正在要求我作出什么回答？

## 二十一、使命宣言的撰写与修订

### 1. 为什么过程和成品同样重要

撰写会迫使人：

- 区分自己的价值与社会脚本；
- 处理不同角色的冲突；
- 把模糊愿望变成清楚语言；
- 发现口头价值与现实行为的差距；
- 为后续目标提供筛选标准。

使命宣言的价值不仅在于最后那页文字，更在于形成文字时发生的自我审视。

### 2. 六步撰写流程

#### 第一步：自由畅想

围绕三个问题连续书写：

1. 谁曾对自己产生积极影响？欣赏其哪些品德？
2. 二十年后希望拥有什么、成为什么、完成什么？
3. 当前真正重要的是什么？

先生成素材，不急于修辞和定稿。

#### 第二步：暂时离开

通过短暂休息降低即时执着，让材料沉淀。

#### 第三步：整理主题

圈出反复出现的关键词、价值、关系、贡献和品德。

#### 第四步：写出初稿

把主题组织成可指导行为的声明，并在一周内随身携带、持续批注。

#### 第五步：形成当前版本

把它放在方便回顾的位置。所谓“定稿”只是当前成熟阶段的稳定版本。

#### 第六步：定期评估

每月检查：

- 它是否代表更好的自己？
- 是否带来方向、挑战和动力？
- 现实生活是否遵循其中价值？
- 是否需要因理解深化而修订？

### 3. 好使命宣言的特征

- 以原则为基础；
- 体现品德和贡献，而非只有占有物；
- 具有个人真实性，不是借来的口号；
- 能覆盖多个重要角色；
- 足够稳定，可长期指导；
- 足够具体，能排除某些选择；
- 可以随认识深化而修订。

### 4. 常见失败模式

- 句子宏大，却无法影响任何选择；
- 写成任务清单，缺乏上位原则；
- 只描述职业，忽略家庭、健康和社会责任；
- 为塑造理想形象而写，不承认真实冲突；
- 一次写完后永不回顾；
- 把使命宣言当作保证成功的咒语。

## 二十二、拓宽思路：从日常紧迫中抬头

作者建议通过想象特殊终点拓宽时间尺度：

- 写自己的悼词；
- 想象银婚或金婚时的关系；
- 想象退休后的贡献和生活；
- 假设生命只剩一个学期。

### 学生实验

当学生假设只剩一个学期时，有人开始向父母表达爱，有人与疏远的亲友和解。短暂生命视角使争执、羞辱和仇恨相对缩小，让爱与关系原则更加清楚。

### 方法的本质

拓宽思路不是预测灾难，而是主动完成通常只有危机才迫使人完成的优先级重估。

可以使用三个时间尺度检查同一决策：

| 时间尺度 | 问题 |
| --- | --- |
| 今天 | 它解决什么紧迫需要？ |
| 一年后 | 它形成什么能力、关系或后果？ |
| 生命终点 | 它是否符合希望成为的人？ |

## 二十三、心灵演练与确认

### 1. 心灵演练的目的

使命宣言需要进入具体情境。心灵演练是在事情发生前，生动想象符合原则的行为，使大脑对正确回应产生熟悉感。

### 2. 确认的五个要素

作者认为有效确认应包括：

1. **个人**：使用“我”，明确责任主体；
2. **积极**：描述要采取的正确行为，而非只写不要做什么；
3. **果断**：使用明确的现在式或行动表达；
4. **可视**：能在具体场景中想象出来；
5. **情感**：连接希望体验的感受和意义。

例如，不写“我不要对孩子发火”，而写成：“当孩子行为不当时，我先停顿，以关爱、坚定和自制清楚回应，并为自己的稳定感到踏实。”

### 3. 亲子情境的演练步骤

1. 放松身体；
2. 想象具体触发场景；
3. 注意旧反应将怎样出现；
4. 想象自己停顿并调用原则；
5. 清楚看见语言、姿态和行动；
6. 体验行为与使命一致的感受；
7. 在现实发生后复盘并修订演练。

### 4. 运动案例

作者帮助担任四分卫的儿子通过呼吸、肌肉放松和比赛情境想象，练习在压力下保持稳定。重点不是幻想胜利，而是预演可控制的判断和动作。

### 5. 演练内容为何必须正确

反复想象失败、恐惧或错误动作，也会提高它们的熟悉度。因此，心灵演练需要：

- 符合现实；
- 聚焦可执行行为；
- 以原则而非虚荣为目标；
- 包含挫折和调整，而非只有完美画面。

### 6. 不能把可视化当作因果魔法

心灵演练可以改善准备、注意、情绪调节和动作熟悉度，但想象本身不会自动改变外部现实。它必须与技能训练、反馈、资源和实际行动结合。

---

## 二十四、关于“左右脑”的批判性理解

作者用左脑负责逻辑语言、右脑负责创造直觉的二分法解释使命宣言写作。这种说法在当时流行，但现代神经科学认为，复杂任务通常由左右半球协同完成，不能把人简单分为“左脑型”或“右脑型”。

本章仍可保留的实践含义是：第一次创造需要综合使用不同认知方式：

- 分析事实和因果；
- 用语言澄清原则；
- 想象未来场景；
- 感受关系与意义；
- 从整体检查角色平衡；
- 再把整体愿景分解为目标。

因此，不必接受严格的左右脑人格分类，也可以使用作者建议的“分析 + 想象 + 情感 + 写作”方法。

## 二十五、确定角色：防止单一领域吞没人生

### 1. 为什么需要角色视角

一个人同时可能是伴侣、父母、子女、朋友、员工、管理者、学习者、邻居和公民。只按任务规划，最容易量化和最紧迫的角色会吞没其他角色。

角色视角帮助人看见：

- 哪些关系长期被忽略；
- 哪个角色占用过量资源；
- 同一原则如何在不同场景实践；
- 人生成功不能只由一个领域定义。

### 2. 角色不等于职位标签

角色应该表达重要责任或关系，而不只是身份名称。例如“父亲”角色的理想结果可能是帮助孩子形成责任、信心和温暖记忆，而不只是完成接送任务。

### 3. 将角色控制在可管理范围

原书建议主要角色尽量不超过七个，过多时可合并。例如把多个职业职能归为“专业贡献者”，把社区和志愿服务归为“公民”。

这不是限制人生丰富性，而是让角色能进入持续回顾和规划。

### 4. 角色检查表

| 角色 | 希望体现的品德 | 理想贡献 | 长期关系或成果 |

## 二十六、从角色到长期目标

### 1. 目标应服务于使命

角色明确后，为每个角色设定长期目标。目标应反映：

- 个人价值；
- 独特能力；
- 关系责任；
- 希望作出的贡献；
- 使命宣言中的原则。

### 2. 结果导向而非活动堆积

“每周陪孩子两小时”是活动；“建立孩子愿意坦诚沟通的稳定关系”是希望产生的结果。活动需要保留，但应知道它服务于什么结果。

### 3. 角色、目标与行动的层级

```text
使命：我为何而活、遵循什么原则
  ↓
角色：我在哪些关系和责任中实践使命
  ↓
长期目标：每个角色希望形成什么结果
  ↓
短期目标：当前阶段推进什么
  ↓
日程与行动：何时、何地、如何落实
```

习惯二负责前面三层，习惯三将继续讨论如何把它们安排进周计划和日常执行。

### 4. 平衡不是每个角色平均用时

不同阶段的角色投入会变化。平衡更接近：

- 没有长期、无意识地遗弃重要角色；
- 资源配置符合使命和现实；
- 临时倾斜具有明确原因和结束条件；
- 重大牺牲经过自觉选择，而非被紧迫事务吞没。

## 二十七、项目中的“以终为始”

习惯二也适用于近期项目。项目开始前应写下：

1. 希望获得的最终结果；
2. 服务对象及其真正需要；
3. 成功和完成的判断标准；
4. 不可牺牲的原则和边界；
5. 关键利益相关者；
6. 主要风险和假设；
7. 实现结果所需步骤与资源；
8. 项目完成后希望保留的能力和关系。

一个简洁模板如下：

```markdown
## 项目的第一次创造

- 项目名称：
- 为什么值得做：
- 最终希望产生的结果：
- 受益者及其需要：
- 完成标准：
- 必须遵守的原则：
- 不做什么：
- 关键步骤：
- 所需资源与协作：
- 主要风险和待验证假设：
- 对长期产能的影响：
```

这与第二章 P/PC 平衡相连：项目不仅要交付结果，也不能无意识地破坏团队、能力或信任。

## 二十八、家庭使命宣言

### 1. 家庭为何需要共同使命

没有共同原则时，家庭容易按即时情绪、个人偏好和压力反应运行。危机出现后，成员可能使用指责、讽刺、冷战或逃避。

家庭使命宣言可以明确：

- 我们希望家成为怎样的地方；
- 家人如何相互对待；
- 如何处理分歧；
- 重视哪些品德和能力；
- 怎样平衡个人需要与共同责任。

### 2. 共同制定比父母宣布更重要

家庭成员参与讨论、反馈、修订和采纳，能够：

- 让不同需要被看见；
- 形成共同语言；
- 增加对结果的认同；
- 练习尊重和合作；
- 使宣言从家长规则变成家庭约定。

### 3. 家庭宣言的使用

- 作为重大决策标准；
- 在冲突后用于复盘，而非作为惩罚武器；
- 定期按成长阶段修订；
- 将抽象原则转为家庭习惯；
- 由父母率先示范。

### 4. 可能包含的主题

- 互助合作；
- 表达爱和感谢；
- 尊重差异与边界；
- 承担家务和承诺；
- 培养每个人的专长；
- 保持整洁和秩序；
- 在冲突中不羞辱、不冷暴力；
- 为共同时间留出空间。

### 5. 风险

家庭使命宣言若由权力较强者单方面制定，可能只是控制工具。参与必须真实，包括允许成员表达不同意见，并根据年龄给予适当影响权。

## 二十九、组织使命宣言

### 1. 组织使命的作用

成功组织需要共同回答：

- 为什么存在；
- 为谁创造什么价值；
- 以哪些原则工作；
- 如何对待员工、顾客和合作伙伴；
- 面对利益冲突时什么不可妥协。

### 2. IBM 案例

作者观察到 IBM 强调个人尊严、卓越与服务，并愿意在员工突发疾病时付出高成本送其回家治疗。案例要说明，原则只有在需要付出真实代价时仍影响决策，才不只是口号。

### 3. 连锁旅馆案例

旅馆员工主动解决顾客问题，甚至主动报告一次顾客并未投诉的延迟。作者发现：

- 总公司有共同使命；
- 本地旅馆根据自身情境形成经营宣言；
- 各层员工参与制定；
- 使命进入招聘、培训、领导和服务行为；
- 员工无需每次等待主管指示。

### 4. 参与为何产生认同

作者提出“唯有参与，才有认同”。其因果过程是：

```text
成员参与表达现实与价值
          ↓
不同观点经过讨论和整合
          ↓
共同语言与目标形成
          ↓
成员看见自己的贡献和责任
          ↓
执行由外部监督转向内部承诺
```

### 5. 参与不等于每个人拥有否决权

真实组织仍有角色、权责和最终决策者。“参与”的重点是：

- 受影响者能提供信息和观点；
- 决策过程透明；
- 反馈被认真处理；
- 最终使命反映真实共同价值；
- 制度与奖励不违背宣言。

### 6. 判断组织使命是否真实

不要只看墙上的文字，应检查：

- 预算是否支持宣称的重点；
- 领导者在压力下如何选择；
- 奖励制度鼓励什么行为；
- 对错误和坏消息如何处理；
- 员工能否说出使命并用于决策；
- 违反原则的高绩效者是否仍被纵容。

## 三十、本章完整论证链

1. 人可能取得外部成功，却因追错目标而感到空虚。
2. 葬礼练习通过生命终点帮助人看见真正重视的品德、关系和贡献。
3. “以终为始”因此要求用最终使命校准当前选择，而不是只提高忙碌效率。
4. 一切事物通常经过智力创造和现实创造，方向必须先于执行。
5. 若不主动完成第一次创造，人生仍会被家庭、社会和旧习惯的脚本设计。
6. 习惯一让人成为创造者，习惯二让人负责人生的第一次创造。
7. 第一次创造属于领导，第二次创造属于管理；做正确的事先于正确地做事。
8. 自我意识、想象力和良知使人能够发现并改写低效剧本。
9. 个人使命宣言把希望的品德、贡献、成就与原则写成上位标准。
10. 使命宣言必须从影响圈核心形成，而核心决定安全感、方向、智慧和力量。
11. 配偶、家庭、金钱、工作等对象都很重要，但作为最终中心会因变化和依赖造成失衡。
12. 原则中心能让各种生活要素回到适当位置，并提供较稳定的判断标准。
13. 心灵演练把抽象使命带入具体高压情境，帮助新剧本获得熟悉度。
14. 角色与长期目标把整体使命分解到家庭、工作和社会责任中，防止单一角色吞没人生。
15. 家庭和组织使命必须通过共同参与形成认同，并进入现实制度与行为。
16. 所以，以终为始不是写一份愿望清单，而是主动决定人生依据什么终点和原则完成第一次创造，再持续用现实选择验证和修订它。

## 三十一、本章的方法论

### 方法一：终点反推法

1. 想象某个角色的长期终点；
2. 写下希望别人真实经历到的品德与贡献；
3. 对照当前行为；
4. 找出最大差距；
5. 设计一个可以在本周改变的行为。

### 方法二：两次创造检查

在开始项目或重大决定前问：

- 最终结果是什么？
- 谁定义了这个结果？
- 它依据什么原则？
- 成功标准是否只包含短期产出？
- 哪些假设尚未验证？
- 如果方向错误，执行越快会造成什么？

### 方法三：领导与管理双清单

| 领导问题 | 管理问题 |
| --- | --- |
| 这件事值得做吗？ | 怎样更有效完成？ |
| 它服务于哪个使命？ | 需要哪些步骤和资源？ |
| 是否符合原则？ | 怎样跟踪进度？ |
| 成功终点是什么？ | 如何按时交付？ |

先回答左侧，再优化右侧。

### 方法四：生活中心压力测试

选择一次近期强烈情绪事件，分析：

- 什么受到威胁？
- 我担心失去什么？
- 我的价值感是否依赖该对象？
- 哪项原则可以提供更稳定的判断？
- 若原则居中，我会如何重新看待其他要素？

### 方法五：角色平衡审计

列出不超过七个主要角色，为每个角色记录：

- 理想贡献；
- 当前状态；
- 最近一次有意义投入；
- 若继续忽略一年的后果；
- 下一项重要而非仅紧急的行动。

### 方法六：使命一致性复盘

每周选择一个重要决策，检查：

1. 它体现了使命中的哪项原则？
2. 是否由恐惧、比较或即时欲望驱动？
3. 对其他角色有什么代价？
4. 是否存在更符合整体使命的第三方案？
5. 需要修改行为，还是使命文字本身？

## 三十三、原书“付诸行动”的整理

### 1. 检查愿景

思考并记录：

- 当前生活是否带来真正快乐与成就感；
- 一直吸引自己的事情是什么；
- 少年时期的志向是否仍有意义；
- 什么最能带来内在满足；
- 自己最擅长什么，有哪些独特优势。

### 2. 整理葬礼练习

分别为家庭、朋友、工作和公共服务写下希望体现的性格、贡献和成就，再对照现实投入。

### 3. 单独安排第一次创造时间

为使命宣言预留不被日常事务打断的时间。若只等待“有空再想”，管理事务会长期挤压领导工作。

### 4. 收集使命素材

保存能够代表理想品德、原则和贡献的故事、句子、人物和个人经历，但最终文字必须转化为自己的理解。

### 5. 识别角色

把主要角色限制在可管理范围，并描述每个角色中最理想的表现。重点不是追求完美，而是明确方向。

### 6. 检查生活中心

用压力下的行为和时间资源，而非口头声明，判断当前中心是否稳定、是否满意。

### 7. 完成一个项目的第一次创造

写下近期项目的理想结果、步骤、原则和成功标准，再开始执行。

### 8. 发起家庭或团队使命讨论

分享本章思想，邀请成员共同讨论，而不是把预先写好的版本要求他人签字认同。

## 三十四、批判性理解与适用边界

### 1. 终点会变化，使命需要修订

人的知识、角色和环境会改变。以终为始不是一次决定终身，而是维持一个相对稳定、可持续校准的方向。

修订使命不一定代表缺乏原则，也可能代表对原则和现实理解加深。

### 2. 终点导向可能压迫过程

若只关注结果，人可能把关系、健康和伦理当作手段。真正的习惯二把品德和原则本身写入终点，因此不能为了理想结果使用违背原则的过程。

### 3. 人生不可能完全设计

疾病、偶然、他人选择和社会环境会改变计划。第一次创造提供方向，不保证现实按蓝图发生。

成熟做法是在原则稳定的前提下，根据新事实调整目标和路径。

### 4. 葬礼练习并非适合所有人

对正在经历丧亲、严重焦虑或创伤的人，这一练习可能造成额外负担。可以替换为：

- 想象八十岁生日；
- 想象退休回顾；
- 想象十年后的自己；
- 写给未来家人的一封信。

关键是拉长时间尺度，不必拘泥于死亡场景。

### 5. 原则中心需要谦逊

“我按原则行动”很容易成为拒绝反馈的理由。个人对原则的解释可能受文化、利益和偏见影响。

应持续检查：所谓原则是否尊重他人尊严、能否普遍适用、长期后果如何、是否只是个人偏好的正当化。

### 6. 左右脑二分不宜按字面接受

复杂的逻辑、语言、想象和情感活动由多个脑区协作。应保留综合使用分析、图像、情感和写作的方法，不必采纳简单的人格半球分类。

### 7. 使命感不能替代心理和现实支持

空虚、抑郁和创伤可能需要专业治疗、社会支持和环境改善。使命宣言能提供意义框架，但不是万能处方。

### 8. “唯有参与，才有认同”不是绝对规律

参与通常提高理解与认同，但成员也可能认同未亲自制定、却公平可信的使命；参与也可能流于形式。

更准确的说法是：真实参与、可见反馈和制度一致性显著提高认同的可能性。

### 9. 使命宣言必须接受现实验证

如果宣言多年不改变任何时间分配、决策或关系行为，它很可能只是理想化自我描述。应以可观察行为判断使命是否进入第二次创造。

## 三十五、易混淆概念辨析

### 以终为始不等于结果至上

终点包括品德、原则和关系，不能只看可量化成果。

### 使命不等于职业

职业是实践使命的角色之一，使命通常跨越家庭、工作和社会贡献。

### 愿景不等于预测

愿景说明希望创造的方向，预测说明认为将会发生什么。愿景可在预测不利时仍指导行动。

### 原则不等于固定规则

原则提供判断方向，具体做法应根据事实和情境变化。

### 自我领导不等于领导别人

本章首先讨论如何决定自己的人生方向，不以职位或下属为前提。

### 管理不等于低级工作

管理负责把正确方向转化为现实成果，是第二次创造的必要能力。

### 生活中心不等于最重视的对象

可以深爱家庭而不以家庭名誉作为自我价值的唯一来源。原则中心会让人更成熟地珍惜其他对象。

### 心灵演练不等于愿望成真

演练改善准备和行为熟悉度，必须与现实行动、技能和反馈结合。

### 参与不等于所有人一致

共同使命允许差异，重点是形成足以指导合作的共同原则与方向。

### 修订使命不等于反复无常

方法、角色和理解可以变化；应检查变化是来自原则深化，还是再次向外部压力妥协。

## 三十六、个人复盘问题

1. 如果从生命终点回看，我现在最忙的事情仍然重要吗？
2. 我希望亲人、朋友和同事分别怎样真实描述我？
3. 我正在攀爬哪架梯子？它靠在谁选择的墙上？
4. 当前最大的目标来自个人原则，还是社会脚本和比较？
5. 哪项行动看似成功，却在牺牲更重要的关系或品德？
6. 我在哪个领域只有第二次创造，没有认真完成第一次创造？
7. 我更擅长领导还是管理？另一侧的缺失造成了什么？
8. 哪条童年、家庭或组织剧本需要重新检查？
9. 我当前的安全感主要来自配偶、家庭、金钱、工作、名利、朋友、敌人、宗教身份还是自我？
10. 当这个中心受威胁时，我的方向、智慧和力量怎样变化？
11. 哪些原则能够让重要生活要素回到适当位置？
12. 我的使命宣言是否包含品德、贡献和不可妥协的原则？
13. 哪个主要角色长期没有得到有意义投入？
14. 近期项目的完成标准是谁定义的，是否包含长期产能？
15. 我是否用可视化替代了训练和行动？
16. 家庭或组织宣称的价值，在哪项制度或压力决策中被违背？
17. 本周哪一项选择可以成为新人生剧本的第二次创造？

## 三十七、本章结论

第四章把积极主动的选择能力引向人生方向。习惯一说明人能选择和创造，习惯二要求人主动承担第一次创造：决定希望成为怎样的人、作出什么贡献，以及用哪些原则衡量成功。

本章最重要的四组关系是：

1. **终点与当下**：生命终点提供长期评价标准，日常选择不断完成那个终点；
2. **第一次与第二次创造**：方向、设计和原则先于执行，执行则检验并实现设计；
3. **领导与管理**：做正确的事先于正确地做事，两者共同构成高效能；
4. **原则与其他中心**：配偶、家庭、工作和金钱都重要，但应围绕原则获得适当位置，而非成为变化无常的最终价值来源。

个人使命宣言是本章最主要的实践工具。它把品德、贡献、角色与原则写成一份可反复检查的个人宪法，再通过长期目标、项目设计和心灵演练进入现实生活。家庭和组织也可以借共同参与形成使命，但宣言是否真实，最终要由预算、制度、压力下的决定和日常行为证明。

“以终为始”的最终目的不是控制未来，而是在无法完全预测未来时仍拥有方向。它让人不必等到成功后才发现梯子搭错了墙，也不必让社会、家庭或旧习惯代写人生。真正的自我领导，是用原则确定罗盘，用愿景选择道路，再让每一个今天逐步成为希望的一生。
