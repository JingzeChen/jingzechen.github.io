## 15 张复习卡

### 1. 为什么从算法转向系统？

**时间：** `00:08:25`

**问：** 游凯超为什么逐渐从算法研究转向机器学习系统？

**答：** 他认为论文评审和小规模算法增量越来越难稳定反映真实价值，而系统性能、规模部署和用户采用更可验证，也更容易形成现实影响。

### 2. vLLM 与 PagedAttention 有什么区别？

**时间：** `00:46:37`

**问：** 为什么不能把 vLLM 等同于 PagedAttention？

**答：** PagedAttention 是管理 KV Cache 的核心技术起点；vLLM 是包含调度、批处理、模型适配、硬件支持和社区治理的完整推理引擎生态。

### 3. 从论文到基础设施最难的是什么？

**时间：** `00:53:30`

**问：** vLLM 从原型走向生产系统的主要难点是什么？

**答：** 不是只实现论文，而是在模型和硬件快速变化时持续重构后端、保持用户接口稳定，并长期处理部署与兼容问题。

### 4. 团队为何决定创业？

**时间：** `01:07:25`

**问：** “如果 vLLM 失败，我们会后悔一辈子”表达了什么决策逻辑？

**答：** 团队把项目长期存续放在个人短期收益之前，认为若没人建立稳定组织来支持项目，未来可能因错失机会而后悔。

### 5. vLLM 如何治理？

**时间：** `01:20:11`

**问：** vLLM 的社区治理为什么需要 BDFL 式拍板？

**答：** 大型项目每天面对大量需求和贡献，开放讨论之外仍需少数维护者决定优先级、拒绝局部需求并维护长期技术方向。

### 6. AI 生成代码给社区带来什么问题？

**时间：** `01:25:32`

**问：** AI Coding 如何改变开源贡献？

**答：** 它降低了提交 PR 的门槛，也增加了缺乏上下文的低质量贡献。维护成本可能从“写代码”转向“过滤噪音和判断方向”。

### 7. 为什么社区需要公司实体？

**时间：** `01:35:22`

**问：** 单靠松散社区为什么难以继续支撑 vLLM？

**答：** 社区难以稳定雇佣人员、签署 NDA、承接资金和长期获取集群算力，而这些都是生产级推理基础设施的刚需。

### 8. 基金会与公司的边界是什么？

**时间：** `01:47:41`

**问：** PyTorch Foundation 与 Inferact 分别承担什么角色？

**答：** 按节目中的描述，基金会保障持续开源和治理边界，公司提供资源、执行和商业交付；日常技术路线仍由维护者体系推动。

### 9. 什么是模型与 Infra 的 co-design？

**时间：** `01:53:10`

**问：** 发电系统类比如何解释 co-design？

**答：** 硬件像自然资源，模型像发电机，推理引擎像电力系统。只有共同设计，才能在具体硬件约束下获得高效率。

### 10. 什么是 Hardware Lottery？

**时间：** `01:56:36`

**问：** 为什么算法是否适配硬件会决定其命运？

**答：** 后摩尔时代硬件越来越专用，能映射到主流芯片高效计算形态的算法更容易扩展和普及，反之可能难以落地。

### 11. RoPE 的工程优势是什么？

**时间：** `01:57:39`

**问：** 为什么节目把 RoPE 视为 co-design 案例？

**答：** 它能较好兼容主流 Attention kernel 和 FlashAttention 生态，模型创新不需要以大幅增加核心算子实现难度为代价。

### 12. 投机解码为什么不只是算法问题？

**时间：** `02:02:45`

**问：** 投机解码的系统取舍是什么？

**答：** 一次猜测更多 Token 可能减少串行步骤，但错误猜测会浪费验证计算；收益依赖模型、置信度筛选和系统实现共同优化。

### 13. Token 为什么不能完全类比电力？

**时间：** `02:18:15`

**问：** Token 与电力的关键差异是什么？

**答：** 电力可以通过标准转换统一使用，而 Token 带有生成模型和系统的烙印，跨模型无法无损互换，适配成本更高。

### 14. Prefix Cache 为什么对 Agent 重要？

**时间：** `02:27:00`

**问：** 什么设计会破坏 Prefix Cache？

**答：** 多轮 Agent 依赖稳定前缀复用 KV 状态；若系统前缀包含不断变化的时间戳等内容，就会导致缓存频繁失效。

### 15. 嘉宾如何判断开源与闭源的长期格局？

**时间：** `02:43:09`

**问：** 为什么游凯超认为开源模型最终会占优？

**答：** 他的判断是：模型规模使用会产生数据与复制能力，单次领先难长期封锁，护城河会转向持续迭代和工程执行。该结论是预测，不是事实。
