## 15 张复习卡

### 1. 什么是 Strong Opinions, Weakly Held？

**问：** 强观点和弱持有怎样同时成立？

**答：** 明确表达当前判断及其前提；新证据改变前提时，主动更新观点，而不是维护面子。

### 2. 上期最大的误判是什么？

**时间：** `00:10:47`

**问：** 戴雨森认为自己低估了什么？

**答：** 低估了 Anthropic、Claude Code 和 Agentic Coding 在短期内带来的使用与收入变化。

### 3. Anthropic 与 OpenAI 的组织差异是什么？

**时间：** `00:13:32`

**问：** 节目怎样比较两家公司？

**答：** Anthropic 被描述为更自上而下、价值观对齐；OpenAI 更自下而上、鼓励发散探索。该描述多为二手信息。

### 4. 什么是 Harness？

**时间：** `00:37:23`

**问：** Harness 包含哪些能力？

**答：** 它在模型之外组织 Context、Memory、工具、权限、Agentic Loop、Sandbox 和持久 Runtime，使模型完成真实长任务。

### 5. Return 问题的三步链是什么？

**时间：** `00:24:07`

**问：** 为什么模型公司收入不等于 AI Return？

**答：** 买 Token 是投入，代码或报告是产出，最终必须转化为客户的新收入、降本或利润。

### 6. 为什么十倍 Coding 效率不等于十倍收入？

**时间：** `00:25:10`

**问：** 企业真正的瓶颈可能是什么？

**答：** 可能不是代码产能，而是产品洞察、需求发现、组织协作、销售和责任承担。

### 7. Harness 为什么可能像操作系统？

**时间：** `00:52:36`

**问：** 模型与 Harness 分别像什么？

**答：** Harness 调度 Runtime、Memory、Loop 和工具，像 OS；模型提供计算与智能，像处理器。

### 8. Harness 的数据飞轮是什么？

**时间：** `00:41:25`

**问：** 为什么 Coding 产品能产生高价值数据？

**答：** 每个真实任务都记录改动、失败、修复和环境信息，可用于评估与后训练，反过来提升模型和产品。

### 9. 什么叫“AGI 在缩水”？

**时间：** `00:57:44`

**问：** 这个说法批评什么？

**答：** AGI 的定义从奇点和重大科学突破，逐渐缩到替代常规程序员；戴雨森认为真正 OOD 创新仍未解决。

### 10. 为什么早期 AI 更适合做 Horizontal？

**时间：** `00:55:53`

**问：** 过早垂直有什么风险？

**答：** 能力和用例仍快速扩张，过早限定行业可能错过更大的通用场景；成熟期再垂直更合理。

### 11. Agent 产品应怎样替代 DAU 指标？

**时间：** `01:26:24`

**问：** 更合适的指标有哪些？

**答：** 自主运行时长、高价值任务完成数、成功率、节省的人类时间和每项任务收入。

### 12. 旧护城河为什么会变成软肋？

**时间：** `01:21:26`

**问：** 封闭超级 App 在 Agent 时代有什么问题？

**答：** 若用户 Agent 无法访问其中的数据和工作流，封闭性不仅锁住用户，也会阻止公司进入 Agent 生态。

### 13. 为什么下一个字节可能不像字节？

**时间：** `01:38:51`

**问：** 戴雨森反对复制什么？

**答：** 反对只复制信息流、DAU、买量和广告商业化；时代级公司应创造新的交互与生产方式。

### 14. AI 原生机会分哪两个阶段？

**时间：** `01:42:37`

**问：** 新技术如何产生原生商业模式？

**答：** 第一阶段用 AI 解决写作、编程等旧问题；第二阶段出现 Agent 协作、市场、协议、组织和新需求。

### 15. 为什么 Agency 仍然重要？

**时间：** `02:11:39`

**问：** 当执行和 Taste 都可能被 AI 提升后，人还保留什么？

**答：** 主动决定做什么、提出什么问题、改变什么现状，以及创造分布外新内容的能力。
