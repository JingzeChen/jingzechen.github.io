## 15 张复习卡

### 1. 本季最关键的技术转折是什么？

**时间：** `00:03:28`

**问：** 广密为什么重视 Opus 4.5 到 4.6？

**答：** 他认为模型从 Chat 跨入能持续完成高价值任务的 Agent 阶段，进步幅度近似一次跨代。

### 2. Coding 为什么是 AI 加速器？

**时间：** `00:08:50`

**问：** Coding 如何形成复利？

**答：** 它直接完成可验证任务，也加速模型研究和产品开发，真实失败与修复又形成训练反馈。

### 3. 为什么 Code 可以表达数字世界？

**时间：** `00:13:00`

**问：** “代码即方案”是什么意思？

**答：** 数字世界中的软件、数据和流程大多能被代码操作，Agent 因而可以通过代码实际改变环境。

### 4. Coding 的难点为什么不只是算法？

**时间：** `00:17:12`

**问：** 还需要哪些能力？

**答：** 战略聚焦、组织文化、数据清洗、Feedback Loop、产品工程和长期处理脏活累活。

### 5. Anthropic 的阶段优势来自哪里？

**时间：** `00:22:10`

**问：** 节目给出的组织解释是什么？

**答：** 聚焦 Coding、创始人技术参与、数据文化、价值观筛选和更一致的组织执行；多为二手观察。

### 6. Anthropic 的主要风险是什么？

**时间：** `00:30:00`

**问：** 为什么领先仍可能失去？

**答：** 算力规划、客户集中、单一路线依赖，以及 OpenAI/Google 的资源和追赶速度。

### 7. OpenAI 为什么被说成错过 Coding？

**时间：** `00:33:35`

**问：** ChatGPT 成功可能带来什么路径依赖？

**答：** 过度关注 To C、DAU 和多方向探索，低估 Coding 的数据、工程和高价值任务窗口。

### 8. 为什么 OpenAI 仍有高胜率？

**时间：** `00:40:30`

**问：** 它有哪些反转资源？

**答：** 人才密度、算力、品牌、用户入口和自下而上的创新文化。

### 9. Google 被怎样定位？

**时间：** `00:47:13`

**问：** 什么叫“最领先的追随者”？

**答：** 短期可能错判 Coding，但 TPU、现金流、研究和分发体系使其长期不易掉队。

### 10. Meta 与 xAI 的主要不确定性是什么？

**时间：** `00:54:16`

**问：** 为什么二者都是高方差挑战者？

**答：** Meta 要解决团队整合和产品聚焦，xAI 要解决核心人员流失、战略摇摆和数据效率。

**时间：** `01:02:00`

**问：** Harness 如何放大模型？

**答：** 为 Agent 配置环境、权限、工具、流程、评估和反馈，使模型能在组织中稳定交付任务。

**时间：** `01:05:42`

**问：** OS 类比强调什么？

**答：** 模型可能成为工作、生活和科研应用的基础平台，并调度工具、数据和 Agent 生态。

**时间：** `01:07:01`

**时间：** `01:12:42`

**问：** 节目给出的行为建议是什么？

**答：** 尽快把 AI 纳入真实工作流，提升问题选择、创造力、Taste 和任务管理能力。
