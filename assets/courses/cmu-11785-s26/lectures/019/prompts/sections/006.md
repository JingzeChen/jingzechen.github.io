--- [课件: lec18.attention.pdf p.15] ---
标题：A problem with this framework
正文：
A problem with this framework
•
All the information in the input is encoded in the final decoder hidden 
state
•
This is only input once to the decoder
– Subsequently, this information is only carried through by recurrence
•
The information in the final encoder hidden state will get “diluted” by the 
recurrence in the decoder
– At later decoder time steps the hidden state has a large contributions from the 
decoder itself, masking the contribution of the encoder hidden state
