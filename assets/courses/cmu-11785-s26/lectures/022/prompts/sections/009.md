标题：Story for the day
正文：
Story for the day
• Classification networks learn to predict the a posteriori 
probabilities of classes
– The network until the final layer is a feature extractor that 
converts the input data to be (almost) linearly separable
– The final layer is a classifier/predictor that operates on linearly 
separable data
• Neural networks can be used to perform linear or non-
linear PCA
– “Autoencoders”
– Can also be used to compose constructive dictionaries for data
• Which, in turn can be used to model data distributions
