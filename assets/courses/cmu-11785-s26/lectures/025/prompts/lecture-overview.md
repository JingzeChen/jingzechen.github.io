## 核心概念与依赖关系

- 生成器与判别器的关系：生成器负责从先验采样后产出样本，判别器为“当前生成器的产物”提供真假反馈；没有这个反馈，GAN 的核心思想就不存在。
- DILLAF loss 与判别器：本讲把“Does it look like a face?”当作口语化目标，判别器就是这个目标的可学习实现。
- 最优判别器与后验概率：在理想化分析下，判别器不是硬分类器，而是在每个 $x$ 上输出“来自真实分布的概率”，即 $D^*(x)=P_X(x)/(P_X(x)+P_G(x))$。
- 生成器与 JSD：当判别器每一步都最优时，把 $D^*$ 代回原 GAN 目标，可把生成器视为在最小化真实分布与生成分布之间的 Jensen-Shannon divergence。
- JSD 与训练问题：JSD 比 KL 更稳定，但在分布不重叠时仍可能给出常数型目标，导致无梯度。
- Wasserstein distance 与 critic：为了解决“相距很远时也要有方向”的问题，WGAN 改用连续的搬运成本视角和实值 critic，并用 Lipschitz 约束保证梯度可用。
- Mode collapse 与分布覆盖：即使样本能骗过判别器，生成器也可能只覆盖真实分布的一小部分模式，因此“看起来像”不等于“覆盖得全”。

## 关键推导、例子与结论边界

- VAE 对照目标：课件给出 $\theta^*=\arg\max_\theta \log P(X;\theta)$，也写成 $\arg\min_\theta -\log P(X;\theta)$；老师用它来说明“似然大”并不直接约束生成样本的视觉真实性。
- 原始 GAN 目标：$\min_G \max_D \mathbb{E}_X[\log D(X)] + \mathbb{E}_Z[\log(1-D(G(Z)))]$。判别器想让真实样本输出 1、生成样本输出 0；生成器想让 $D(G(Z))$ 变成 1。
- 二分类计数例子：某个 $x$ 上真实分布密度约 0.4、生成分布约 0.1，于是若各采 100 个样本，真实类约占 40 个、生成类约占 10 个，所以真实后验概率约为 0.8。这就是“最优判别器输出后验概率”的直觉来源。
- KL/JSD 两点质量反例：当真实质量在 0、生成质量在 $\theta$ 时，KL 在 $\theta\neq 0$ 时会因为 $\log(1/0)$ 爆炸；JSD 则在所有 $\theta\neq 0$ 处恒等于 $\log 2$。两者都不能给出“朝 0 靠近”的细粒度梯度。
- Wasserstein 结论边界：它在本讲中以“土堆填坑”“成本 = 质量 × 距离”的直觉出现，并通过 critic 提供平滑梯度；但显式最优传输求解很难，因此课堂只讲了对偶化思路和 Lipschitz 约束，不做完整理论证明。
- 架构结论边界：conditional GAN、StyleGAN、CycleGAN、StarGAN 等都被作为代表性思想介绍，课堂重点是“为什么要这样改”，而不是给出全部网络细节与实现配方。

## 易错点与待核对项

### 002 00:10:52-00:20:52

**本段在整讲中的作用：** 从“VAE 为什么不够直接”切到“GAN 新在哪里”。老师把“像不像脸”抽象成需要的新损失，再正式定义 GAN 的生成器、判别器和对抗训练框架。

**教学展开：** 老师先用“教小孩画脸”的类比说明：如果画出来像一团 blob，最高层反馈应该是“这不像脸”，而不是“似然值是多少”。Poll 2 进一步确认三点：VAE 不是隐式模型；似然最大化不能保证训练集外样本像脸；如果有一个可微损失能直接判断“像不像脸”，生成结果更可能朝对的方向改进。老师把这个目标口语化地叫作 DILLAF loss，并据此正式定义 GAN：一个生成器负责生成目标类别样本，一个判别器/对手负责判断这些样本是否像真的，再把两者放进同一个神经网络训练框架。随后他说明 GAN 2014 年提出，目标依旧是建模训练数据分布 $P(X)$，但训练依赖的是这对对手。接着分别讲两个部件：生成器从先验 $Z\sim P(Z)$ 出发生成样本；判别器接收任意输入，判断它是真实还是由生成器产生的。老师特别强调判别器不能预先单独训成泛化的“脸/非脸分类器”后再固定使用，而必须和当前生成器同步训练，因为它要区分的是“当前这版生成器正在产出的东西”和真实数据。最后他开始写判别器的目标：如果用 sigmoid 输出，理想状态是真实样本输出 1，生成样本输出 0，并分别最大化相应对数项。

**概念、符号与推导：** DILLAF loss 指“Does it look like a face?”。生成器输入为 $Z\sim P(Z)$，输出为 $G(Z)$。老师用 $P_G(X)$ 记生成器在样本空间中的分布，同时提醒真正随机的是输入的 $Z$。判别器输出 $D(X)$。训练判别器时，希望真实样本满足 $D(X)=1$，生成样本满足 $D(X)=0$；对应对数目标是最大化 $\log D(X)$ 与 $\log(1-D(X))$。

**例子与课堂提示：** “教小孩画脸”是本段核心类比。与 diffusion 的对比提醒学生：GAN 的关键创新不一定是生成器结构，而是把判别器当成了新的训练损失。

**本段掌握检查：** 似然最大化不足，因为它只约束训练数据，不直接约束新样本视觉真实性；DILLAF loss 是“这看起来像不像脸”；GAN 的两个网络分别负责生成与判别；判别器必须与当前生成器同步训练，而不是事先固定。

**待核对项：** “DILLAF” 是课堂助记法，非正式术语；字幕里 “deaf/daf loss” 都在指这件事。

### 003 00:20:49-00:30:48

**本段在整讲中的作用：** 把直觉性描述正式变成训练目标，并解释为什么判别器必须先训、要更频繁更新。后半段则开始从二分类后验概率角度分析最优判别器。

**教学展开：** 老师先把判别器目标说完整：对真实样本最大化 $\log D(X)$，对生成样本最大化 $\log(1-D(G(Z)))$。随后转到生成器：因为梯度能从判别器回传到生成器，而判别器对假样本想输出 0，所以生成器要迫使判别器在 $G(Z)$ 上输出 1，也就是最小化 $\log(1-D(G(Z)))$。这三者合起来就是原始 GAN 的 min-max 目标。老师提醒训练完后只需要生成器，判别器只是训练时的“像不像脸”损失。然后他解释训练顺序：先用当前生成器产物训练判别器，再用最新判别器训练生成器，然后反复循环。Poll 3 的两个答案都是判别器，因为“判别器就是损失”。课堂上还给了经验频率：通常生成器更新一次，对应判别器大约更新五次。接着老师回到最优行为分析：把真实分布和生成分布看成两类数据，在某个 $x$ 处若真实密度约 0.4、生成密度约 0.1，那么各采 100 个样本时，大约有 40 个真实样本和 10 个生成样本落在这里，因此观察到该 $x$ 时，样本来自真实分布的后验概率约是 80%。

**概念、符号与推导：** 本段完整写出 $\min_G \max_D \mathbb{E}_X[\log D(X)] + \mathbb{E}_Z[\log(1-D(G(Z)))]$。判别器希望 $D(X)=1$、$D(G(Z))=0$，生成器希望 $D(G(Z))=1$。二分类计数例子则把“后验概率”具体化为 $40/(40+10)=0.8$。

**例子与课堂提示：** “判别器就是损失”是训练顺序的总原则。40 对 10 的计数例子则把最优判别器的含义从抽象公式变成可心算的比例。

**本段掌握检查：** 生成器要最小化 $\log(1-D(G(Z)))$，因为它想骗过判别器；原始 GAN 目标是标准的 min-max 期望式；判别器要先训且更频繁更新，因为损失质量决定了生成器训练质量；在 40 对 10 的例子里，真实后验概率是 0.8。

**待核对项：** 字幕里有少量口误与误识，不影响“判别器是损失”和“五比一更新频率”的主结论。

### 004 00:30:46-00:40:44

**本段在整讲中的作用：** 这是理论分析核心：最优判别器输出后验概率，生成器与判别器交替移动边界与分布；在判别器每步都最优的理想化分析下，生成器实际上是在最小化 JSD。

**教学展开：** 老师先强调优秀分类器在每个 $x$ 上都应输出后验概率，而不是只做僵硬的“真/假”决定，因此决策边界位于两类后验概率相等的交叉点。把这放回 GAN 里，生成器的目标就是把当前生成分布往真实分布所在区域推；判别器则在每次生成器更新后重学新的边界。这个“判别器学边界、生成器推分布”的过程反复进行，直到两条分布完全重合。届时，判别器对任何输入都只能输出 0.5，也就是彻底分不清真伪。随后老师把最优判别器写成 $P_X(x)/(P_X(x)+P_G(x))$，并把它代回原损失。为了理解代回后的项，他回顾 KL 散度：若分母在某个点为 0，KL 可能在那一点直接发散到无穷，而且 KL 还不对称。于是他引入 Jensen-Shannon divergence：分别比较 $P$ 与平均分布、$Q$ 与平均分布。这样即使单边为 0，平均分布也不为 0；只有双边同时为 0 时，对应项因前面的 0 权重而消失。最终结论是：如果每一步都把判别器训到最优，那么生成器正在最小化真实分布与生成分布之间的 JSD。

**概念、符号与推导：** 最优判别器为 $D^*(x)=P_X(x)/(P_X(x)+P_G(x))$。JSD 写成 $0.5\,\mathrm{KL}(P,0.5(P+Q))+0.5\,\mathrm{KL}(Q,0.5(P+Q))$。KL 的风险在于分母可能为 0，JSD 则通过平均分布避免 blow up。理想化结论是：生成器最小化的等价目标是 JSD。

**例子与课堂提示：** “把分布推过边界”是理解交替训练的最好图像；“判别器 confused，输出 0.5”是两条分布重合时的直观标志；KL 的单点爆炸反例提醒学生，数值稳定性和可优化性并不自动成立。

**本段掌握检查：** 最优判别器输出的是后验概率；决策边界在两类后验相等处；最优判别器的闭式是 $P_X/(P_X+P_G)$；KL 会因分母为 0 爆炸；理想 GAN 生成器等价于在最小化 JSD。

**待核对项：** 先验均匀这一前提在课件后页才显式写出，但本段口头推导已经默认采用了该设定。

### 005 00:40:42-00:50:41

**本段在整讲中的作用：** 这一段解释“训练停下来”为何既可能是成功也可能是失败，并把讲解正式交给 TA 去系统分析 vanilla GAN 的两大问题。

**教学展开：** 老师先说：若 $P_G=P_X$，则判别器处处输出 0.5，导数为 0，梯度无法继续反传，所以训练会停止。但他马上指出，随机判别器若也处处输出 0.5，同样会让梯度消失，因此零梯度并不自动说明模型学对了。这类点被他称为 min-max stationary point，而 stationary point 本身可能不稳定：生成器可能 overshoot，判别器也可能过于陡峭、自信却错。于是他再次强调生成器与判别器必须同步训练，而且判别器必须总是针对当前生成器优化。随后他把训练步骤再总结一遍：先训练判别器，再训练生成器，循环往复。投票题则把可能的失败原因列出来并逐一确认：模式坍塌、JSD 导数差、判别器随机、判别器过于确定都可能发生。接下来 TA 接手，开宗明义说 vanilla GAN 有两大问题：vanishing gradients 和 mode collapse。她先讲 vanishing gradients：如果判别器太强，sigmoid 输出会接近 0 或 1，生成样本所在区域的曲线几乎平坦，生成器拿不到有效梯度；如果判别器太弱，输出又会几乎处处是 0.5，同样没有可靠反馈。最后她开始切到另一类原因：当两条分布相隔太远时，sigmoid 饱和本身也会带来梯度过小。

**概念、符号与推导：** 当 $P_G(X)=P_X(X)$ 时，$D(X)=0.5$，且向后传播梯度为 0。Min-max stationary point 的关键结论是：零梯度既可能来自理想匹配，也可能来自坏判别器。vanishing gradients 在这里先从判别器太强或太弱两端切入。

**例子与课堂提示：** “随机判别器也会输出 0.5”是本段最该记住的警告；投票题把四类失败原因并列，有助于防止学生把所有问题都归咎于同一个机制。

**本段掌握检查：** 判别器处处 0.5 可能表示成功也可能表示失败；同步训练是因为判别器必须跟着当前生成器提供反馈；TA 定义的两个大问题是 vanishing gradients 和 mode collapse；判别器太强或太弱都会让梯度失真。

**待核对项：** 讲台设备切换和插话可忽略；字幕里 vanilla/vanishing/mode collapse 均有误识。

### 006 00:50:38-01:00:37

**本段在整讲中的作用：** 这一段把“梯度为什么会没”追到散度本身。TA 用点质量例子证明 KL 与 JSD 在不重叠分布上都不提供好梯度，再引出 Wasserstein distance 的“搬运成本”视角。

**教学展开：** TA 先从图上说明：当真实分布和生成分布离得很远时，判别器会非常自信，sigmoid 输出贴近 0 或 1，生成器所在区域的梯度趋近于 0。随后她构造了一维 toy example：真实数据始终位于 0，生成数据始终位于 $\theta$，目标是把点质量从 $\theta$ 推回 0。对 KL 而言，只要 $\theta\neq 0$，就会出现真实概率为 1、生成概率为 0 的位置，于是有 $\log(1/0)$，KL 直接变成无穷；只有在 $\theta=0$ 时它才为 0，因此根本没有可用梯度。JSD 虽然不爆炸，但在这个例子里只要两边不重叠就恒等于 $\log 2$，同样无法反映“离 0 近了一点还是远了一点”。TA 接着说 least-squares GAN 虽然绕开了对数爆炸，但它仍然依赖判别器本身，所以一旦判别器行为不好，梯度还是可能没信息。于是她提出我们需要一种新的距离：不仅数值稳定，还要在分布相距很远时也反映它们究竟差多远。最后她用“土堆和坑”的比喻引入 Wasserstein distance，把生成分布看成土堆、真实分布看成要填满的坑，距离就是最小搬运工作量。

**概念、符号与推导：** 在点质量例子里，KL 对 $\theta\neq 0$ 发散，JSD 对 $\theta\neq 0$ 恒为 $\log 2$。least-squares GAN 比 KL 的数值行为好，但没有摆脱“依赖判别器”的问题。Wasserstein distance 的直觉定义是最小化“搬运质量 × 搬运距离”的总成本。

**例子与课堂提示：** 点质量例子最重要，因为它让学生直接看到目标函数形状。TA 特别提醒：JSD 的问题在这里不是发散，而是常数化。土堆填坑比喻则帮助记住 Wasserstein 的几何意义。

**本段掌握检查：** KL 在点质量例子里因 $\log(1/0)$ 失败；JSD 虽然有限，但在不重叠时恒为 $\log 2$，不给方向；least-squares GAN 仍依赖判别器；Wasserstein distance 衡量的是最小搬运成本。

**待核对项：** 字幕中的 “GS divergence”“le square g”“versust distance” 分别对应 JS divergence、least-squares GAN、Wasserstein distance。

### 007 01:00:34-01:10:34

**本段在整讲中的作用：** 这一段把 Wasserstein 的直觉变成可训练形式，并正式引入 WGAN；同时把另一大问题 mode collapse 的定义放上台面。

**教学展开：** TA 先把 Wasserstein 的“搬土”直觉画成运输矩阵：底部是生成分布，顶部是真实分布，中间矩阵的每个元素表示从一个生成位置向一个真实位置搬了多少概率质量。总成本就是所有搬运的质量乘距离之和，因此图上对角线附近值更大，意味着“就近搬运”更便宜。回到两点质量例子时，解决方案就是把 $\theta$ 处那团质量搬到 0，成本正好是 $|\theta|$，所以随着 $\theta$ 靠近 0，损失会平滑下降。这给了 KL/JSD 没有的连续梯度。但显式求最优搬运很难，于是 TA 引入 Kantorovich-Rubinstein duality：不再直接算传输计划，而是训练一个 critic，让它给真实样本更高分、给生成样本更低分。critic 输出实值而不是概率，因此当生成样本逐渐靠近真实分布时，它能持续给出平滑变化的分数。为了防止 critic 又变成过陡的分类器，必须对它加 1-Lipschitz 约束。原始 WGAN 用 weight clipping，后续更稳的办法是 gradient penalty，直接把梯度范数拉到接近 1。TA 的图示还对比了普通 GAN 判别器与 Wasserstein critic：前者在生成样本附近常常饱和变平，后者更接近线性，因此更容易提供非零梯度。最后她把第二大问题 mode collapse 说清楚：真实分布可能有 8 个模态，但生成器可能把很多不同噪声都映射到同一个模态，只学到分布的一小块。

**概念、符号与推导：** 两点质量例子下 Wasserstein 距离是 $|\theta|$，因此对 $\theta$ 给出平滑梯度。critic 与传统判别器不同，它输出实值分数。1-Lipschitz 是 critic 的必要约束；weight clipping 和 gradient penalty 都是在 enforce 这个约束。mode collapse 则是生成器对真实分布覆盖不足的问题。

**例子与课堂提示：** 对角线附近搬运成本低、V 形损失曲线、8 个高斯模态坍到一个点，这三个图像构成了本段最值得记忆的画面。

**本段掌握检查：** Wasserstein 为何更适合不重叠分布；critic 与 discriminator 的差异；为什么必须加 1-Lipschitz 约束；weight clipping 与 gradient penalty 的作用；mode collapse 为什么说明“骗过判别器”不等于“学到完整分布”。

**待核对项：** 字幕把“NP-hard/very hard”类表述误成了 “empty heart”；mode collapse 例子的最后一句在字幕里截断了。[需回听]

### 008 01:10:31-01:20:29

**本段在整讲中的作用：** 这一段收拢 vanilla GAN 的问题，并展开代表性 GAN 架构与应用，从“如何提高稳定性与可控性”一路讲到 paired、unpaired 和多域翻译。

**教学展开：** TA 先讲 mode collapse 的缓解办法：一种做法是让判别器比较一个 batch 内多个样本，若大量生成样本太像，就惩罚生成器；另一种是用依赖整体分布的 Wasserstein 思路，分布坍到一点时仍会有很大损失。之后她总结 vanilla GAN 两大问题就是 vanishing gradients 和 mode collapse。接着她把 GAN 发展粗分成五个阶段：先加控制，再做 image-to-image translation，再扩大模型与注意力，再进入 style-based 可控生成，最后是 transformer-based/hybrid。代表性架构先从 conditional GAN 开始：当我们不想随机出“某个人”，而想按指定条件生成时，就把条件 $Y$ 同时送给生成器和判别器，判别器既检查真假也检查是否匹配条件。数字生成的例子说明条件能决定类别而不消灭类内变化。然后是 progressive GAN：从很低分辨率开始，逐层增加分辨率和网络深度，先学全局结构、再学细节。接着是 StyleGAN：latent 不直接送进生成器，而是先过 mapping network，再在不同层作为 style 注入；每层先规范化特征，再按 style 向量产生的参数做缩放和平移，另加随机噪声控制局部细节。TA 用 source A 和 source B 的混合例子说明：换早层 style 会改姿态与脸型，换中层会改五官，换晚层只改颜色纹理。应用部分先讲 pix2pix，它假设有 paired data，用 L1 重建损失保持结构、用对抗损失提升真实感。随后讲 CycleGAN：在没有 paired data 时，学习 $X\to Y$ 和 $Y\to X$ 两个映射，再用 cycle consistency 确保回到原图。最后她把多域问题抛出来：如果每两个 domain 都单独练一个模型会很低效，因此引出 StarGAN。

**概念、符号与推导：** Conditional GAN 把条件变量送入生成器与判别器；StyleGAN 在各层注入 style，并通过规范化加缩放/平移控制不同尺度属性；pix2pix 使用 L1 + adversarial loss；CycleGAN 使用双向映射与 cycle consistency；StarGAN 用域标签把多域映射统一到单一模型中。

**例子与课堂提示：** “想要朋友的图像而不是别人”解释了 conditional GAN 的动机；StyleGAN 的 A/B 混合图清楚区分了不同层控制的语义范围；paired 与 unpaired 的对比则决定了该用 pix2pix 还是 CycleGAN。

**本段掌握检查：** 如何缓解 mode collapse；conditional GAN 为什么同时改生成器和判别器；progressive GAN 为什么从低分辨率开始；StyleGAN 各层控制什么；pix2pix 与 CycleGAN 的差别是什么。

**待核对项：** “recessing gan” 是字幕误识；“五个阶段”是 TA 的串讲框架而非课件逐条原文。
