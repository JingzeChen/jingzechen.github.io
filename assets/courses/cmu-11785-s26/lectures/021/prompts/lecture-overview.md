# Lecture 20 概览

## 学习目标
- 说明老师如何把现代大语言模型拆成预训练、评测与 scaling laws、后训练三段流程。
- 说明为什么“只靠更大模型和更多算力”不够，以及为什么数据设计与训练阶段切换同样关键。
- 说明监督微调、基于人类偏好的奖励、可验证奖励之间的差异，以及它们各自解决什么问题、遗留什么问题。
- 说明老师在结尾给出的总判断：简单方法在足够规模下很强，但仍伴随递减收益、工程复杂度与不可预测缺陷。

## 需要的先修知识
- Transformer 尤其是 decoder-only 自回归语言模型。
- next-token prediction、cross entropy、validation loss、perplexity。
- 监督学习、迁移学习、微调的基本概念。
- 强化学习的最基本视角：策略、采样、奖励、期望回报。

## 老师的教学主线
- 先对比旧范式与 foundation model 范式，说明我们到底希望模型具备哪些能力。
- 再回到最底层的问题：如果大模型主要靠 web text 的自监督训练获得能力，那么训练数据、评测方式和算力分配该如何设计。
- 随后进入 scaling laws：把“大预算下该怎么训练”变成一个可外推的经验问题，同时指出它只能解释一部分现象。
- 最后转向 post-training：先用 SFT 把模型变成可对话助手，再用 RLHF 或 RLVR 之类的信号去推动更贴近目标的行为。

## 核心概念与依赖关系
- foundation model 的目标能力链条是：语言理解、世界知识、对齐、能力、安全、上下文学习、推理、检索与工具使用。
- 预训练依赖“大而杂的数据 + 通用架构”，其逻辑是把归纳偏置更多地交给数据而不是手工结构。
- scaling laws 依赖可观测的 validation/test loss 与算力、参数量、数据量之间的幂律关系，用于预算内选择更优训练配置。
- 后训练依赖预训练已经学到的语言和世界先验；没有这个基础，小规模高质量数据很难支撑泛化。
- RLHF/RLVR 进一步依赖 SFT 已经把模型带到一个较好的初始化点，否则奖励学习既慢也不稳定。

## 关键推导、例子与结论边界
- 关键幂律形式来自课件：$L(X)=X^{-\alpha}$，以及 Chinchilla 风格的分解 $L(N,D)=E+\frac{A}{N^{\alpha}}+\frac{B}{D^{\beta}}$。
- 老师用 Eiffel Tower、代词指代、电影评价、数学题、爱因斯坦角色扮演、代码补全说明“语言建模”并不只是机械补词。
- 老师又用 GSM8K 的历史对比说明：纯粹按 pre-training scaling 外推，会对能力增长做出过于悲观的估计。
- 这些结论的边界也被明确点出：loss 的下降不自动等价于目标能力提升；SFT 与 RL 也都会因为奖励设计不充分而出现泛化偏差或 reward hacking。

## 易错点与待核对项
- 不要把“语言模型最终仍在做 next-token prediction”误读成“所以后训练没有改变行为目标”。老师的意思是训练接口仍然自回归，但数据分布和奖励已经显著改变了行为。
- 不要把 Kaplan 论文中的“参数更重要”当成最终结论；老师后面明确用 Chinchilla 视角修正为参数与数据大致同等扩展。
- 不要把 RLHF 与 RLVR 混为一谈。前者强调偏好或奖励模型，后者强调可高精度验证的打分函数。

## 掌握标准
- 能按老师顺序复述：目标能力 -> 数据与预训练 -> 评测与 scaling laws -> SFT -> RLHF/RLVR -> 结尾判断。
- 能解释为什么 loss/perplexity 既重要又不足，以及 benchmark contamination 与显式刷榜为何构成评测危机。
- 能解释为什么后训练不是抛弃预训练，而是利用预训练形成的强先验去支持小数据泛化。
- 能说明 RFT、RLHF、RLVR 分别在学什么信号，以及它们各自可能失败在哪里。

## 复习顺序
- 先看本讲整体目标与三段式结构。
- 再看预训练部分，尤其是“数据即偏置”和 web text 语言建模例子。
- 然后复习评测与 scaling laws 的公式、经验规律、Kaplan 与 Chinchilla 差异。
- 最后复习 post-training：模板化对话、SFT 小数据泛化、reward model、verifiable rewards、RFT 与 reward hacking。
