正文：
“Train on the Web”
• Must crawl pages, starting from seed links! 
• The average page is useless gibberish. How to handle this? 
• Idea #1: Over-sample certain sites! Wikipedia, arXiv, GitHub? 
• Idea #2: Filter based on known heuristics! Upvotes? PageRank? 
• Idea #3: Ask an LLM to “assess quality” and distill into a tiny model. 
• Pages that remain still need a ton of cleaning and deduplication… 
HTML, JavaScript, Boilerplate → clean text for next token prediction.
