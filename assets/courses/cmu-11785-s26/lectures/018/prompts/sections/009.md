Changing this output at time t does not affect the output at t+1
E.g.   If we have drawn “It was a”  vs “It was an”,  the probability
that the next word is “dark” remains the same (dark must ideally
not follow “an”)
This is because the output at time t does not influence the
computation at t+1
The RNN recursion only considers the hidden 
state h(t-1) from the previous time and not the

Pseudocode: Beam search
# Assuming encoder output H is available
path = <sos>
beam = {path}
pathscore = [path] = 1
state[path] = h[0]  # Output of encoder
do  # Step forward
nextbeam = {}
nextpathscore = []
nextstate = {}
for path in beam:
cfin = path[end]
hpath = state[path]
[y,h] = RNN_output_step(hpath,cfin)
for c in Symbolset
newpath = path + c
nextstate[newpath] = h
nextpathscore[newpath] = pathscore[path]*y[c]
nextbeam += newpath # Set addition

function prune (state, score, beam, beamwidth)
sortedscore = sort(score)
threshold = sortedscore[beamwidth]
prunedstate = {}
prunedscore = []
prunedbeam = {}
bestscore = -inf
bestpath = none
for path in beam:
if score[path] > threshold:
prunedbeam += path # set addition
prunedstate[path] = state[path]
prunedscore[path] = score[path]
if score[path] > bestscore
bestscore = score[path]
bestpath = path
end
end
end
return prunedbeam, prunedscore, prunedstate, bestpath

Story so far
•
Language models model the probability of word (or symbol 
sequences) in the language, typically through next-symbol prediction
•
The “simple” sequence-to-sequence model for tasks such as machine 
translation are performed using an encoder-decoder model
– The encoder extracts a feature-representations for the input symbol 
sequence
– The decoder is a conditional language model that uses this 
representation to conditionally generate the output symbol sequence
– Inference is performed to find the most probable output sequence given 
the input sequence
•
The same mechanism can be used for other conditional generation 
tasks, such as image captioning, video captioning, etc.
