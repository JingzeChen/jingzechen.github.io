# Lecture 13 总览

## 本讲定位
本讲是 RNN 系列第一讲，主题是“为什么序列任务需要递归模型，以及最基础的 RNN / 双向 RNN 应该怎样理解与训练”。讲解主线从序列建模动机出发，先否定有限窗口，再引出 state-space 递归、BPTT 和 bidirectional 结构。

## 整体教学展开
- 先用语音、文本、股价三个任务说明：输入顺序本身携带信息，序列任务不能只看无序特征集合。
- 再用股票时间延迟网络说明有限响应系统的局限，导出“必须看无限过去”。
- 然后回顾几种早期递归思路：输出反馈、Jordan 记忆、Elman context，并解释其信息压缩或梯度阻断问题。
- 接着正式定义 state-space RNN：隐藏状态递归、输出由隐藏态产生，初始状态可固定也可学习。
- 后半讲聚焦训练：把时间展开后的 RNN 看成共享参数深网络，用 BPTT 对整条序列反传并累加各时刻梯度。
- 最后讨论双向 RNN：当未来可见时，应该同时利用来自过去和未来的上下文证据。

## 核心概念、符号与推导
- 有限响应与无限响应：有限窗口模型只能看固定长度历史，RNN 通过递归隐藏状态把影响延续到未来任意时刻。
- 标准 state-space 关系：$h_t = f(x_t, h_{t-1})$，$y_t = g(h_t)$。
- 训练视角：一个样本是整段输入序列与整段目标输出序列；参数在时间上共享。
- BPTT 关键规则：激活处乘 Jacobian，分支处梯度求和，共享参数的时间梯度逐时刻累加。
- 双向层关键关系：当前位置表示由前向隐藏状态和后向隐藏状态拼接得到。

## 全讲例子与课堂提示
- 语音中的 `hello` 检测说明“序列输入、单输出”。
- Steelers 段落与机器翻译说明“词序与上下文”决定语义。
- 股票预测说明“趋势”而不是单点值才是决策依据。
- `light` / `box`、`light shoe` 例子说明未来上下文会改变当前词的判断，是双向 RNN 的直接动机。
- 看到教材里的回路箭头时，不要理解成单时刻无限循环，而要理解成跨时间递归。
