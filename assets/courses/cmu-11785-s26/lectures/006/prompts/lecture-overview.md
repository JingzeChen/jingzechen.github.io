# Lecture Overview

## 讲次定位
本讲把“训练神经网络”里的求导问题完整展开。前半段先把经验风险最小化、梯度下降、导数的图式理解和 distributed chain rule 重新搭好；中段用一个小网络把前向传播与标量版 backward pass 走通；后半段再切到矩阵/雅可比表达，得到可直接用于分层网络的 back propagation 模板。

## 核心主线
- 训练目标不是直接“会更新参数”，而是先能计算单样本 divergence 对任意参数的导数，再对样本平均得到 loss 的梯度。
- Influence diagram 是整讲统一语言：单链路靠连乘，分叉结构靠求和。
- 标量版 backward pass 的核心规律是：先从输出处拿到导数，再交替得到 $z$ 的导数、上一层 $y$ 的导数和当前层参数导数。
- 矩阵版 back propagation 只是把这些局部规则改写成 Jacobian 与权重矩阵的右乘，不改变主逻辑。

## 重点边界与待核对
- 这讲只解决“如何算导数并把它放进梯度下降”，不解决收敛、泛化、输出语义等更大问题。
- softmax 那段 transcript 中关于某条导数写成 $y(1-y)$ 的对象不够清楚，整理时已标记需回听。
