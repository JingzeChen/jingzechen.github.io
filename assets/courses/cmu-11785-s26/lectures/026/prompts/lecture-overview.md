## 核心概念与依赖关系
- 图的基本对象是节点和边；图学习首先依赖“关系结构”而不是固定空间位置。
- 因为图没有自然顺序，所以模型必须 permutation-invariant；这一点决定了聚合函数和表示方式的设计约束。
- 图节点嵌入不是单看节点本身，而是要结合节点特征、局部邻域、结构角色。
- GNN 是总范式，核心是 message passing：gather 邻居信息，aggregate 成摘要，update 自身表示。
- 原始 GNN 的问题是收敛慢、回传长、计算贵，于是 GCN 用共享权重和归一化邻接矩阵做高效卷积式更新。
- GCN 的问题是把邻居平均对待，于是 GAT 通过注意力学习邻居权重。
- GAT 仍然局部，只能显式看近邻；如果要抓远距离依赖，就会遇到层数增加和 over-smoothing 风险。
- Graph Transformer 用全局注意力突破局部传播限制，但又必须补上图结构编码，而且计算代价上升到 O(N^2)。
- 再往后则进入表达力、等变性、几何群和图生成等更深层研究主题。

- message passing 的核心公式关系在材料里可稳定确认的是“邻域集合、邻居聚合、自身更新、重复 L 层得到 L-hop 信息”；精确下标写法在字幕里不稳定，不能擅自补写。[需回听]
- GCN 的关键组成可确认是 normalized adjacency matrix、共享权重矩阵 W 与激活函数；结论是它更快、更可扩展。

### 002 00:13:20-00:23:17

#### 本段在整讲中的作用

#### 教学展开
- 老师先直接问“what is graph”，并让学生回答“nodes and edges”，随后把图概括为“描述实体及其关系的一般语言”。
- 紧接着老师用咖啡因分子举例：原子是节点，原子之间的化学键是边，这样一个复杂分子就能图化。
- 然后老师追问“为什么深度学习的人要关心图”，课堂里先出现 drug discovery，随后老师补充交通预测、社交网络推荐、流媒体内容推荐等现实应用。

- 接着老师总结图数据的三大挑战：不规则、无自然顺序、标准模型难以直接编码连接信息。
- 为解释“lack natural order”，老师画了简单链式图 A-B-C，强调即便交换 A 和 C 的视觉位置，只要连接关系不变，图就没变，因此模型必须 permutation-invariant。
- 最后老师进入 graph basics：图可以写成 vertices 和 edges 的有序对；随后通过邻接矩阵讲解边存在时记 1、不存在时记 0，以及对角线为什么通常是 0；如果显式给节点加 self relationship，则对角线位置可以变成 1。

#### 概念、符号与推导
- 图：由节点和边组成，用来表达实体与关系。
- 节点与边：在咖啡因分子例子里，节点对应原子，边对应化学键。
- Euclidean data 与 non-Euclidean data：老师用课堂问答说明图问题更多落在后者。
- permutation invariance：重新标号或重画节点位置，不应改变图的语义关系。
- 图的基本记号：老师口头说图是 vertices 和 edges 的 ordered pair；提示材料的课件页 21 写为 G = (V, E)。
- 邻接矩阵：课件页 22 给出定义，n 是顶点数，A(i, j) = 1 表示 i 到 j 有边，A(i, j) = 0 表示没有。
- 自环表示：如果节点与自身存在关系，则相应对角线元素可以置为 1。
- 本段没有展开额外公式推导，重点是定义和表示法。

#### 例子与课堂提示
- 咖啡因分子例子服务于“图能自然表达复杂实体内部关系”。
- drug discovery 例子服务于“图学习的现实任务不是抽象推理，而是性质预测与安全判断”。
- 交通路由例子服务于“边和节点上的结构会影响最优路径选择”。
- 社交网络和 Netflix 推荐例子服务于“图可以表达人、物品、兴趣之间的关系网络”。
- A-B-C 的重排例子是这一段最关键的课堂提示：视觉位置变化不代表图结构变化，所以不能给图强行套序列顺序。

### 003 00:23:17-00:33:15

- 因此老师给出结论：解决方案是 Graph Neural Networks。
- 在进入 GNN 前，老师通过投票确认：节点嵌入的目标确实是把节点映射到连续向量空间，同时保留结构和语义属性。

#### 概念、符号与推导
- edge list / edge matrix：用若干对 (u, v) 来表示哪些节点之间有边。
- embedding：把复杂高维对象压缩成稠密低维向量表示。
- 图节点嵌入的三项来源：节点自身特征、局部邻域、结构角色。
- 三类图学习任务：node classification、edge prediction、graph-level task。
- 两步法 Graph Embeddings + MLP：先生成固定 embedding，再在其上训练 MLP；老师明确指出这会切断对 embedding 过程的反向微调。
- 本段没有正式公式推导，但为下一段的消息传递公式做了概念铺垫。

#### 例子与课堂提示
- “为什么邻接矩阵左上角是 0”这个追问，服务于让大家不要把矩阵看成抽象符号，而是始终和“有没有边”对应起来。
- 词嵌入和图像嵌入的回顾，服务于说明“图嵌入不是从零开始的新世界，而是 embedding 思想在另一种数据结构上的延伸”。

### 006 00:53:04-01:03:03

#### 本段在整讲中的作用
- 这一段讨论 GCN 还不够好的地方，引出 GAT，并进一步说明深层图模型为何会遭遇 over-smoothing，最后把问题推到“需要全局注意力和 Transformer 思路”。
- 它是从“卷积版图模型”过渡到“注意力版图模型”和“全局建模需求”的关键承上启下段。

#### 教学展开
- 老师先问 GCN 还有什么问题，然后指出标准 GCN 用的是 predefined uniform aggregation，也就是把所有邻居一视同仁。
- 老师解释说，这样做的问题是：不管邻居的重要性、特征相关性和连接性质如何，统统平均，会丢掉有区分度的结构信息。
- 因此老师说“we need attention”，并引出 Graph Attention Networks。
- 对 GAT 的描述是：先对每个节点做共享线性变换，把节点投到新的特征空间；再用 attention 机制比较节点表示，而不是直接求平均；最后经过 softmax 把权重归一化，使不同邻居的重要性可解释。
- 接着老师讲训练和优化：除了 pooling、batching、regularization 等常规手段，GAT 有一个特别需要注意的约束，就是层数不宜过深，通常 2-4 层较合理。
- 原因是 over-smoothing：随着层数增加，节点 embedding 会趋于相似，模型表达力下降，节点变得难以区分。
- 老师引用不同规模数据集与不同模型的趋势图，说明不管是 GCN、GAT 还是 GraphSAGE，随着层数继续加深，都会出现类似的性能塌缩或表示趋同现象。
- 随后老师进一步指出 GAT 的局限：它虽然比平均聚合灵活，但本质上仍是局部 message passing，只能显式处理邻居子集，难以直接编码远距离节点之间的完整结构关系。
- 所以如果要捕捉 global patterns 或 long-range dependencies，只靠继续堆层数并不好，反而会把 over-smoothing 问题推得更严重。
- 最后老师回顾 Transformer：self-attention、Q/K/V 和 attention 后的前馈网络仍是关键机制，但把这套东西搬到图上时，必须改造为适配 irregular、non-sequential、non-grid 的图结构。

#### 概念、符号与推导
- uniform / isotropic aggregation：对所有邻居使用统一、无差别的聚合规则。
- GAT 的核心改动：先做共享线性变换，再学习邻居权重，而不是直接均值聚合。
- softmax：把注意力权重归一化，使其更容易解释为相对重要性。
- over-smoothing：层数增加后，节点表示收敛到相近数值，导致表达性下降、节点难以区分。
- 局部消息传递限制：即便用了注意力，GAT 关注的仍是局部邻域，而不是天然全局结构。
- Transformer 回顾：self-attention、Q/K/V、feed-forward block。
- 本段没有完整推导公式；虽然课件页 53 给了 attention 形式，transcript 里主要是口头解释其直觉和作用。

#### 例子与课堂提示

- “2-4 层最优”是很强的课堂经验提示，说明图模型深并不天然更好。
- 不同规模数据集上都出现 over-smoothing 趋势，这个观察服务于“问题不是某个小数据集偶然坏掉，而是机制上的风险”。

### 007 01:03:01-01:12:59

#### 本段在整讲中的作用
- 这一段把“为什么需要 Graph Transformer”讲清楚，并且在讲完后对 GNN、GCN、GAT、GT 做了一轮明确的模型比较，是全讲的选型总结段。

#### 教学展开
- 老师先强调：图不是序列，没有天然顺序，所以不能直接把序列里的 positional encoding 原封不动搬过来；图上需要 structural encoding。
- 接着老师给出图 Transformer 的核心动机：如果局部 message passing 无法让远处节点及时影响目标节点，就让每个节点都能 attend 到图中的其他节点，从而显式建模 global dependencies。
- 在图示例里，A 与 H、I 这些远距离甚至不直接相连的节点，本来在普通 GNN 局部传递下很难互相影响；而 graph transformer 用 full attention 让这类远距离信息也能进入表示。
- 不过老师同时提醒，这样做会把问题变成 heterogeneous graph/全局关系建模问题，因为有些节点之间本来没有边，却仍要决定如何利用它们的信息。
- 随后老师说图 Transformer 的处理流程仍然与 Transformer 架构相似，只是消息传播的承载对象从序列 token 变成图节点与结构编码。
- 讲完 graph transformer 之后，老师做了一次总回顾：
- GNN 是 message passing 范式本身，像所有图模型的父框架，但单独来看太慢、太贵。
- GCN 用平均邻域信息换来了计算高效，适合中等规模、较简单图。
- GAT 用可学习注意力给邻居分配不同权重，更适合高关系密度场景，但仍有局部聚合和 over-smoothing 风险。
- Graph Transformer 通过全局注意力获得长程依赖能力，解决前面模型难以直接抓住的远距离关系，但代价是计算复杂度上升到 O(N^2)。
- 最后老师回答了一个关于 edge information 的问题：如果边也有特征，基本框架并不变；消息传递可以同时用节点特征、边特征和整图特征。

#### 概念、符号与推导
- graph structural encoding：图上替代序列 positional encoding 的结构编码方法。
- full attention：每个节点可以对所有其他节点分配注意力，而不局限于一跳邻居。
- global / long-range dependencies：图中远距离节点之间的影响关系。
- 复杂度：老师明确指出 Graph Transformer 的 attention 代价是 O(N^2)。
- 模型比较链条：GNN（范式）→ GCN（快但平均）→ GAT（加权但局部）→ GT（全局但贵）。
- 边信息扩展：message passing 可以同时使用节点、边、图级别的特征；这不是另起炉灶，而是把现有框架扩展到更丰富的特征源。
- 本段没有公式推导，重点是结构差异与适用边界。

### 009 01:22:54-01:29:38

#### 本段在整讲中的作用
- 这一段是课后问答式收束，教授用更抽象、更统一的角度重新解释为什么图学习和图 Transformer 难而强，把前面所有内容压缩成“规则网格只是图的一种特例”。
- 它不是引入新模型，而是把全讲的设计原则重新说得更透。

#### 教学展开
- 教授先回应“图能否看成有序或无序”的问题，指出与图像不同，图像其实是一个完美规则网格上的图；而一般图可以任意重画，只要连接关系不变，图就不变。
- 他据此强调：普通图没有自然方向、没有自然顺序，因此不能像 CNN 那样给“上、下、左、右”分配固定不同权重；这就是 permutation invariance 必须成立的原因。
- 接着教授把 GNN 重新解释成分层展开的图：每一层都是同一张图的一个时间步/层步，节点在每一层从邻居取信息，更新自己的表示，不断重复直到表示饱和。
- 然后他指出 naive 的反复传播最终会让节点越来越像，这是过平滑的直观来源。
- 在这个框架下，GCN 被解释为：收集所有邻居、做平均、再与自身表示结合得到新表示。
- GAT 则是在这个平均步骤前加入“哪个邻居更重要”的比较与加权，得到 attended aggregation 或 weighted pooling。
- 但教授接着指出，若图上远距离路径很长，局部逐层传播仍需要很多层；层数又带来均化风险。
- Graph Transformer 的捷径是让每个节点一次就看所有节点，避免信息必须沿着路径逐跳走完。
- 可问题也随之出现：如果每个节点都看所有节点，原图结构本身就不再直接体现在注意力连接里，所以必须把结构信息转移到 positional encodings 里，而这些编码的构造本身就进入更深的图论和谱方法问题。
- 教授最后补充两个现实判断：第一，超大图上的 attention map 很难解释；第二，图模型之所以复杂，是因为数据结构复杂，但也正因如此，它们非常强，因为图像、时间序列、交通、股票乃至课堂同学关系，本质上都能被建模成图。
- 最终教授以“everything is a graph”收束，并说明这也是为什么把图模型放到课程最后讲，因为它们往往是最强但也最复杂的一类模型。

#### 概念、符号与推导
- permutation invariance：同一张图可被不同方式重画或重标号，但模型输出不应改变。
- 图像是图的特例：规则网格结构让方向性卷积核成立；一般图缺少这种稳定方向基准。
- 分层 GNN 视角：一层一层地把同一张图“展开”，每层做一次邻域信息聚合和表示更新。
- GCN：邻域平均加自身更新。
- GAT：先比较邻居重要性，再做加权聚合。
- Graph Transformer：所有节点全连接式注意力，再依赖结构/位置编码补回图结构信息。
- positional encodings 的来源：教授明确提到会涉及 spectral decomposition 等图论工具。
- 本段没有公式推导，但给出了四类模型背后最简洁的机制级统一解释。

#### 例子与课堂提示
- 教授把图像说成“排成完美网格的图”，这是一条非常强的统一视角，服务于把 CNN 和 GNN 放进同一框架里理解。
- 他现场“重画同一张图”的想法，是解释为什么图上没有固定方向权重的关键提示。
- 用“从这里到那里要走四步，所以需要四层”来解释长路径传播，是理解局部模型深度需求的最直观例子。
- 对 attention maps 难解释的提醒，服务于打破“有注意力就一定更可解释”的误解。
- “everything is a graph”并不是鼓励胡乱建模，而是强调只要关系结构被恰当建出，许多对象都可放进图学习视角里。
