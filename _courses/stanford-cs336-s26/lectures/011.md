## 老师的教学主线
老师先把本讲定位成经典 scaling laws 之后的“案例与细节”补课：前几讲已经讲了 Kaplan、Hestness、Chinchilla，这次要回答的是，在真实开源大模型实践里，人们怎样把这些想法变成可执行的 recipe。[00:00:05-00:02:16][课件: lecture_11.pdf p.2-p.4]

第一条主线是公开 scaling recipe 的比较。老师先用 MiniCPM 展示“稳定化路线”：通过 muP、per-parameter learning rate 和 WSD schedule，让最优学习率更稳、让 Chinchilla sweep 更便宜；再用 DeepSeek 展示“拟合路线”：承认 batch 与 learning rate 会随规模变，直接用小规模 grid search 和 IsoFLOPs 分析把规律拟合出来，并进一步外推到真实大模型。[00:03:36-00:22:30][课件: lecture_11.pdf p.6-p.24]

随后老师快速扫过 Qwen、Kimi K2、Hunyuan、LLaMA 3 与 MiniMax-01，说明到 2024 以后，这套 scaling 基本功已经被行业默认掌握，因此论文更多把 scaling 用在 MoE sparsity、architecture choice，或是 log loss 到 downstream accuracy 的映射上，而不再逐页复述 Chinchilla 基础。[00:22:35-00:29:59][课件: lecture_11.pdf p.25-p.30]

第二条主线是“如何在实践里控制规模漂移”。老师先借 StepFun 总结 learning rate / batch scaling 的经验规律，再强调这些公式仍有很强的条件性；接着转到 optimizer，说明公平比较必须同时看超参数失配、compute 轴与 Chinchilla ratio 轴，并用 muon 的起落故事展示“小尺度强势方法”在大尺度上未必直观成立。[00:30:27-00:59:56][课件: lecture_11.pdf p.31-p.44]

最后，老师回到 MiniCPM 背后的理论野心，也就是 muP：先设定宽网络极限下哪些量必须保持不变，再用量级分析推回初始化和层学习率应该如何缩放。讲末再用一组 stress test 说明 muP 的优势、边界和未解决问题，最终落回整讲结论：scaling laws 确实是实践工具，但它们远不是已经完全“科学化、自动化”的银弹。[00:59:56-01:16:58][课件: lecture_11.pdf p.45-p.58]

## 核心概念与依赖关系
- MiniCPM 与 DeepSeek 代表两种不同的实践哲学：前者尽量让超参数对规模不敏感，后者承认其敏感性并直接拟合其缩放规律。这一对比是整讲后半部分组织结构的骨架。[00:22:14-00:22:30][00:30:27-00:31:04]
- WSD 学习率连接了“训练过程设计”和“Chinchilla 实验成本”：它之所以重要，不只是因为末端效果接近 cosine，更因为它让数据维度上的重复实验只需重付末段 decay 的代价。[00:11:09-00:14:32][课件: lecture_11.pdf p.14-p.16]
- StepFun 的工作把 DeepSeek 风格方法推广为更系统的经验程序：先高分辨率 grid search 出最优点，再看 batch 与 learning rate 各自依赖哪些变量，并检验这些规律能否迁移到 MoE。[00:33:31-00:39:58][课件: lecture_11.pdf p.34-p.37]
- optimizer 比较的结论依赖三层条件：是否把每种 optimizer 的 learning rate / weight decay 调公平、是否沿 compute 轴检查、以及是否沿 Chinchilla ratio 轴检查。这些条件共同决定你看到的是“算法增益”还是“实验设计伪影”。[00:43:59-00:49:56][课件: lecture_11.pdf p.39-p.41]
- muon 与 muP 分别对应“新 optimizer”与“新参数化 / 缩放规则”。muon 把矩阵参数的更新当成谱对象处理；muP 则从宽度极限下的激活与更新不变量出发，反推出初始化和学习率的层级缩放规则。[00:50:57-00:54:45][00:59:56-01:12:35][课件: lecture_11.pdf p.42-p.50]
- muP 的理论层与经验层必须一起看：理论上它依赖 A1、A2 和若干量级假设；经验上它在受控宽度扩展中能稳定最优 learning rate，但遇到 learned RMSNorm gain、Lion 类 optimizer 或强 decoupled weight decay 时会失效。[01:00:40-01:12:35][01:13:19-01:15:47][课件: lecture_11.pdf p.46-p.57]
- 讲末 recap 把所有方法放回同一个工具箱：设架构、设 optimizer hparam、降低 sweep 成本，是实践里三类不同但相互耦合的 scaling 问题；muP、small-scale scaling fit、WSD 则是三类可以组合使用的工具。[01:15:52-01:16:58][课件: lecture_11.pdf p.58]

## 关键推导、例子与结论边界
- WSD 的关键不是一个公式，而是一种训练计划重构：把学习率分成 warmup、stable、decay 后，你能在 stable 末尾回滚并重做 decay，从而把 Chinchilla 数据 sweep 从“整段重训”缩成“末段重训”。这改变的是实验成本结构，而不只是调参习惯。[00:11:09-00:14:32][课件: lecture_11.pdf p.14-p.16]
- DeepSeek 的关键例子是“灰点拟合、星点验证”：先用较小计算规模的模型拟合 power law，再用真实大模型检验预测误差，从而证明这类 scaling analysis 对真实 open model 有外推价值。[00:21:25-00:22:03][课件: lecture_11.pdf p.24]
- StepFun 给出的 batch / learning rate 规律是经验性结论，而不是无条件真理。老师明确指出它们对训练数据、schedule 乃至具体 recipe 都有依赖，因此不能把数字直接抄成通用常数。[00:36:08-00:38:58]
- optimizer 部分的重要边界是：超参数调不好会把 Adam 人为调得很差；只沿 compute 看而忽略 Chinchilla ratio，也会把某些算法在特定 token-to-parameter 区间的偏好误判成“普遍更优”。[00:43:59-00:47:21][课件: lecture_11.pdf p.39-p.40]
- cautious AdamC 那个“前面像完美直线、后面突然 blow up”的例子，构成整讲最强的风险提醒：良好的 scaling 图像可以跨很多数量级都成立，却仍可能在更大尺度失效，因此老师始终反对把某条直线当成自动可靠的定律。[00:47:23-00:48:58][课件: lecture_11.pdf p.41]
- muon 的理论直觉是矩阵谱更新：把动量更新矩阵的奇异值全部压成 1，只保留方向；它与 Adam / AdaGrad 的关系，不是“另一个坐标缩放”，而是“从 coordinate-wise 变成 spectral-direction-wise”。[00:50:57-00:52:41][课件: lecture_11.pdf p.42]
- muP 的关键推导链是：先要求初始化激活与一步更新后的激活变化都保持 $\Theta(1)$，再把单坐标尺度换成整层 $\Theta(\sqrt{n_l})$ 范数尺度，接着通过高斯矩阵 operator norm、rank-1 更新结构与 loss update 的强假设，反推出初始化与学习率随 fan-in / fan-out 的缩放规则。[01:00:40-01:10:24][课件: lecture_11.pdf p.46-p.50]
- 老师反复承认 muP 的数学是“physicists math”：依赖近似、量级、无主阶抵消和 loss update 为 $O(1)$ 等假设。因此要理解它的用处，更重要的是 grasp 它的 construction principle，而不是误以为这是已经封闭的严格定理体系。[01:07:21-01:12:35]

## 易错点与待核对项
- 不要把这讲理解成“再讲一遍 Chinchilla”。老师真正做的是把 Chinchilla 放进近年开源实践里，讨论如何省算力、如何拟合 hparam、如何做 architecture / optimizer 决策。[00:00:20-00:01:15][00:28:09-00:29:59]
- 不要把 WSD 简化成“和 cosine 差不多的一条曲线”。老师最强调的是它允许在 stable checkpoint 处回滚并续训，从而改变 sweep 的成本结构。[00:12:04-00:12:38]
- 不要把任何一条 learning rate / batch scaling law 当成通用真理。老师明确说，连自变量该取 loss、compute 还是 data，都存在分歧；而数据分布变化本身也会让最优点漂移。[00:31:51-00:33:15][00:37:44-00:38:04]
- 不要把 optimizer 比较当成“同一组 hparam 跑谁曲线低谁就赢”。学习率和 weight decay 若未单独调好，结论可能完全反转。[00:43:59-00:44:50][课件: lecture_11.pdf p.39]
- 不要只看 compute 轴上的扩展性，而忽略 Chinchilla ratio。老师明确把 token-to-parameter ratio 视为一个经常被遗漏但足以改变算法相对优劣的 confounder。[00:46:00-00:47:21]
- 不要把 muon 在 NanoGPT speedrun 上的成功，直接当成其在大规模预训练中“更优”的证明。老师给出的最稳妥结论只是：它已经证明可行，但是否优于 AdamW 仍缺严肃大规模 ablation。[00:53:38-00:54:11]
- 不要把 muP 的推导当作完全严格的数学定理。老师自己明确说这是量级分析，并额外依赖若干并不完全令人满意的假设。[01:07:21-01:09:54]

## 概念、符号与推导
- IsoFLOPs 分析：固定总 FLOPs 预算，在模型大小与 token 数之间改变配比，观察最终 loss 或最佳配比如何变化。[00:10:05-00:10:19]
- cosine schedule 的限制：它必须事先知道训练的总 horizon，因此长度一改，整条 schedule 就不同，不能简单从旧 run 接着训。[00:10:24-00:10:56]
- WSD（warmup-stable-decay）学习率：
  - warmup：固定步数，不依赖总训练长度；
  - stable：长时间恒定学习率；
  - decay：末尾快速下降到接近 0，通常约占总训练的 10%-20%。[00:11:20-00:12:04][课件: lecture_11.pdf p.14-p.15]
- WSD 让数据维度 sweep 便宜的因果链：stable 之前的大部分训练可复用，只需从 stable 末尾重新展开并做新的末端 decay，因此重复成本接近总训练的最后一小段，而不是整段重训。[00:12:06-00:12:38]
- Chinchilla method 1 / method 3：本段只说 MiniCPM 采用 lower envelope 与 joint fit 两种方法，并未重新逐式推导；重点是它们在 WSD 支持下可以更便宜地采样。[00:14:32-00:15:08][课件: lecture_11.pdf p.16-p.18]
- 本段无新的正式公式推导，重点是训练计划与实验成本结构。

## 概念、符号与推导
- critical batch（Kaplan/OpenAI）：把最优 batch size 表达成最终 loss 的函数，而不是 compute 或数据量的函数。[00:32:13-00:32:30][课件: lecture_11.pdf p.33]

- 本段的经验结论：
  - 最优 batch size 主要由数据量 $D$ 驱动；
  - 最优 learning rate 随模型增大而减小，随数据量增大而增大；

## 概念、符号与推导
- 标准 momentum 更新框架：先把梯度累积进 $B_t$ 之类的动量变量，再用该变量更新参数；muon 没改“先积累动量”这件事，改的是“把 $B_t$ 变成什么样再施加出去”。[00:49:56-00:50:24]
- muon 的矩阵更新思想：
  - 对矩阵参数的更新矩阵 $B_t$ 做奇异值分解 $B_t = USV^\top$；
  - 把奇异值矩阵 $S$ 归一成全 1；
  - 最终更新近似为 $UV^\top$。[00:51:15-00:51:54][课件: lecture_11.pdf p.42]
- 与 Adam / AdaGrad 的对比：Adam / AdaGrad 是 coordinate-wise 的尺度调整；muon 则是 spectral-direction-wise 的尺度调整。[00:51:55-00:52:19]

- NewtonSchultz：对“把奇异值压成 1”的操作做矩阵乘法近似，因此比直接做 SVD 更系统友好。[00:52:41-00:52:49][00:55:04-00:55:14]

## 概念、符号与推导
- A1：初始化激活应保持 $\Theta(1)$；若单个激活为 $\Theta(1)$，整层范数应为 $\Theta(\sqrt{n_l})$。[01:00:56-01:02:29][课件: lecture_11.pdf p.46]
- A2：一次梯度更新后，激活变化仍应是 $\Theta(1)$；这正是老师口中的 feature learning，而与 NTK 中“变化趋零”的极限相对。[01:01:24-01:02:03][课件: lecture_11.pdf p.46]
- A1 的简化推导框架：
  - 设 $h_l = W_l h_{l-1}$；
  - 初始化 $W_l \sim \mathcal{N}(0, \sigma^2 I)$；
  - 用高斯矩阵 operator norm 的量级估计 $\|W_l\|_*$；
  - 近似令 $\|h_l\|_2 \approx \|W_l\|_* \|h_{l-1}\|_2$；
  - 通过归纳选取 $\sigma$，使输出层范数维持在 $\Theta(\sqrt{n_l})$。[01:02:52-01:05:15][课件: lecture_11.pdf p.47]
- A2 的简化推导框架：
  - 对单样本 SGD，线性层有 $\Delta W_l = -\eta_l \nabla_{h_l}\ell\, h_{l-1}^\top$，是 rank-1 外积；
  - 激活变化可展开成旧权重乘前层变化、权重变化乘旧激活、权重变化乘前层变化等项；
  - 希望这些主项都达到 $\Theta(\sqrt{n_l})$ 的层范数量级，从而倒推出 $\|\Delta W_l\|$ 的目标比例。[01:05:19-01:08:29][课件: lecture_11.pdf p.48]
- 额外强假设：loss update 为 $O(1)$。老师本人也说这是较不令人满意的假设，但它使后续学习率量级的代数关系能闭合起来。[01:08:51-01:09:54][课件: lecture_11.pdf p.49]

- 01:11:21-01:11:49，老师对这一长段推导做高层总结：muP 的有趣之处不仅是给出了一套可用技巧，还在于其方法论很不同。它先考虑网络放宽度极限时哪些量该保持不变，再根据这些 invariance 约束反推超参数必须怎样缩放。[01:11:49-01:12:20]

## 概念、符号与推导
- 从上一段到本段收尾的关键式：在老师的量级假设下，层学习率应按 fan-out / fan-in 比例缩放；对 Adam，则近似改成按 fan-in 的倒数缩放。[01:09:54-01:10:24][课件: lecture_11.pdf p.49-p.50]
- muP 的 recipe 解释：
  - 初始化不再只看标准 fan-in，而要在标准初始化上叠加 fan-out / fan-in 的修正；
  - 学习率不再全层共享常数，而要做 layer-specific scaling；
  - 对 Adam，较大 fan-in 的层需要更小的学习率。[01:10:37-01:11:21][课件: lecture_11.pdf p.50]
- muP 的方法论抽象：先定义网络在宽度极限下应保持的 invariance，再用附加假设把这些 invariance 变成对初始化与学习率的约束。[01:11:49-01:12:35]
- 实证边界：
  - 在受控宽度扩展中，muP 能较好维持最优 learning rate 的不变性；
  - learned RMSNorm gain、sign-based / exotic optimizer、强 decoupled weight decay 是主要破坏项；
  - 其他若干理论外部件，如某些激活或初始化变化，并不一定立刻使它失效。[01:13:19-01:15:11][课件: lecture_11.pdf p.52-p.56]
