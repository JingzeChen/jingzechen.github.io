## 学习目标
- 通过横向比较现代大语言模型，分清哪些架构与超参数选择已形成强共识，哪些仍在快速变化。[课件: lecture_03.pdf p.2][课件: lecture_03.pdf p.7]
- 理解现代 Transformer 相比原版最关键的默认变化：non-residual norm、RMSNorm、GLU、RoPE、推理友好的 attention 头压缩。[课件: lecture_03.pdf p.3][课件: lecture_03.pdf p.4][课件: lecture_03.pdf p.29][课件: lecture_03.pdf p.55][课件: lecture_03.pdf p.63]
- 建立一套务实判断框架：先用行业默认值起步，再把精力集中在真正仍有不确定性的长上下文与稳定性问题上。[课件: lecture_03.pdf p.8][课件: lecture_03.pdf p.51][课件: lecture_03.pdf p.67]

## 需要的先修知识
- 需要知道原版 Transformer 的基本部件：残差流、LayerNorm、FFN、multi-head attention、位置编码。[课件: lecture_03.pdf p.3]
- 需要知道 attention 是基于内积的，并理解自回归生成与训练/prefill 在计算模式上的差异。[00:31:28-00:31:39][01:17:00-01:18:22]
- 需要能跟上常见模型训练术语：warmup、gradient spikes、KV cache、dropout、weight decay、arithmetic intensity。[00:09:54-00:10:18][00:15:00-00:16:14][01:00:35-01:03:19][01:17:23-01:18:22]

## 老师的教学主线
- 先从“看很多模型报告”而不是“背一个标准答案”出发，把本讲定位成经验综述。[00:00:38-00:01:29][课件: lecture_03.pdf p.2]
- 再沿着原版 Transformer 到现代默认的演化线，依次讨论 norm、激活、位置编码，说明主干其实改得不多，但几处改动高度稳定。[00:01:55-00:39:03][课件: lecture_03.pdf p.10][课件: lecture_03.pdf p.29][课件: lecture_03.pdf p.35]
- 接着切到超参数，强调很多量都有安全默认范围，真正重要的是理解这些默认值背后的系统与经验依据。[00:43:40-01:04:04][课件: lecture_03.pdf p.37][课件: lecture_03.pdf p.51]
- 最后把重点转到稳定训练和推理成本：softmax 是危险区，QK norm / z-loss / soft-capping 是稳态技巧；GQA 与混合 attention 是面向部署和长上下文的当代主线。[01:05:02-01:29:08][课件: lecture_03.pdf p.54][课件: lecture_03.pdf p.55][课件: lecture_03.pdf p.63][课件: lecture_03.pdf p.65]

## 核心概念与依赖关系
- `norm 放置 -> 稳定性 -> 深层训练能力`：把 LayerNorm 移出残差主干，可以保住残差流和梯度传播，再进一步自然过渡到 QK norm 等更细稳定技巧。[课件: lecture_03.pdf p.10][课件: lecture_03.pdf p.12][课件: lecture_03.pdf p.55]
- `RMSNorm / 去 bias -> 更少数据搬运 -> 更高 wall-clock 效率`：老师把这条线直接绑到 arithmetic intensity，而不是只谈 FLOPs。[课件: lecture_03.pdf p.15][课件: lecture_03.pdf p.16][课件: lecture_03.pdf p.18]
- `GLU -> 额外矩阵 -> d_ff 需做 2/3 修正`：架构选择会反向约束超参数默认值。[课件: lecture_03.pdf p.23][课件: lecture_03.pdf p.38]
- `RoPE -> 相对位置目标 -> Q/K 旋转实现`：位置编码不只是“加一个位置向量”，而是决定注意力如何保留相对位移信息。[课件: lecture_03.pdf p.31][课件: lecture_03.pdf p.35]
- `训练/prefill 与生成推理差异 -> KV cache -> GQA/MQA`：只有先看到推理期的内存访问瓶颈，才会明白为什么要减少 K/V 头数。[课件: lecture_03.pdf p.58][课件: lecture_03.pdf p.60][课件: lecture_03.pdf p.61][课件: lecture_03.pdf p.62]
- `长上下文成本 -> full/local 交替 attention`：这是本讲结尾指出的最新活跃创新区。[课件: lecture_03.pdf p.64][课件: lecture_03.pdf p.65][课件: lecture_03.pdf p.66]

## 关键推导、例子与结论边界
- 关键经验式包括：`d_ff = 4 d_model`，GLU 常改成约 `8/3 d_model`，而 `num_heads * head_dim ≈ d_model` 与 `d_model / n_layers ≈ 100` 是另外两条常用默认。[课件: lecture_03.pdf p.37][课件: lecture_03.pdf p.38][课件: lecture_03.pdf p.42][课件: lecture_03.pdf p.44]
- RoPE 的关键目标式是 `<f(x,i), f(y,j)> = g(x,y,i-j)`；老师用 “we know that” / “of course we know” 的旋转例子解释它如何保住相对关系。[课件: lecture_03.pdf p.31][课件: lecture_03.pdf p.32]
- 输出 softmax 的 `z-loss`、attention softmax 的 QK norm 与 soft-capping，展示了稳定性技巧主要围绕 softmax 数值行为展开。[课件: lecture_03.pdf p.54][课件: lecture_03.pdf p.55][课件: lecture_03.pdf p.56]
- 结论边界上，老师反复强调：很多默认值只是“安全且够好”，不是数学定理。T5 的 `64x d_ff`、Gemma 4 的 p-RoPE、Google 系若干例外，都说明创新仍会出现。[课件: lecture_03.pdf p.39][课件: lecture_03.pdf p.41][课件: lecture_03.pdf p.43][00:37:16-00:37:32]

## 易错点与待核对项
- 不要把“现代模型普遍用 prenorm”误解成“只能 prenorm”；老师明确展示了 non-residual post-norm 和 double norm 变体。[课件: lecture_03.pdf p.13]
- 不要把 RMSNorm 的理由简化成“FLOPs 更少”，本讲更强调的是 runtime 与数据搬运。[课件: lecture_03.pdf p.15][课件: lecture_03.pdf p.16]
- 不要把 GLU 理解成绝对必要条件；老师明确说 GPT-3 等非 GLU 模型也能工作，只是主流经验更偏向门控。[课件: lecture_03.pdf p.26]
- 不要把 regularization 在 LM 里简单等同为“防过拟合”；weight decay 在这里常更像优化干预。[00:59:55-01:03:19]
- 需要回听确认的地方主要是字幕中的作者名、个别人名、Gemma 4 口头术语，以及少数 [INAUDIBLE] 问答细节。[需回听]

## 概念、符号与推导
- 原版 Transformer 的三个被点名默认项：位置编码用正弦余弦；FFN 用 ReLU；norm 形式用 post-norm LayerNorm。[课件: lecture_03.pdf p.3]

## 概念、符号与推导
- `Residual stream clean`：让残差主干里的 `x` 尽量少受额外归一化干扰，以便前向信号和反向梯度都能直通传播。[00:10:54-00:12:07]
- pre-norm / non-residual norm：LayerNorm 放在 attention 或 FFN 计算之前，但不放进残差加法主干。[00:12:46-00:13:00][课件: lecture_03.pdf p.10][课件: lecture_03.pdf p.13]

## 概念、符号与推导
- ReLU FFN：`FF(x) = max(0, xW1) W2`。[课件: lecture_03.pdf p.21]
- GeLU FFN：`FF(x) = GELU(xW1) W2`，其中 `GELU(x) = xΦ(x)`。[课件: lecture_03.pdf p.21]
- ReGLU：把 `max(0, xW1)` 再与逐元素线性项 `xV` 相乘，得到 `FF_ReGLU(x) = (max(0, xW1) ⊗ xV) W2`。[课件: lecture_03.pdf p.22]
- GeGLU / SwiGLU：沿用同一门控结构，只是把第一项激活换成 GeLU 或 Swish，其中 Swish 约为 `x * sigmoid(x)`。[课件: lecture_03.pdf p.23]
- 参数匹配推导：普通 FFN 主要有两组矩阵，门控 FFN 变成三组矩阵；为近似保持参数量不变，常把门控模型的 `d_ff` 缩为原先的 `2/3`。[00:24:16-00:24:58][课件: lecture_03.pdf p.23]
- Parallel block 不是新公式推导，而是拓扑改写：把“attention 后接 MLP”的串行结构改成“attention 输出与 MLP 输出并行计算后一起加回残差流”。[00:28:17-00:28:40][课件: lecture_03.pdf p.28]

## 教学展开

3. `[00:32:25-00:34:16]` 然后老师引出 RoPE，并给出一个非常“带立场”的目标：如果只关心相对位置，那么词 `x` 在位置 `i`、词 `y` 在位置 `j` 的交互，应该只通过 `i-j` 影响内积结果，而不应泄露绝对位置。[课件: lecture_03.pdf p.31]

5. `[00:34:24-00:35:52]` RoPE 的核心想法是利用“内积对共同旋转不变”。先取与位置无关的词语义向量，再按词所在的绝对位置对向量做旋转；这样若两个词之间的相对位移相同，它们的相对夹角就相同，内积行为也相同。[课件: lecture_03.pdf p.32]
6. `[00:35:03-00:35:52]` 老师用两个短语举例：“we know that” 中 `we` 在位置 0、`know` 在位置 1；而 “of course we know” 中它们分别在位置 2 和 3。虽然绝对位置整体平移了，但相对角度仍差 1，因此二者交互可以保持一致。[课件: lecture_03.pdf p.32]
7. `[00:36:00-00:37:36]` 高维实现上，不去做复杂任意旋转，而是把向量坐标两两配对，每对做二维旋转。不同坐标对使用不同频率，慢频率负责更长程依赖，快频率负责近邻关系。这就是老师认为最直观的 RoPE 理解方式。[课件: lecture_03.pdf p.33]
8. `[00:37:16-00:37:32]` 老师顺带提到 Gemma 4 的 p-RoPE：只旋转前两个坐标，也是一个可行但更极端的选择。[00:37:16-00:37:32][课件: lecture_03.pdf p.33]
9. `[00:37:36-00:38:54]` 真正实现时，要对 query 和 key 乘上按位置生成的正弦余弦旋转，而不是像原始正弦位置编码那样把它们加到 embedding 里。正因为是乘法旋转而非加法叠加，才没有绝对位置交叉项；而且它应在每次 attention 计算层面施加，以持续维持位置不变性目标。[课件: lecture_03.pdf p.34][课件: lecture_03.pdf p.35]

- 位置编码四类：正弦位置编码、绝对位置向量、相对位置偏置、RoPE。[00:31:40-00:32:34][课件: lecture_03.pdf p.30]
- RoPE 的目标形式：`<f(x,i), f(y,j)> = g(x,y,i-j)`，也就是交互只依赖相对位置差，而不依赖绝对位置本身。[00:33:31-00:33:47][课件: lecture_03.pdf p.31]

- RoPE 的构造原则：先保留与位置无关的语义向量，再按绝对位置做旋转；由于内积对共同旋转结构友好，相同相对位移会保留相同相对关系。[00:34:24-00:35:52][课件: lecture_03.pdf p.32]

- 实现层面的关键差别：RoPE 对 query/key 做乘法式旋转，不是把位置向量加到 token embedding 上，因此避免了绝对位置交叉项。[00:37:36-00:38:54][课件: lecture_03.pdf p.34][课件: lecture_03.pdf p.35]

3. `[01:01:23-01:03:19]` 接下来老师给出反直觉解释：weight decay 有时并不主要作为 regularizer，而是和优化器、学习率衰减相互作用，从而改善优化过程。单遍语言建模里训练损失和验证损失常几乎重合，说明它不是靠抑制过拟合获益；真正提升常出现在配合 learning rate decay 时，较强 weight decay 会前期慢、后期收敛到更好的点。
4. `[01:03:27-01:04:04]` 老师据此总结超参数部分：很多看似吓人的参数都有标准默认值，包括课件明确写出的 `d_ff = 4 d_model`；唯独“正则化”需要多试几种，因为它常不是按你以为的方式起作用。[课件: lecture_03.pdf p.37]
5. `[01:04:07-01:04:59]` 简短问答里，老师表示自己对 diffusion 架构没有足够整理，不愿在这里给确定结论；对“为什么正则化主要影响优化”则回答说，像 weight decay 这种缩向零的机制，会与学习率及其衰减策略共同改变可用优化路径。
6. `[01:05:02-01:06:07]` 之后整讲进入稳定性主题。老师说，这几年的大模型训练比起再抠一点点性能，更担心训练中途爆炸：一旦梯度 norm 出现大 spike，可能造成质量恶化，甚至让几百万美元训练无法继续。
7. `[01:06:14-01:07:07]` 他先列出首要嫌疑对象：softmax。原因有两个，一是含指数，二是有除法，两者都可能数值失控。语言模型里至少有两个 softmax 危险区：输出分布 softmax 和 attention 内部 softmax。
8. `[01:07:07-01:09:24]` 对输出 softmax，老师把 log probability 写成“模型输出项 `u` 减去 log normalizer `log z`”。若 `u` 本身还算正常，但 `z` 过大或过小，损失就可能炸掉。因为 softmax 对整体平移不敏感，所以可以在不改变输出分布的前提下，额外惩罚 `log z` 远离 0。
9. `[01:08:39-01:09:52]` 这就是 `z-loss`：在损失中加入一个平方的 `log z` 正则项，把 normalizer 约束在数值更稳定的范围。老师说它最早由 Jacob Devlin 相关工作提出，后来被 Baichuan、DCLM、OLMo 等开放模型重新采用，用于稳定输出 softmax。

## 概念、符号与推导
- 单遍预训练直觉：只做 single-pass SGD 时，模型通常难以“记住”数据，因此过拟合不是主要矛盾。
- weight decay 的本段定义不是“传统正则化器”而是“可能改善优化动态的干预项”，尤其在和学习率衰减共同使用时更明显。
- 输出 softmax 的老师口头分解：`log p = u - log z`，其中 `u` 是模型输出打分，`z` 是 softmax normalizer。
- 数值稳定目标：希望 `z` 接近 1，等价地希望 `log z` 接近 0；这样损失中的 normalizer 项更稳定。
- `z-loss` 推导思路：softmax 对整体平移不敏感，因此可在损失中加一个与 `log z` 偏离 0 有关的平方惩罚项，而不改变“输出分布只看相对 logit”的基本结构。[需回听]

## 本段在整讲中的作用

## 教学展开
1. `[01:09:52-01:11:28]` 老师把 attention softmax 的稳定性方案概括成一句经验话：如果不稳定，能塞 LayerNorm 的地方就塞进去。QK norm 的设计哲学正是如此。做法是在 `Q` 和 `K` 进入点积和 softmax 之前再做一次 norm，让它们尺度大致统一，从而防止 attention logits 失控。[课件: lecture_03.pdf p.55]
2. `[01:11:00-01:11:57]` 他补充这项技术最早来自多模态世界，后来被语言模型大量吸收。经验上，QK norm 通常不明显伤性能，却能减少 attention degeneracy，因此已经很接近“现代标准干预”。[课件: lecture_03.pdf p.55]
3. `[01:12:03-01:13:53]` 另一种更强的稳定性技巧是 logit soft-capping。它不是只控制 softmax 输入的尺度，而是直接把 logits 用 `tanh` 一类有界函数截住，使其不可能太大或太小。Gemma 2/3/4 都用了这类技巧。[课件: lecture_03.pdf p.56]
4. `[01:13:09-01:13:53]` 老师也明确讲了代价：soft-capping 太强，会削弱模型表达非常确信信号的能力，所以单独使用时可能带来质量下降；相比之下，QK norm 的副作用更小。[01:13:09-01:13:53][需回听]
5. `[01:14:09-01:15:16]` 稳定性部分结束后，老师进入 attention 改造的最后一块：真正广泛落地的不是 exotic SSM，而是 GQA/MQA 以及 sliding window 这类更务实的 dense-attention 变体。[课件: lecture_03.pdf p.57]
6. `[01:15:16-01:16:56]` 老师先让大家切换视角到部署。训练或 prefill 时，attention 的总算术量大约是 `b n d^2`，内存访问约有 `b n d + b h n^2 + d^2` 这样的项，因此只要 head dim 足够大、batch 或 sequence 足够长，算术强度就还不错，GPU 能被喂饱。[课件: lecture_03.pdf p.58]
7. `[01:17:00-01:18:02]` 但到了自回归生成阶段，情况完全不同：token 必须一步一步生成，不能像训练那样并行整段计算，所以必须保留过去的 KV cache，重复利用已算好的子矩阵，只增量计算新 token 的部分。[课件: lecture_03.pdf p.59]
8. `[01:18:02-01:19:29]` 这样虽然省掉了很多重复算术，但内存访问模式变差了。老师说算术量本身并没消失，只是拆成了增量步骤；与此同时，要一遍遍读参数和缓存，导致 arithmetic intensity 变得不理想，尤其会冒出难压的 `n/d` 项，于是“小模型长序列推理”非常难高效。[课件: lecture_03.pdf p.60]
9. `[01:19:29-01:19:49]` 这一困境直接引向下一段的 MQA：既然生成期最痛的是 KV cache 和内存访问，就想办法减少 key/value 头数，让缓存变小。

## 概念、符号与推导
- QK norm：在 query 和 key 做点积前先做 LayerNorm/RMSNorm，使进入 softmax 的 logits 源头尺度更统一。[01:10:05-01:10:59][课件: lecture_03.pdf p.55]
- logit soft-capping：对进入 softmax 的 logits 做有界压缩，例如 `tanh` 软截断，以硬性限制数值范围。[01:12:22-01:12:51][课件: lecture_03.pdf p.56]
- 训练/prefill 阶段的量级分析：总算术量约 `b n d^2`，总内存访问约 `b n d + b h n^2 + d^2`，因此算术强度相对可接受。[01:15:54-01:16:56][课件: lecture_03.pdf p.58]
- 自回归生成阶段：保留 KV cache 以避免重算整个注意力矩阵，但增量读取缓存会让 memory access 变重。[01:17:23-01:18:22][课件: lecture_03.pdf p.59]
- 生成阶段的关键不利项：内存访问中出现与 `n` 和 `d` 更难协调的比例，老师口头总结成“需要大 batch + 短序列，或者更大的 `d` 才好服务”。[01:18:37-01:19:25][课件: lecture_03.pdf p.60]

## 例子与课堂提示

## 概念、符号与推导
- MQA：保留多组 query，但让所有头共享单组或极少数组 key/value，以显著缩小 KV cache。[01:19:32-01:20:57][课件: lecture_03.pdf p.61]
- GQA：保留较多 query heads，只减少 key/value heads，因此存在一个“query heads : KV heads”的可调比例，用来平衡推理效率和表达能力。[01:21:07-01:21:36][课件: lecture_03.pdf p.62]
- GQA 的经验结论：在相近质量下，它比 full multi-head 推理更便宜；在相近成本下，它比极端 MQA 更能保持性能。[01:21:57-01:23:07][课件: lecture_03.pdf p.63]
- Sliding window attention：限制大多数层只看固定局部窗口，以降低长上下文的 attention 成本。[01:25:08-01:26:18][课件: lecture_03.pdf p.64]
- 交替式长上下文结构：例如“每四层一层 full attention，其余层用 local/sliding attention”，通过层间传播让局部层间接获得全局信息。[01:26:01-01:27:13][课件: lecture_03.pdf p.65]
- 新主题总结：现代长上下文模型常采用混合结构，不再坚持“所有层都做统一的全局 attention”。[01:27:49-01:28:32][课件: lecture_03.pdf p.66]

## 本段掌握检查
1. 问：MQA 与标准 multi-head 相比，最核心的变化是什么？答：query 仍有多组，但 key/value 在各头间共享，从而大幅缩小 KV cache。[01:19:46-01:20:57][课件: lecture_03.pdf p.61]
2. 问：为什么 GQA 比 MQA 更受欢迎？答：因为它不把 K/V 压到只剩一组，而是保留一个可调的 KV 头数，因此在推理成本和表达能力之间取得更优折中。[01:20:57-01:23:07][课件: lecture_03.pdf p.62][课件: lecture_03.pdf p.63]
3. 问：老师对“规则很多时还搜不搜超参数”的回答是什么？答：仍然会搜，但通常带着明确 thesis 一次改一项，而不是把所有设置全部打散重搜。[01:23:18-01:23:53]
4. 问：滑窗注意力为什么在最近一年重新流行？答：因为它把 full attention 和 cheaper local attention 交替起来，在长上下文质量与推理成本之间打到了甜点区。[01:25:37-01:26:18][课件: lecture_03.pdf p.64][课件: lecture_03.pdf p.65]
5. 问：整讲最后老师希望学生带走的总判断是什么？答：大模型在架构与超参数上已有很多共识，仍持续活跃变化的重点主要是位置/上下文处理和少数局部设计。[01:28:38-01:29:08][课件: lecture_03.pdf p.67]
