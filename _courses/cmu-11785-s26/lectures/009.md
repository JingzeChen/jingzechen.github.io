- title: Lecture 08: Training Part VI Optimizers and Regularizers Choosing a Divergence (Loss) Function Batch Normalization Dropout
- mode: consolidated-section-notes

## 学习目标
- 理解散度函数的形状如何影响梯度下降的收敛速度与稳定性。
- 能区分回归中的 L2 与分类中的 KL，并说明 softmax 分类里为何更偏向 KL。
- 理解 batch normalization 的问题背景、前向定义、反向传播耦合与训练/推理差异。
- 掌握 regularization、weight decay 与 dropout 的基本动机、实现直觉和适用边界。
- 认识 early stopping、gradient clipping、data augmentation 等常见训练启发式的作用场景。

## 需要的先修知识
- 损失函数、梯度下降、mini-batch、反向传播。
- sigmoid、softmax、回归与分类输出解释。
- 均值、方差、标准化与 Bernoulli 随机变量。

## 老师的教学主线
- 从训练网络的统一损失最小化框架出发，先解决“选什么 divergence”。
- 再说明 mini-batch 训练的分布假设为什么会被深层非线性破坏，并引出 batch normalization。
- 然后分析数据欠定导致的过拟合，说明显式正则化与深度带来的隐式正则化。
- 最后用 bagging 解释 dropout，并把一系列实用训练 heuristics 串成完整流程。

## 核心概念与依赖关系
- 散度函数是总损失的核心构件，它的形状直接影响优化轨迹。
- L2 与 KL 的选择先依赖任务类型，再依赖最终层非线性之后的真实优化几何。
- batch norm 用批统计量对齐 mini-batch，但因此引入了批内样本耦合。
- 正则化通过限制权重大小来抑制感知机过陡，从而抑制过拟合。
- weight decay 是 L2 正则在梯度更新式中的实现形态。
- dropout 通过随机失活近似对大量子网络做集成，强化鲁棒性。

## 关键推导、例子与结论边界
- 好散度应当远离最优点时斜率够大、接近最优点时又不至于太陡。
- softmax 分类里，KL 虽然在输出概率层面未必“最好看”，但对 $z$ 与最终层权重更友好。
- batch norm 的前向过程是“标准化 + 可学习重定位”，反向传播关键在于所有 $z_i$ 通过批均值和批方差互相影响。
- 若一个 mini-batch 内样本过于相似，batch norm 可能把传回前面的梯度压成 0。
- 更深的网络不仅能表达复杂函数，还可能因层层平滑而带来隐式正则化。
- dropout 推理阶段无法枚举所有子网络，只能用期望近似；这是有效但并非精确的替代。

## 易错点与待核对项
- 不要只凭输出层面的曲线直觉选择分类损失。
- 不要忘记 batch norm 在推理时不能再用“当前单样本”的均值和方差。
- 不要忽略 batch norm 的失败边界：批内样本若极度同质，梯度会退化。
- 不要把 weight decay 当成与 L2 正则无关的魔法技巧。
- 不要默认 dropout 与 batch norm 一定能稳定叠加。
- 关键回听点集中在 BN 求导口述、正则化系数记号、以及最后一段多处 ASR 失真句。

## 掌握标准
- 能解释为什么分类常用 KL 而不是直接套 L2。
- 能写出并解释 batch norm 的前向两步以及训练/推理的统计量差异。
- 能口头说明 batch norm 反向传播为什么要把所有 $u_j$ 对同一个 $z_i$ 的贡献加起来。
- 能把正则化、weight decay、深层网络隐式正则化与 dropout 放在同一条“提升泛化”的主线上理解。
- 能说出 early stopping、gradient clipping、data augmentation 分别在解决什么问题。

## 本段在整讲中的作用
本段先把前几讲的训练框架压缩回顾一遍，再把今天的主题聚焦到“散度函数如何影响梯度下降是否好优化”。[00:01:28]-[00:03:11] 老师先重申损失、梯度下降、批量/小批量更新与趋势类优化方法的关系，然后把整讲的第一条主线落在“如何选一个形状合适的 divergence”。

## 教学展开
- [00:01:28] 老师说明这是训练系列最后一讲，先回顾训练神经网络是在最小化损失函数，损失衡量网络输出与期望输出之间的差距。
- [00:02:12] 损失只依赖网络参数，优化方法是沿损失对参数的梯度做迭代更新。
- [00:02:26] 回顾 batch update 必须每次扫完整个训练集；SGD 和 mini-batch 用随机样本或子集更新，速度更快但方差更大。
- [00:02:47] 老师回顾“趋势类算法”会综合更长期的梯度及其方差，从而得到更快、更稳的收敛。[需回听 00:02:47]
- [00:03:14] 进入今天问题设定：总损失是对所有训练样本的平均散度，梯度下降是否好收敛，取决于散度函数的形状。
- [00:03:41] 老师点名好散度的基本性质：可微、两输入相同时时值为 0、整体非负。
- [00:04:22] 进一步强调，满足基本性质还不够，关键是形状要能在最优点外给出“朝正确方向且足够显著”的梯度。
- [00:04:35] 通过三种示意曲线比较：远处太平、近处太陡的碗形不利于优化；远处斜率大、接近最优时斜率小的形状更适合梯度下降。
- [00:06:49] 老师开始进入具体散度选择：回归常用 L2，分类常用 KL。
- [00:07:05] 标量回归时，L2 定义为 $\frac{1}{2}(y-d)^2$；加上 $\frac{1}{2}$ 只是为了求导时抵消 2。
- [00:07:26] 向量回归时，L2 是各输出维度误差平方和的一半。
- [00:07:47] 二分类时使用 KL 散度，老师口述其形式并追问其合理性。
- [00:08:43] 老师给出理由：若真实标签与预测完全相反，分类错误应当被视为“无限严重”，KL 具有这种性质，因此更符合分类任务精神。
- [00:09:08] 多分类时，softmax 输出概率向量，KL 写成对各类求和；若目标是 one-hot，则只剩目标类概率的负对数。
- [00:09:38] 段末抛出下一个问题：为什么分类不直接用 L2？为下一段对比 L2 与 KL 的优化几何做铺垫。

## 概念、符号与推导
- [00:03:14] 总损失：训练时把所有样本上的散度取平均，视作网络全部参数的函数。
- [00:03:41] 好散度的基本条件：可微、$D(y,d)=0$ 当 $y=d$、且 $D(y,d)\ge 0$。
- [00:04:22] 形状条件：最优点外需要足够大的正确方向梯度；远处太平会导致步子太小，近处太陡会导致越过最优点。
- [00:07:05] 标量回归的 L2：$D_{L2}=\frac{1}{2}(y-d)^2$。
- [00:07:26] 向量回归的 L2：$D_{L2}=\frac{1}{2}\sum_i (y_i-d_i)^2$。
- [00:07:47] 二分类 KL：老师口述为 $-d\log y-(1-d)\log(1-y)$。
- [00:09:08] 多分类 KL：老师口述为 $\sum_i d_i\log d_i-d_i\log y_i$；当 $d$ 为 one-hot 时，前项为常数，可化成目标类概率的负对数。

## 例子与课堂提示
- [00:04:35] 三种一维散度曲线的比较服务于“什么形状才利于梯度下降”这个核心判断。
- [00:05:21] 老师用“远处平坦、近处陡峭”的碗形说明：远离最优点时移动慢，接近最优点时又容易来回弹跳。
- [00:05:56] 与之对照，右侧曲线“远处陡、近处缓”能实现“远处大步、近处小步”。
- [00:08:43] “预测 0 而目标是 1”或反之应被视作无限错误，是老师解释 KL 更合适的课堂直觉。
- [00:09:25] one-hot 目标下只看目标类负对数，是老师提醒大家把多分类交叉熵与 KL 联系起来的地方。

## 本段掌握检查
1. 梯度下降友好的散度，除了可微、非负、相等时为 0 之外，还要具备什么形状特征？
答案：最优点外要有足够大的正确方向梯度；远处不能太平，最优点附近也不能过陡。

2. 为什么“远处平、近处陡”的散度形状不好？
答案：远处梯度太小，走得慢；靠近最优点时梯度太大，容易越过最优点并反复振荡。

3. 回归任务里老师给出的常用散度是什么？公式如何写？
答案：L2 散度。标量情形是 $\frac{1}{2}(y-d)^2$，向量情形是 $\frac{1}{2}\sum_i (y_i-d_i)^2$。

4. 为什么分类任务里老师更偏向 KL？
答案：KL 更符合概率输出和分类错误的语义，尤其当预测与真实类别完全相反时，错误代价会变得极大。

5. one-hot 多分类目标下，KL 会简化成什么？
答案：简化成目标类预测概率的负对数。

### 00:10:00-00:19:59

## 本段在整讲中的作用
本段承接上一段“为什么分类常用 KL”这个问题，核心任务是把“看起来更平滑的 L2”与“真正对 softmax 分类更友好的 KL”区分开。老师把讨论对象从输出概率 $y$ 推到 softmax 输入的仿射量 $z$，说明优化几何在经过非线性后会改变。[00:10:00]-[00:18:45]

## 教学展开
- [00:10:00] 老师先比较目标为 0.5 时的 KL 与 L2：两者关于输出概率 $y$ 都是凸的，且 L2 看起来更像“标准碗形”。
- [00:10:36] 紧接着老师指出，真正训练网络时并不是只看对 $y$ 的散度，而要看误差经过 softmax 之前的仿射输入 $z$ 如何影响优化。
- [00:10:53] 老师口述网络链条：输入经过网络得到仿射值 $z$，再经 softmax 得到 $y$，最后与目标 $d$ 计算 KL。[需回听 00:10:53]
- [00:11:18] 因此可以分别考察散度对 $y$ 的导数，以及散度对 $z$ 的导数；老师强调后者更贴近真实训练。
- [00:11:41] 对 $z$ 而言，KL 的形状更“好看”，L2 反而变差。老师借此说明：通过非线性后，早先看上去好的函数可能变坏，反之亦然。
- [00:12:25] 结论是：除了概率解释之外，KL 在 softmax 输入层面也更利于分类优化。
- [00:12:49] 老师进一步把讨论投影到最终 softmax 层参数 $W_1,W_2$ 上：若把损失看作这些权重的函数，L2 形成像“花”一样的非凸面，而 KL 更接近碗形。
- [00:14:05] 老师补充实现细节：分类的最终层总是隐含 softmax；在 PyTorch 中，损失函数内部已经处理 softmax 与对 $z$ 的导数，因此代码里常只显式写线性层。
- [00:15:43] 老师总结一个很重要的统一结论：无论是线性输出加 L2 的回归，还是 softmax 输出加 KL 的分类，对最终仿射量 $z$ 的梯度都等于误差 $y-d$。
- [00:16:21] 因为反向传播传递的是这个“误差”，所以 backpropagation 也常被称作 error backpropagation。
- [00:17:03] 老师插入 Poll 1 让学生确认两件事：最终 softmax 层权重下 KL 是凸的；常见回归/分类网络里对最终仿射量 $z$ 的梯度都是 $y-d$。
- [00:18:45] 段末用一句“散度的选择会影响学到的网络与训练结果”收束，并准备转向 batch normalization。

## 概念、符号与推导
- [00:10:00] 关于输出概率 $y$ 比较 L2 与 KL 时，两者在所举例子中都为凸函数。
- [00:10:53] 分类网络链条：$x \to z \to y=\mathrm{softmax}(z) \to D(y,d)$。
- [00:11:18] 老师强调应关注 $\frac{\partial D}{\partial z}$，因为真实训练中的梯度要继续向前层传播。
- [00:12:49] 当把损失视为最终 softmax 层参数的函数时，KL 对权重更接近凸，L2 则会形成更差的非凸损失面。
- [00:15:43] 对最终仿射量的梯度统一成误差项：$\frac{\partial L}{\partial z}=y-d$。
- [00:16:21] “误差反向传播”的称呼来自于最终层传播的就是这个误差向量。

## 例子与课堂提示
- [00:10:00] 老师先故意承认“L2 看起来更碗形”，再在后面推翻这个直觉，用来提醒学生不要只看输出层面。
- [00:12:49] 二维特征、两参数 softmax 的例子服务于“对权重看损失面”这一层理解：L2 会形成花状非凸面，KL 更规整。
- [00:14:05] PyTorch 隐含 softmax 的提醒是课堂实现提示，避免学生在代码里重复做 softmax。
- [00:17:03] Poll 1 把理论压缩成两个必须记住的判断：KL 对最终 softmax 权重更友好；常见最终层梯度是 $y-d$。

## 本段掌握检查
1. 为什么老师说只看散度对输出概率 $y$ 的形状不够？
答案：因为真实训练时梯度要经过 softmax 等非线性继续往前传播，更关键的是散度对仿射输入 $z$ 或最终层权重的形状。

2. 在 softmax 分类网络里，KL 与 L2 哪个对最终 softmax 层权重更接近凸？
答案：KL 更接近凸，L2 会形成更差的非凸损失面。

3. 老师为什么说“看起来好”的函数经过非线性后可能变坏？
答案：因为通过 softmax 这类非线性变换后，原先关于 $y$ 的几何形状映射到关于 $z$ 或权重的空间时可能被扭曲。

4. 常见回归网络与常见 softmax 分类网络，对最终仿射量 $z$ 的梯度分别是什么？
答案：两者都是 $y-d$。

5. 为什么 backpropagation 也叫 error backpropagation？
答案：因为最终层向后传递的核心量就是预测输出减目标输出的误差项。

## 教学展开

## 概念、符号与推导
- [00:40:21] 总梯度拆分：$\frac{\partial L}{\partial z_i}=\sum_j \frac{\partial L}{\partial u_j}\frac{\partial u_j}{\partial z_i}$。
- [00:41:21] through line 的三条路径：
  1. 直接项 $\frac{\partial u_i}{\partial z_i}$。
  2. 均值项 $\frac{\partial u_i}{\partial \mu_B}\frac{\partial \mu_B}{\partial z_i}$。
  3. 方差项 $\frac{\partial u_i}{\partial \sigma_B^2}\frac{\partial \sigma_B^2}{\partial z_i}$。

- [00:43:10] 均值相关项中，$\frac{\partial u_i}{\partial \mu_B}=-\frac{1}{\sqrt{\sigma_B^2+\epsilon}}$，$\frac{\partial \mu_B}{\partial z_i}=\frac{1}{B}$。
- [00:43:55]-[00:45:15] 方差相关项由幂函数求导得到，包含 $-(z_i-\mu_B)(\sigma_B^2+\epsilon)^{-3/2}/2$ 这一结构。[需回听 00:44:11]
