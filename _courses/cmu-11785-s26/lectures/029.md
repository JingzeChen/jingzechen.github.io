## 学习目标
- 说清 Hopfield net 的容量瓶颈为什么会把“加 hidden bits”变成玻尔兹曼机问题。
- 理解老师如何用自由能与温度把物理系统的随机演化改写成状态分布建模。
- 能解释单 bit 条件分布为什么是 sigmoid，以及这如何给出随机 Hopfield/Boltzmann 更新规则。
- 能复述 full Boltzmann machine 与 RBM 的训练逻辑、采样逻辑和历史用途。

## 需要的先修知识
- Hopfield net 的能量、稳定态、content-addressable memory 与 Hebbian learning。
- 概率论中的条件概率、边缘化、期望与最大似然。
- 微积分中的链式法则、对数求导与拉格朗日乘子。
- 热力学中温度、熵、自由能与退火的直觉。

## 老师的教学主线
老师先回顾上一讲的 Hopfield net 与容量问题，再指出通过加 hidden neurons 扩容后，“hidden bits 不必精确回忆、同一 visible pattern 可有多组 completion”这一事实，使得系统更适合被理解为概率机器。随后他从热力学出发说明真实系统在非零温度下 obey Boltzmann distribution，并据此推导出单个 bit 的 sigmoid 条件分布和随机更新规则。

在随机网络定义完成后，老师把训练写成最大似然：观测模式的相关性要被提高，模型自由运行时产生的相关性要被压低。再进一步，加入 hidden units 后要最大化 visible 的边缘概率，于是训练分成 clamped 补全与 unclamped 自由运行两阶段。最后他引出 RBM、contrastive divergence 和无监督预训练，并把这条线索连接到 2000 年代后神经网络复兴。

## 核心概念与依赖关系
- 容量只与网络宽度同阶，所以扩容要增加神经元数目。
- hidden neurons 让同一 visible pattern 可以对应多个 completion，因此模型必须处理分布而不是单个状态。
- 非零温度下系统最小化的是 Helmholtz free energy，其稳态分布是 Boltzmann distribution。
- 整体状态 obey Boltzmann distribution 时，单 bit 在固定其余位条件下 obey logistic/sigmoid。
- 训练梯度是数据期望减模型期望；加入 hidden units 后，数据期望本身也要通过条件采样补全。
- RBM 通过结构限制把 full BM 的慢采样简化成分层交替采样，并支持 contrastive divergence 和预训练。

## 关键推导、例子与结论边界
- 自由能最小化推出 Boltzmann/Gibbs distribution。
- 比较只差一个 bit 的两个状态，可推出单 bit 的 sigmoid 条件分布。
- 最大似然梯度可写成 \(\langle s_i s_j \rangle_{data} - \langle s_i s_j \rangle_{model}\)；含 hidden units 时第一项改为对 \(P(H\mid V)\) 的期望。
- 加 hidden bits 扩容、大小 valley 逃逸、给类别追加 bits 做分类，分别对应本讲的容量、随机性、应用三条主线。
- 完整 Boltzmann machine 在大问题上训练很慢；RBM 和 contrastive divergence 是老师给出的主要实用化答案。

## 易错点与待核对项
- hidden bits 不是“无关到可忽略”，而是“不作为最终输出目标，但会参与能量和训练”。
- 随机 Hopfield/Boltzmann 系统不是每一步都降能量；它只是在分布上偏向低能状态。
- 训练里的 data distribution 与 model Boltzmann distribution 不是同一个东西。
- 课件多个公式页 OCR 丢字严重；本讲若要抄精确公式，必须回看原 PDF 或视频。[需回听]

- 能解释 Boltzmann distribution、sigmoid 条件分布、maximum likelihood 梯度三者之间的衔接。
- 能区分 full BM 与 RBM 的结构和训练差异。

## 本段在整讲中的作用
本段先把上一讲的 Hopfield network 全部收拢回来，再把本讲真正要解决的问题钉住：如果 Hopfield net 的容量大致只和神经元数目同阶，怎样在仍然只关心原始图像前 N 个像素的前提下，存下更多模式。老师先回顾 Hopfield net 为什么能做 content-addressable memory、为什么 Hebbian learning 只能给出有限容量，然后把“给模式补上不关心的额外比特”这一扩容思路引出来，为后面把网络改写成玻尔兹曼机做铺垫。

## 教学展开
老师先说明本讲是整门课最后一讲，主题是 Boltzmann machines，并把它放在上一讲 Hopfield networks 的延长线上。随后他按顺序回顾：Hopfield net 是一个对称、带环的二值网络；每个神经元都试图和其他神经元加权输出形成的 local field 对齐；从任意初态出发，网络会通过神经元翻转不断降低能量，直到到达稳定态。

接着老师重申 Hopfield net 的记忆解释：如果目标模式被设计成稳定极小值，那么给网络一个带噪版本或部分缺失版本，它会自动清噪或补全，因此它是 content-addressable memory。随后他回顾了训练层面：单个模式时，Hebbian rule 相当于把两两神经元取值乘积写进权重；多个模式时可以对这些 Hebbian 权重求平均。但这样做的容量有限，课件给出的是大约 0.14N 个随机模式，经验上和更一般的优化观点一起看，网络可刻意存储的模式数仍然是 O(N) 量级。

在这个基础上，老师提出工程问题：如果一张图本身只有 N 个像素，而网络容量又大致受 N 限制，怎样存更多图？他的答案是直接给网络加 K 个我们并不关心取值的新神经元，把原本 N 位的模式补成 N+K 位。这样网络宽度变成 N+K，理论上可存储的模式数量也随之上升。随后他把术语固定下来：真正对应目标模式的前 N 个神经元是 visible neurons，新增但只为扩容服务的 K 个神经元是 hidden neurons。最后他说明一个直接但粗糙的做法是随机填这些 don't care bits，并指出真正的问题已经转成：这些额外比特究竟该怎样填，才能让记忆能力最大化。

## 概念、符号与推导
- Hopfield net：loopy、binary、symmetric 的网络；神经元输出取 +1/-1。
- local field：某个神经元看到的其他神经元输出的加权组合；神经元翻转方向由它决定。
- energy：老师回顾了“每次演化都会降低能量、能量有下界、所以有限步收敛”的结论，但本段没有重新展开公式推导。
- content-addressable memory：初始化在某个已存模式附近，网络会演化回该模式。
- Hebbian learning：单模式时权重等于对应神经元值的乘积；多模式时可对这些乘积求平均。
- 容量结论：课件回顾了 Hebbian 训练下可稳定存储约 0.14N 个随机模式的结论，也回顾了更一般的“容量与 N 同阶”的说法。
- 扩容记号：原始模式宽度为 N；新增 K 个不关心位后，模式宽度变为 N+K；前 N 个位置对应 visible neurons，新增 K 个位置对应 hidden neurons。
- 本段无新的公式推导。

## 例子与课堂提示
- 老师沿用上一讲的记忆例子：给网络 Bug Bunny 的带噪版本，网络会清噪；给它 Chip and Dale 的局部版本，网络会补全。这两个例子服务于“Hopfield net 是按内容寻址的记忆”这一点。
- 老师给出工程化的千像素图像例子：若图像有约 1000 个像素，网络大致只能刻意存 1000 个模式；若想存 2000 个模式，就给每张图再补 1000 个任意像素。这服务于“扩容的最直接办法是加不关心位”。
- 他反复提醒两件事必须同时看：可存模式数大致随神经元数增长，而神经元数原本又受输入像素数约束。这正是 hidden neurons 出现的原因。
- 课件最后把“随机填 hidden bits”只当成 baseline，而不是最终方案，提示后续真正关键的是如何聪明地利用这些不关心位。

## 本段掌握检查
1. 为什么 Hopfield net 会在有限步内收敛到稳定状态？
参考答案：因为每次神经元翻转都会让网络能量下降，能量又有下界，所以不可能无限次下降。

2. 为什么说 Hopfield net 是 content-addressable memory？
参考答案：因为只要初始状态离某个已存模式不太远，网络就会自动演化回那个模式，所以可以靠“内容相近”而不是地址来回忆。

3. 老师为什么说单靠 Hebbian rule 容量不够？
参考答案：因为它能刻意存储的模式数大致只和 N 同阶，课件还回顾了约 0.14N 个随机模式的经典结论，远不足以支撑更多记忆。

4. visible neurons 和 hidden neurons 在本讲里的定义分别是什么？
参考答案：visible neurons 是前 N 个、真正承载目标模式的神经元；hidden neurons 是为了扩容额外加入、具体取值本身不关心的神经元。

5. 给模式补 K 个 don't care bits 的直接收益是什么？
参考答案：模式宽度从 N 变成 N+K，网络规模随之增大，因此可存储模式数也随之提升。

### 002 00:09:57-00:19:56
## 本段在整讲中的作用
本段把“加 hidden bits 扩容”从一个粗糙工程点子推进成真正的建模问题。老师先说明，如果还按普通 Hopfield net 的办法随机填充并按老规则召回，就浪费了 hidden bits 的自由度；然后他指出正是这些“不必精确回忆”的 hidden bits，使得网络应该从确定性记忆机转成概率机器。这一段直接把课程从 Hopfield net 的扩容问题过渡到 Boltzmann machine 的物理与概率视角。

## 教学展开
老师先承接上一段的扩容方案，指出如果只是把 hidden bits 随机补上，再用原来的“初始化然后让网络演化”的召回方式，其实没有利用一个显而易见的事实：我们并不在乎这些额外比特的精确取值。随后他借助课件中的投票题检查三点：Hopfield net 的容量是 O(N)；可以通过把模式补上 K 个额外位把容量从 N 扩到 N+K；而召回 visible pattern 时，并不要求那 K 个隐藏位也被一模一样地回忆出来。

在投票之后，老师把可以利用的结构说得更具体。第一，召回时只要前 N 个 visible bits 正确，hidden bits 出错无所谓。第二，对于同一个 visible pattern，没有必要只配一个 hidden completion；完全可以给同一个数字或图案配许多不同的 hidden variants，并把它们都存进去。这样一来，能量地形中会出现多个不同的 valley，它们在 hidden 部分不同，但在 visible 部分对应同一个目标模式，于是召回会更鲁棒。

接着老师评价“随机填 hidden bits”的做法：它当然能工作，但没有充分利用冗余。更聪明的做法应该是专门挑 hidden bits，让整个扩展后的模式更“容易被记住”。于是问题从“怎么随便补 hidden bits”变成“怎样设置这些 bits 并怎样存储它们，才能最大化记忆能力”。老师给出的方向是：不要再把 Hopfield net 只看成确定性下降到某个 valley 的机器，而要把它整个改看成概率机器。最后他明确说，这正是本讲后半段的内容，也就是为什么玻尔兹曼机与诺奖线索会出现。

## 概念、符号与推导
- hidden bits / don't care bits：扩容时新增的 K 个比特；召回 visible pattern 时不要求它们严格复原。
- recall robustness：如果同一个 visible pattern 允许对应多个不同的 hidden completions，那么网络落到其中任一个 completion 都能得到同一个 visible 结果，因此召回更稳。
- multiple valleys：在能量地形上，可以允许多个 valley 共享同一个 visible pattern，只是在 hidden bits 上不同。
- probabilistic machine：老师提出，为了系统利用 hidden bits 的冗余，必须把网络理解为概率模型，而不只是确定性地往低能量处走的系统。
- 本段无公式推导。

## 例子与课堂提示
- 老师用“同一个 digit 可以造出许多不同 copy”的例子解释 multiple hidden completions：同一个可见数字可以配多组不同 hidden bits，而且这些副本都能被存储。这服务于“hidden 冗余能增强召回鲁棒性”。
- 他强调“只要前 N 个 visible bits 回对了就够了”，这是理解 hidden neurons 作用的关键课堂提示；如果把 hidden bits 也当成必须精确回忆的目标，就等于白白放弃了扩容带来的自由度。
- 他把随机填充描述为“should work but does not sufficiently exploit redundancy”，提醒不要把一个可行 baseline 误当成好解法。
- 老师口头把本讲分成“上一讲解释 Hopfield 为什么得奖，本讲解释 Boltzmann 方向为什么重要”的叙事线，用来提醒学生：这里的改写不是技巧，而是视角转变。

## 本段掌握检查
1. 为什么老师说在扩容后的网络里，hidden bits 没必要被精确召回？
参考答案：因为我们真正关心的是 visible pattern；只要前 N 个可见位正确，剩下的 hidden bits 出错并不会影响我们读取目标模式。

2. 对同一个 visible pattern 存多组 hidden bits 有什么好处？
参考答案：这会在能量地形里形成多个对应同一 visible 输出的 valley，从而让召回更鲁棒。

3. 随机填 hidden bits 为什么不够好？
参考答案：因为它虽然能工作，但没有专门利用 hidden bits 的冗余去让整体模式更容易记住。

4. 这一段为什么会把 Hopfield net 引向概率模型？
参考答案：因为一旦允许 hidden bits 不必唯一、也不必精确回忆，就需要一个能表示“多种 completion 都可接受”的概率视角。

5. 这一段真正提出的新问题是什么？
参考答案：不是“能不能补 hidden bits”，而是“该怎样设置和存储 hidden bits 才能最大化记忆能力”。

### 003 00:19:56-00:29:56
## 本段在整讲中的作用
本段把“为什么要概率化”落实到热力学语言上。老师不再把系统看成静止地待在某一个最低能状态，而是强调非零温度下系统会在多个状态间随机游走，因此真正被决定的是状态分布而不是单个状态。本段的终点是从 Helmholtz free energy 推出 Boltzmann distribution，为后面把 Hopfield net 改写成随机网络提供概率公式基础。

## 教学展开
老师先从物理直觉开始，提问绝对零度意味着什么。借学生回答，他说明在 0 Kelvin 时粒子不动，而只要温度高于绝对零度，粒子就会振动，因此自旋玻璃不可能永远停在某个固定配置。于是，真实被描述的对象不是“系统此刻在哪个唯一状态”，而是“系统以什么概率访问不同状态”。

在这个基础上，老师回顾状态能量的概念：每个状态都有自己的 potential energy；如果系统在各状态之间跳动，那么整个系统能做功的能力就应该由对所有状态能量取期望来表示。接着他引入熵，强调系统内部无序会抵消掉一部分可用能量；温度越高，这种无序越强。由此，真正会在固定温度下被降低的不是单纯的 internal energy，而是 Helmholtz free energy，也就是“能量期望减去温度加权的熵项”。

随后老师说明，在固定温度下让系统自然退火，系统会通过改变访问各状态的频率来降低 free energy，直到达到某个最小自由能的稳态分布。这个稳态分布就是 Boltzmann distribution。最后他把推导思路交代完整：在概率和为 1 的约束下，对自由能表达式加上拉格朗日乘子并对各状态概率求导，解出来的最优分布是状态能量的指数负比值。老师进一步解释温度效应：低能状态的概率指数级更高；当 T=0 时只剩最低能状态概率为 1；当 T 很大时，各状态逐渐趋向均匀。

## 概念、符号与推导
- 状态能量：每个状态 s 都有能量 E(s)。老师口头回顾了 Hopfield/spin-glass 中“每个配置对应一个能量”的设定。
- 内能（expected energy）：老师给出的含义是对所有状态按其概率加权后的能量期望，可记为
  \(\sum_s p(s) E(s)\)。
- 熵：老师口头给出的是 \(-k \sum_s p(s) \log p(s)\) 这一形式，其中 k 是 Boltzmann constant；温度越高，无序影响越大。
- Helmholtz free energy：按老师口述，可写成“能量期望减去温度乘熵”，等价于
  \(F = \sum_s p(s)E(s) + kT \sum_s p(s)\log p(s)\)。
- 约束条件：所有状态概率求和为 1，因此要引入拉格朗日项 \(\lambda (\sum_s p(s)-1)\)。
- 推导结果：对各 \(p(s)\) 求导并令其为 0，可得
  \(p(s)=\frac{1}{Z}\exp\left(-\frac{E(s)}{kT}\right)\)，
  老师同时说明这也叫 Gibbs distribution，Z 是归一化常数。
- 温度极限：T=0 时系统只停在最低能状态；T 很大时各状态更接近等概率。

## 例子与课堂提示

## 教学展开
老师先给出新的解释：stochastic Hopfield network 不再只是一个会下降能量的系统，而是一个对二值状态分布建模的生成模型；在平衡时，它生成状态的概率由 Boltzmann distribution 给出。随后他追问最实际的问题：如果要在实现上让网络随机演化，神经元翻转规则是什么。

- 对数几率：老师的推导核心是

## 本段在整讲中的作用
本段进入训练问题，讨论没有 hidden units 时的玻尔兹曼机怎样做 maximum likelihood learning。老师把 Hopfield net 中“压低目标模式能量、抬高其他模式能量”的直觉，改写成“让模型给观测到的状态分配更高概率”。这一段最重要的结果是梯度可以拆成 data term 减去 model term，为后面加入 hidden neurons 之后的训练规则提供模板。

## 教学展开
老师先从概率目标讲起：训练数据本身是从真实数据分布抽样来的，所以模型应给这些观测到的状态更高概率；而对未出现或极少出现的模式，则应给低概率。于是训练目标不再只是“记住若干固定模式”，而是“学习一个希望状态分布”。他举例说，如果训练集中 2 比 9 多得多，那么模型就应该给 2 分配更高概率，因为召回 2 时更应少出错。

随后老师把单个状态的概率写成 Boltzmann form，说明取对数后会变成两部分：第一部分是与该状态能量相关的项；第二部分是所有状态指数和的对数，也就是分配函数对应的 log-sum-exp 项。把这个对数似然对所有训练样本取平均，就得到平均 log likelihood。

接下来老师分别看梯度的两部分。第一项求导后，就是训练数据上 \(s_i s_j\) 的平均，这和上一讲 Hopfield net 的 Hebbian 项完全一样。真正困难的是第二项：它看起来像“对所有状态的指数和再取对数”的导数。但老师一步步用链式法则展开，指出这项导数最终等于所有可能状态上 \(s_i s_j\) 的概率加权平均，也就是在当前模型 Boltzmann distribution 下的期望。

最后老师解释为什么这仍然可做：虽然不能把指数数量级的所有状态枚举完，但可以采样。采样方法不是别的，正是让随机网络自己运行起来，从模型分布中抽状态样本。于是整体训练流程很清楚：初始化权重，让网络自由运行拿到 simulated states，用“数据上的平均乘积”减去“模型样本上的平均乘积”作为梯度，再更新权重。老师特别指出，这本质上就是把 Hopfield 的训练规则换成了一个概率版的对比项。

## 概念、符号与推导
- 训练目标：最大化训练数据状态的平均 log likelihood。
- 单状态概率：老师一直使用 Boltzmann form，可记为
  \(P(S)=\frac{e^{-E(S)}}{Z}\)。
- 对数似然分解：
  \(\log P(S) = -E(S) - \log Z\)，
  其中 \(\log Z\) 对应 transcript 里“crazy summation log of a summation of an exponent”。
- 数据项梯度：对权重 \(w_{ij}\) 求导后，第一项给出训练数据上 \(s_i s_j\) 的平均。
- 模型项梯度：第二项求导后，得到所有状态上 \(s_i s_j\) 按模型概率加权的期望。
- 经典更新式：
  \(\frac{\partial \log P(\text{data})}{\partial w_{ij}} = \langle s_i s_j \rangle_{\text{data}} - \langle s_i s_j \rangle_{\text{model}}\)。
- 采样近似：\(\langle s_i s_j \rangle_{\text{model}}\) 不能穷举时，用随机网络自由运行得到的 simulated samples 近似。

## 本段在整讲中的作用
本段把前一段的最大似然训练从“没有 hidden units 的玻尔兹曼机”推广到“真正用 hidden neurons 扩容的玻尔兹曼机”。老师先用一句话概括随机版和上一讲的差别只有“按 sigmoid 掷硬币”，然后把焦点转到 hidden bits 如何在训练时被补全。最终得到的是 clamped phase 与 unclamped phase 两步式训练框架，这就是完整 Boltzmann machine 的核心算法骨架。

## 教学展开
老师先回顾：如果没有 hidden units，随机版和上一讲 deterministic Hopfield 的差别极小，实质上只是把确定性更新改成按 sigmoid 概率掷硬币。然后他回到本讲最初的扩容动机：要增加容量，就要加一批我们不直接关心取值的 hidden neurons。

接着老师从工程直觉发问：既然这些 hidden neurons 没有目标标签，该怎样把它们填出来？学生回答后，老师把答案明确化：对给定 visible pattern，hidden bits 应当服从条件 Boltzmann distribution。做法不是手工选一个 hidden pattern，而是固定 visible bits，让 hidden 部分在当前模型下演化并采样。这样就把一个只给了 visible 部分的训练样本补成了完整状态。

随后老师从概率建模角度重新整理记号：完整状态可以写成 \((V,H)\)，其中 V 是 visible bits，H 是 hidden bits。训练时真正想最大化的是 visible 状态的边缘概率 \(P(V)\)，而不是某个单一 completion 的联合概率，因为对同一个 V 可以有许多不同的 H。老师解释说，理想上当然希望 completion 带来更低总能量，但可选 hidden patterns 有 \(2^K\) 个，穷举不可行，所以应当在期望意义下对所有可能 H 建模。

最后他把训练算法拆成两步。第一步是 clamped phase：固定 visible bits，只让 hidden bits 按 Boltzmann 分布演化，得到若干 completed patterns。第二步是 unclamped phase：解除 visible clamp，让整张网络一起自由演化，从联合分布上得到自由样本。梯度则由这两种样本中的 bit 乘积之差构成，和上一段的“数据项减模型项”形式完全平行。老师还特别提醒，hidden completions 依赖当前权重，所以每次参数更新后都要重新做补全过程。

## 概念、符号与推导
- 状态分解：完整状态写作 \(S=(V,H)\)，V 为 visible bits，H 为 hidden bits。
- 训练目标：最大化 visible pattern 的边缘概率
  \(P(V)=\sum_H P(V,H)\)。
- 训练数据不完整性：训练样本只给出 V，不给出 H，因此即便对训练样本，完整状态也是未知的。
- 第一项期望：对每个训练 visible pattern，需要在 \(P(H\mid V)\) 下对 hidden states 取期望；老师口头把它解释成“固定 visible bits，让 hidden bits 服从 Boltzmann distribution 去补全”。
- 第二项期望：和前一段一样，对全状态 \((V,H)\) 的自由运行分布取期望。
- 梯度结构：仍然是“clamped 样本中的乘积期望”减去“自由样本中的乘积期望”；逐字符公式在课件 92-99 页里，但 OCR 缺失较多。
- 两阶段采样：
  1. clamp V，采样 H，得到 completed pattern；
  2. unclamp V 和 H，让整网自由演化，得到 model sample。

## 例子与课堂提示
- 老师强调“你不必为一个 visible pattern 挑唯一最优 hidden pattern”，而是可以在期望里利用所有 completion。这一点服务于理解 latent variables 的本质。
- 他反复用“这些 hidden bits 取决于当前权重”提醒学生：completion 不是一次性预处理，而是训练内环的一部分；参数一变，补出来的 hidden pattern 也应跟着变。
- “先 clamp visible，再 free-run 全网”的两步流程是本段最重要的课堂提示；没有这两步，就无法把前一段的最大似然梯度推广到含 hidden units 的模型。
- transcript 中老师几次用“even without the math, this makes sense”强调这里的算法直觉先于繁琐推导，说明掌握 sampling 逻辑比抄完整公式更重要。

## 本段掌握检查
1. 为什么训练含 hidden neurons 的 Boltzmann machine 时目标变成最大化 \(P(V)\) 而不是某个固定 completion 的概率？
参考答案：因为训练数据只给 visible bits，同一个 V 可以对应很多不同的 hidden patterns，所以应对所有 H 求边缘化。

2. clamped phase 具体做什么？
参考答案：固定训练样本的 visible bits，只让 hidden bits 按当前模型的条件 Boltzmann distribution 演化并采样，用来补全完整状态。

## 本段在整讲中的作用
本段是整讲的总结和外延扩展。老师先把 Boltzmann machine 对容量、局部极小值逃逸、分类三方面的意义讲清楚，再指出完整 Boltzmann machine 训练过慢，于是引出 Restricted Boltzmann Machine 和 contrastive divergence。最后，他把 RBM 的无监督预训练连接到 2000 年代神经网络复兴的起点，构成整讲的历史落点。

## 教学展开
老师先用 Poll 4 复核两点：用来扩容的 irrelevant bits 对应 hidden neurons；训练玻尔兹曼机时，确实要通过采样 hidden values 来补全完整模式。随后他给出一个新的动机，说明概率化不仅是为了扩容，也是为了跳出局部极小值。老师画出有大 valley 也有小 valley 的能量地形，指出如果只做确定性能量下降，系统会被困在小 valley 里；而有了随机机制，就会以非零概率先向上，再掉进更大的、真正有意义的 valley，因此 recall 过程有机会逃离 parasitic memories。

接着老师谈分类。他说可以把 class ID 也编码成若干 bits 追加到特征后面，于是分类就变成 pattern completion：固定输入特征，让类比特自己补全。面对“100 类需要多少位”的提问，老师纠正学生说不是 100 位，而是大约 7 位就够，并补充说还可以多留一些 buffer，像纠错码那样提高鲁棒性。至此，玻尔兹曼机不仅能做记忆和补全，还能做条件概率估计与分类。

然后老师转向现实问题：完整 Boltzmann machine 训练太慢。因为可见层和隐藏层中的每个神经元都互相作用，权重数量随 \((N+K)^2\) 增长，整网自由演化要做很久。为此他引出 Restricted Boltzmann Machine：visible units 只连 hidden units，hidden units 也只连 visible units，层内不再彼此通信。这样在 clamped phase，只要固定 visible bits，就可以一步采样出 hidden bits，不需要内部反复迭代；自由运行阶段虽然仍要交替采样 visible 与 hidden，但比完整 Boltzmann machine 高效很多。

随后老师说明，在 RBM 上，梯度仍然是“第一步的乘积减去后面自由运行样本的乘积”。而利用 Hopfield net 里“只需抬高目标模式附近邻域”这一直觉，可以进一步得到 contrastive divergence：根本不必把自由运行推到无穷远，只做很少步，甚至一轮可见-隐藏-可见-隐藏更新，就能给出足够好的梯度估计。最后老师用课件扫过 RBM 的应用与扩展：它是很好的二值/二值化数据生成模型，可扩展到连续值的 harmoniums，可叠成更深结构，还可用于分类和回归。

在收束部分，老师回到历史：2000 年前后神经网络并非没人知道，而是难训练、容易陷入局部极小值，学界对它很冷淡。Hinton 的关键洞见是可以先丢掉标签，用 RBM 在原始训练数据上做无监督预训练，把学到的权重拿来初始化最终分类器。这样一来，之前“根本训不动”的深层网络 suddenly started working，由此开启了 2004 年后、尤其 2010 年前后的神经网络复兴。

## 概念、符号与推导
- 局部极小值逃逸：随机更新允许系统以非零概率走向更高能状态，因此有机会离开小的 parasitic valley，进入更大的目标 valley。
- 分类视角：把类别编码成附加比特，与输入特征拼接；给定特征、固定特征位后，对类别位做 pattern completion，相当于估计后验类别分布。
- RBM 结构限制：visible units 只连 hidden units，hidden units 只连 visible units；层内无连接。
- RBM clamped sampling：visible 固定时，hidden 可一步条件采样出来，因为 hidden 之间不再互相依赖。
- RBM free sampling：交替从 visible 采样 hidden、再从 hidden 采样 visible，形成 Gibbs chain。
- contrastive divergence：老师用“只需抬高目标模式附近邻域”的直觉解释为何不必把自由运行推到完全平衡；只做少量步就能近似梯度。
- RBM 梯度：仍是数据侧相关性与短链/自由链相关性的差；课件在第 116-118 页写成 \(\langle v_i h_j \rangle\) 形式。
- 连续值扩展：课件提到 exponential family harmoniums，可处理连续值 visible 或 hidden units。

- 老师画“小 valley 与大 valley”的能量地形，说明随机上坡为什么重要。这个例子直接服务于理解“玻尔兹曼机不只是扩容工具，也是逃出坏局部极小值的工具”。
