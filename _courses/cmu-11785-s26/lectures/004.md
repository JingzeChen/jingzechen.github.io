## 学习目标

- 理解本讲为什么要从“网络能表示函数”转向“网络怎样学到函数”。
- 掌握 perceptron、前馈网络、参数化函数 f(x; W) 这几个训练章节的基本记号。
- 说明为什么手工构造网络只能处理极简单任务，以及为什么真实训练必须转向自动估计参数。
- 掌握单个 perceptron 在线性可分数据上的学习目标、几何解释与更新直觉。
- 理解 perceptron rule 为什么不能直接训练多层 threshold MLP。
- 理解 threshold activation 与离散错分计数为何无法提供局部优化方向。
- 掌握两个 learnability requirements：激活函数可微、divergence 可微。
- 区分 expected risk、empirical risk、loss 与最终优化变量 W 的关系。

- 微积分：导数、可微、链式法则、期望值的基本直觉。

## 老师的教学主线

- 先回顾网络有足够表示能力，但仅有“能表示”还不等于“能学出来”。
- 然后从最基本的 perceptron 和前馈网络定义出发，把学习问题写成“找参数 W”。
- 接着用 diamond boundary 说明手工构造网络虽然可行，但不能扩展到一般问题。
- 再把训练具体化为分类任务，先分析单个 perceptron 在线性可分数据上的几何学习规则。
- 随后用 double pentagon 说明 perceptron rule 一旦进入多层 threshold 网络，就会因中间标签未知而变成组合优化。
- 再追究更深层原因：threshold activation 与 0/1 错误计数几乎不给局部方向信息。
- 因而转向连续、可微的激活函数与可微的 divergence。
- 最终把真实训练写成对训练样本平均 divergence 的最小化，也就是 empirical risk minimization。

## 核心概念与依赖关系

- universal approximation -> learning problem：前两讲回答“网络能表示什么”，本讲开始回答“参数怎样得到”。
- perceptron -> network：多层网络是由多个 perceptron 组成，因此单个神经元的表示、参数和可微性决定了全网训练是否可行。
- architecture -> learnability：即便网络理论上能表示函数，若结构容量不足或学习规则不对，仍然学不出来。
- handcrafting -> automatic estimation：手工搭边界只能处理最简单例子，自动学习才是通用方案。
- target function g(x) -> network function f(x; W)：训练就是调 W，让网络函数逼近目标函数。
- divergence -> expected risk：divergence 负责逐点量化 mismatch，对输入空间按 P(X) 加权后得到理想风险。
- training samples -> empirical risk：由于既没有完整 g(X) 也没有显式 P(X)，只能用训练样本上的平均 divergence 做经验近似。
- threshold activations -> combinatorial hardness：多层 threshold perceptron 既需要中间 relabeling，又缺少可用导数信号，导致训练困难。
- differentiable activations + differentiable divergence -> optimization：只有这两者同时成立，训练才能落回“如何通过改 W 让 loss 下降”的连续优化问题。

## 关键推导、例子与结论边界

- diamond boundary 手工构造：老师明确给出一条边界线的方程 x1 - x2 + 1 = 0，并说明四个边界感知机加顶部 AND 可拼出完整 diamond；结论边界是“只适用于极简单问题”。[00:10:06]-[00:11:14]
- perceptron 的几何解释：W^T X=0 定义超平面，W^T X = ||W|| ||X|| cos(theta) 用来判断样本落在边界哪一侧。[00:29:54]-[00:31:39]
- perceptron 更新直觉：错分正样本加 x，错分负样本减 x，本质是在把法向量拖向该样本的 ideal direction。[00:34:46]-[00:39:21]
- double pentagon 例子：说明“结构能表示”不等于“perceptron rule 能学”，因为中间层需要原始标签之外的 relabeling。[00:42:40]-[00:49:51]
- threshold 平移/旋转反例：错分个数可能长期不变，所以局部看不到该往哪个方向改参数。[00:54:07]-[00:56:47]
- 平滑激活 dotted-lines 例子：即便分类结果不变，连续输出到目标值的距离仍会变化，因此可用导数恢复方向信息。[00:59:45]-[01:03:32]
- sigmoid 解释：老师给出 1 / (1 + e^{-z}) 并把它解释成 P(Y=1|X)；本讲只用直觉，不展开更细概率推导。[01:07:21]-[01:08:08]
- 加权风险与经验风险：理想目标是按 P(X) 加权的 divergence 积分；实际目标是训练样本平均 divergence，二者关系只被讲成“期望上的近似/无偏估计”，本讲没有给出严格证明条件。[01:14:21]-[01:22:22]

## 概念、符号与推导

- 感知机的基本计算链条：输入先形成加权和加偏置的 affine quantity，再经 activation function 输出。[00:04:49]-[00:05:26]

- 参数：单个感知机的参数是 weights 与 bias；网络层面把所有参数合并记作 W。[00:05:29]-[00:05:38][00:08:03]-[00:08:27]

- 网络函数记号：f(x; W)。分号前是输入，分号后是参数，这是老师强调的标准写法。[00:07:43]-[00:08:10]
- 学习定义：学习网络就是学习 W，使 f(x; W) 近似目标函数。[00:08:13]-[00:08:33]
- 本段无完整公式推导，重点是概念定义与记号准备。

## 本段在整讲中的作用

本段把上一段留下的向量形式转成感知机分类边界的几何解释，并在这个几何视角下推出 perceptron algorithm 的更新直觉。老师不靠抽象证明，而是先说明超平面与法向量 W 的关系，再解释为什么错分的正样本该加 x，错分的负样本该减 x。这样学生在进入正式学习规则前，先理解了每次更新到底在“把边界往哪里推”。

## 教学展开

- [00:29:54] 老师先回答上一段问题：若两个向量内积为 0，它们彼此垂直。因此 W^T X=0 表示所有与 W 成 90° 的点集合，这个集合本身就是分类超平面。[00:30:17]
- [00:30:21] 对于不在超平面上的任意向量 X，内积 W^T X 可写为 ||W|| ||X|| cos(theta)。这让几何关系直接和符号联系起来。[00:30:43]
- [00:30:51] 如果 X 与 W 在超平面同侧，则夹角小于 90°，cos(theta) 为正，所以 W^T X>0；若 X 落在另一侧，夹角大于 90°，cos(theta) 为负，因此 W^T X<0。[00:31:39]
- [00:31:46] 老师据此总结 perceptron problem：找到某个向量 W，使得由 W^T X=0 定义的平面把数据完美分开，并让正类红点满足 W^T X>0，负类蓝点满足 W^T X<0。[00:32:17][课件: lec3.learning.pdf p.40-p.42]
- [00:32:30] 之后老师介绍 Rosenblatt 的 online perceptron solution。它从某个初始 W 出发，每次遇到错分样本才更新；若数据线性可分，则它保证能找到正确分离面。[00:32:52][课件: lec3.learning.pdf p.43-p.45]
- [00:32:57] 为了解释更新规则，老师先只看一个正类样本 x。他问：在所有能把这个样本判成正类的线性分类器里，哪个最 conservative，也就是使边界朝所有方向都尽量远离该点？答案是让权重方向直接对准 x。[00:34:25]
- [00:34:25] 同理，若样本是负类，则理想权重方向应是 -x。老师称之为这个样本的 ideal weight。[00:34:40]
- [00:34:46] 基于这个想法，perceptron learning rule 变得非常简单：遍历训练样本，若某个正类样本被错分为负类，就把当前权重更新为 W = W + x；若某个负类样本被错分为正类，就更新为 W = W - x。[00:35:47]
- [00:36:14] 老师随后用图示例：先随机初始化一个 W，于是得到一条初始 decision boundary。[00:36:46]
- [00:37:00] 第一个被发现的错分样本是落在错误一侧的负类点。因为负类的 ideal weight 是 -x，所以要把这个向量“加到当前权重上”，也就是等价于从 W 中减去 x，把 W 往远离该负点的方向拖动。[00:37:58]
- [00:38:03] 用新边界重新检查所有点后，又发现一个错分的正类点；对它的更新则是加上 x，把权重往该正点方向拖动。[00:38:42]
- [00:38:42] 更新后边界变成 perfect classification，不再出错，于是训练停止。老师借此说明 perceptron algorithm 的操作性：只有错分才更新，更新方向由样本类别决定。[00:39:21]
- [00:39:25] 本段最后老师再次回到“最 conservative classifier”的直觉解释，强调对正类而言，最理想的单点分类器就是让权重朝向该点，这也是更新式背后的几何理由。[00:39:53]

## 概念、符号与推导

- 超平面定义：W^T X=0 表示所有与 W 垂直的点的集合。[00:29:54]-[00:30:17]
- 内积公式：W^T X = ||W|| ||X|| cos(theta)。[00:30:21]-[00:30:43]
- 符号判断：与 W 同侧时 cos(theta)>0，因此 W^T X>0；异侧时 cos(theta)<0，因此 W^T X<0。[00:30:51]-[00:31:39]
- 感知机学习目标：找 W，使正类样本满足 W^T X>0，负类样本满足 W^T X<0。[00:31:46]-[00:32:17]
- online perceptron algorithm：初始化 W，逐样本检查，只在错分样本处更新。[00:32:30]-[00:32:52]
- ideal weight：正类样本的 ideal weight 是 +x，负类样本的 ideal weight 是 -x。[00:34:01]-[00:34:40]
- 更新规则：错分正样本时 W = W + x；错分负样本时 W = W - x。[00:35:11]-[00:35:47]

- [01:07:13] 在这些激活里，sigmoid 被单独拎出来。老师给出其公式 1 / (1 + e^{-z})，说明当 z 从负无穷到正无穷时，函数会平滑地从 0 过渡到 1。[01:07:32]
- [01:07:36] 更重要的是，老师给出 sigmoid 的解释：输出值可以被看成输入属于 class 1 的概率，也就是 P(Y=1|X)。这部分更详细的直觉推导留给 slides 和 quiz。[01:08:08][课件: lec3.learning.pdf p.107]
- [01:08:22] 最后老师把“可微激活”为何重要说成链式关系：若 sigma(z) 对 z 可微，而 z 又是输入和权重的 affine function，那么小幅扰动 W 会先改变 z，再通过 sigma 改变 y，因此我们能知道权重微调如何影响神经元输出。[01:09:10]

## 概念、符号与推导

- threshold 与平滑激活的区别：前者只给离散类别结果，后者给连续输出值，因此可用“目标值与输出值之间的距离”代替单纯错分计数。[00:59:45]-[01:02:16]

- subderivatives：老师把它描述成在不可导角点处可替代导数使用的“导数界限”，详细内容留到后续课程。[01:06:55]-[01:07:11]
- sigmoid 公式：1 / (1 + e^{-z})。[01:07:21]-[01:07:29]

- 链式影响关系：W 的微小变化先改变 z，再经 sigma 改变 y，因此输出对参数的变化可被计算。[01:08:22]-[01:09:10]

### 01:09:41-01:19:38

## 本段在整讲中的作用

本段把上一段“单个可微感知机能感知参数微调”的直觉，扩展为整个网络层面的可微性，并在此基础上重新定义训练目标：不再是盲目最小化整体阴影面积，而是最小化按输入出现概率加权的 divergence。老师随后再把这个理想风险压缩回训练样本的平均 divergence，为最终的 empirical risk minimization 只差最后一步命名。

## 教学展开

- [01:09:41] 老师先从单个 perceptron 的可微性往外推：若每个感知机对其输入和权重都可微，就能逐层计算某个权重的小扰动会如何穿过后续神经元，最终改变整个网络输出 y。[01:10:56][课件: lec3.learning.pdf p.126-p.128]
- [01:10:56] 因而对非 threshold activation 而言，网络输出相对每个参数 generally 都有有限且通常非零的导数；这些导数以后会通过 chain rule 具体推出来，但此处重点是“全网输出对参数变化可测”。[01:11:24]
- [01:11:24] 这自然引出第二个 requirement：不仅网络输出要对参数可微，error function 也必须对网络输出可微。[01:11:29]
- [01:11:29] 老师重述 divergence 的三条要求：它衡量网络输出与目标函数之间的 mismatch；当两者相同时 divergence 为 0；不同时 divergence 为正；此外现在还要额外要求它对网络输出 f 可微。[01:12:07][课件: lec3.learning.pdf p.129-p.130]
- [01:12:12] 结合两层可微性后，老师得到关键链条：参数 W 的微小变化会改变网络输出 y，而 y 的微小变化又会改变 divergence，所以我们终于能计算“轻微改动某个权重，会让 divergence 增减多少”。[01:12:49]
- [01:13:13] 在这个基础上，老师回到最早那幅目标函数与网络函数之间的阴影图。理想上，我们要最小化整块阴影面积，也就是对整个输入空间上的 divergence 做积分。[01:13:45][课件: lec3.learning.pdf p.131]
- [01:13:45] 但老师马上加了一个更现实的修正：如果先验上知道某些输入区间根本不会发生，就没必要浪费精力拟合这些区域；更一般地，不同输入出现的频率不同，重要性也不同。[01:14:21]
- [01:14:21] 因而整体误差不该只是“把每个 x 上的 divergence 机械相加”，而应该按 x 在现实中出现的概率 P(X) 加权。出现越频繁的输入，其 divergence 越重要。[01:15:39][课件: lec3.learning.pdf p.132]
- [01:15:39] 老师多次解释这一步的含义：现在真正想最小化的不是普通 shaded area，而是 weighted shaded area；若某个 x 从不出现，它的误差就不应对目标产生影响。[01:16:29]
- [01:16:48] 不过在现实里，既没有处处已知的 g(X)，也没有显式已知的 P(X)，所以这个加权积分仍算不出来。[01:17:24]
- [01:17:24] 因此实际可做的仍是回到训练样本：对观测到的 input-output pairs 计算网络输出与目标输出之间的 average divergence，把它当作上述理想风险的经验近似。[01:17:58][课件: lec3.learning.pdf p.133-p.134]
- [01:18:01] 老师最后点明：这个加权积分其实就是 divergence 的 expected value；我们希望样本平均 divergence 与这个期望量接近，这就为下一段正式命名 empirical risk minimization 做好了准备。[01:18:10]-[01:19:38]

## 概念、符号与推导

- 全网可微性：若每个感知机对输入和参数可微，则整个网络输出对任一参数也可微，可通过 chain rule 计算。[01:09:41]-[01:11:24]
- divergence 的性质：f=g 时为 0；f≠g 时为正；并且对 f 可微。[01:11:29]-[01:12:07]
- 组合链条：参数变化 -> 输出 y 变化 -> divergence 变化，因此可计算参数变化对 divergence 的影响。[01:12:12]-[01:12:49]
- 理想目标：对整个输入空间上的 divergence 积分，也就是整体 shaded area。[01:13:13]-[01:13:45]
- 加权修正：用 P(X) 表示输入出现概率，对 divergence 按输入重要性加权。[01:14:21]-[01:15:39]
- weighted shaded area：老师反复强调现在真正想最小化的是“按 P(X) 加权后的阴影面积”。[01:15:39]-[01:16:29]
- 经验近似：在训练样本上求 average divergence，用它近似理想的加权期望风险。[01:16:48]-[01:18:10]
- 期望解释：加权积分本质上是 divergence 的 expected value。[01:18:01]-[01:18:10]

## 例子与课堂提示

- “某些输入区间根本不会发生”这个例子很关键，它提醒学生：训练目标不是对输入空间一视同仁，而是应该更重视真实会出现的区域。[01:13:45]-[01:14:21]
- 老师多次解释 P(X) 的课堂提示非常直接：出现频率高的 x 更重要，因此它们的误差应该更重。[01:15:24]-[01:15:39]
- 虽然这里已经讲到 expected value 和 weighted divergence，但老师仍反复提醒“现实里算不出来”，避免学生误以为理论目标就是可直接优化的数值公式。[01:16:48]-[01:17:24]

## 本段掌握检查

1. 为什么单个可微感知机的性质能推广到整个网络？
答：因为每层都可微时，可用 chain rule 把某个参数的扰动一路传到最终输出。[01:09:41]-[01:11:24]

2. divergence 在本段新增了哪条要求？
答：除了“相等时为 0、不等时为正”外，还要对网络输出可微。[01:11:43]-[01:12:07]

3. 为什么老师要把 divergence 按 P(X) 加权？
答：因为不同输入出现频率不同，频繁出现的输入更重要，不该和几乎不会出现的输入同等对待。[01:14:21]-[01:15:39]

4. weighted shaded area 和普通 shaded area 的区别是什么？
答：前者在每个输入位置上还乘了输入出现概率，反映了真实重要性。[01:15:39]-[01:16:29]

5. 现实里为什么还要回到 training samples？
答：因为既没有处处已知的目标函数 g(X)，也没有显式已知的 P(X)，所以理想积分无法直接计算。[01:16:48]-[01:17:24]

### 01:19:35-01:23:05

## 本段在整讲中的作用

本段完成整讲收束。老师把上一段“样本平均 divergence 是理想风险近似”的说法正式命名为 empirical risk minimization，并把训练目标压缩成一个最清晰的数学任务：给定训练集，定义 loss，最小化关于 W 的函数。到这里，本讲从“为什么 perceptron rule 不够”顺利落到“后续训练将被视为一个函数最小化问题”。[01:20:29]-[01:22:56][课件: lec3.learning.pdf p.134-p.139]

## 教学展开

- [01:19:35] 老师先承接上一段：如果反复从数据分布里抽出很多训练样本集合，并对每个集合计算平均 divergence，那么这些平均值的平均，在数学期望上会逼近我们真正想要的那块 weighted shaded area。[01:19:55]
- [01:19:59] 这就是为什么，尽管我们既不知道真实的 P(X) 也不知道完整的 g(X)，仍然可以把训练样本上的 average divergence 当作实际优化目标。[01:20:29]
- [01:20:29] 老师正式命名：给定一批 training input-output pairs，定义网络实际输出和目标输出之间的 divergence，并对全部训练样本求平均；训练时最小化这项平均 divergence，这整套做法就叫 empirical risk minimization。[01:20:42]-[01:21:03][课件: lec3.learning.pdf p.135-p.136]
- [01:21:03] 老师还指出，在深度学习与本课程语境中，这个训练集上的平均 divergence 通常直接叫 loss。[01:21:13]
- [01:21:16] 他特别提醒：loss 不是我们真正想最小化的 weighted shaded area 本身，而只是对 expected divergence 的一个 estimate；之所以使用它，是因为它是一个 unbiased estimate，于是最小化它被期望能带来对真实期望风险的同时下降。[01:21:46]
- [01:21:49] 接着老师做一个非常重要的变量约束：训练集一旦给定就是固定的，因此在 loss 里真正可变的只有网络参数 W。也就是说，本讲之后的优化对象就是“一个仅关于 W 的函数”。[01:22:00]
- [01:22:04] 由此他把问题写成最终版本：给定训练样本，定义 loss 为样本平均 divergence，然后找到让 loss 最小的参数 W。[01:22:20][课件: lec3.learning.pdf p.137-p.138]
- [01:22:20] 老师最后点明这个问题所属的更大范畴：这就是 function minimization，也就是 optimization 的一个实例。[01:22:22]
- [01:22:26] 结尾的 story so far 再回顾整讲主线：threshold perceptron 网络的训练之所以困难，是因为组合复杂度和不可微问题；解决办法是用连续、非零导数的激活函数，定义可微 divergence，并优化参数去最小化训练误差，这个过程就是 empirical risk minimization。[01:22:56]
- [01:22:56] 老师在 [01:23:01] 处结束课堂，并为超时两分钟致歉。

## 概念、符号与推导

- empirical risk：训练样本上的 average divergence。[01:20:46]-[01:21:03][课件: lec3.learning.pdf p.134-p.136]
- empirical risk minimization：通过调整 W，最小化训练集上的平均 divergence。[01:20:29]-[01:21:03]
- loss：本课程与深度学习语境下，对训练集平均 divergence 的常用称呼。[01:21:03]-[01:21:13]
- loss 与真实目标的关系：loss 是对 expected divergence/weighted shaded area 的 estimate，而非真实目标本身。[01:21:16]-[01:21:38]
- unbiased estimate：老师用它来说明为何经验平均可以作为期望风险的替代目标。[01:21:38]-[01:21:46]
- 变量收缩：训练集固定后，loss 只依赖 W，因此训练问题是“最小化关于 W 的函数”。[01:21:49]-[01:22:20]
- 最终问题表述：给定训练样本，求使 loss 最小的参数 W；这是 optimization/function minimization 问题。[01:22:04]-[01:22:22]

## 例子与课堂提示

- 老师用“很多批训练样本的平均，再去平均”的说法，帮助学生把经验平均为什么能代表期望风险理解成一种采样直觉，而不是仅仅记一个名词。[01:19:35]-[01:20:29]
- “loss 不是阴影面积本身”是本段最重要的课堂提醒之一，避免学生把训练目标和真实泛化目标完全混同。[01:21:16]-[01:21:38]
