## 老师的教学主线

- 先从上一讲的 perceptron 回顾出发，把单元重写成“先算仿射项，再过 activation”的统一格式。

## 核心概念与依赖关系

- perceptron 两步分解 -> activation 讨论：只有先把单元拆成仿射项与输出函数，后面才能比较 threshold、sigmoid、tanh、ReLU、softplus 的差异。
- linear/affine 区分 -> 决策边界理解：把感知机写成 affine term 后，更容易把它看成超平面分类器。
- MLP -> universal Boolean function：truth table 可写成 DNF，DNF 可翻译成“隐藏层 AND clauses + 输出层 OR”。
- Karnaugh map -> 宽度压缩：DNF 的可化简程度直接决定一层隐藏层网络需要多宽。
- checkerboard/parity -> depth 必要性：最坏情况下单层指数宽，而深层 XOR 构造只需线性神经元。
- 布尔函数视角 -> 分类视角：在实值输入空间中，布尔输出对应输入空间区域划分，因此布尔逻辑组合可转成分类边界组合。
- polygon -> circle -> cylinder -> 任意边界：多边形求和的极限给出圆形局部响应，再把很多局部响应并起来即可逼近复杂边界。
- pulse/cylinder -> universal approximation：一维靠 pulse，高维靠 cylinder，核心都是“局部基元叠加”。
- width/depth/activation/capacity：
每层是否够宽决定信息能否被表达出来；是否足够深决定这些信息能否被逐层组合；activation 是否 graded 决定信息会不会过早丢失；capacity 决定可表达的断开区域复杂度上限。

## 关键推导、例子与结论边界

- 感知机重写：$z=\sum_i w_i x_i-t$，输出由阈值函数 $\theta(z)$ 给出。这是全讲后续所有 activation 讨论的基础。[00:05:50]-[00:07:38]
- 单隐藏层布尔通用性来自 DNF：每个输出为 1 的 truth table 行对应一个 clause，再由输出层统一 OR。[00:32:31]-[00:33:48]
- Karnaugh map 例子说明：同样的布尔函数，DNF 是否可分组化简，直接决定隐藏层宽度是 7 变 3，还是在 checkerboard 情况下完全压不下去。[00:36:39]-[00:40:13]
- XOR 例子给出深度收益：单隐藏层在最坏情况要 $2^{n-1}$ 级宽度，而深层构造可压到 $3(n-1)$ 个神经元和 $2\log_2 n$ 层。[00:43:50]-[00:46:39]
- 多边形/双多边形例子说明：深层更容易直接组合不连通区域；单层虽然也能做，但需要通过很多小圆的逼近来实现。[00:54:48]-[01:05:34]
- universal classifier 的边界：结论是“任意精度逼近分类边界”，不是“用有限一层精确表达任意边界”。[01:04:22]-[01:05:34]
- pulse 与 cylinder 构造说明 universal approximator 的边界同样是“arbitrary precision approximation”，不是 exact representation。[01:12:35]-[01:15:05]
- 宽度不足的反例说明：深度不是万能补救；若前层输出已经把关键几何位置信息压掉，后续再深也可能无能为力。[01:16:29]-[01:18:04]
- activation 的作用边界：threshold 最容易丢信息；sigmoid 有 graded information 但会饱和；ReLU/leaky ReLU 在信息传递上更占优，但仍不能替代足够的方向覆盖和容量。[01:18:56]-[01:23:14]

### 00:31:43-00:41:41

#### 本段在整讲中的作用

本段给出“单隐藏层也能表示任意布尔函数”的构造性证明，同时揭示其代价可能极高。老师通过 truth table、DNF 和 Karnaugh map 说明一层隐藏层足以通用，但最坏情况下隐藏层宽度会对输入维度呈指数增长。

#### 教学展开

- [00:31:54] 老师先回应前面关于层数的讨论，声称任意布尔函数都能用“一个 hidden layer”来实现，并说明要理解这一点，先把布尔函数看成 truth table。[00:31:54]-[00:32:08]
- [00:32:08] 他强调，truth table 不必列出所有输出，只需写出输出为 1 的输入组合；其余组合默认输出 0。[00:32:08]-[00:32:28]
- [00:32:31] 接着老师把这些“输出为 1 的行”写成 DNF。每一行对应一个 clause，例如某一行表示 $x_1=0,x_2=0,x_3=1,x_4=1,x_5=0$，对应布尔项 $\lnot x_1\land \lnot x_2\land x_3\land x_4\land \lnot x_5$。[00:32:31]-[00:33:20]
- [00:33:20] 所有这些 clause 再 OR 起来，就能精确表示原 truth table。[00:33:20]-[00:33:22]
- [00:33:24] 老师随后把 DNF 直接翻译成 MLP：隐藏层中每个 perceptron 实现一个 AND clause，输出层用一个 perceptron 把所有 clause OR 在一起。[00:33:24]-[00:33:48]
- [00:33:48] 因此，不管 truth table 有多大、多复杂，都能用“一个 hidden layer + 一个 output OR”来实现，说明单隐藏层 MLP 是 universal Boolean function。[00:33:48]-[00:34:25]
- [00:34:29] 老师接着提出真正困难的问题：如果只能用一层隐藏层，最坏情况下这层需要多少 perceptrons。[00:34:29]-[00:35:03]
- [00:35:03] 为回答这个问题，他引入 Karnaugh map。K-map 是一种拓扑化的位模式表示，相邻格子只差一位；最上与最下、最左与最右也可以视作相邻，所以整个表面拓扑上像一个 torus。[00:35:03]-[00:36:22]
- [00:36:39] 老师先展示一个 4 变量 K-map，其中输出为 1 的格子共有 7 个；朴素 DNF 会有 7 个 clause。[00:36:39]-[00:36:58]
- [00:37:01] 然后他开始分组相邻格子做化简：四个相邻格可合并为一个只依赖 $y,z$ 的 clause；两个相邻格可合并为去掉某一位后仍成立的 clause；四个角因为边界相接，也能一起化成一个 clause。[00:37:01]-[00:38:00]
- [00:38:00] 化简后，原来 7 项的 DNF 降到 3 项，于是对应的一层隐藏层网络只需要 3 个 hidden neurons。[00:38:00]-[00:38:18]
- [00:38:22] 但老师关心的是“绝对最坏情况”：什么样的高亮格子根本无法再分组化简。[00:38:22]-[00:38:56]
- [00:38:56] 答案是 checkerboard。因为任意两个输出为 1 的格子都不相邻，DNF 不能压缩；对于 4 变量的例子，需要 8 个 clauses。[00:38:56]-[00:39:19]
- [00:39:26] 他再给出一个 6 变量的三维 K-map 版本，对应隐藏层需要 32 个 neurons。[00:39:26]-[00:39:46]
- [00:39:50] 老师总结一般式：对 $n$ 个输入变量的布尔函数，如果采用一层隐藏层的 DNF 构造，最坏情况下隐藏层需要 $2^{n-1}$ 个 neurons，因此网络宽度对输入数是指数级的。[00:39:50]-[00:40:13]
- [00:40:28] 本段最后通过 poll 检查学生能否应用公式：10 个输入的 checkerboard 需要 512 个隐藏神经元，老师确认这是正确答案。[00:40:28]-[00:41:36]

#### 概念、符号与推导

- truth table 视角：布尔函数可由输入组合和对应输出完全刻画；只列出输出为 1 的行即可，其余默认输出为 0。[00:32:03]-[00:32:28]
- DNF 视角：每个输出为 1 的输入组合对应一个 AND clause，所有 clause 再 OR 起来就表示原函数。[00:32:31]-[00:33:22]
- 单隐藏层构造：隐藏层每个神经元对应一个 clause，输出层对应总 OR。[00:33:24]-[00:33:48]
- Karnaugh map：把 truth table 以“相邻格只差一位”的方式排成网格；四边还可环连成 torus。[00:35:03]-[00:36:22]
- 化简原则：相邻输出 1 的格子可合并，表示某些变量对该 clause 不再关键，从而减少 DNF 项数。[00:37:01]-[00:38:18]
- 最坏情况 checkerboard：无法分组化简，因此 DNF 项数达到最大。[00:38:56]-[00:39:19]
- 结论：一层隐藏层布尔 MLP 在最坏情况下需要 $2^{n-1}$ 个 hidden neurons。[00:39:50]-[00:40:13]

#### 概念、符号与推导

- 一维 pulse 构造：两个阈值单元分别在 $T_1,T_2$ 处切换，输出权重 1 和 -1，相减后得到一个局部脉冲。[01:12:35]-[01:13:11]
