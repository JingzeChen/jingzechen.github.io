## 学习目标
- 说清 CNN 为什么会从生物视觉研究中长出来，而不只是从“扫描模式”抽象推导出来。
- 复述 Hubel-Wiesel 的感受野、方向选择性、S-cells/C-cells 分工，以及这些概念如何迁移到计算模型。
- 解释 Fukushima 的 neocognitron 如何用 S-plane/C-plane 和共享响应实现位置不变性。
- 说明 LeCun 如何通过加监督、方形感受野、stride、pooling 和参数共享把 neocognitron 工程化为现代 CNN。
- 能按前向计算顺序讲清卷积、池化、下采样、上采样、padding、channels、filters、flatten、MLP 之间的关系。
- 能说出为何随着网络加深，常常要增加 channels、减小空间尺寸，以及老师给出的信息量补偿规则。

## 需要的先修知识
- 上一讲关于 scanning、distributed scan、non-distributed scan、位置不变性与卷积网络雏形的内容。
- 感知机 / MLP 的前向计算、activation function、softmax、loss 与 backprop 基本概念。
- 张量维度的基本读法：空间尺寸、通道数、局部窗口、stride、padding。

## 老师的教学主线
老师先从生物视觉史开头，而不是直接从工程实现讲起。他先用视觉错觉与 gestalt 说明早期研究只看行为现象，接着用 Hubel-Wiesel 的猫实验引出感受野、兴奋/抑制区域、方向选择性、S-cells 与 C-cells。随后指出这个生物模型缺少位置不变性的解释，于是过渡到 Fukushima 的 neocognitron：同一 plane 内共享响应、不同位置扫描输入、C-plane 做清理，从而实现位置不变性与更深层复杂模式检测。再往后，他说明 LeCun 如何加上监督和工程化约束，把这套结构变成现代 CNN。后半讲则完全切到算子与架构设计，逐层讲清卷积、池化、重采样、通道数、参数量与训练方式。

## 核心概念与依赖关系
- 感受野：单个神经元只看输入中的局部区域，是局部扫描与局部连接的来源。
- 方向选择性：不同细胞对不同方向的光条最敏感，是“模式检测器”直觉的来源。
- S-cells / C-cells：S 找模式，C 清理模式；后者是 pooling 直觉来源。
- S-plane / C-plane：同一 plane 内部响应共享，是参数共享与 shift invariance 的来源。
- 卷积层：把“同一类神经元在不同位置重复出现”改写成“一个 filter 扫描整张图”。
- 池化层：把“C-cell 对局部强响应做清理”改写成局部 max/mean 聚合。
- 下采样 / stride：把空间尺寸减小，以控制计算与存储，同时用更多 channels 补偿。
- 上采样：通过插零扩大尺寸，通常要接卷积才能重新生成有意义的值。
- flatten + MLP：把空间特征图转为类别决策。

依赖关系可以顺着以下链条理解：
感受野 -> 局部扫描 -> 方向选择性 -> S/C 分工 -> S/C 层级堆叠 -> neocognitron 的位置不变性 -> LeCun 的监督化与参数共享 -> 卷积层/池化层/stride/padding -> 完整 CNN 架构与训练。

## 关键推导、例子与结论边界
- 关键推导 1：卷积层的一个输出位置，来自局部窗口与 filter 的逐元素乘积求和，再跨所有输入 channels 求和，加 bias，最后过激活。
- 关键推导 2：若输入边长为 $n$、filter 边长为 $m$，老师口头意图表达的无 padding 输出边长是 $n-m+1$；same-size 需要在边缘补零。
- 关键推导 3：stride / pooling 会压缩空间尺寸，因此若希望不显著减少承载信息的数值总量，就需要同步增加 channels；老师给出的规则是 $K_l \ge D^2 K_{l-1}$。
- 关键例子 1：视觉错觉中的立方体、狗、带刺球体，用于解释 gestalt。
- 关键例子 2：Jennifer Aniston neuron / grandmother cell，用于解释位置不变性。
- 关键例子 3：花瓣轻微抖动但仍应识别为花，用于解释 max pooling 的局部抖动不变性。
- 关键例子 4：RGB 图像说明第一层卷积核为什么必须有 3 个输入通道。
- 关键例子 5：LeCun 的早期 digit recognizer 说明最小 CNN 可以如何拼接。

结论边界：
- 老师没有在本讲正式推导 backprop 在卷积与池化中的细节，而是留到下一讲。
- transcript 中多个尺寸公式和术语有 ASR 错误，本讲笔记只保留了老师明确表达的结构关系，不额外发明规范公式。

## 本段在整讲中的作用
本段先把课程从“训练神经网络”切换到“卷积神经网络”的生物学起源：老师先提醒上一讲已经从“扫描模式”的第一性原理推导过 CNN，然后改从视觉神经科学的历史出发，解释为什么后续会出现 S-cell/C-cell、感受野、方向选择性这些概念。就整讲位置而言，它是后面一切计算结构的历史动机与概念地基；课件在本段只提供标题页，实质内容主要来自 transcript，课件 p.1 仅用于确认讲次。

## 教学展开
- [00:00:22] 老师先回顾上一讲：CNN 已经被从“扫描模式”推导出来，其核心是通过扫描实现位置不变的模式检测，并说明本讲要转到 CNN 的第二部分。
- [00:01:01] 老师强调 CNN 的历史起点并不是“扫描原理”，而是生物视觉研究，因此转向“动物如何看见”的问题。
- [00:01:28] 他先讲早期研究方法：早期对视觉的理解大多来自行为实验，而不是直接神经测量。
- [00:01:42] 老师用三个视觉错觉例子引出 gestalt：左图会被看成立方体，中图会被看成狗，右图会被看成带刺球体，尽管图中并不存在完整对象。
- [00:02:53] 他把 gestalt 定义为大脑把离散碎片组织成完整对象的倾向，并指出这类研究只能说明“会发生什么”，还不能回答“图像在脑中如何被处理”。
- [00:03:15] 讲述转折点：1959 年 Hubel 和 Wiesel 开始研究视觉的神经相关物，老师将其定位为首次真正进入“图像如何被神经元处理”的研究。[需回听 00:03:22]
- [00:03:25] 老师用“如果你设计机器人视觉系统，你不会这么接线”来吐槽视觉系统的“反向布线”，说明视网膜、神经连线和后部脑区之间的关系，并引出 V1 / striate cortex。
- [00:04:54] 接着讲实验设置：24 只猫、麻醉、人工呼吸、把电极插入 striate cortex，带有明显课堂调侃色彩地描述实验过程。[需回听 00:05:05]
- [00:05:23] 然后说明实验任务：让猫眼保持睁开，把不同光斑和运动方向的光刺激打到眼睛里，观察单个细胞放电。
- [00:06:07] 实验首先发现每个皮层细胞只连接到视网膜上一小块区域，这个局部区域就是 receptive field（感受野）。
- [00:06:30] 在感受野内部，又能分出 inhibitory region 和 excitatory region：光落在抑制区会压制放电，光只落在兴奋区才会驱动细胞。
- [00:06:56] 老师进一步说明，这些兴奋区与抑制区的排列常常形成“有方向的线状结构”，于是不同细胞对不同方向的光条最敏感。
- [00:07:27] 他描述经典实验现象：光条旋转时，某个细胞只在接近竖直方向时剧烈放电，横向时几乎不响应，因此可以说该细胞偏好 vertical bands。
- [00:08:04] 结论是：oriented slits of light 是激活 striate cortex neurons 最有效的刺激。
- [00:08:12] 随后引出两级处理：simple S-cells 和 complex C-cells。两者都对有方向的光条有反应，但 C-cells 不容易被随机噪声误导。
- [00:08:43] 老师解释其机理：视网膜底层更像对近圆形光斑响应；S-cells 通过组合这些底层响应，形成对线状方向模式的敏感；C-cells 再从一组 S-cells 中取最强响应，清理噪声。
- [00:09:46] 本段最后再次落点：S-cells 发现有方向的模式，C-cells 通过“取一小组中的最大者”来清理这些模式，为下段的层级堆叠做铺垫。

## 概念、符号与推导
- receptive field：单个皮层细胞在视网膜上“看见”的小区域；该区域之外的刺激不会引发该细胞反应。[00:06:07]
- inhibitory region / excitatory region：感受野内部的抑制区与兴奋区；只有“兴奋区受光、抑制区不受光”的组合才容易让细胞放电。[00:06:30]
- gestalt：大脑把不连续碎片组织成完整对象的倾向。[00:02:53]
- S-cells：对有方向的光条敏感，容易受局部噪声干扰。[00:08:12-00:09:07]
- C-cells：对一组 S-cells 的响应做“取最强者”的清理，因此比 S-cells 更鲁棒。[00:09:17-00:09:56]
- 方向选择性：不同细胞对应不同的方向偏好，如竖直、水平或斜向。[00:06:56-00:08:08]
- 本段无公式推导。

## 例子与课堂提示
- [00:01:42] 立方体、狗、带刺球体三个视觉错觉例子服务于“gestalt 不是看见真实对象，而是大脑补全对象”的知识点。
- [00:03:25] “如果由人设计，不会把线缆放在传感器前面”的机器人视觉类比，用来帮助学生理解生物视觉系统的结构并不直观。
- [00:05:05] “truth serum”“猫可能没活下来”等调侃是在帮助学生记住 Hubel-Wiesel 实验环境，但不构成技术结论。[需回听 00:05:05]
- [00:07:27] 光条从水平转到竖直再转回去时放电峰值出现又消失，是方向选择性的核心演示。
- [00:09:17] “C-cell 取一组 S-cell 中最强者”的解释，是后面 max pooling 直觉的最早课堂提示。

## 本段掌握检查

5. 问：本段如何为后续 CNN 铺路？

### 00:10:02-00:20:01

## 本段在整讲中的作用
本段把 Hubel-Wiesel 的生物实验结论推进成“可计算模型”的需求说明。老师先补完 S/C 层级会逐层变复杂这一点，再指出原模型缺少位置不变性，于是引出 Fukushima 的 neocognitron。就整讲结构而言，这一段完成了从生物观察到第一个计算化视觉层级模型的过渡。

## 教学展开
- [00:10:02] 老师先补上 Hubel-Wiesel 的层级 buildup：S-cells 被 C-cells 清理后，又能作为下一层 S-cells 的输入，如此层层叠加，越深层检测到的模式越复杂。
- [00:10:42] 他补充说，后续文献里还观察到了更复杂的响应，但同时也承认这一整套生物学模型并不能解释颜色、空间频率等特征，V1 的确切组织仍是研究热点。
- [00:12:16] 老师借课堂投票总结第一问答案：S cells find the pattern，C cells clean them up。
- [00:12:26] 随即快进到 1980 年的 Fukushima，指出他识别出 Hubel-Wiesel 模型的一个关键缺口：它没有解释输入的 position invariance。
- [00:12:56] 老师用 Jennifer Aniston neuron / grandmother cell 例子说明“位置不变性”：只要祖母出现在视野里，不管在左、右还是中央，某个高层细胞都可能触发。
- [00:14:28] 因此 Fukushima 提出第一个建立在 Hubel-Wiesel 之上的计算模型；模型由一串模块组成，每个模块包含一层 S-cells 和一层 C-cells。
- [00:14:56] 在每个模块里，只有 S-cells 是 plastic 的，也就是可以学习；C-cells 的响应规则是固定的。
- [00:15:21] 老师随后解释 S-plane：一个模块里的 S-cells 按 plane 组织，同一 plane 内所有神经元响应完全相同，只是各自看输入的不同局部区域。

## 概念、符号与推导
- convolutional layer：由多张矩形 maps 组成；这些 maps 对应 neocognitron 的 S-planes，也可称 feature maps 或 activation maps。[00:33:35-00:33:57]
- affine map -> activation map：在单个输出 map 内，先逐位置求仿射值，得到 affine map；再对每个位置施加非线性，得到 activation map。[00:34:23-00:34:46]
- 单通道局部计算：把方形 filter 放在局部窗口上，逐元素做 weight × input 并求和，得到一个位置的 affine 输出。[00:36:07-00:36:56]
- 多通道扩展：如果前一层有多个输入 maps，则 filter 也要有同样多的 channels；每个 channel 在对应输入 map 上做局部乘加，再跨 channels 求和。[00:37:16-00:38:35]
- 偏置项：老师提醒“因为它是个 neuron，所以可以有 bias”，并把 bias 放在跨通道总和之外。[00:35:48-00:35:50, 00:39:54-00:40:00]
- 本段可明确写出的推导关系是：
  1. 固定一个输出位置。
  2. 对每个输入通道，取该位置下方的局部窗口。
  3. 与对应 filter channel 逐元素相乘并求和。
  4. 再对所有输入通道求和。
  5. 最后加 bias，得到该位置的 affine 值。
  6. 再逐点施加 activation，得到输出 activation map。[00:34:23-00:39:58]

## 本段在整讲中的作用

## 教学展开

- [00:46:55] 老师总结卷积层：它是用一组 filters 扫描输入；一个 filter 就是扫描层里的一个 neuron；每个 filter 共同扫描前一层所有 maps，并且“一个 filter 生成一个输出 map”。
- [00:47:41] 他进一步点明两个对应关系：输出 maps 的个数 = filters 的个数；单个 filter 的 channels 数 = 输入 maps 的个数。
- [00:48:00] 同时再次提醒，不做 padding 的话，卷积在边缘会丢行丢列，存在 edge effects。

## 概念、符号与推导
- cuboid view：把输入 maps 按通道堆叠成 3D 张量，把 filter channels 也堆叠成 3D 张量；一个输出位置由两者对应元素乘积总和给出。[00:40:52-00:41:56]
- 输出 maps 数 = filters 数：每个 filter 生成一张输出 activation map。[00:46:55-00:47:35]
- filter channels 数 = 输入 maps 数：因为每个 filter 必须同时读取前一层全部输入 maps。[00:47:35-00:47:47]
- 无 padding 的卷积尺寸：输入边长 $n$、filter 边长 $m$ 时，输出边长为 $n-m+1$。[00:42:26-00:44:00]
- same-size padding：老师口头给出的思路是总共会损失 $m-1$，因此上下左右各补 $(m-1)/2$ 个零层，可把卷积后尺寸恢复到原大小；此说法隐含 $m$ 为奇数。[00:44:44-00:45:44]
- 卷积层前向骨架：3D 局部块与 3D filter 做内积，加 bias，过 activation，逐位置重复，填满整张输出 map。[00:45:54-00:46:33]

### 00:49:45-00:59:44

## 本段在整讲中的作用

## 教学展开

- [00:57:47] 他又口头给出 pooling 带 stride 的尺寸关系，形式类似“输入减去 pooling block，再除以 stride，加 1”；同样因为 transcript 有歧义，建议回听确认精确写法。[需回听 00:57:47]

## 概念、符号与推导
- max pooling：在 $k \times k$ 局部窗口内选择最大值作为输出窗口位置的值。[00:50:36-00:50:57]

- pooling 的通道关系：pooling 是逐 channel 进行的，因此输出 maps 数 = 输入 maps 数。[00:52:55-00:53:40]
- downsampling：每隔 $S$ 保留一行/列，删除其余 $S-1$ 行/列，从而降低空间尺寸。[00:54:19-00:55:09]
- convolution/pooling with stride：把“算子本身”和“下采样”合并为一个带 stride 的扫描过程。[00:55:09-00:57:24]
- upsampling / dilation：在相邻行列之间插入零，使 map 尺寸扩大。[00:58:18-00:59:18]

1. 问：max pooling 为什么能带来 jitter invariance？
答：因为它只关心局部窗口里有没有强响应，不关心强响应落在窗口里的精确位置；所以特征轻微平移时，窗口输出仍可能保持不变。[00:50:36-00:51:26]
2. 问：为什么 max pooling 要先记录最大值的位置？

## 本段掌握检查
1. 问：为什么第一层卷积核必须有 3 个 channels？
答：因为彩色图像由 R、G、B 三个输入 channels 组成，卷积核需要同时读取这三个通道的局部信息。[01:04:51-01:06:07]
2. 问：1x1 convolution 在老师这里被解释成什么？
答：它是在每个位置上仅对各输入 channels 做加权组合，不看周边邻域，因此相当于 non-distributed scan。[01:07:01-01:08:02]
3. 问：第一层卷积层需要决定哪些主要超参数？
答：filters 数量、filter 的空间大小、stride，以及是否做 zero padding。[01:08:18-01:09:29]
4. 问：为什么 stride 大于 1 会隐含 downsampling？
答：因为卷积核不再逐点移动，而是跨步移动，从而跳过中间位置，直接减少输出 map 的空间尺寸。[01:08:50-01:09:08]
5. 问：老师对 filter 大小给了什么直觉？
答：小 filter 更适合抓细粒度特征，但如果太小，就不再覆盖足够的空间范围。[01:06:42-01:06:58]

### 01:09:37-01:19:36

## 本段在整讲中的作用
本段把“单层怎么做”扩展成“整网怎么堆”，并进一步回答一个架构设计问题：为什么网络越往后常常通道更多、空间更小。老师在这里第一次显式从信息量角度分析 pooling/downsampling 的代价与补偿规则。

## 教学展开
- [01:09:37] 老师先把第一层卷积的计算完整说清：对每个输出位置，先在每个输入 channel 上做局部乘加，再跨 channels 求和，最后加上 bias；通常在 CNN 里 bias 甚至常被忽略，因为经验上区别不大。
- [01:10:32] 然后总结第一层参数量：若第一层有 $K_1$ 个 $L \times L \times 3$ 的 filters，则参数量按“$K_1$ 乘每个 filter 的参数个数”计算，所有参数都要学习。
- [01:11:02] 接着进入 pooling layer 的超参数：pooling window 大小 $P \times P$、pooling stride，以及 pooling 类型；通常默认 max pooling。
- [01:11:45] 老师再次强调实现细节：对每个窗口先记录最大值位置，再把该值复制到输出；整个 pooling 是逐 channel 做的。
- [01:12:27] 因此 pooling 后输出 channels 数与卷积前一致，因为 pooling 是 channel by channel 的。
- [01:12:40] 之后补充一组术语：filters 常叫 kernels；单个 filter 的输出叫 channel，因此“输出 channels 数”其实就是“filters 数”。
- [01:13:01] 下一层再用一组新的 filters（老师口头用 $K_3$ 举例）作用在这些 pooled maps 上，于是产生新的输出 channels；参数选择依然是 filters 数、filter 大小、stride。
- [01:13:53] 整个 CNN 继续这样交替堆叠，最后把所有 channels 拉平成一个向量，再接一个 softmax 或完整 MLP 做分类。
- [01:14:23] 老师随后提出一个更重要的问题：为什么需要 pooling / downsampling？
- [01:14:30] 第一层回答是“为了检测更多特征，你想增加 channels”，因为每个 channel 可理解为一个特征检测器。
- [01:15:02] 然后他从信息量角度计算：若输入有 $k$ 个 channels、每个 channel 是 $n \times n$，则总值数量是 $k n^2$。[需回听 01:15:24]
- [01:15:28] 经过卷积变成 $k_1$ 个 maps 后，如果暂时忽略边缘效应并保留空间尺寸，总值数量变成 $k_1 n^2$；若 $k_1 < k$，则已经丢失信息。
- [01:16:28] 再做 stride 2 的 pooling 后，空间尺寸缩成原来的四分之一，于是总值数量变成 $k_1 n^2 / 4$。
- [01:17:13] 为了在这个 stride 2 的 pooling 之后“不比原输入更少信息”，老师给出条件：$k_1 \ge 4k$。
- [01:17:39] 他随即把这个经验推广：若第 $l$ 层使用 stride 为 $D$ 的 downsampling，则后续通道数至少应满足 $K_l \ge D^2 K_{l-1}$，否则会丢信息。
- [01:18:47] 本段最后把它解释成一个 trade-off：你既想要更多 channels 来检测更多模式，又想通过 downsampling 压缩存储与计算，因此需要在“空间变小”和“通道变多”之间平衡。
- [01:19:18] 老师收口到超参数清单：要选择卷积层与 pooling/downsampling 层的层数；每个卷积层要选 filters 数、filter 尺寸与 stride；每个 pooling 层也要选窗口与 stride。

## 概念、符号与推导
- kernel / filter / channel：filter 又称 kernel；每个 filter 生成一个输出 channel，因此输出 channels 数 = filters 数。[01:12:40-01:12:59]
- flatten：把末层所有 channels 的所有空间位置按顺序拉平成一个长向量，再交给 MLP。[01:13:53-01:14:10]
- 特征检测器视角：每个 output channel 都对应一种 learned feature detector，因此 channels 越多，可分辨的模式类型通常越多。[01:14:30-01:14:51]
- 信息量计算思路：
  1. 输入总值数为输入 channels 数 × 每个 channel 的空间元素数。
  2. 卷积若不改空间尺寸，则总值数变为输出 channels 数 × 同样的空间元素数。
  3. stride 2 的 pooling 会把每个 channel 的空间元素数缩为原来的四分之一。
  4. 若希望总值数不下降，则需要输出 channels 数至少补偿这部分缩减。[01:15:02-01:17:37]
- 关键条件：
  - 仅卷积且空间尺寸不变时，若不想比输入少信息，需有 $k_1 \ge k$。[01:16:08-01:16:26]
  - 再接 stride 2 pooling 时，需有 $k_1 \ge 4k$。[01:17:13-01:17:37]
  - 一般化表达：$K_l \ge D^2 K_{l-1}$，其中 $D$ 是下采样 stride。[01:17:39-01:18:34]

## 例子与课堂提示
- [01:10:53] “bias 通常不怎么考虑”是经验性实现提示，不是理论上 bias 不存在。
- [01:12:40] 老师特意补 jargon，是为了避免学生把“map”“channel”“filter output”当成不同对象；在这段里它们经常是一组互相关联的叫法。
- [01:15:02] 从“总共有多少个数值”来分析是否丢信息，是本段最重要的课堂视角转换：它把结构设计变成了数量级平衡问题。
- [01:18:47] 老师没有说“满足条件就一定不丢语义信息”，而是说这是为了尽量 retain information；这个表述边界需要保留。

## 本段掌握检查
1. 问：为什么老师说增加 channels 等于增加可检测特征数？
答：因为每个 output channel 都对应一个 learned filter，也就是一种特征检测器；filters 越多，能检测的模式种类通常越多。[01:14:30-01:14:51]
2. 问：如果卷积后空间尺寸不变，为什么至少需要 $k_1 \ge k$？
答：因为输入总值数是 $k n^2$，输出总值数是 $k_1 n^2$；若 $k_1 < k$，输出承载的数值总量就少于输入。[01:15:02-01:16:26]
3. 问：为什么 stride 2 pooling 后老师给出 $k_1 \ge 4k$？
答：因为 pooling 把每个 channel 的空间元素数缩成四分之一，所以要靠把 channels 增加到至少 4 倍，才能补偿空间压缩带来的总值数减少。[01:16:28-01:17:37]
4. 问：一般化的通道补偿规则是什么？
答：若第 $l$ 层做 stride 为 $D$ 的 downsampling，则为了尽量不降总值数，老师给出 $K_l \ge D^2 K_{l-1}$。[01:17:39-01:18:34]
5. 问：整个 CNN 在分类前的最后一步通常是什么？
答：把最后的多通道 maps flatten 成一个向量，再送入 softmax 或更完整的 MLP。[01:13:53-01:14:10]

- [01:21:15] 然后用 gradient descent 的变体更新参数，梯度通过 backprop 计算；但 backprop 的具体细节会留到下一次课展开。
- [01:21:27] 最后老师做全讲总结：CNN 是 mammalian vision 计算模型的 supervised 版本；它用 learned filters 的 convolutional layers 做 shift-invariant pattern recognition；用 pooling layers 对局部群组响应做操作，以增强对 jitter 的鲁棒性；整个网络参数可用常规 backprop 学习。

## 概念、符号与推导
