## 学习目标
- 理解普通 MLP 为什么对模式位置敏感，以及 CNN 试图解决的正是这个问题。
- 能把扫描式检测、共享参数大网络、逐层 maps 扫描这三种说法互相对应起来。
- 掌握共享参数训练时“梯度求和”的核心规则。
- 能比较 nondistributed 与 distributed scanning 的参数量，并说明后者的泛化、参数和计算收益。
- 记住本讲最后引入的术语与修饰：filter、receptive field、flattening、stride、pooling、TDNN。

## 需要的先修知识
- 多层感知机、前向传播、softmax。
- 反向传播和梯度下降。
- 层级表示与模式组合的基本直觉。

## 老师的教学主线
- 用语音 welcome 与图像 flower 两个任务指出：位置变化会让普通 MLP 失去识别能力。
- 用扫描式局部 detector 代替“整段/整图一次性判别”，从结构上获得位置不变性。
- 把扫描看成共享参数的大网络，并说明共享参数照样可以训练，只是梯度要合并。
- 把整网逐位置扫描改写成逐层扫描 maps，再把大窗口分析分布到多层，形成层级表示。
- 以参数量、计算复用和若干术语收尾，给出完整 CNN/TDNN 视图。

## 核心概念与依赖关系
- shift invariance 是问题定义层面的要求。
- scanning 是获得 shift invariance 的第一层结构答案。
- giant shared-parameter network 是 scanning 的等价网络视图。
- shared-parameter backprop 是这一视图下可训练性的数学保证。
- maps 与逐层扫描是把 scanning 重排为 CNN 形式的中间桥梁。
- distributed scanning 让低层学局部、高层学组合，是 CNN 高效性的来源。
- filter、receptive field、flattening、stride、pooling 是在这一结构上进一步描述行为和修饰操作的术语。

## 关键推导、例子与结论边界
- 共享参数梯度：公共值的梯度等于所有共享边对应梯度之和，再据此做一次更新并复制回去。
- 1D 参数量示例：非分布式为 8D*N1 + N1*N2 + N2*N3；分布式为 2D*N1 + 4*N1*N2 + N2*N3。
- 计算复用结论来自相邻窗口重叠区域的已算响应可直接复用。
- pooling 在本讲只讲动机、max 直觉和作用，不讲完整实现细节。

## 易错点与待核对项
- 不要把位置不变性理解成“靠更多数据凑出来”；本讲核心是结构共享。
- 不要把 giant network 理解成普通全连接网络；这里的大网络含有重复子网与共享参数。
- 不要把 distributed scanning 理解成“目标窗口缩小了”；它只是把同等检测范围拆到多层实现。
- Poll 4 的错误选项是“中间变量内存需求会减少”。
- 专有名词和少数术语存在 ASR 误识别，需要按各段待核对项回听确认。

## 掌握标准
- 能用自己的话说明 welcome/flower 例子为什么迫使我们引入 CNN。
- 能解释扫描、共享子网和逐层 maps 扫描三者是同一件事的不同视角。
- 能写出共享参数梯度求和规则和 1D 参数量对比式。
- 能解释 distributed scanning 的三项主要收益，并准确说出 stride、pooling、filter、receptive field 的作用。

## 本段在整讲中的作用
- [00:02:19] 老师先收束前几讲：MLP 已经能做通用函数逼近和反向传播训练，然后把本讲目标切到卷积网络，说明这是在已有 MLP 框架上继续推进的新主题。
- [00:03:20] 本段真正要解决的问题是：当目标模式的位置变化时，传统 MLP 为什么会失效，以及为什么必须引入“平移不变”能力。这个问题构成整讲后续“扫描”思路的出发点。

## 教学展开
- [00:02:19] 先回顾“故事到目前为止”：MLP 是通用函数逼近器，可做布尔函数、分类和回归，也能靠梯度下降和反向传播训练（课件 p.2）。
- [00:02:58] 再回顾此前模型形态：输入向量逐层送入多层感知机，网络能够识别数字或其他向量数据中的模式（课件 p.3）。
- [00:03:20] 引入新的语音任务：给定固定时长录音，判断其中是否包含 welcome；录音先转成谱图一类的向量序列（课件 p.4）。
- [00:03:49] 指出“朴素方案”是让一个 MLP 直接看完整段输入并输出 yes/no，但老师马上追问：如果网络只学会识别录音前半段的 welcome，它能否识别后半段出现的 welcome。
- [00:04:44] 结论是否定的，因为一旦把输入展平成向量，目标模式仅仅平移位置，就会形成完全不同的向量表示；原网络不会自动把它们视为同一模式（课件 p.5-p.6）。
- [00:06:21] 再用图像里的花朵举同样的反例：左上角的花和右下角的花，对普通 MLP 来说依然是不同向量，因此“看过左上角花朵”的 MLP 不保证认识右下角花朵（课件 p.8-p.10）。
- [00:07:16] 抽象出一般需求：很多任务只关心模式是否存在，不关心它出现在何处，因此网络必须具备 shift invariance，亦即目标模式平移后仍能触发（课件 p.11）。
- [00:08:12] 学生提出数据增强思路，老师承认这能部分覆盖位置变化，但指出代价是需要更大的网络和更多覆盖不同位置的训练数据，因此不是理想结构性解法。

## 概念、符号与推导
- [00:02:41] MLP 是 universal function approximator，这里是整讲的前置结论，不在本段重新推导（课件 p.2）。
- [00:07:46] Shift invariance：如果把目标模式在输入中平移，网络输出仍应保持“检测到该模式”的判断不变（课件 p.11）。
- [00:03:20] 语音输入在本讲中被视为“向量序列”，图像输入被视为“像素向量/矩阵”；老师用“展开成向量后位置一变即变成另一个点”来解释传统 MLP 的脆弱性。
- 本段无公式推导。

## 例子与课堂提示
- [00:03:20] 语音例子“录音里是否有 welcome”服务于提出 1D 模式检测任务，强调时间轴上的位置变化会误导普通 MLP。
- [00:06:21] 图像例子“图片里是否有花”服务于把同一问题推广到 2D，说明空间位置变化同样会让普通 MLP 失去泛化能力。
- [00:08:12] 数据增强被当作课堂反例：它不是不行，而是代价高，无法从结构上保证高效的平移不变性。
- [00:07:16] 老师反复强调“只关心存在，不关心位置”，这是理解 CNN 为什么必要的课堂主线。

## 本段掌握检查
1. 为什么一个只见过“录音前半段 welcome”的普通 MLP 不保证识别“后半段 welcome”？参考答案：因为输入展平成向量后，目标平移会变成完全不同的向量坐标，普通 MLP 对位置敏感。
2. 花朵例子想说明什么？参考答案：图像中的目标只要位置变化，普通 MLP 也会把它当成不同输入，因此不能天然做到位置无关识别。
3. 本段对网络提出的核心新要求是什么？参考答案：shift invariance，即目标模式平移后网络仍能触发。
4. 为什么老师不把数据增强当作最终答案？参考答案：它需要更大网络和更多覆盖不同位置的数据，代价太高，不能替代结构性设计。

### 00:10:45-00:20:45

## 本段在整讲中的作用
- [00:10:45] 本段给出解决 shift invariance 的第一版结构性答案：不要整段输入一次判别，而是先做局部检测，再把各位置检测结果聚合成全局判断。
- [00:13:26] 它同时把“扫描”重新解释成“一个带重复子网的大网络”，为后面共享参数、反向传播训练和卷积化改写打基础。

## 教学展开
- [00:10:45] 老师先解释全局输出如何由局部窗口输出得到：只要某个窗口对 welcome 的检测值很高，整段录音就应判为包含 welcome；如果所有窗口都低，则判为不包含（课件 p.18-p.21）。
- [00:11:08] 说明聚合器不一定非得是 max，也可以是 perceptron、softmax，甚至再接一个 MLP；但基本思想不变，都是把各位置局部证据合并成一个“整段是否含有目标”的结论（课件 p.19-p.21）。
- [00:11:54] 回答“什么叫 scanning”：沿输入从左到右移动，在每个位置切出一个小片段，把该片段送进同一个 MLP，得到该位置的输出；所有位置的输出再统一送入 softmax（课件 p.22, p.24）。
- [00:12:45] 回答学生关于多个单词或多个 welcome 的疑问：welcome-detector 只对 welcome 响应；如果有多个 welcome 更没有问题，因为 max 只要求至少一个位置高即可。
- [00:13:26] 老师进一步说，这其实就是一个 giant network：每个窗口对应一个子网，这些子网的输出被上层聚合器合并，所以整体仍可看成一个大网络（课件 p.23, p.25）。
- [00:14:11] 关键区别在于：底层有很多子网，但它们是 identical subnets。每个子网看不同位置，却共享同一组参数，因此整个网络天然具备 shift invariance。
- [00:15:07] 老师把同一思路迁移到图像花朵检测：窗口大小应与预期目标大小相称，然后在整张图上扫描局部窗口寻找目标。

## 概念、符号与推导
- [00:11:54] 1D 扫描伪代码：对每个位置 t 取出局部片段 XSegment = x(:, t:t+K-1)，计算 y(t) = MLP(XSegment)，再用所有 y(t) 形成全局输出 Y（课件 p.22, p.24）。
- [00:10:45] max 聚合的逻辑等价于“只要某处检测到目标就输出真”的布尔 OR（课件 p.19-p.21）。
- [00:13:26] giant network 的定义不是新公式，而是结构重述：整体网络由多个窗口子网和最终聚合层组成，但所有窗口子网参数相同。
- [00:14:43] shared/identical subnets 是本段最重要的结构约束；它是 shift invariance 的来源，而不是“碰巧训练到了各个位置”。

## 例子与课堂提示
- [00:10:45] 老师用“至少有一个窗口高就说明录音里有 welcome”帮助学生把局部检测和全局判定联系起来。
- [00:12:45] “多个 welcome 也没关系”这个课堂提示，服务于澄清 max 聚合只关心是否存在至少一次触发。
- [00:15:07] 花朵例子提醒学生：扫描窗口大小要和待检测对象尺度对应，否则 detector 的职责定义就不清楚。
- [00:13:26] “其实只是一个大网络”是本段的关键认知转折，后续所有训练与参数共享都建立在这一重述之上。

## 本段掌握检查
1. 扫描式 welcome 检测的基本流程是什么？参考答案：在每个位置切出一个窗口，用同一个 MLP 做局部检测，再把所有位置的输出用 max、softmax 或更一般的聚合器合并。
2. 为什么多个 welcome 不会破坏这个方案？参考答案：因为全局判定只要求至少一个位置输出高，多个位置高同样满足条件。
3. 扫描网络和普通大 MLP 的差别在哪里？参考答案：扫描网络底层由许多相同子网组成，这些子网参数共享，只是观察输入的不同位置。
4. 本段中 shift invariance 是怎么获得的？参考答案：通过在所有位置复用同一个 detector，而不是为每个位置训练不同参数。

### 00:20:42-00:30:35

## 本段在整讲中的作用
- [00:20:42] 本段把“扫描网络可训练”这件事讲清楚：它先说明扫描仍然只是一个大网络，因此可用常规反向传播训练；随后补上“共享参数如何求梯度”的关键数学环节。

## 教学展开
- [00:20:42] 老师先用 1D 小例子说明 stride 为 2 和 stride 为 1 时扫描图示的差异，但强调本质都是“同一个 MLP 在每个位置被重复计算”。
- [00:21:34] 把同一想法推广回图像与语音：无论 2D 花朵检测还是 1D 语音检测，都是整个网络扫完整个输入，各位置输出再进入最终决策层。
- [00:22:06] 一旦接受“它只是一个 giant network”，训练就简单了：直接用 conventional backpropagation；训练 flower detector 时，不需要标出花在图中哪里，只需给出“有花/无花”的整图标签。
- [00:22:41] 语音也一样，只需提供“录音里有/没有 welcome”的样本，不需要人工对齐目标出现的精确位置；扫描结构会把“找位置”内化进整体网络。
- [00:23:20] 老师随后补充一个新约束：所有扫描子网是 identical，因此更新一个副本的参数，必须同步更新所有副本；这就是 shared parameter network。
- [00:24:33] 为了抽象这个问题，老师不再只谈扫描网络，而是给出一般的共享参数网络定义：某些边的权重被强制为同一个公共值。
- [00:25:29] 接着推导共享值的梯度：公共参数同时影响多条边，所以对公共值求损失导数时，要把所有路径上的贡献都加起来。
- [00:27:49] 最后回到一般情形：对每个共享集合 S，先把该集合里每条边对损失的导数求出并求和，得到公共权重的梯度；更新共享值后，再把新值复制回所有具体边。
- [00:29:42] 小结：位置不变模式分类靠扫描完成；扫描等价于带重复子网的大网络；学习时依然反传，但必须把共享参数对应的多个梯度项合并。

## 概念、符号与推导
- [00:23:30] Shared parameter network：网络中某个参数集合被约束为同一个值，例如两条边的权重都等于公共值 Ws。
- [00:25:47] 公共值 Ws 对损失 Div 的影响要沿所有共享路径累计：dDiv/dWs = dDiv/dw1 * dw1/dWs + dDiv/dw2 * dw2/dWs + ...。
- [00:26:20] 因为共享约束是“wi = Ws”，所以 dwi/dWs = 1；于是公共参数的梯度化简为所有共享边各自梯度之和。
- [00:28:25] 对任意共享集合 S，有 dLoss/dwS = sum over e in S of dLoss/de。老师强调每一项仍由普通 backprop 计算，只是在共享值处相加。
- [00:29:22] 更新步骤：先用上式得到共享值梯度，再做梯度下降更新共享值，最后把更新后的公共值复制回集合 S 中每条具体边。

## 教学展开
- [01:10:20] 老师先完成参数比较的口头结论：在相同神经元规模下，distributed 版本第一层参数明显更少，因此整体参数可大幅下降。

- [01:15:52] 接着进入术语。老师建议把每层 map 想成在“重绘输入”：第一层把找到的花瓣等特征高亮出来，第二层高亮更高阶组合，第三层继续高亮更复杂模式（课件 p.273-p.277）。
- [01:16:55] 每个扫描神经元的一组权重叫 filter；神经元在原输入上响应的区域叫 receptive field。第一层的 receptive field 直接由权重布局决定，更高层的 receptive field 还取决于下层 receptive field 和 stride（课件 p.278-p.279）。
- [01:17:45] 末层输出通常不再保留二维图状排列，而会被拉直为向量送入后续决策器，这个重组动作叫 flattening（课件 p.280）。
- [01:17:58] 再谈 stride：默认步长是 1，所以输出图大小大致与输入相近；若 stride 大于 1，输出图会按 stride 缩小，计算量也下降（课件 p.281-p.282）。
- [01:19:02] 最后引出 pooling 处理 jitter。局部子模式轻微平移不应改变高层模式判断，因此可以在一个局部窗口里取 max 等聚合值，把“在这片区域里出现即可”编码出来；具体 pooling 细节留到下一讲（课件 p.283-p.284）。

## 概念、符号与推导
- [01:10:45] 计算复用的逻辑：相邻扫描窗口在底层覆盖区域上重叠，若这些区域的底层响应已算出，后续窗口可直接复用，无须从头前向传播。
- [01:13:07] 参数对比样例：非分布式 1034 个权重，分布式 194 个权重，用于说明节省可能接近一个数量级（课件 p.267）。
- [01:15:24] Poll 4 的否定项是“reduced memory requirement for intermediate variables during inference”，老师明确否认，因为中间变量仍需保留和计算（课件 p.270）。
- [01:16:55] Filter：单个扫描神经元或一组同类扫描单元共享的一套权重，用来检测其所在 map 上的某类模式（课件 p.278）。
- [01:17:07] Receptive field：某个神经元在原输入上“看到”的区域；对高层神经元而言，它由下层 receptive field 与 stride 递推放大（课件 p.279）。
- [01:17:45] Flattening：把末层矩形 maps 改排成向量后送入 softmax/MLP 的过程（课件 p.280）。
- [01:17:58] Stride：扫描步长。步长为 S 时，输出图沿相应轴按约 S 的因子缩小（课件 p.281-p.282）。
- [01:19:42] Pooling：对局部窗口输出做 max 或其他聚合，以获得对微小位移的鲁棒性；老师此处主要给出 max pooling 直觉，详细实现留到下一讲（课件 p.283-p.284）。
