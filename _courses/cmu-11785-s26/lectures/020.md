## 学习目标
这份总笔记要支持两层复习：第一层是按老师实际课堂顺序，完整把 transformer 从“为什么需要”到“如何搭起来”讲通；第二层是把老师最后快速扫过的现代改进压缩成结构化索引。学完后，应该能解释 RNN 为什么让位给 attention，能复述原始 transformer 的每个部件如何串联，也能辨认 T5、BERT、GPT、rotary、ALiBi、FlashAttention、KV caching 分别处在什么层面。

## 需要的先修知识
默认先修包括：RNN/encoder-decoder、embedding、softmax、矩阵乘法、梯度消失与爆炸、teacher forcing、sequence-to-sequence、next-token prediction、beam search 等。老师多次把 homework four 作为落点，因此还默认学生要把课堂概念落到 PyTorch 实现、维度变换和 attention 可视化 debug 上。

## 老师的教学主线
老师的叙事顺序非常清楚。开头先交代本讲覆盖范围，并说明本讲会直接服务 homework four。随后从经典 encoder-decoder RNN 出发，指出固定长度上下文导致信息瓶颈，远距离依赖需要 O(n) 顺序传播，且 GPU 无法充分并行。接着用早期 attention 说明：如果解码器当前步能直接访问全部编码器隐藏状态，就不必把整段序列压成一个固定向量；进一步，如果模型能保留整段表示再自行选择关注点，那么 recurrence 也许就不是序列建模的必要条件。之后课堂主线稳定推进：文本先做 tokenization，再由 embedding 映射到向量，再通过 positional encoding 注入顺序信息，然后进入 scaled dot-product attention、multi-head attention、masking、cross-attention、feed-forward、residual + layer norm 和输出投影，构成原始 transformer 的完整链条。最后 10 分钟老师快速回顾 self-attention 要点，转入现代变体与高效实现：三类架构、位置编码改进、FlashAttention、KV caching。尾声明确表示还有多模态、PEFT、量化等内容停留在 slides，没有口头展开。

## 核心概念与依赖关系
这讲的依赖结构可以压成一条链。最前面是问题定义：RNN 的固定长度摘要、长程依赖和顺序计算三重限制。attention 是第一层解法：用 query 对全部源端状态打分，再对 value 做加权和，让信息访问不再被最后一个隐藏状态卡死。transformer 则把 attention 升级成主导架构，但它需要新的输入端：tokenization 把原始文本变成离散 ID，embedding 把 ID 变成学习得到的向量。因为纯 attention 不保序，必须加入 positional encoding。此后 scaled dot-product attention 成为核心操作，多头机制让不同相关性模式并行建模，masking 保证编码器可双向、解码器可自回归，cross-attention 则把“被生成序列”和“条件输入”联结起来。attention 子层之后还要靠 feed-forward 增加非线性、靠 residual 和 layer norm 保住训练稳定性，最终由输出投影回到词表分布。现代综述的几条支线依附于这一主架构：T5/BERT/GPT 是结构或训练目标上的不同取舍；rotary/T5 bias/ALiBi 是位置编码层的改进；FlashAttention 和 KV caching 是同一注意力机制的高效实现。

## 关键推导、例子与结论边界
本讲真正需要记住的推导结论并不多，但都很关键。第一，RNN 中远距离 token 的通信路径长度是 O(n)，这既解释长程依赖难学，也解释梯度消失/爆炸风险。第二，scaled dot-product attention 里的 `1/sqrt(d_k)` 不是装饰：老师给出的理由是若 `Q,K` 近似零均值单位方差，点积方差会随 `d_k` 增大，softmax 输入过大时分布过尖、梯度变差。第三，multi-head attention 的实现本质是把总维度拆成 `h × d_h`，让多个 head 并行做同一个核心运算，再合并回来。第四，sinusoidal positional encoding 的口头可复述结论是“偶数维 sin、奇数维 cos、多频率、与 embedding 相加、固定偏移可线性关联”，但课堂 transcript 没逐字给出完整公式，因此不能擅自补写超出已读证据的项。例子方面，法译英的 encoder-decoder 图负责说明固定长度 context vector 的信息瓶颈；`the dog bit the man` 对比 `the man bit the dog` 说明无位置编码时 bag-of-words 化；语音到文本对齐图说明 attention map 可作为 debug 工具；视觉 cross-attention 图里的 “bear / watches / bird” 则帮助理解不同 query 会把注意力拉向不同区域。结论边界同样明确：WordPiece 背后的 likelihood 模型、GQA/MQA/MLA 的原理，以及 ViT、Conformer、PEFT、量化的细节，课堂中都没有被充分口述展开。

## 易错点与待核对项
最常见的混淆点有几组。第一，attention 不是只看最后一个编码器状态，而是让当前 query 对所有候选状态做分配。第二，softmax 前的缩放是 `sqrt(d_k)`，不是 `d_k`。第三，self-attention 与 cross-attention 的差别不是“有没有 encoder”，而是 Q、K、V 是否来自同一序列。第四，layer norm 是按 embedding 维规范化，不是按 batch 维。第五，课件里出现某个主题，并不等于老师已经在课堂上讲完该主题。需要标记为 [需回听] 或仅保留高层结论的地方主要有三处：一是 `[00:04:08]-[00:04:46]` 的 RNN 回顾字幕有缺口；二是 `[00:27:16]-[00:28:34]` 关于 WordPiece likelihood 的问答里老师自己说不完全确定；三是 sinusoidal positional encoding 的完整公式在 slide 上有，但 transcript 只保留口头总结。

## 掌握标准
复习完这讲，至少要能做到以下几件事。能从信息瓶颈、长程依赖和并行性三个角度解释 RNN 的局限。能按顺序说出 transformer 的主流程，不把 tokenization、embedding、position、attention、FFN、norm、output 搞乱。能解释为什么要用 softmax、为什么要除以 `sqrt(d_k)`、为什么需要多头、为什么 decoder 需要 causal mask。能区分 T5、BERT、GPT 三类代表系统的结构位置与训练目标。能说明 FlashAttention 改的是 IO 实现而不是 attention 数学定义，KV caching 改的是推理时是否重复计算历史 key/value。

### 00:00:00-00:09:58
作用：这一段先完成讲者交接和课程路线说明，再回到 RNN 时代的序列建模。老师明确本讲会从 RNN 的限制出发，讲 attention、vanilla transformer、现代变体、效率技巧、多模态应用和 fine-tuning，因此它是整讲的问题定义与目录页。

展开：老师先介绍代讲人 Guru 的身份、与课程的关系，以及他即将去做小语言模型和边缘部署相关工作的背景。随后他直接给出本讲路线：先回看 RNN 的局限，再讲 attention 和 2017 原始 transformer，然后再扫现代发展。进入正题后，他用法译英 encoder-decoder RNN 回顾大家熟悉的旧范式：每个时间步的隐藏状态依赖当前输入嵌入和前一时刻隐藏状态；编码器最后一个隐藏状态被当作固定长度 context vector；解码器基于这个向量和自身历史生成目标序列。老师马上指出这会形成信息瓶颈，短句翻译问题不大，但长段落中开头词对结尾词的影响会被过度压缩。接着又指出长程依赖需要穿过很长的顺序链路，梯度消失与爆炸仍会出现。最后再补充一个结构性问题：语言关系更像图，不像严格线性链，而 RNN 的顺序计算也让 GPU 并行能力发挥不出来。

概念：本段能确定的核心概念有三个。第一，RNN 在时间步 `t` 的隐藏状态依赖当前输入和前一隐藏状态。第二，编码器最后一个隐藏状态承担固定长度 context vector 的角色。第三，远距离 token 的通信路径长度是 `O(n)`，这为长程依赖困难提供了明确解释。老师还口头提到“124-dimensional embedding” 作为压缩过强的例子，但 transcript 没交代该数字来源，因此只能保留为课堂举例，不外推其配置来源。

例子与提示：法译英 encoder-decoder 图例服务于说明“最后一个隐藏状态压全部信息”这件事。老师用“4 个词翻 7 个词还好，长段落就危险”来解释瓶颈，用“word 1 和 word 100 之间需要 99 步”来解释 O(n) 路径长度，用 GPU 擅长并行而 RNN 迫使其顺序工作来解释硬件瓶颈。

掌握检查：为什么固定长度 context vector 会成为问题？答：它把整段信息压到一个向量里，长输入时会丢失远距信息。为什么 RNN 难学长程依赖？答：通信路径随序列长度线性增加，梯度易衰减或爆炸。为什么 RNN 不利于大规模训练？答：时间步存在顺序依赖，GPU 无法充分并行。

### 00:09:56-00:19:55
作用：这段把问题推进到 early attention 和 tokenization。前半段回答“attention 如何先缓解 RNN 的信息瓶颈”，后半段回答“transformer 的输入到底怎么开始处理”，因此是从动机跨到实现的桥。

展开：老师先说明，解码器当前时间步不必再只依赖编码器最后一个隐藏状态，而可以和全部源端隐藏状态做相似度比较，得到 attention distribution，再对所有源端隐藏状态做加权和，形成新的动态 context vector。这样每个目标端位置都能访问全部源端信息，固定长度摘要造成的信息衰减被缓解。老师进一步据此提出一个关键转折：如果模型能保留整段序列并自己决定哪些 token 更相关，那么 recurrence 可能并不是序列建模的必要条件。接着他引出 transformer，并先把看似复杂的结构图去魅为一条流水线：tokenization、embedding、位置编码、重复 attention 和 MLP、最后线性层映射到词表概率。随后正式进入 tokenization，说明模型不能直接处理纯文本，必须先把文本拆成可管理单元，再映射为整数 ID。字符级切分词表很小，几乎不会碰到 OOV，但序列会非常长，单字符语义也弱；词级切分语义更直接，但词表会很大，对未见词处理很差。

概念：这里 attention 的口头定义是：对当前解码步，用 attention 分布对全部源端隐藏状态做加权和，得到新的 context vector。tokenization 的定义是：把文本拆成若干单位并映射到唯一整数 ID。老师还点出了两个关键权衡：词表大小 vs 序列长度，语义完整度 vs 泛化/OOV 处理能力。本段没有给出矩阵级公式，只保留“distribution -> weighted sum -> dynamic context”的计算链。

例子与提示：课堂里最重要的直观例子是“某个目标端词高度依赖源端某个位置”，它说明 attention 不是平均看所有源端状态。字符级与词级切分的对比则是作业设计里要实际面对的取舍：字符级计算重、词级泛化弱。老师还提示，一旦 recurrence 不是硬约束，后面关于并行和架构设计的选择空间就被打开了。

掌握检查：early attention 相对固定长度 context vector 改了什么？答：它让当前解码步对所有编码器隐藏状态分配权重并做加权和。为什么这会让人怀疑 recurrence 的必要性？答：因为模型可以保留整段信息并动态检索，不再依赖沿时间轴传单个状态。字符级与词级 tokenization 的主要缺点各是什么？答：字符级序列太长且语义弱；词级词表太大且 OOV 差。

待核对：开头 `[00:09:56]-[00:10:00]` 承接上一段的字幕很碎，只能确认老师在继续解释 decoder 当前步与 encoder 各隐藏状态做 dot product 的思路。

### 00:19:53-00:29:02
作用：这一段是 transformer 输入端的细化实现，目的不是再讲“为什么切词”，而是讲“现代模型实际上怎么切词，以及各方法牺牲了什么”。

展开：老师先收束词级切分的问题：不同词形变化都要各占一个 token，未见词处理差，但词本身的语义又更完整。于是他引出主流子词方法。BPE 被描述为 Llama、Gemma、Qwen2 常用，也是作业要接触的方法。课堂问答里，老师先回答“token 的值怎么决定”：字符级和词级一般从训练集做字典，ID 是索引；BPE 这类方法则先给定目标词表大小，再从基础 token 集合出发迭代构造词表。随后老师按步骤解释 BPE：以 256 个 byte 值为起点，反复合并最常见的相邻 token 对，每次合并都生成新的 token ID，直到达到预设词表大小。接着是 unigram：与 BPE 相反，它从大子词池出发，持续剪掉最不有用的 10%-20% token，用与训练数据似然/损失相关的准则保留更优词表，还能在推理时为同一词采样不同切法，带来一定正则化效果。SentencePiece 的重点是显式把空格当作特殊 token，以避免只适合“按空格切词”的语言假设。WordPiece 被老师概括为一种更看重训练数据 likelihood 的底向上合并方案。最后老师提醒，工程实践里优先考虑 tokenizer 与上游模型/下游 pipeline 的兼容性，而不是只讨论理论优劣。

概念：BPE 的核心概念包括“256 byte 基础集合”“目标词表大小作为超参数”“按频率迭代合并 pair”。Unigram 的关键概念包括“从大词表出发”“通过损失/似然准则进行裁剪”“允许同词多切分作为正则化”。SentencePiece 的关键点是“把空格显式进词表”。WordPiece 的关键点是“比 BPE 更关心 likelihood 而非单纯频率”。老师没有给出这些方法的完整数学定义，只保留了足够做高层比较的口头结论。

例子与提示：`love / loving / loved` 的例子说明词级切分如何让词表迅速膨胀。中文、日文被老师用来说明“默认空格分词”为什么会失效。课堂提示还包括：token ID 本身不是语义值，只是词表索引；真正需要调的是方法、词表大小和与整个模型栈的兼容性。

掌握检查：BPE 怎样构造词表？答：从 256 byte 起步，持续合并最常见 pair，直到达到目标词表大小。unigram 与 BPE 的方向差异是什么？答：unigram 从大到小裁剪，BPE 从小到大合并。SentencePiece 解决什么语言问题？答：显式处理空格，因此更适合中文、日文等不可靠依赖空格的场景。

待核对：关于 WordPiece likelihood 的具体概率模型，老师在问答中表示自己不完全确定，所以只能记录为“比 BPE 更偏向 likelihood 的合并准则”，不能补充更细机制。[需回听]

<div id="section-04" class="course-note-section-anchor" aria-hidden="true">&nbsp;</div>

### 00:29:58-00:39:58
作用：这段从离散 token ID 迈向连续向量表示，再把“无序的 attention”补上“有序的句子结构”，因此是输入端到注意力端的最后准备。

展开：老师先公布上一题投票答案，强调字符级 tokenization 的缺点不是词表大，而是序列长度大。随后正式介绍 embedding：作业里最直接的实现是 `nn.Embedding`，它维护一个 `(vocab_size × embedding_dim)` 的可学习矩阵，每个 token ID 只是取其中一行。老师强调，虽然表面上只是查表，这个矩阵会随任务目标一起学，因此最终会在向量空间中形成有语义的几何结构。之后进入 positional encoding。老师指出，RNN 自带时间顺序，而 attention 本身对位置不敏感；不给位置时，`the dog bit the man` 与 `the man bit the dog` 会近乎等价。于是他列出位置编码的几项要求：位置唯一、可重复、可估距离、最好可外推到训练长度之外。然后介绍原始 transformer 的 sinusoidal positional encoding：偶数维使用正弦、奇数维使用余弦，不同维度对应不同频率，并与 embedding 直接相加，而不是拼接。老师给出的口头理由是，固定偏移后的编码能通过三角恒等式表示为原编码的线性函数，所以模型有机会更容易学到相对位置信息；但实际外推到远超训练长度的句子时，并不总是稳健。

概念：`nn.Embedding` 可被视为一个参数矩阵，token ID 通过索引选行。位置编码的要求包括唯一、确定、可估距离、可扩展。sinusoidal positional encoding 的确定结论是：偶数维用 sin，奇数维用 cos，频率随维度变化；位置向量与 embedding 相加，因此不改变 `d_model`。老师没有把完整公式逐字读出，只读到了结构和性质。

例子与提示：`the dog bit the man` 与 `the man bit the dog` 是本段最关键的反例，用来强调“无位置就无语法”。老师还提示，位置编码若是确定的，就可以预先计算并缓存。关于 embedding，他提醒学生不要只把它看成 ID 到向量的机械映射，而要理解它最终会形成任务相关的语义空间。

### 00:39:55-00:49:54
作用：这段一半在讲位置编码的“为什么真的能用”，一半在讲 attention 的“最小可实现核心操作”，因此它既解释输入表示，也定义核心算子。

展开：老师先继续讲位置编码的直观效果。他比较了位置 5 和位置 6、以及位置 6 和位置 80 在不同维度上的数值差异，指出不同频率让某些维度更擅长区分近距离位置，另一些维度更擅长区分远距离位置。于是模型相当于从多个尺度同时观察同一个位置。投票题也正是围绕这个结论展开：不同波长被分配给不同维度，是为了让模型在不同尺度上捕捉模式。随后老师进入 transformer 的核心操作 scaled dot-product attention。他先用数据库做 hard lookup 与 deep learning 做 soft lookup 的对比，帮助学生理解 QKV：传统数据库查到一个精确 key 就取一个值，而 attention 是根据 query 与各 key 的相关性给 value 做加权平均，并用 softmax 保证权重有界且可解释。接着老师说明 self-attention 中的 Q、K、V 都来自输入 `X` 本身的线性投影。忽略 batch 时，`Q` 与 `K` 可理解为 `L × d_model`，先做 `QK^T` 得到相似度矩阵，再 softmax，再与 `V` 相乘得到输出。法英翻译中的注意力图被用来说明：当实现正确时，attention map 往往有可解释结构，这一点对 homework four 的调试很重要。

概念：本段可明确保留的定义包括：soft lookup、QKV 均由输入线性仿射而来、softmax 把相似度分数变成每个 query 下和为 1 的权重分布。位置编码的多尺度作用也被具体化为“如果一个维度区分不了位置，其他维度仍可能提供信号”。老师没有在本段给出 `sqrt(d_k)` 的解释，而是预告后面说明。

例子与提示：位置 5/6 和 6/80 的例子是这段理解多频率 positional encoding 的关键。数据库 hard lookup vs attention soft lookup 的类比则帮助学生把抽象矩阵乘法转回熟悉的查询检索直觉。作业提示也很明确：看 attention map 是否有合理结构，是最实用的 debug 手段之一。

掌握检查：不同波长为何分配到不同维度？答：为了让模型在不同尺度分辨位置。scaled dot-product attention 的输入和输出逻辑是什么？答：用 query 与 key 计算相似度，经 softmax 得到权重，再对 value 做加权和。self-attention 里的 Q、K、V 从哪里来？答：都来自输入 `X` 的线性投影。

### 00:49:52-00:59:51
作用：这一段把 attention 从“知道它在做什么”推进到“知道它为什么这样设计、怎么扩到多头、怎么保证自回归训练不作弊”，属于最核心的实现段。

展开：老师先从语音识别例子出发解释 attention map 的调试价值：语音片段和文字 token 不是一一对应，但若模型正确，整体仍应呈现大体顺序对齐；如果完全看不出这种趋势，说明模型可能有 bug。随后老师回答“为什么 dot product 还不够”：在 `Q、K` 近似零均值单位方差时，点积的方差会随 `d_k` 增大，softmax 的输入容易变得过大或过小，从而进入梯度不友好的区域，所以需要除以 `sqrt(d_k)`。然后老师引出 multi-head attention。单头只提供一种相似度视角，而不同 head 可以建模不同关系，因此把总维度拆成 `h × d_h`，各自做投影和 scaled dot-product attention，再把所有 head 的输出拼接并过一层输出投影。老师也口头拆解了实现流程：从 `(B,L,D_k)` reshape 为 `(B,L,h,D_h)`，再转成 `(B,h,L,D_h)`，各 head 并行做 attention，之后转回并合并维度。接下来是 masking：编码器侧没有“偷看未来”的问题，因此通常是双向注意力；解码器侧要做自回归生成和 teacher forcing 训练，所以必须施加 causal mask，确保当前位置只能访问当前位置及其之前。最后老师开始过渡到 self-attention 和 cross-attention 的差别，为下一段铺路。

概念：这里有四个必须记住的概念。第一，`1/sqrt(d_k)` 用于防止 softmax 饱和并改善梯度。第二，multi-head attention 的维度关系是 `D_k = h × D_h`。第三，核心张量流是 `(B,L,D_k) -> (B,L,h,D_h) -> (B,h,L,D_h)`，计算后再转回。第四，mask 分为双向无因果约束和 decoder 侧的 causal mask。本段没有给出比这些更完整的数学证明。

例子与提示：语音到文本的对齐图是最重要的例子，它告诉学生 attention 图不一定是一一对齐，但大体的顺序感应该在。老师还给出工程提示：实现多头时，不一定真要给每个 head 单独写一组线性层，也可以用一次大线性层后 reshape/split 达到等价效果。

掌握检查：为什么要除以 `sqrt(d_k)`？答：因为点积方差随维度增大，softmax 会变得过尖、梯度变差。multi-head attention 的动机是什么？答：让不同 head 学习不同关系。为什么 decoder 需要 causal mask？答：防止训练和生成时偷看未来 token。

### 00:59:49-01:09:46
作用：这一段完成原始 transformer 架构的最后一块，把 cross-attention、FFN、残差归一化、输出层与 pre/post norm 的差别全部拼起来，使前半讲闭环。

展开：老师先正式定义 cross-attention：self-attention 的 QKV 都来自同一序列，而 cross-attention 的 query 来自解码器，key/value 来自编码器输出，用于条件生成。结合 slide p.64 的视觉例子，老师说明 query 文本 “a furry bear watches a bird” 会让注意力在“bear”“watches”“bird”三个词上落到不同图像区域，从而体现条件查询的选择性。随后进入 feed-forward block，老师强调它“就是一个 MLP”，原始模型通常把维度从 `d_model` 扩到 `4 × d_model`，经过非线性后再压回原维，用额外非线性提升建模能力。然后是 add & norm：每个子层外都有残差连接和 layer norm；layer norm 按 embedding 维度做均值方差规范化，以提升训练稳定性。接着老师区分 pre-norm 和 post-norm，说明作业会采用 pre-norm，因为课程实验里它更容易训练，而 post-norm 往往需要更精细地调学习率和 warm-up。最后，老师用输出层把整个架构收束起来：在 next-token prediction 中，需再接线性层把 `d_model` 投影到词表空间，经 softmax 得到词表分布，并把最后时间步向量解释成下一个 token 的条件概率。解码时可用 greedy、beam search、top-k、top-p 等方法。

概念：本段需要记住的结构定义包括：cross-attention 中 `Q` 来自 decoder，`K,V` 来自 encoder；FFN 的典型宽度变化是 `d_model -> 4d_model -> d_model`；layer norm 沿 embedding 维统计；pre-norm 与 post-norm 的区别只在 norm 相对残差与子层的位置不同；输出投影负责把隐藏状态映射回词表空间。本段无额外严格公式，但 slide p.63-p.72 明确给出了这些模块的结构位置。

例子与提示：视觉例子里 “bear / watches / bird” 三个词关注的图像区域不同，是理解 cross-attention 的最好直观图。老师给出的训练提示也值得记：pre-norm 不是更“正确”，而是更好训；post-norm 也能成功，只是更依赖正确的超参数设置。

掌握检查：cross-attention 与 self-attention 的核心区别是什么？答：QKV 是否来自同一序列。为什么 FFN 要扩到四倍维度？答：为了增加非线性与建模容量。为什么作业选择 pre-norm？答：因为它更稳定、较少超参数脆弱性。

### 01:09:45-01:19:44
作用：这一段是从“原始 transformer 怎么工作”转向“后来大家怎么改它”。课堂结构上，它是现代综述的主段。

展开：老师先复盘自测题，确认 self-attention 的三个正确点：无位置编码时 attention 对排列不敏感、softmax 前应按 `sqrt(d)` 缩放、QKV 是输入 `X` 的仿射变换；错误项是“按 d 本身缩放”。随后他快速扫过三类架构。encoder-decoder 适合条件生成，如 text-to-text、翻译、语音到文本；T5 是典型代表，可通过 prompt 中的 task token 决定当前任务。encoder-only 以 BERT 为代表，主要目的是通过 masked token prediction 与 next sentence prediction 预训练出可迁移的语义表示，再拿去做下游任务。decoder-only 以 GPT 为代表，训练目标就是 next-token prediction；大语言模型则是在数据规模、模态和工具能力上不断把这一范式放大。接着老师转入位置编码改进，指出 sinusoidal encoding 对训练分布之外的长序列外推并不理想，于是出现了 rotary、T5 bias、ALiBi 等方案。它们的共同点是未必直接把位置向量加到输入上，而是通过修改 attention 内部的 query、key、value 或 bias 来引入位置信息。最后老师讲 attention 的效率问题：尽管 attention 易于并行，但复杂度依旧对序列长度呈二次增长。FlashAttention 是典型改进，它不改变 attention 的数学结果，而是通过 tiled computation、online softmax 和更少的慢速内存访问，把更多数据交换留在 GPU SRAM，从而获得大约 `2.8×` 的速度提升。段尾引出 KV caching：在自回归推理中，不必每一步都重算全部历史 key/value，而是缓存历史，仅对新时间步增量计算。

概念：这一段的框架型知识很多。结构上有三类 transformer：encoder-decoder、encoder-only、decoder-only。训练目标上，BERT 依赖 masked token prediction 和 next sentence prediction，GPT 依赖 next-token prediction。位置编码改进层面，老师只确认了 rotary、T5 bias、ALiBi 等名字，以及它们通过 attention 内部修改而非简单“加到输入”来增强长度外推。高效注意力层面，FlashAttention 的关键是 IO-aware、tiled、online softmax、数学等价；KV caching 的关键是复用历史 key/value 减少重复计算。

例子与提示：T5、BERT、GPT 被老师用作三类架构最重要的代表。课堂里还有两个工程提示：一是 FlashAttention 改的是实现方式，不是改目标函数；二是 KV caching 是作业或推理实践里很值得直接尝试的优化。slide p.76、p.84、p.90 列出了 GQA、MQA、MLA，但老师没有口头展开，所以不能补讲其原理或优缺点。
