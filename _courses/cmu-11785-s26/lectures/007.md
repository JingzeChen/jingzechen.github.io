## 学习目标
- 重新建立“backprop 负责算导数，gradient descent 负责更新参数”的训练框架。
- 理解为什么最小化可微 proxy loss 不保证最小化 classification error。
- 理解大型网络 loss surface 中 saddle point、local minima 与收敛问题的关系。
- 掌握一维/二维二次函数下学习率与收敛、振荡、发散之间的关系。
- 理解 decaying learning rate、Rprop、momentum 与 Nesterov acceleration 的直觉和适用边界。

## 需要的先修知识
- 多层感知机的前向传播与反向传播。
- 向量求导、Jacobian、链式法则。
- 梯度下降基本形式与学习率含义。
- 一元二次函数、Taylor 展开、局部二阶近似。
- 凸函数、凸集、鞍点的基本几何直觉。

## 老师的教学主线
- 先回顾训练算法与导数来源，确保所有人站在同一个符号起点上。
- 再说明“训练目标的可优化替身”与“真正任务目标”之间可能错位。
- 然后把问题转到 loss surface 与收敛性：即便目标设置没错，梯度下降也可能因曲率差异而缓慢、振荡或发散。
- 接下来给出几种改进思路：先是学习率衰减，再是 per-dimension heuristic，最后是历史趋势法。
- 最后以 momentum / Nesterov 收束本讲，并把 stochastic / incremental updates 与 generalization 留给后续课程。

## 核心概念与依赖关系
- backpropagation：计算 loss 对各参数的导数；它服务于梯度下降，而不是替代梯度下降。
- divergence / proxy loss：为了可微而引入的替代目标；它与 classification error 有关，但不等价。
- bias-variance：解释为什么“不完全贴训练集”的 proxy 解有时反而更稳。
- loss surface：决定训练会遇到 global optimum、local minima 还是 saddle points。
- convex analysis：为研究收敛速度和学习率阈值提供可分析模板。
- learning rate schedule：在探索与收敛之间折中。
- Rprop：按导数符号调节各维步长。
- momentum：按历史梯度步平均，抑制振荡方向。
- Nesterov acceleration：先 look-ahead 再修正的更快趋势法。

## 关键推导、例子与结论边界
- 关键推导 1：对一维二次函数 \(E(w)=\frac{1}{2}aw^2+bw+c\) 在 \(w_k\) 处做 Taylor 展开，得到 \(w^*=w_k-[E''(w_k)]^{-1}E'(w_k)\)，从而读出最优步长是二阶导的逆。
- 关键推导 2：一维下学习率若小于两倍最优步长则收敛，等于两倍则振荡，大于两倍则发散。
- 关键推导 3：running average 的递推 \(\bar x_{k+1}=\frac{k}{k+1}\bar x_k+\frac{1}{k+1}x_{k+1}\)，迁移为 momentum 的历史步更新思想。
- 关键例子 1：大量“安全区域”样本会主导 divergence，使 proxy optimum 偏离真正分类边界。
- 关键例子 2：加入一个 spoiler 点后，perceptron 会显著改边界，而 backprop proxy 解可能只轻微移动。
- 关键例子 3：二维椭圆等高线揭示不同方向最优步长不同，统一学习率无法同时最优。
- 结论边界 1：本讲大量收敛推导建立在 convex / quadratic 近似之上，老师明确承认深网真实 loss surface 一般并不凸。
- 结论边界 2：momentum 并非在所有函数上都更快；对 constant slope function，它没有额外收益。

## 易错点与待核对项
- 易错点：把 backprop 和 gradient descent 当成同一个东西。前者负责求导，后者负责更新。
- 易错点：把最小化 divergence 误当成最小化 classification error。
- 易错点：以为“会发散的大学习率”一定不好；本讲强调前期适度逃逸可能有益。
- 易错点：以为给每一维不同 learning rate 仍然叫标准 gradient descent；老师明确否定。
- 易错点：以为 momentum 必然更快；constant slope 是反例。
- 待核对项：section 004 中 ASR 对 prime / double prime 多有混淆，若要精确复核公式，应回听原音。
- 待核对项：Quickprop 发明者与 Nesterov 的拼写需统一，以免沿用 ASR 误拼。

## 掌握标准
- 能口头复述本讲为什么要用 proxy loss，以及 proxy 与 classification error 为何不等价。
- 能说明 saddle point 与 local minimum 的差异，并解释它们为何会影响训练。
- 能从一维二次函数推导出最优步长与“2 倍阈值”结论。
- 能解释为什么多维情形下统一学习率会导致慢收敛或发散。
- 能比较 decaying learning rate、Rprop、momentum、Nesterov 各自利用了什么信息来改善训练。

## 本段在整讲中的作用
这一段先把前几讲已经建立的训练框架重新压紧：神经网络为什么能学、训练目标是什么、梯度从哪里来、一次完整训练迭代如何组织。它不是进入新主题，而是在正式讨论“backprop 是否总是有效、如何收敛”之前，把后面所有论证都要依赖的符号、算法顺序和导数来源重申一遍（参见课件 p.1-p.6）。

## 教学展开
- [00:01:22] 老师先点名回顾上节课内容，学生回答“向量求导、反向传播”，老师随即追问：反向传播是拿来做什么的。结论是：它用来计算梯度，而梯度会被梯度下降用于更新参数。
- [00:01:58] 接着老师用“story so far”重新串起训练问题：神经网络是通用逼近器，但前提是结构合适；训练时要先指定 architecture，再学习 weights 和 biases；训练目标是最小化训练集上的总 loss，也就是经验风险最小化（课件 p.2）。
- [00:02:36] 老师把总体训练流程说成一个函数最小化问题：给定训练数据，定义总训练误差为“网络实际输出与目标输出之间 divergence 的平均值”，它是所有网络参数的函数；梯度下降从初始化参数开始，反复求 loss 对参数的导数，再沿梯度反方向走，直到 loss 不再下降（课件 p.3-p.4）。
- [00:03:11] 然后进入上节课的向量化推导回顾。老师强调：要计算导数，必须先做 forward pass，把中间变量全部算出来；随后再从输出端一路 backward，逐层把导数传回去。
- [00:03:45] 在前向传播里，每一层先算 affine term，再施加 activation。老师口头描述的是：上一层输出乘本层权重矩阵，再加上偏置，得到本层的 affine quantity；再对它施加激活函数，得到该层输出（课件 p.5）。
- [00:04:33] 老师随后把依赖关系画成 influence diagram：上一层输出影响当前层的 affine term，当前层 affine term 再影响当前层输出。沿边的导数分别是“对上一层输出的导数等于权重矩阵”和“对 affine term 的导数等于激活函数的 Jacobian”（课件 p.5）。
- [00:05:53] 反向传播的顺序据此确定：如果已知 divergence 对当前层输出的导数，就先右乘 activation 的 Jacobian 得到对 affine term 的导数；再右乘权重矩阵，把导数继续传回前一层输出。
- [00:06:41] 老师特别点出两个参数导数结论：对 biases 的导数就是对该层 affine term 的导数；对 weights 的导数则由“边的输入”与“边输出处的导数”相乘得到。这里的输入是上一层输出，边输出处对应当前层 affine term（课件 p.6）。
- [00:07:19] 最后老师把完整训练算法重新过一遍：初始化所有权重与偏置；前向计算网络输出和 divergence；反向逐层计算中间变量及参数导数；把每个参数在训练集上的导数做平均，得到总 loss 对该参数的导数，再交给梯度下降更新（课件 p.6）。
- [00:08:01] 随后用 Poll 0 检查学生是否记得权重导数公式，并在 [00:09:05] 给出答案：权重导数等于该边的输入乘该边输出端的导数，这个问题答对之后，本讲正式切换到“backprop 是否总是做对的事”。

## 概念、符号与推导
- 神经网络训练目标：最小化训练集上的 total loss，即训练样本上“实际输出与目标输出 divergence 的平均值”（[00:02:36]；课件 p.2, p.4）。
- 参数集合：所有层的 weights 与 biases（[00:02:51]）。
- 梯度下降更新思想：先求 loss 对参数的导数，再沿梯度反方向更新（[00:02:56]-[00:03:08]；课件 p.3）。
- 前向传播层内两步：
  1. 计算 affine term：由上一层输出、当前层权重矩阵和偏置得到（[00:03:45]-[00:04:18]）。
  2. 施加 activation，得到当前层输出（[00:04:18]-[00:04:21]）。
- 依赖链：\(y^{k-1} \to z^k \to y^k\)（口头符号来自 transcript；课件 p.5）。
- 边上导数：
  1. \(\partial z^k / \partial y^{k-1}\) 是权重矩阵（[00:04:33]-[00:04:49]）。
  2. \(\partial y^k / \partial z^k\) 是激活函数的 Jacobian（[00:05:01]-[00:05:12]）。
- 反向传播递推：
  1. 已知 divergence 对 \(y^k\) 的导数时，右乘 activation 的 Jacobian，得到对 \(z^k\) 的导数（[00:05:53]-[00:06:11]）。
  2. 再由对 \(z^k\) 的导数右乘权重矩阵，得到对 \(y^{k-1}\) 的导数（[00:06:13]-[00:06:33]）。
- 参数导数：
  1. 对 bias 的导数就是对 \(z\) 的导数（[00:06:41]-[00:06:48]）。
  2. 对 weight 的导数是“输入乘输出端导数”，即上一层输出乘当前层 affine term 处的导数（[00:06:51]-[00:07:05]；课件 p.6）。
- 本段无新的长公式推导，重点是把前一讲推导结果重新按训练算法顺序串起来。

## 例子与课堂提示

- [00:03:11] “先 forward 再 backward”的提醒服务于理解为什么中间变量必须先算出来，否则后向链式法则没有可用的局部导数。
- [00:04:33] influence diagram 的画法服务于把 Jacobian、权重矩阵和链式法则的乘法顺序对应起来，避免只记公式不知来源。

## 本段掌握检查
1. 问：老师为什么说 backpropagation 不是直接用来“训练”，而是用来“计算梯度”？答：因为参数更新真正使用的是梯度下降；backprop 的职责是算出 loss 对网络参数的导数，再把这些导数交给梯度下降使用。
2. 问：本讲开头对神经网络训练问题的标准表述是什么？答：先指定网络结构，再学习 weights 和 biases，使训练集上的总 loss，也就是实际输出与目标输出 divergence 的平均值，尽可能小。
3. 问：为什么必须先做 forward pass 才能做 backward pass？答：因为 backward 需要用到各层中间变量以及每条边的局部导数，这些量都要在 forward 中先算出来。
4. 问：在老师的符号里，\(y^{k-1} \to z^k \to y^k\) 这条链上两个关键局部导数分别是什么？答：\(\partial z^k / \partial y^{k-1}\) 是权重矩阵，\(\partial y^k / \partial z^k\) 是激活函数的 Jacobian。
5. 问：对 weights 和 biases 的导数分别怎样得到？答：对 bias 的导数就是对该层 affine term 的导数；对 weight 的导数是该边输入乘该边输出端的导数，也就是上一层输出乘当前层 affine term 处的导数。

### 002 00:10:02-00:20:02

片段：00:10:02-00:20:02

## 本段在整讲中的作用
这一段提出本讲第一个核心问题：即便梯度下降真的把可微 proxy loss 降到了最小，它是不是就找到了真正想要的分类器？老师先把“backprop”口头上扩展成“用 backprop 算梯度的梯度下降训练”，然后用阈值激活与平滑激活的对比，把“proxy loss 只是替身目标”这一层风险讲清楚。

## 教学展开
- [00:10:02] 老师先澄清术语：严格说 backprop 只是“计算导数的算法”，但课堂上后面会用它指代“用 backprop 算梯度再做梯度下降的整体训练过程”。
- [00:10:24] 接着老师抛出今天要回答的问题：这种训练是否总能做对的事、如何收敛、收敛速度怎样、有哪些限制，以及后面如何加速。
- [00:10:55] 第一问是“它是否总是 right”。老师把问题具体化为：假设你真的通过 backprop 算到梯度，并且梯度下降真的找到了 divergence function 的最小值，这个最小值就一定对应你真正想要的分类解吗？
- [00:11:21] 老师先回到阈值分类器的老图：红蓝两类的最优 threshold 本应在某个位置，但如果用 hard threshold activation，稍微左右挪动分界线，并不会告诉你分类误差有没有变化，因此你没法判断更新方向是否正确。
- [00:12:24] 为了得到可优化的方向信息，之前的做法是把 hard threshold 换成 smooth function，并且不再数误分类个数，而是累计 target output 和 actual output 之间的总距离。老师指出，在这种 surrogate 下，把函数向左移动时，总距离减小，于是梯度会提示“继续往左”。
- [00:13:05] 老师立刻追问：这看上去像是在做对的事，但是否每次都保证正确？
- [00:13:32] 反例随之给出：如果安全区域里有“5 trillion”那么多蓝点，虽然每个点到平滑函数的距离都非常小，但因为数量巨大，总和仍可非常可观。于是这些“本来已经安全”的点会共同推动函数继续向右，以便它们自己的微小距离再减一点。
- [00:14:36] 这时 proxy objective 会把分类边界推到“entirely wrong”的位置。也就是说，数据明明仍然可分，但由于优化的是“总距离”而不是“分类错误数”，训练会偏好一个错误分类器。
- [00:15:01] 老师据此总结：当前误差项只是我们真正目标 classification error 的 proxy。它确实让优化变得可行，但如果训练数据分布不合适，proxy 的真最小值会把分类器推向错误解。
- [00:16:15] 接着老师将结论说得更正式：在分类问题里，classification error 对权重是不可微的；我们真正优化的 divergence 只是其替身，因此“最小化 divergence”并不推出“最小化 classification error”。
- [00:16:30] 为了把这个逻辑固定下来，老师用单个 perceptron 做更具体的线性可分例子：原始两类数据线性可分时，感知机规则与 proxy loss 方法都可能找到相同边界。
- [00:17:20] 但只要再加一个“spoiler”红点，即使两类仍然线性可分，感知机规则仍会找到真正分开的边界；而 proxy loss 下，这个单独红点对总 loss 的贡献太小，只会让原边界轻微移动，而不是翻到真正分开的解。

## 概念、符号与推导
- 术语约定：本段里老师将 “backprop” 口头上扩展为“用 backprop 计算梯度的梯度下降训练过程”（[00:10:02]-[00:10:21]）。
- 真正目标：classification error，即误分类数最少的分类器（[00:11:53]-[00:12:06]）。
- 代理目标：target output 与 actual output 之间的 total distance / divergence（[00:12:24]-[00:12:41]）。
- 阈值激活的问题：分类错误是分段不变的，稍微移动阈值不一定改变 error，因此不能提供“应该往哪边动”的信息（[00:11:21]-[00:11:50]）。
- 平滑激活的作用：把不可微的分类错误替换成随参数连续变化的 divergence，从而让“向左还是向右”可由误差变化判断（[00:12:24]-[00:13:03]）。
- 关键逻辑链：
  1. classification error 对权重不可微（[00:16:15]-[00:16:20]）；
  2. 训练实际优化的是可微 divergence（[00:16:20]-[00:16:24]）；
  3. divergence 只是 proxy（[00:15:08]-[00:15:16]）；
  4. 所以最小化 divergence 不保证最小化 classification error（[00:15:53]-[00:16:28]）。
- 本段无公式推导，核心是目标函数之间的不等价性证明思路：通过 counterexample 说明 proxy optimum 可与分类 optimum 分离。

## 例子与课堂提示

- [00:14:36] 老师把这些样本更正为“不是 rubbish，而是 training points”，提醒学生问题不在于样本无效，而在于 objective 的偏好与任务目标不一致。

- [00:18:18] 老师反复改变 spoiler 的位置，提醒学生不要把这个现象误解成某个特殊点位的巧合；只要新样本对总 divergence 影响太小，这种错配都可能发生。

## 本段在整讲中的作用
这一段把上一段“proxy 最优不等于分类最优”的坏消息，再推进一层：坏消息未必全坏。老师引入 bias-variance 视角，解释为什么 backprop 找到的解虽然偏，但可能更稳定；随后从“全局最优也未必对”自然转到“loss surface 本身也可能很难”，为后面的收敛分析起桥。

## 教学展开
- [00:19:59] 老师让学生比较两条边界：感知机找到的蓝线会因加一个点而大幅摆动，而 backprop 对应的红线变化不大。问题是：这种“不怎么变”的行为是好还是坏？
- [00:20:21] 老师的答案是“通常是 desirable”。原因不是红线更接近训练集上的完美分离，而是感知机虽然 low bias，能在可分时做到零训练误差，但它 high variance，只要加一个训练点，解就可能彻底变掉。
- [00:20:45] 相比之下，backprop-based rule“prefers consistency over perfection”。它不容易因为一两个样本就完全改写答案，因此是低方差估计器。老师把这解释为：虽然它不一定找到“right solution”，在很多场景里却可能比训练误差最低的那个解更好。
- [00:21:22] 随后老师把论证从单 perceptron 推广到需要复杂边界的 MLP。即便真实边界是非线性的，MLP 也可能学到一个稍有偏差但变化平稳的边界；加入单个 spoiler 时，它不会为了完美拟合这个点而 wildly 去追一个形状剧变的边界。
- [00:22:22] 老师因此明确给出一句总结：backpropagation 往往不会找到 separating solution，哪怕这个解在网络可表示的函数类里，因为该分离解不是当前 loss function 的可行最优解；但换来的好处是 trained classifier 具有更低的 variance。
- [00:22:48] 然后老师用 Poll 1 检查学生是否掌握“最小化可微 loss 并不必然最小化分类误差”。在 [00:23:51] 他让学生回答并解释：这一命题是 false。

- [00:24:47] 接着他指出现实中还会有 local minima；gradient descent 可能落到很多不同的极小值里。
- [00:25:01] 关于大型网络的 loss surface，老师说“很多数学工作”表明：比起真正的 local minima，更常见的可能是 saddle points。鞍点的定义是：一个方向上下降，另一个方向上上升，但梯度仍可能为零。
- [00:25:23] 他又补充：在大网络里，local minima 往往彼此差不多，函数值很接近；这个说法对 large networks 比较成立，但对 small networks 不一定成立。
- [00:25:54] 到这里老师给出阶段性总结：神经网络能通过 gradient descent 训练，backprop 提供导数；但梯度下降不保证找到 true solution，因为 loss optimum 可能不是真正分类解；另外 loss function 还可能有大量 unpleasant saddle points 或 local minima。

- [00:27:13] 由于 MLP 难以直接分析，老师决定借 convex optimization 的视角入手，并用“street light effect”解释这种方法论：先分析能看清楚的凸问题，再把经验迁移回看不清的深网训练。
- [00:27:50] 于是本段最后定义了 convex surface 与 convex set：若任取两点连线都位于曲面之上，则曲面是凸的；若集合内任取两点连线都仍落在集合内，则集合是凸集。老师说明之后就要在“凸函数 + 凸集”的环境下做收敛分析。

## 概念、符号与推导
- low bias / high variance：感知机在可分时倾向于零训练误差，因此 bias 低；但加入少量训练点即可让解大变，因此 variance 高（[00:20:27]-[00:20:43]）。
- low variance estimator：backprop-based rule 不容易因一两个样本彻底改变解，因此方差更低（[00:20:45]-[00:20:58]）。
- saddle point 定义：一个方向上函数下降、另一个方向上函数上升，但该点梯度可以为零（[00:25:11]-[00:25:20]；课件 p.37）。
- large network 上的经验性结论：
  1. saddle points 可能比 local minima 更常见（[00:25:01]-[00:25:11]；课件 p.37-p.38）；
  2. 多数 local minima 彼此值接近，近似等价（[00:25:23]-[00:25:39]；课件 p.37-p.38）；
  3. 上述结论对小网络未必成立（[00:25:39]-[00:25:41]）。
- convex surface 的几何定义：任取曲面上两点，连线都位于曲面之上（[00:27:50]-[00:28:20]；课件 p.42）。
- convex set 的定义：任取集合中两点，连线的所有点都仍在集合内（[00:28:35]-[00:28:54]）。
- 本段无公式推导，重点是概念切换：从 bias-variance 解释过渡到 loss surface 与 convex analysis 的准备。

## 本段在整讲中的作用

## 教学展开
- [00:29:54] 老师说，为了研究何时收敛，先看“最美的凸函数”二次函数。它离最优点远时够陡，靠近最优点时又不会太平，也不会太尖锐，因此最适合作为分析模板。
- [00:30:15] 他顺便拿 \(x^4\) 做对照：这种函数在最小值附近更平、远处更陡，会让梯度下降走得很慢，因此不是理想分析对象。
- [00:30:32] 然后老师写出一维二次目标：\(E(w)=\frac{1}{2}aw^2+bw+c\)。前面的 \(\frac{1}{2}\) 只是为了后面求导方便。
- [00:30:58] 他先提醒，求二次函数最小值既可以直接解方程，也可以做 gradient descent；但课堂真正关心的是：如果用迭代法，什么步长能在最少步数内到达最优点？
- [00:32:26] 为回答这个问题，老师先回顾 Taylor series。围绕某个点 \(x_0\) 的函数展开是常数项、一阶项、二阶项再加更高阶项的和。
- [00:33:40] 接着他把展开中心换成当前迭代点 \(w_k\)。由于目标本身是 quadratic，没有三阶及以上导数，所以 Taylor 展开在二阶就截断，不是近似而是精确表达。
- [00:34:07] 因而可写成：\(E(w)=E(w_k)+E'(w_k)(w-w_k)+\frac{1}{2}E''(w_k)(w-w_k)^2\)。老师随后指出这里二阶导就是常数 \(a\)。
- [00:35:38] 对这个式子对 \(w\) 求导并令其为零，得到一阶最优条件：\(E'(w_k)+E''(w_k)(w-w_k)=0\)。
- [00:36:36] 再把二阶导逆过去，老师解出最优点：\(w^*=w_k-[E''(w_k)]^{-1}E'(w_k)\)。
- [00:37:46] 老师随后把它与标准梯度下降迭代形式对比，指出如果学习率恰好取为二阶导的逆，也就是这里的 \(a^{-1}\)，那么从当前点到最优点只需一步。
- [00:39:01] 本段尾声再次浓缩为一句：把目标在当前点写成二次形式后，最优一步长就是 second derivative 的 inverse；这正是后续收敛阈值分析的出发点。

## 概念、符号与推导
- 理想目标函数：
  \[
  E(w)=\frac{1}{2}aw^2+bw+c
  \]
  其中前面的 \(\frac{1}{2}\) 只是求导方便（[00:30:32]-[00:30:55]）。
- Taylor 展开回顾：
  \[
  f(x)=f(x_0)+f'(x_0)(x-x_0)+\frac{1}{2}f''(x_0)(x-x_0)^2+\frac{1}{6}f'''(x_0)(x-x_0)^3+\cdots
  \]
  （[00:32:33]-[00:33:26]）。
- 对二次函数在 \(w_k\) 处展开时，高于二阶的项全部消失，因此有
  \[
  E(w)=E(w_k)+E'(w_k)(w-w_k)+\frac{1}{2}E''(w_k)(w-w_k)^2
  \]
  （[00:33:40]-[00:34:48]）。
- 二次函数的导数性质：
  \[
  E'(w)=aw+b,\qquad E''(w)=a
  \]
  （[00:34:54]-[00:35:17]）。
- 对展开式求导并令零：
  \[
  E'(w_k)+E''(w_k)(w-w_k)=0
  \]
  （[00:35:38]-[00:36:31]）。
- 解出最优点：
  \[
  w^*=w_k-[E''(w_k)]^{-1}E'(w_k)
  \]
  （[00:36:36]-[00:37:33]）。
- 与梯度下降对比得到最优固定步长：
  \[
  \eta_{\mathrm{opt}}=[E''(w_k)]^{-1}=a^{-1}
  \]
  用此步长可以一步到达最优点（[00:37:46]-[00:38:49]）。

## 例子与课堂提示

## 本段在整讲中的作用

## 教学展开

- decaying learning rate 的课堂写法：
  1. \(\eta_k=\eta_0/(k-1)\)；
  2. \(\eta_k=\eta_0/(k-1)^2\)；

### 007 00:59:44-01:09:42

## 本段在整讲中的作用
这一段从“为什么不能精确做每方向二阶步长”转向第一个实用替代法 Rprop。老师不再追求严格沿梯度或严格用 Hessian，而是只利用导数符号去自适应放大、缩小各坐标步长，并借此说明“用趋势信息代替精确曲率”可以更快、更稳。

## 教学展开
- [00:59:44] 老师先承上启下：既然显式计算每个方向的二阶信息太贵，就要找“some other solutions”，即使用导数信息但不完全追随导数的算法。
- [01:00:00] 他点名两类 slide 上的方法：Rprop 和 Quickprop，并说明它们不是严格 derivative-based，而是 derivative-inspired。当前重点先讲 Rprop。
- [01:00:10] Rprop 全称 resilient propagation。它的核心思想是：每个分量各自维护步长，只看该分量当前导数与上一轮导数的符号关系。
- [01:00:21] 若当前导数与上一次导数同号，说明前进方向一致、仍在朝正确方向走，于是把该分量步长乘上一个放大因子 \(\alpha\)。
- [01:00:32] 若导数符号翻转，则说明刚刚 overshoot 了一个 minimum，于是要回退、缩小步长，并反向更新。老师口头说是按因子 \(\beta\) 缩小。
- [01:00:41] 为了让规则更直观，老师画了一维图：起点处导数为负，所以向前走；下一点导数仍为负，表示方向正确，于是把步长乘 \(\alpha\) 继续加大；若还是负，再乘 \(\alpha\) 继续放大。
- [01:01:36] 这样不断鼓励前进后，迟早会某一步跨过最小值。跨过后导数改号，这就触发“回去、缩小、再走”的机制。
- [01:02:12] 老师强调：整个算法非常简单，只是对每个方向单独追踪一个步长而已。但由于大步有时会跳出浅局部极小值、掉进更深 valley，Rprop 往往能比 vanilla gradient descent 找到更好的解。
- [01:03:22] 在回答学生问题时，老师补充：Rprop 仍然需要 backprop。原因不是它用导数大小，而是它至少要知道导数符号，所以每一轮仍得先通过 backprop 计算导数。
- [01:04:00] 他还指出，Rprop 实现里通常会对步长设置 ceiling 和 floor，防止分量步长无限放大或缩小到无意义。
- [01:04:20] 之后老师给出性质判断：Rprop 是一个 remarkably simple 的 first-order method，对 loss function 几乎不做假设，甚至不要求凸性，但实践中却常常比 plain gradient descent 更有效，甚至能和某些高级二阶法竞争。
- [01:05:45] 课堂小测的标准答案也再次把规则说清：一旦 overshoot，Rprop 会回到 earlier estimate，并取一个更小的步长。
- [01:06:01] 老师随后提到 Quickprop：它试图利用相邻迭代的差异去近似二阶导，发明者是 Scott Fahlman，很多问题上仍然很快，但本段不展开它的细节。
- [01:06:29] 接着老师回顾本讲至此的主线：梯度下降可能错过 obvious answers，这未必坏；vanilla gradient descent 因各维度差异可能过慢或不稳；二阶法能规范化维度差异但复杂；adaptive 或 decaying learning rates、以及解耦维度的方法，都可能改善收敛。
- [01:06:54] 最后，老师开始为 momentum 铺垫一个更细的观察：看一个二维优化轨迹时，某个方向上的导数可能一直同号，表示平滑收敛；另一个方向上的导数则可能正负交替，表示在该方向上反复弹跳。这个“导数符号模式”将直接引向下一段的趋势平均思想。

## 概念、符号与推导
- Rprop 的分量级规则：
  1. 若当前导数与上一轮导数同号，则增大该分量步长（乘 \(\alpha\)）（[01:00:21]-[01:01:14]）。
  2. 若符号翻转，则视为越过极小值，回退并把该分量步长按 \(\beta\) 缩小（[01:01:36]-[01:02:02]）。
- Rprop 只依赖导数的 sign，不依赖其绝对值大小（[01:01:19]-[01:01:23]）。
- 算法结构：每个坐标独立维护步长，因此本质上是在用启发式追踪“每个方向该走多大”，而不是统一共享一个学习率（[01:00:13]-[01:00:17], [01:02:12]-[01:02:15]）。
- 与 backprop 的关系：Rprop 不是替代 backprop，而是替代“拿到梯度后如何更新参数”的那一步；为了知道符号，导数仍需由 backprop 计算（[01:03:22]-[01:04:18]）。
- 本段无严格公式推导，核心是算法规则与其几何后果。

### 008 01:09:39-01:19:20

片段：01:09:39-01:19:20

## 本段在整讲中的作用
这一段给出本讲第二个核心改进法：momentum 及其 Nesterov 加速版本。老师先从“不同方向的导数符号序列”观察出发，构造运行平均，再解释为什么这会压制振荡方向、强化平滑方向；最后通过交换两步顺序，引出更快的 Nesterov 方法。

## 教学展开
- [01:09:39] 老师先把上一段的“导数符号模式”说清：若一个方向上导数一直同号，说明该方向在平滑推进；若一个方向上导数正负交替，则说明该方向不断来回 bounce。
- [01:10:08] 于是问题变成：能不能不要直接用当前导数，而改用过去导数的平均？对一直同号的方向，平均后仍会保留显著值；对正负交替的方向，正负会互相抵消，只剩一个很小的值。
- [01:10:52] 这就是 momentum 的直观来源。老师先回顾一般 running average 的形式：看见第 \(k+1\) 个观测后，新平均应是旧平均缩放后再加上当前观测。
- [01:10:47] 他从普通平均定义开始证明：\(\bar x_k=\frac{1}{k}\sum_{i=1}^k x_i\)，于是
  \(\bar x_{k+1}=\frac{k}{k+1}\bar x_k+\frac{1}{k+1}x_{k+1}\)。
  老师借此说明，运行平均可以写成“之前的平均 + 最新观测”的递推式。
- [01:12:30] 接着把这一公式挪到优化里：不再直接用当前梯度步，而是维护“梯度步的运行平均”；更新参数时，用这个 running average 去更新，而不是只用当前那一步。
- [01:13:46] 老师用轨迹图解释效果：plain gradient descent 在某一方向会来回振荡，而 momentum 通过平均历史步骤，会让该方向振荡幅度减小，同时沿稳定方向推进得更快。
- [01:14:32] 为了说明 momentum 的几何含义，老师把一次更新拆开：先按当前位置的梯度走一步，再加上前一次更新的一个缩放版本。也就是说，当前步不仅受当前梯度影响，还带着上一轮“惯性”。
- [01:15:56] 然后老师说，这两步其实可以换顺序。标准 momentum 是“先当前梯度步，再加过去步的缩放”；如果改成“先沿上一步延伸，再在那个前瞻位置看梯度并走一步”，就得到更快的方法。
- [01:16:47] 这就是 Nesterov method。老师强调：对凸函数，它被证明是到达解最快的方法之一；虽然他没有展开数学证明，但从图上看已经能直观看到第二种顺序更快。
- [01:17:39] 视觉比较中，momentum 是“先走梯度，再加历史步”；Nesterov 则是“先 look ahead，再按那里的梯度修正”，因此更像提前预判轨迹。
- [01:18:17] 本段末尾，老师把 Nesterov 的训练步骤口头过一遍：每步先把当前参数沿上次更新方向延展一个缩放量，再在新位置算梯度，再按该梯度继续更新，同时记录这次总更新量。
- [01:19:00] 最终总结一句：momentum 和 trend-based methods 的共同点，是都在看历史步子的趋势，用趋势来决定当前步，而不是只看当前点的即时导数。

## 概念、符号与推导
- running average 的定义与递推：
  \[
  \bar x_k=\frac{1}{k}\sum_{i=1}^k x_i,
  \qquad
  \bar x_{k+1}=\frac{k}{k+1}\bar x_k+\frac{1}{k+1}x_{k+1}
  \]
  （[01:10:47]-[01:12:17]）。
- momentum 的课堂思想：维护历史 gradient steps 的运行平均；在同号方向上，平均值会累积得较大；在反复改号的方向上，平均值会被抵消得较小（[01:09:39]-[01:10:39], [01:12:30]-[01:13:27]）。
- 普通梯度步在老师的口头描述中是 “minus eta times current derivative”，而 momentum 使用的是这些梯度步的 running average 来做更新（[01:12:53]-[01:13:27]）。
- 标准 momentum 的几何分解：
  1. 先按当前梯度走一步；
  2. 再加上上一次更新的缩放版本（[01:14:32]-[01:15:28]）。
- Nesterov 的几何分解：
  1. 先沿上一次更新方向做一个缩放的 look-ahead；
  2. 再在 look-ahead 后的位置计算梯度并更新（[01:15:56]-[01:16:47], [01:18:17]-[01:18:46]）。
- 本段没有给出完整符号化伪代码推导，重点是递推平均公式和两种更新顺序的比较。

## 例子与课堂提示
- [01:09:39] “同号序列”和“正负交替序列”的并排观察，是本段最重要的课堂切入口。它服务于让学生明白 momentum 不是神秘技巧，而是对导数时间序列做降噪。
- [01:10:47] 老师特地证明 running average 公式，是为了让学生不把 momentum 看成拍脑袋 heuristic，而把它看成“有标准递推形式的历史平均”。
- [01:13:46] plain GD 和 momentum 轨迹图的对比服务于直观看出：momentum 会削弱振荡方向、强化稳定方向。
- [01:16:47] 老师坦言自己不能把 Nesterov 的最优性证明讲清，但仍坚持讲图像直觉，提醒学生这里先抓“为什么看起来更快”，而不硬吞抽象证明。

## 本段掌握检查
1. 问：为什么对历史导数或历史梯度步做平均，有助于改进收敛？答：因为平滑收敛方向上的同号信号会累积，而振荡方向上的正负信号会互相抵消，从而自动放大该快走的方向、缩小该减振的方向。
2. 问：老师在课堂上给出的 running average 递推公式是什么？答：\(\bar x_{k+1}=\frac{k}{k+1}\bar x_k+\frac{1}{k+1}x_{k+1}\)。
3. 问：标准 momentum 更新在几何上如何理解？答：先按当前位置梯度走一步，再加上前一次更新的一个缩放版本，相当于给更新加入惯性。
4. 问：Nesterov 与标准 momentum 的核心区别是什么？答：Nesterov 先沿历史方向 look ahead，再在前瞻位置算梯度并修正；标准 momentum 则是先算当前梯度步，再把历史步加上去。
5. 问：老师对 Nesterov 方法给出的结论是什么？答：在凸函数上它被证明更快，是一种对 momentum 的改进。

## 教学展开
- [01:19:43] 老师用最后一个课堂投票追问 momentum 的局限：如果你维护的是 running average，而目标函数在某一方向上的 slope 根本是常数，那么 momentum 会不会更快？
- [01:20:03] 老师引导学生回答：若 slope 在每个点都相同，那么每次看到的梯度也是相同的；其 running average 与单次梯度完全一样，不会产生额外优势。

  1. gradient descent 可能错过 obvious answers，但这未必是坏事；
  2. vanilla gradient descent 会因不同维度曲率差异而过慢或不稳；
  3. second-order methods 能通过缩放空间来规范化不同维度，但实现复杂；
  4. adaptive 或 decaying learning rates 能改善收敛；
  5. 解耦各维度需要 heuristic；
  6. momentum methods 通过强调稳定改进方向，被老师称为 demonstrably superior。

## 概念、符号与推导
- constant slope function 上，若每一步梯度都相同，则其 running average 与当前梯度相同，因此 momentum 不会改变更新方向或更新幅度模式（[01:20:03]-[01:20:42]）。
- second-order methods 的课堂定位：通过对空间做缩放来消解各方向曲率差异，但代价复杂（[01:21:09]-[01:21:16]）。
- 最终策略图谱：
  1. decaying / adaptive learning rates 用于兼顾探索与收敛；
  2. per-dimension heuristics 用于处理各方向曲率不一致；
  3. momentum/trend methods 用于强调持续改善方向（[01:20:58]-[01:21:36]）。
- 本段无公式推导，主要是边界条件和全讲总结。

## 例子与课堂提示
