## 学习目标
本讲围绕 reinforcement learning 的一条统一主线展开：把 sequential decision making 问题写成 value、policy 和 Bellman 递归，再依次理解为什么需要 Markov state、为什么会出现 model-free learning、为什么要从表格法走到 deep RL，以及当环境 reward 不可得时为何会出现 RLHF。听完后，至少应能复述 state/reward/cost/objective 的定义，解释 information state 与 Markov assumption，区分 Monte Carlo、TD、SARSA、Q-learning 的直觉差异，并说清 replay、target network 与 RLHF 分别是在解决什么问题。

## 需要的先修知识
需要熟悉监督学习的基本范式，知道 static dataset 与 sequential interaction 的区别；需要能理解“value 是递归定义”的想法，以及概率、期望、最优化与基本神经网络 generalization 的概念。老师在后半段多次把 RL 与 gradient descent、函数学习、generalization 联系起来，因此如果已经学过神经网络训练、误差更新、以及为什么 correlated data 会伤害训练，会更容易跟上。

## 老师的教学主线
老师先用“为什么需要 RL”立题，再用出租车找乘客的网格世界定义 state、reward、cost、objective。然后他从无 agency 的随机世界讲到 value function 与 Markov/information state，再引入有 agency 的 MDP、policy、deterministic/stochastic choice 与 discount。接着他说明大状态空间下闭式/精确求解会变得 intractable，于是转向 model-free RL：Monte Carlo、temporal difference、SARSA、Q-learning。再往后，他把表格法推广为 function approximation，说明 naive DQN 为何不稳定，以及 DeepMind 如何用 replay 和 target network 让它可训练。最后他说明现实里最难的是 reward design，于是引出 RLHF，并用 limitations/open problems 与问答把整讲收束。

## 核心概念与依赖关系
全讲最底层的依赖关系是：先有 sequential decision problem，才需要定义 state、reward、cost 和 objective；有了 state，才能讨论 value；value 在 Markov world 中能用 Bellman 递归表达；一旦系统可以选动作，就从 Markov process 进入 Markov decision process，并通过 value 诱导 policy。若环境已知且状态小，可以直接算；若环境未知或过大，就需要 model-free RL 从交互中估 value 或 action value。表格法状态一多会失效，于是需要 function approximation 和神经网络。神经网络带来 generalization，但又与 bootstrapping 和 correlated sequential data 叠加出不稳定性，因此需要 replay 和 target network。最后，如果 reward 本身没有天然定义，就必须先从 human preference 学 reward model，这就是 RLHF。

## 关键推导、例子与结论边界
讲义里的关键递归来自 Bellman 思路：状态价值不是局部一步，而是“当前局部 reward/cost + 后续可能状态的期望价值”。出租车网格例子承载了绝大多数定义；“女儿成长为 CEO”解释 long-horizon objective；rock-paper-scissors 解释为什么 policy 不能永远可预测；军方 targeting 案例解释 reward design 错了会训练出错误行为；社交媒体战损评估变成搞笑 bot 说明 RLHF 里人类本身也是噪声来源。老师给出的结论边界同样清楚：如果 transcript 没保留公式本体，就只能记录口头递归与因果链，不能补写未出现的精确式子；如果任务 reward 天生模糊，RL 的难点就不在优化器，而在定义目标。

## 易错点与待核对项
最容易混淆的点有四个。第一，value 不是单纯距离，也不是单纯 cost，而是综合 reward 与 cost 后可期望得到的最好收益。第二，Markov 性不是“世界天然无历史”，而是“当前状态表示是否已经包含决策所需全部信息”；必要时要把 history 编进 information state。第三，Q-learning 和 DQN 不是把 Bellman 换掉，而是换了学习对象与表示方式。第四，RLHF 不是另一套完全不同的 RL，而只是把 reward 来源换成人类偏好。待核对项主要集中在开场议程、早期 Bellman 板书、若干玩笑插话、以及字幕把 NeurIPS、safest、oscillation 等词识别错的地方，这些都已在分段笔记里标出 [需回听]。

## 掌握标准
如果已经掌握本讲，你应该能不看讲稿回答下面这些问题：为什么 supervised learning 不能直接替代 RL；出租车例子里的 state/reward/cost/objective 各是什么；information state 为什么能把非 Markov 的物理世界改写成 Markov 模型；Monte Carlo 与 TD 的更新时机与误差来源有何差别；为什么 on-policy 会保守、off-policy 更能利用探索；DQN 为什么不稳定、replay 与 target network 分别稳定了什么；RLHF 解决的是哪个环节的问题，以及它新增的人类噪声在哪里。

## 复习顺序
建议先复习出租车例子中的四元组定义，再复习 information state 与 Markov assumption，因为后面的 MDP、policy、Bellman、Monte Carlo、TD、Q-learning 都依赖这一层。第二轮复习看 model-free RL 的三步跳：Monte Carlo 为什么慢、TD 为什么快但有偏、Q-learning 为什么直接学 action value。第三轮再看 DQN 的不稳定性与两种修复。最后复习 RLHF 与 limitations，把“reward design 比优化更难”这一结论和老师的两个失败故事连起来看。

### 00:22:38-00:32:36
作用：本段在“无 agency 的 value world”之上正式引入 agency、policy 和 Markov decision process，并解释 deterministic policy、stochastic policy、discount、以及大状态空间下的 intractability。它是从建模进入求解方法的桥。

展开：00:22:38-00:23:34，老师先回顾前面已经有了 information state 和 Markov world，但此前一切都“没有 agency”，只能按概率被动移动。现在他让系统可以自己决定动作，这个决策框架就叫 Markov decision process。课件 p.1 只是标题页“Reinforcement Learning / Created By: Bradley Warren / Painstakingly improved by Bhiksha Raj”，没有新增技术内容。00:23:40-00:25:21，他说明 MDP 的作用是利用前面算出的 state values，在任意 state 选择最优 move，据此形成 policy。大方向是朝“下一个 value 更高的 state”走；若多个方向 value 一样，还要决定 tie-breaker，是 stochastic 还是 deterministic，比如总向左、总向右。00:25:42-00:28:06，他把环境从静态世界改成会响应行动的世界，举“抗议者堵路”的例子，说明纯贪心的固定策略在变化环境里未必成立。随后用和学生打 rock-paper-scissors 的演示解释：如果策略永远出石头，环境会适应，你的 policy 会迅速失效，因此策略里常常需要 stochastic element。00:28:24-00:30:08，他引入 discount：现在时刻和近期回报比遥远未来更可信，因为我们对未来的判断其实是用过去经验在外推，discount 更大意味着对久远预测和旧经验的信任更低。00:30:12-00:31:37，他再回到 Bellman 方程和九宫格，指出真实世界规模一旦从小网格扩到全城出租车调度，就会快速变得 intractable，要求我们知道整个世界才能 act。00:31:37-00:32:36，他用“state space、action space、best state”的回看，把问题转向 model-free RL：如果不知道网格外是什么，只能边行动边学。

### 01:12:12-01:22:11
作用：本段是问答部分对 Markov assumption、policy、information state 的一次高密度复盘。它把前面老师的直观叙述重新压成更严格的条件判断：什么时候“看邻居里 value 最大者”是合法 policy，什么时候 state 需要扩充为带历史的 information state。

展开：01:12:12-01:13:14，Bhiksha Raj 继续追问：如果你只知道每个节点的 value，不知道整张地图的最优路径，怎么走？答案是看所有邻居，去 value 最高的那个方向，这就形成了 policy，而且是 deterministic policy。01:13:27-01:14:12，有学生说这像 greedy search；Bhiksha Raj 反问“如果 value 真定义好了，它就应该 already encode overall best”，因此关键不是 greedy 对不对，而是 value 成立所依赖的假设。01:14:12-01:16:18，他逐层逼问这个假设：value 为什么可以固定？因为终点不动、环境规则不变，而且更深层的 Markov assumption 是“未来只取决于你现在在哪里，而不取决于你怎么来的”。一旦路口是否能转弯取决于来向，例如某处不许右转，那 value 就依赖历史，单节点 state 不再有效。01:16:18-01:17:24，他据此说明“这就不是 Markov 了”，但可以通过改 state 使之重新变成 Markov：把 state 从“当前路口”改成“从哪个路口来到当前路口”的有序对，例如 56、63、69、65。01:17:24-01:18:35，他让学生数状态数：如果 state 是九个 intersections，就有 9 个 states；如果 state 是“边的有向有序对”，则每条边算两个方向，一共 24 个 states。01:18:47-01:19:57，他进一步推广：如果约束依赖两步历史，可以把 state 扩成 triplets；更一般地，只要需要回看的历史是有限的，就常常能通过“blow up state space”把过程重写成 Markov。于是要区分 information state 与 world state：前者是我们为了满足 Markov 性而构造的状态空间，后者是物理世界里的原始状态。01:20:01-01:22:11，他回到随机交通指挥的场景，说明光有固定 value 还不够，一旦某个路口之后存在随机分流，value 的计算就要转入期望值形式；这一点在下一段被正式写成 Bellman equation。

概念、符号与推导：本段的核心概念是 deterministic policy、Markov assumption、information state、world state。老师明确指出：只看邻居 value 做决策成立的前提，是当前 state 已经充分，未来不依赖过去轨迹。若历史依赖存在，就要把“来自哪里”等历史编码进 state。计数上，九个 intersections 对应 9 个物理 states；若状态改成有向边的 ordered pair，数量会随边数双向展开，本例学生答出的数是 24。推理主线不是新公式，而是一个结构性命题：有限历史依赖经常可以通过增广 state 变成 Markov representation。

例子与课堂提示：Morwood 与 Fifth 的路口例子非常关键：它说明“同一个几何路口”在不同来向下可行动作不同，因此 world state 若只写成位置会丢信息。老师反复强调“我们活在 Markov worlds”其实是工程化表述，不是说现实天然无历史，而是说很多时候可以通过扩大 state space 近似或重写成 Markov 模型。最后关于橙色背心施工人员随机指挥交通的 Pittsburgh 例子，则把全班再次推回“概率转移”这一主题。
