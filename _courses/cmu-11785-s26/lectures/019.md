## 学习目标
- 理解老师如何从 simple seq2seq 的失败点，一步步推出 attention、self-attention、masked self-attention 和 transformer。
- 能按课堂顺序解释 context vector、attention weight、Q/K/V、positional encoding、mask、GPT、BERT 分别解决什么问题。
- 能依据本讲的 transcript 与课件页，回答“为什么平均不够”“为什么 decoder 需要 mask”“为什么 transformer 更快”这类核心问题。

## 需要的先修知识
- 需要已熟悉上一讲延续下来的 seq2seq、beam search、next-token prediction、encoder/decoder 的课堂语境。
- 需要 softmax、加权平均、RNN 隐状态递推、条件语言模型这些基础概念。
- 需要知道 <sos>、<eos>、teacher forcing、maximum likelihood 训练在序列模型里的含义。

## 老师的教学主线
- 先回顾 simple delayed self-referencing seq2seq，并把 decoder 重新定义成对输入条件化的语言模型。
- 再指出简单模型有两个根本问题：单个最终 hidden state 既过载又会在 decoder 递归中被继续稀释。
- 接着提出“每个输出词都应动态加权全部输入 hidden states”，形成 attention 与 context vector。
- 然后把 attention 细化为 raw score、softmax 权重和 context，并进一步拆成 query、key、value 的职责分工。
- 再讨论训练与推理：beam search、teacher forcing、Gumbel trick、多头注意力与成功案例。
- 最后把 attention 从 encoder-decoder 对齐推广成 self-attention，再加 positional encoding 和 causal mask，得到 transformer，并用 GPT/BERT 说明其后续主流变体。

## 核心概念与依赖关系
- simple seq2seq 是起点：encoder 把整句压到句末 hidden state，decoder 以此为条件递归生成。
- 条件语言模型视角解释了为什么 decoder 的任务比普通语言模型复杂得多。
- context vector 依赖于 attention weights；attention weights 又依赖于 decoder state 与 encoder state 的动态关系。
- raw attention score 必须经过 softmax 才能成为合法 attention weight，因为老师要求权重非负且和为 1。
- query/key/value 把“决定关注谁”和“真正传递什么内容”拆开。
- self-attention 让一个位置的表示显式吸收同一句里其他位置的信息，取代 encoder recurrence 的主要功能。
- positional encoding 让这种显式吸收不仅看内容，还看相对距离。
- masked self-attention 则把 decoder 的因果生成约束嵌进相同机制中。
- transformer 是“positional encoding + multi-head self-attention + MLP + 残差”替代大量 recurrence 的 seq2seq 方案；GPT 和 BERT 是其 decoder-only 与 encoder-only 方向。

## 关键推导、例子与结论边界
- 关键公式链是课堂稳定给出的：先算 e_i^{(t)} = g(h_i, s_{t-1}) 这类 raw score，再 softmax 得 attention weights，最后对 hidden states 或 values 加权求和形成 context。
- 几何约束来自老师对 polytope 的解释：如果权重都为正且和为 1，加权和就留在原 hidden states 张成的“内部”，因此更像平均而不是任意外推。
- “I ate an apple” 与其德语翻译支撑了“不同输出关注不同输入”的主结论；Bahdanau 对齐图则支撑了 attention 在实际翻译里确实学到了这种对应。
- “apple 是水果还是电脑” 支撑 self-attention 的上下文化动机；“远近不同的 ate 对 apple 不该等价” 支撑 positional encoding 的距离动机。
- 结论边界：本讲对 GPT/BERT 只做结构定位，不展开完整训练目标与后续家族谱系；课件 caveats 只提醒选型与部署边界，不构成对所有 transformer 的统一定量结论。

## 易错点与待核对项
- 不要把 raw score 和最终 attention weight 混淆；没有 softmax 就没有“全正且和为 1”的权重。
- 不要把等权平均误当成 attention；attention 的关键是权重会随当前输出步或当前位置变化。
- 不要把 key 与 value 当成同义重复；老师明确说 key 更粗、更像匹配线索，value 更具体、更像真正被传递的内容。
- 不要忘记 decoder 端每一层都要 mask，不能因为上一层已经是 decoder 输出就改用 full self-attention。
- transcript 中若干德语词和个别术语存在 OCR 漂移，引用原词时要保留 [需回听]。
- 课件里多页公式 OCR 破损，尤其 section 008 的位置编码与 masked block 页面；当前仅记录可从 supplied evidence 稳定确认的关系。

#### 本段在整讲中的作用
本段先把本讲放回上一讲已经开启的 sequence-to-sequence 主题中，重新界定“序列进、序列出且输入输出未必时间对齐”的问题，再回顾最简单的 delayed self-referencing seq2seq 结构。老师随后把 decoder 明确解释为“以输入为条件的语言模型”，并用这一点说明本讲后续为什么必须解决表示压缩与条件建模过于复杂的问题。片段末尾已经转入“单个最终隐状态被过载”的缺陷，为下一段的 attention 动机铺垫。

#### 教学展开
- 00:01:17-00:02:38：老师说明本讲继续讨论 sequence-to-sequence models。与标量/向量输入输出不同，这里是序列输入映射到序列输出，且当前关注的是“输入输出之间没有明显一一对应”的情形。

- 00:02:38-00:04:57：回顾 delayed sequence-to-sequence 与 delayed self-referencing sequence-to-sequence。输入序列先经前半网络处理到 <eos>，得到最终隐表示；输出端以该隐表示和 <sos> 为起点递归地产生输出；每一步输出再作为下一步输入，直到生成 <eos>。
- 00:04:41-00:04:57：给出命名。处理输入的一侧叫 encoder，利用最终输入表示生成输出序列的一侧叫 decoder。
- 00:04:59-00:06:04：老师追问 decoder 的语言模型本质，纠正“translator”之类回答，明确它是 conditional language model，不是普通 language model；其条件是输入序列。
- 00:06:04-00:08:57：解释条件语言模型为何远比普通语言模型复杂。普通语言模型只需给语言中所有可能句子一个概率分布；条件语言模型则要对“每个可能输入条件下”的所有可能句子建模，相当于“一整个输入空间上的无穷多个语言模型”被一个模型统一承载。
- 00:09:15-00:10:04：老师开始引出问题：整个输入都被 encoder 在句末压到一个 hidden state 中，这个表示会过载；详细展开留到下一段。

#### 概念、符号与推导
- sequence-to-sequence：输入是序列，输出也是序列；这里特别关注输入输出无明显时间同步或逐位置对应的版本。
- delayed sequence-to-sequence：先完整处理输入，再开始输出。
- delayed self-referencing sequence-to-sequence：decoder 每一步把刚生成的输出再喂回下一步输入，因此未来输出依赖过去输出。
- <eos>：输入序列终止标记；encoder 在该位置的最终 hidden representation 被拿来启动输出。
- <sos>：输出序列起始标记；decoder 用它配合初始隐状态开始生成第一个输出。
- encoder：处理输入序列并产出最终输入表示的网络部分。
- decoder：以 encoder 提供的表示为条件、递归生成输出序列的网络部分。
- conditional language model：decoder 建模的是“给定输入时输出语言序列的概率分布”。
- 本段无公式推导。

#### 例子与课堂提示
- 机器翻译例子服务于“输入输出不必逐词对齐”这个知识点：英语 “I ate an apple” 与德语输出之间没有显然的一一位置对应。
- 对话系统例子服务于“甚至看不出表面对应”这一点：输入是故障描述，输出是建议排查动作。
- 老师反复追问 decoder 是什么模型，提示不要把 seq2seq 只当成“翻译器”，而要看成“条件语言模型”。
- 老师用“一种输入对应一个条件分布”的解释提醒学生：复杂度提升来自条件集合爆炸，而不是只来自输出长度。
- 片尾刚提到“最终 hidden state 过载”，提示后续 attention 不是装饰，而是为了解决单向压缩信息瓶颈。

#### 本段掌握检查
1. 问：本讲当前关注的 seq2seq 任务与普通逐时刻同步序列任务有什么不同？
答：老师强调这里输入输出之间没有明显一一对应，甚至符号顺序都可能不保持。
2. 问：delayed self-referencing seq2seq 的输出端是如何运行的？
答：decoder 以 encoder 最终隐状态和 <sos> 开始生成，每一步输出再作为下一步输入，直到产生 <eos>。
3. 问：encoder 和 decoder 在本讲中的定义分别是什么？
答：encoder 处理输入并生成输入表示；decoder 利用该表示生成输出序列。
4. 问：老师把 decoder 明确称为什么模型？
答：conditional language model。
5. 问：为什么 conditional language model 比普通 language model 更复杂？
答：因为它不是只对“语言整体”给一个分布，而是要对“每个可能输入条件下”的输出句子分布建模，相当于许多条件化语言模型被一个系统同时表示。

### 00:10:02-00:20:00
#### 本段在整讲中的作用
本段把“简单翻译模型”为什么不够用讲清楚：一方面 encoder 最终状态到 decoder 的信息会在递归中被冲淡，另一方面所有输入被压成单个向量，无法让不同输出直接对接不同输入位置。老师先尝试“把最终表示送到每个 decoder 时刻”和“平均所有输入隐状态”两种修补办法，再指出仍然不够，由此把问题精确导向 context vector 与动态加权平均。

#### 教学展开
- 00:10:02-00:11:04：先讲 decoder 侧的问题。最终输入表示被递归传过整个解码过程，随着时间推进会不断被后续输出信息覆盖；句尾输出越来越依赖已生成输出，而更少依赖原始输入。
- 00:11:19-00:12:06：再讲 encoder 侧的问题。过长输入会让早期词的信息在到达最终隐状态时已经很弱，尤其第一词的信息到句末几乎只剩很弱信号。
- 00:12:09-00:12:48：老师给出第一种补救：把 encoder 表示直接送到每个 decoder 隐状态，而不只送初始状态。这样能缓解“解码递归稀释”问题，但还没解决“所有输入被压到一个向量”这一根本问题。
- 00:12:50-00:14:25：老师继续指出，输出符号往往只依赖输入中的特定部分。若只保留句末单个向量，decoder 可能分不清哪一部分该对应哪一个输出词。
- 00:14:34-00:15:03：课堂有人提议“feed everything”，老师把它收束成“先把所有输入 hidden states 做平均，再送给 decoder 每一步”，认为这至少让每个输入都对最终供给有贡献。
- 00:15:14-00:16:28：马上指出平均仍然不对，因为平均给每个输入相同权重，也把同一个平均向量提供给所有输出词；而实际上不同输出应关注不同输入。
- 00:16:32-00:18:31：老师定义 context vector：对输入 hidden states 的加权平均，而且权重随当前输出时刻变化。随后用第 0、1、2、3、4 个输出各自对应一组不同权重来说明“每个输出都有自己的加权组合”。
- 00:18:31-00:20:00：总结需要一种机制，能在生成某个输出时自动把权重集中到相关输入词上，为下一段正式定义 attention weights 做准备。

#### 概念、符号与推导
- decoder-side dilution：最终输入表示在 decoder 的时间递归中不断被后续输出覆盖，越到后面越难保留原输入影响。
- encoder-side dilution：输入越长，越早出现的词到最终 encoder hidden state 的贡献越弱。
- direct feed to every decoder state：把 encoder 结果送入每个 decoder 时刻，只解决“输入信息在 decoder 中被继续冲淡”的问题，不解决“所有输入被压成单向量”的问题。
- average of all encoder hidden states：把所有输入 hidden states 等权平均，再送给每个输出时刻。
- context vector：对所有输入 hidden states 的加权平均；关键要求是“不同输出时刻用不同权重”。
- 权重索引含义：老师口头区分“上标/括号表示第几个输出时刻”“下标 i 表示输入位置”。
- 本段没有写出完整公式，但已经明确了结构：每个输出时刻都对应一组作用在全部输入位置上的权重。

#### 例子与课堂提示
- “I” 与其德语对应词的关系被用来说明：某些输出强依赖某个特定输入位置，而不是平均依赖全部输入。
- “habe / gegessen” 与 “ate” 的关系被用来说明：一个输入词也可能强影响多个输出词。
- 老师用“平均给 I 与 apple 同等重要性”说明等权平均的问题，因为不同输出词对输入的关注点不同。
- transcript 中出现了 “ish”“off field”“onion”等明显 OCR 或听写异常词形；它们服务的概念很清楚，即“不同输出需要不同关注位置”，但具体词形应回听后再精修。
- 老师反复追问 “Does this solve the problem completely?”，课堂提示是：看到任何“平均”方案都要立刻追问“是否丢失位置相关性与输出相关性”。

#### 本段掌握检查
1. 问：简单 seq2seq 在 decoder 侧的第一个核心问题是什么？
答：最终输入表示沿 decoder 递归传播时会被后续输出信息不断覆盖，后面词越来越少依赖原输入。
2. 问：简单 seq2seq 在 encoder 侧的第二个核心问题是什么？
答：所有输入被压到最终单个 hidden state，中前部输入信息会随输入变长而被冲淡。
3. 问：把 encoder 表示直接送给每个 decoder 时刻解决了什么，没解决什么？
答：它缓解了解码递归稀释，但仍没解决“所有输入被压在一个向量里、不同输出无法直接连到不同输入部分”的问题。
4. 问：为什么“平均所有输入 hidden states”仍不够？
答：因为平均对所有输入一视同仁，而且给所有输出词同一个平均向量，不能表达“不同输出关注不同输入”。
5. 问：老师在本段把 context vector 定义成什么？
答：定义成对输入 hidden states 的加权平均，且权重依赖当前正在生成的输出。

#### 概念、符号与推导
- h_i：第 i 个输入位置的 encoder hidden state。
- s_{t-1}：生成第 t 个输出前、decoder 上一时刻的状态。
- e_i^{(t)}：第 t 个输出时刻对第 i 个输入位置计算得到的 raw attention score。老师先称其为 arbitrary function 的输出。
- w_i^{(t)}：第 t 个输出时刻的 actual attention weight；由同一时刻的全部 e_i^{(t)} 经 softmax 归一化得到。
- c^{(t)}：第 t 个输出时刻的 context vector；由全部输入 hidden states 按 w_i^{(t)} 做加权和得到。
- 约束：所有 w_i^{(t)} > 0，且对固定 t 有各输入位置上的权重和为 1，这样加权和落在 hidden states 张成的包内。

#### 概念、符号与推导
- positional encoding 的要求：所有位置编码向量长度相同；每个位置编码唯一；两个位置编码的相关性随距离增大而下降；关系只依赖相对距离，即 P_{t+τ} = M(τ)P_t。
- 正弦余弦位置编码：老师说标准向量由不同频率的 sine/cosine 组成；其线性关系使网络能学习平移不变、依赖间隔的模式。
- encoder self-attention：当前位置可访问全输入，因此可对过去与未来都做注意。
- masked self-attention：decoder 在位置 t 只能访问 0 到 t 的内容，必须把 t+1 及以后的位置 mask 掉，使其 attention weight 为 0。
- masked multi-head self-attention：每个 head 都做同样的因果 mask，再把各 head 输出拼接并送入共享 MLP。
- 复杂度结论：长度为 N 的 self-attention，每个 head 需形成一张 N×N 注意力矩阵。
- residual framework：老师只说明 transformer 在所画结构外还带 residual，用来让导数流动更顺畅。
- GPT：decoder-only transformer；BERT：encoder-only transformer，用于表示学习。
