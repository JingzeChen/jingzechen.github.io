## 学习目标

- 理解为什么训练神经网络可以被重述为“最小化 loss 的函数优化问题”。
- 掌握本讲对 derivative、partial derivative、gradient、level set 与 Hessian 的基本定义和几何意义。
- 能区分一元与多变量函数中，哪些条件只是候选极值条件，哪些条件可以进一步区分最小值、最大值、拐点和 saddle point。
- 理解最基本的 gradient descent 直觉：为什么沿负梯度方向更新，以及为什么步长会与局部斜率大小相关。
- 明确本讲对网络函数 $f$、层、神经元、激活函数以及输入/目标输出/实际输出表示的设定。
- 能说清回归、二分类、多分类在输出层与目标表示上的差异，以及 divergence function 可微性的必要性。

## 需要的先修知识

- 一元微积分中关于导数、二阶导数和极值判别的基础概念。

## 老师的教学主线

- 先回顾上一讲的经验风险最小化，把训练网络明确重写成 loss 最小化问题。
- 再从最基础的导数定义讲起，逐步过渡到偏导数、gradient 与 Hessian。
- 接着说明“gradient 为零”为什么只是候选条件，并用二阶信息区分不同类型的临界点。
- 然后把这些数学直觉整理成 gradient descent 的最基本更新规则与收敛口径。
- 在优化框架就位后，把问题重新落到神经网络训练，开始定义网络函数 $f$ 的结构与参数。
- 最后补齐输出层设计、标签表示与 divergence function 的可微性要求，使训练目标的各个部件都被定义完整。

## 核心概念与依赖关系

- 经验风险最小化 -> loss 只依赖参数 -> 训练是参数空间中的函数最小化。
- 导数的局部线性乘子定义 -> 多变量偏导集合 -> derivative 行向量 -> gradient 列向量。
- 内积最大化性质 -> gradient 是最快上升方向 -> 负梯度是最快下降方向 -> gradient descent 更新。
- 零导数/零梯度 -> 只给出候选临界点 -> Hessian 或二阶导数决定其是最小值、最大值、拐点还是 saddle point。
- 网络函数 $f$ 的可微结构 -> 激活函数选择 -> 输出层表示 -> divergence function 必须可微 -> 才能对 loss 做梯度更新。
- 任务类型 -> 输出表示不同：回归通常用 identity，二分类用 sigmoid，多分类用 one-hot 目标和 softmax 概率输出。

## 关键推导、例子与结论边界

- 本讲的第一条核心推导是把导数解释成 $\Delta y = \alpha \Delta x$ 里的局部线性乘子，而不是只把它当成 $dy/dx$ 的商记号。
- 第二条核心推导是利用内积在同向时最大的性质，解释为什么 gradient 给出最快上升方向，负梯度给出最快下降方向。
- 第三条关键链条是“先找一阶导数或 gradient 为零的候选点，再用二阶导数或 Hessian 判断类型”。
- sign-based update 与 full-derivative update 的对比说明了为什么标准 gradient descent 不只是看方向，也要利用局部斜率大小调节步长。
- softmax 的例子说明 vector activation 会让各输出彼此耦合；one-hot 只是目标表示，不参与 softmax 内部指数化。
- 二分类数字识别、多分类数字识别和 OCR 式词表分类，是本讲输出层设计的三个代表性例子。

## 易错点与待核对项

- 不要把 derivative 和 gradient 混为一谈；本讲里 gradient 是 derivative 的转置。
- 不要把“导数等于零”直接当成“已经找到最小值”；拐点、最大值和 saddle point 都会制造混淆。
- 不要把 softmax 内部的指数化和 one-hot 目标表示混为一件事。
- 不要忽略 divergence function 的可微性；网络可微并不自动保证最终 loss 可微。
- 多处 ASR 把 affine、nabla、Hessian、eigenvalue 等术语转写错误；section 008 与 009 的公式提取还存在明显乱码，使用时应优先依赖已记录的可辨认文字关系。

#### 本段在整讲中的作用

本段把上一讲的“经验风险最小化”重新拉回到本讲主线：训练神经网络本质上是对损失函数做最小化。老师先把训练问题重述为函数优化问题，再用导数的定义给后面的梯度下降做数学准备，最后从标量自变量过渡到向量自变量，为后续的偏导数、梯度和 Hessian 铺路。

#### 教学展开

- [00:00:55] 老师先回顾上一讲：给定训练输入输出对，网络对每个输入产生实际输出，再计算它与目标输出之间的 divergence，并在整个训练集上取平均，得到 empirical risk，也就是 loss。[00:01:04]-[00:01:34]
- [00:01:34] 因为 loss 只依赖网络参数，所以训练网络就是寻找一组参数，让 loss 最小；老师明确指出这就是一个函数最小化问题。[00:01:34]-[00:01:53]
- [00:01:57] 在正式讲优化方法前，老师先说要快速复习 function optimization 的基础，并从 derivative 讲起。[00:01:57]-[00:02:03]
- [00:02:07] 老师先向学生提问“导数是什么”，课堂回答包括瞬时变化率、变化量、斜率、一个变量相对于另一个变量的变化率；老师评价这些说法“方向对，但不完整”。[00:02:11]-[00:02:47]
- [00:02:50] 老师给出自己的定义：在某一点处，导数描述“自变量发生极小增量时，函数值会增加多少”；他把它表述成一个乘子 $\alpha$，用来把 $\Delta x$ 变成对应的 $\Delta y$。[00:02:50]-[00:03:19]
- [00:03:19] 老师解释为什么可以这样定义：任何平滑连续函数在足够细的局部尺度上都近似线性，因此局部变化可以用一个线性乘子来描述。[00:03:19]-[00:03:29]
- [00:03:29] 老师特别强调，学校常见的 $dy/dx$ 记号不是“普适正确”的导数定义；如果 $x$ 是向量，就不存在“除以向量”这种自然写法，因此真正稳妥的理解应是“把输入微小增量映射到输出微小增量的乘子”。[00:03:29]-[00:04:39]
- [00:04:43] 对于标量函数的标量自变量情形，老师承认 $dy/dx$ 可以用，但更推荐写成 $f'(x)$，因为这种写法显式提醒人们：导数依赖于所处的位置 $x$。[00:04:43]-[00:06:24]
- [00:06:27] 老师随后把标量函数的导数解释成局部斜率：函数随 $x$ 增大而上升时导数为正，下降时为负；曲线越陡，导数绝对值越大；局部平坦处导数为零。[00:06:27]-[00:07:22]
- [00:07:27] 接着老师过渡到多变量情形：若 $y$ 是标量而 $x$ 是有多个分量的向量，则 $\Delta x$ 也是向量，仍可写成 $\Delta y = \alpha \Delta x$，但此时 $\alpha$ 必须是行向量，才能把列向量 $\Delta x$ 映射成标量 $\Delta y$。[00:07:27]-[00:09:24]
- [00:09:30] 老师最后说明：这个行向量里的每个分量都对应某个输入分量的作用；当只改变 $x_1$ 而保持其他分量不变时，对应乘子就是 $y$ 对 $x_1$ 的偏导数。本段结尾停在“每个 $\alpha_i$ 都是相应偏导”的说明上。[00:09:30]-[00:10:32]

#### 概念、符号与推导

- [00:01:20] loss：训练集上实际输出与期望输出之间 average divergence 的经验平均，因此是网络参数的函数。[00:01:20]-[00:01:42]
- [00:02:50] 导数的工作定义：若 $y=f(x)$，在某点附近有 $\Delta y = \alpha \Delta x$，其中 $\alpha$ 就是该点处的 derivative，用来描述自变量微小变化如何线性近似地影响函数值。[00:02:50]-[00:03:19]
- [00:03:19] 这一定义依赖的前提：平滑连续函数在足够小的局部范围内近似线性。[00:03:19]-[00:03:29]
- [00:03:37] $dy/dx$ 不是通用定义，因为当 $x$ 为向量时无法把导数解释成“除以 $dx$”；因此老师坚持把导数视为乘子而不是商。[00:03:37]-[00:04:39]
- [00:04:43] 在 $x,y$ 都是标量时，$dy/dx$ 可以使用；但 $f'(x)$ 更合适，因为它显式体现“导数依赖于 $x$ 所在位置”。[00:04:43]-[00:06:24]
- [00:06:27] 标量自变量时的几何含义：导数正负表示局部上升或下降，绝对值表示局部陡峭程度，零表示局部平坦。[00:06:27]-[00:07:22]
- [00:07:27] 若 $y$ 是标量、$x=[x_1,\dots,x_D]^T$ 是列向量，则 $\Delta x$ 也是列向量。因为 $\Delta y$ 是标量，所以在 $\Delta y = \alpha \Delta x$ 中，$\alpha$ 必须是行向量。[00:07:27]-[00:09:24]
- [00:09:30] 行向量 $\alpha$ 的各分量分别乘对应的 $\Delta x_i$；当仅有第 $i$ 个分量变化时，$\alpha_i$ 就是 $y$ 对 $x_i$ 的偏导数。[00:09:30]-[00:10:32]

#### 本段掌握检查

1. 为什么老师说训练网络是一个函数最小化问题？
答案：因为训练集平均 divergence 形成的 loss 只依赖网络参数，训练就是找一组参数使 loss 最小。[00:01:20]-[00:01:53]

2. 老师给导数的核心定义是什么？
答案：导数是在某点处把输入微小增量 $\Delta x$ 映射为输出微小增量 $\Delta y$ 的线性乘子 $\alpha$。[00:02:50]-[00:03:19]

3. 为什么 $dy/dx$ 不是通用的导数记号？

4. 对标量函数 $y=f(x)$ 来说，导数的正负和大小分别表示什么？

5. 若输入 $x$ 是列向量而输出 $y$ 是标量，导数 $\alpha$ 的形状为什么必须是行向量？
