## 学习目标
- 理解为什么序列训练的核心难点不在反向传播本身，而在输出序列与目标序列之间 divergence 的定义。
- 区分 conventional MLP、time-synchronous recurrent model、整段输入末尾分类模型，以及 order-synchronous but time-asynchronous sequence-to-sequence model。
- 理解 alignment、compression、expansion、decoding 之间的关系，并能把“找 alignment”重述成有约束图搜索问题。
- 掌握 Viterbi 在本讲中的用途：在当前模型和目标 compressed sequence 已知时，找出最可能的 time-synchronous alignment。
- 理解“猜 alignment 再训练”的 loss、梯度和迭代流程，并说明它为何容易受初始对齐影响，以及为什么会引出 CTC。

## 需要的先修知识
- RNN、LSTM、GRU 的基本训练框架。
- softmax 输出可解释为 posterior probability 的常识。
- KL divergence、cross entropy 与负对数概率之间的关系。
- 序列建模里“逐时刻输出”和“整段后输出”的差别。
- 动态规划或 DAG 最优路径搜索的基本直觉。

## 老师的教学主线
老师先回顾循环网络训练的总目标：最小化输出序列与目标序列之间的 divergence。接着他先把最简单的 conventional MLP 和时间同步 RNN 讲清楚，用“总 divergence 可拆成各时刻局部项之和”建立母问题。然后他把问题推进到“读完整段后输出一个类别”的模型，并说明中间时刻输出也可以贡献训练信号。

在这个基础上，老师切入真正的 sequence-to-sequence 异步输出问题：网络每个时刻都有 posterior probability，但不知道哪些时刻该正式读出符号。最开始的 greedy decode 只是逐时刻 argmax 后再 collapse 重复，它只能给出近似、不能保证得到最优的 order-synchronous 输出。于是老师转向训练视角，引入 alignment；如果 alignment 已知，loss 很容易定义；如果未知，就要么猜、要么考虑全部可能 alignment。本讲只讲前者。

最后，老师把 alignment 估计改写成 Viterbi 图搜索：先把目标 compressed sequence 展成一个有序 reduced table，再在“向右/右下”的合法路径集合里找最高分路径。找到最佳 alignment 后，训练又回到逐时刻 cross entropy 累加。整讲在最后指出：这种显式猜 alignment 的方法容易被初始猜测带进局部最优，因此下一讲转向 CTC。

## 核心概念与依赖关系
- sequence divergence：本讲所有训练讨论的起点。只有先定义好输出序列与目标序列之间的 divergence，反向传播才有意义。
- time-synchronous model：最基础的母问题。它要求每个输入都有一个输出，因此最容易把总 loss 写成各时刻 loss 之和。
- sequence classification after full input：它仍然是时间同步网络，只是只读取最后一个输出；一旦把中间输出也纳入 loss，就和母问题更接近。
- order-synchronous but time-asynchronous model：本讲真正的困难场景。输出顺序受输入顺序约束，但并不知道具体在哪些时刻读出。
- alignment：把异步输出序列绑定到时间轴上的额外信息。没有 alignment，只知道目标符号序列仍不足以直接写 loss。
- compression / expansion：老师用它们把 alignment 问题形式化。压缩序列可展开成许多时间同步序列；许多时间同步序列又会压回同一个压缩序列。
- decoding：从网络输出中取出序列结果的过程。简单 greedy decode 是逐时刻 argmax 加 collapse；更严格的 alignment decode 则是 Viterbi。
- Viterbi：在 reduced table 对应的 DAG 上找最高分合法路径。它依赖“最优路径的前缀也必须最优”的动态规划结构。
- guessed alignment training：先用当前模型找最佳 alignment，再用该 alignment 计算 loss 和梯度，反复迭代。
- CTC 预告：因为 guessed alignment training 太依赖初始对齐，所以更好的方向是不显式承诺某一条 alignment，而是把全部可能 alignment 纳入训练。

## 关键推导、例子与结论边界
- 对 mother problem 的关键推导边界：老师没有把完整 BPTT 公式重新推一遍，而是强调一条结构性假设，即在 one-to-one correspondence 成立时，总 divergence 可分解成各时刻 divergence 之和。
- 对 sequence classification 的关键结论：如果目标在整个有效输入段内保持一致，那么只在最后一帧定义 loss 会浪费中间输出，因此可以对所有时刻加权求和。
- 对异步输出推理的关键边界：逐时刻 argmax 再 collapse 只是启发式 decoding，不能区分拉长符号与重复符号，也不能保证得到最优的 order-synchronous sequence。
- alignment 已知时的关键推导：把对齐符号复制到整个时间轴后，总 loss 变成逐时刻 KL/cross entropy 的和；对 one-hot 目标，它进一步化成目标符号负对数概率之和。
- Viterbi 的关键结论：不是逐列选局部最大值，而是在合法路径约束下做全局最优搜索；每个节点只保留最佳父节点和最佳路径分数即可。
- 本讲明确留到下一讲的内容有三类：
  - 如何不显式固定单一 alignment；
  - 如何系统区分 repeated symbol 与 extended symbol；
  - CTC decoder 的正式处理方式。

## 易错点与待核对项
- 容易混淆“目标符号序列已知”和“alignment 已知”。本讲明确说后者是额外信息。
- 容易把 greedy collapse 误当成最优 decoding。老师多次强调它只找到 time-synchronous 最优，再压缩，不保证 order-synchronous 最优。
- 容易把“只保留目标符号的行”误当成足够约束。实际上还必须保留目标顺序，所以重复符号行也要按目标位置复制。
- 容易把 Viterbi 误解成“每一列选最大概率符号”。Poll 4 特意用这一项做干扰。
- ASR 待复核的高价值点主要集中在术语和示例音素：

#### 概念、符号与推导
- 课件 p.2 的核心结论：训练目标是最小化输出序列与目标输出序列之间的 divergence。
- 本段明确的困难：输入和输出可能 not time aligned，甚至不同步，因此 divergence  的定义不能默认逐时刻配对。
- 对 conventional MLP 的处理思路：模型本身无 recurrence，但仍可把整段输出看作序 列，再定义 sequence-level divergence。
- 老师给出的简化前提：实际输出序列与目标输出序列之间存在 one-to-one correspondence。
- 在此前提下，总 divergence 可写成“各时刻局部 divergence 的和”；因此对某个输出 $Y(t)$ 的梯度，只需看该时刻的局部项。
- 本段没有展开完整公式，只给出了“可加分解”的思路；没有比这更细的板书推导。

#### 例子与课堂提示
- 课件 p.4-p.5 的 translation 和 image captioning 例子，用来说明“输入和输出都可 能是整段结构”，并不是所有序列任务都要求逐时刻配对。

### 00:10:02-00:19:59

#### 本段在整讲中的作用
这一段把“时间同步模型”讲成后续一切变体的母问题：先说明什么叫每个输入对应一个输出，再展示 sequence classification 场景如何从“只在最后读一个输出”推广到“所有中间输出都可贡献训练信号”。后面处理异步输出时，老师会不断把复杂问题退回到这一类时间同 步思路上。

#### 教学展开
1. [00:10:02]-[00:11:22] 对照课件 p.12-p.14，老师定义 time-synchronous model：每个输入都有一个输出，既可以单向，也可以双向；但本讲为了讲解统一，默认按单向模型表述。
2. [00:11:50]-[00:13:39] 结合课件 p.15-p.17，老师说明这类模型的训练：模型输出序 列与目标输出序列等长，因此 divergence 可定义为两序列之间的 divergence，并进一步 简化成逐时刻 divergence 之和；局部 divergence 最常见是 KL divergence。
3. [00:13:46]-[00:15:08] Poll 2 的正确选项是第 1 和第 3 条：每个输入对应一个输出；true/desired outputs 的 divergence 可以由每个时刻的加性项构成。双向模型也可以 存在，所以“只能单向”是错的。
4. [00:15:22]-[00:16:49] 老师转到另一类基础模型：读完整个输入序列，只在最后输出 一个类别。例子包括 speech recognition、sentiment analysis、question answering。
5. [00:16:51]-[00:18:18] 推理时，网络在最后给出一个对全部类别的 posterior probability vector；分类时取最大 posterior 的符号。但老师提醒，网络结构其实在每个中间 时刻也都产生输出，只是我们通常不读取。
6. [00:18:21]-[00:20:18] 训练时如果只在最后一个时刻定义 divergence，会浪费中间输出携带的信息。课件 p.25-p.28 的修正是：把目标标签复制到整个时间轴，在所有时刻都 定义 divergence，并把这些项加权求和。
7. [00:20:29]-[00:21:03] 老师解释权重的含义：
   - speech recognition 中，如果整段都表示同一音素，所有时刻权重都可取 1；
   - question answering 中，如果答案只应在句末出现，则前面时刻权重应为 0 或较小 。
8. [00:21:09]-[00:19:59] 本段最后把学生带回“更有趣的模型”：order synchronous but time asynchronous 的 sequence-to-sequence，这为下一段正式进入异步输出埋下钩子。

#### 概念、符号与推导
- time-synchronous model：每个输入时刻对应一个输出时刻，输入输出存在严格一一时间对应。
- 对这类模型，老师继续沿用“总 divergence = 各时刻 divergence 之和”的简化。
- sequence classification 版本中，虽然只读取最后一个输出，但中间时刻同样存在输出概率向量。
- 课件 p.28 给出的推广是加权和：不同时间的 divergence 乘不同权重，再求和作为训练目标。
- 权重不是固定公式，而是任务假设的一部分：若目标整段恒定，可均匀加权；若答案只在末尾出现，可只让末尾项占主要权重。
- 本段没有新引入复杂符号推导，关键是把“最后一个输出的 loss”扩展为“所有时刻的加权 loss”。

#### 例子与课堂提示
- 词性标注例子（课件 p.13）用来说明最标准的 time-synchronous 场景：每个词都有一 个标签。
- sentiment analysis 的否定词例子说明：有些任务必须看到整句最后，才能安全输出最 终类别。
- “中间输出其实也存在，只是我们没读”是本段最重要的课堂提示，它直接支持后面把更多训练信号从中间时刻拿回来。

#### 本段在整讲中的作用
这一段把抽象的 alignment problem 进一步改造成一个可求解的有约束路径搜索问题。老 师先说明为什么“逐时刻最大概率”不行，再逐步加入三层约束：只保留目标符号、按目标顺序重排行、再把合法对齐描述成从左上到右下的路径集合。

#### 教学展开
1. [00:49:46]-[00:50:30] 老师先指出最朴素的做法失败：若直接在完整概率表中逐时刻 取最大概率符号，得到的符号可能根本不在目标 compressed sequence 里。
2. [00:50:33]-[00:51:31] 第一层修正：丢掉所有不在目标序列中的符号行。比如目标是 beefy，就只保留 /B/、/IY/、/F/ 对应的概率行，得到 reduced table。
3. [00:51:35]-[00:52:29] 但老师马上指出，这仍不够，因为只保留目标符号并不能保证 输出顺序正确；你可能得到的仍是目标集合里的符号，却不是目标顺序。
4. [00:52:35]-[00:54:02] 第二层修正：按照目标 compressed symbol sequence 的顺序 构造表。若目标有四个符号，表就有四行；某个符号若在目标中重复出现，就把同一概率行复制到对应的多个位置。
5. [00:54:13]-[00:55:35] 第三层修正：定义合法 alignment 路径。路径必须从左上走到右下；每一步只能“向右”或“右下对角”。这样任何路径都会产生“先若干个 B，再若干个 IY，再若干个 F，再若干个 IY”的序列，长度也和输入长度一致。
6. [00:56:22]-[00:57:18] 老师把这个表重述成图：每个单元格是一个节点，每个节点向 右和右下对角连接。于是每一条从 source 到 sink 的路径，都对应一个合法 alignment。
7. [00:57:26]-[00:58:45] 为了比较路径优劣，老师给节点赋值：节点分数就是网络在该 时间对该符号给出的概率；边分数全部设为 1。于是一路径的得分就是路径上所有节点概率的乘积，等价地也可看成对数概率之和。
8. [00:59:03]-[00:59:45] alignment 估计被彻底改写成图搜索：在所有合法路径中，找 分数最高的那条。

#### 概念、符号与推导
- reduced table：从完整输出概率表中，仅抽取目标 compressed sequence 相关符号得到的较小表。
- 若目标序列中某符号重复出现，则该符号对应的概率行也要在 reduced table 中重复出 现，以保留顺序信息。
- 合法路径约束：
  - 起点固定为左上；
  - 终点固定为右下；
  - 每一步只能保持当前行继续向右，或下移一行并前进一个时间步。
- 节点概率：当前时间、当前目标符号对应的网络输出概率。
- 路径得分：路径上所有节点概率的乘积；等价地可改写成对数概率之和。
- 因此 alignment 问题转化为“在 DAG 上找最高得分路径”的问题。

#### 例子与课堂提示

### 00:59:43-01:09:39

- 课件页码：lec15.recurrent.pdf p.69-p.80

#### 本段在整讲中的作用
这一段把“最高得分路径”具体落成 Viterbi 动态规划的思想。老师先说明路径数量指数爆 炸，不能枚举；再用“最优路径的前缀也必须最优”这个局部最优扩展性质，推出对每个节点只保留最佳父节点和最佳路径分数即可。

#### 教学展开
1. [00:59:43]-[01:00:23] 老师先重复路径得分定义：一条完整路径或部分路径的得分， 都是所经过节点概率的乘积。
2. [01:00:13]-[01:01:08] 由于合法路径数量是指数级，暴力枚举不可行，因此问题被视 为一个有向无环图上的最优路径搜索。
3. [01:01:12]-[01:01:51] 老师提出可用动态规划，尤其是 breadth-first 风格的 Viterbi 算法，来找 source 到 sink 的最高分路径。
4. [01:02:13]-[01:03:57] Viterbi 的核心逻辑：一个节点的最优路径，只可能来自它的 某个父节点的最优路径扩展。第二优的前缀不可能扩展后反超第一优前缀。
5. [01:04:06]-[01:05:27] 因而对每个节点，只需做两件事：
   - 比较所有父节点的 best path score；
   - 选出分数最大的父节点作为 best parent，并把该分数乘当前节点概率，得到当前节 点的 best path score。
6. [01:05:29]-[01:06:37] 老师引入记号：$y_t^{(s)}$ 表示时间 $t$ 上某个符号 $s$  的网络输出概率；$S(r)$ 表示第 $r$ 行对应的目标符号。
7. [01:06:40]-[01:07:18] 初始化：第一列所有节点都没有父节点；左上角节点的 best path score 就是它自己的节点概率；其他无法作为起点的第一列节点 best path score 为 0。
8. [01:07:19]-[01:09:39] 递推：之后按列从左到右推进。每个节点查看其父节点，记录 best parent，再把 best parent 的分数乘当前节点概率作为自己的 best path score。顶行因只有一个父节点，可以单独处理。

#### 概念、符号与推导
- 记号：$y_t^{(s)}$ 表示时间 $t$ 上符号 $s$ 的 posterior probability。
- 记号：$S(r)$ 表示 reduced table 第 $r$ 行所对应的目标符号。
- 动态规划状态：
  - best parent，记下当前节点来自哪一个父节点；
  - best path score，记下从 source 到当前节点的最佳路径分数。
- 最优子结构：当前节点的最佳路径一定来自某个父节点的最佳路径，而不是来自该父节点的次优路径。
- 初始化：只有左上角允许作为合法起点，其 best path score 为该节点概率；同列其他 节点记为 0。
- 递推关系：当前节点的 best path score = 最佳父节点的 best path score × 当前节点概率。

#### 例子与课堂提示
- 老师把“第二优前缀不可能扩展成整体第一优”讲得很口语，但这是本段唯一真正支撑 Viterbi 的逻辑核心。
- 在课堂上，老师专门把顶行作为特例处理，是为了让学生直观看到“父节点数可能不同， 但原则一样”。
- 老师不断用“computer science majors”调侃，提醒这里本质上已经是经典图搜索/动态规划问题，而不是神经网络专属技巧。

#### 本段掌握检查
1. 为什么不能直接枚举所有 alignment 路径？
   参考答案：因为合法路径数量呈指数增长。
2. Viterbi 在这里依赖的最优子结构是什么？
   参考答案：一个节点的最优路径一定是某个父节点最优路径的扩展。
3. 对每个节点需要保存哪两类信息？
   参考答案：最佳父节点 best parent 和到该节点的最佳路径分数 best path score。
4. 第一列的初始化规则是什么？
   参考答案：左上角分数等于自身节点概率，同列其他不可能作为起点的节点分数为 0， 父节点为空。
5. 递推时如何更新当前节点分数？
   参考答案：比较所有父节点的最佳路径分数，选最大者，再乘以当前节点概率。

### 01:09:35-01:19:34

- 课件页码：lec15.recurrent.pdf p.80-p.99

#### 本段在整讲中的作用
这一段把 Viterbi 从思路推进到可训练的完整闭环：先把递推与回溯讲完，再把得到的最 佳 alignment 接回 loss、梯度和迭代训练流程。也就是说，老师在这里把“估计 alignment”和“用该 alignment 训练网络”真正接上了。

#### 教学展开
1. [01:09:35]-[01:11:06] 老师继续讲递推细节：
   - 顶行只有一个父节点，因此 best parent 直接沿顶行传递；
   - 其余行的父节点来自同一行左侧或上一行左侧；
   - 比较两者的 best path score，取较大者为 best parent。
2. [01:11:08]-[01:12:04] 老师说明按列推进的全过程：在一列里对每个节点都记录 best parent 与 best path score，然后进入下一列，直到右下角。
3. [01:12:25]-[01:13:00] 回溯阶段：最终节点固定是右下角；从它开始，沿着存好的 best parent 一直追溯回起点，就得到最可能的完整 alignment。
4. [01:13:56]-[01:14:49] Poll 4 的正确选项是前两条：
   - decoding 找到的是 compressed sequence 对输入的最可能 alignment；
   - 它运行在依据目标 compressed sequence 构造出来的概率表上。
   “逐列选最大符号”不是 Viterbi。
5. [01:14:55]-[01:15:53] 老师展示伪代码，但口头说会略过实现细节；重点是输出结果 是一条“当前模型给出的最佳猜测 alignment”。
6. [01:15:59]-[01:16:47] 一旦拿到 time-synchronous aligned sequence，训练就回到 前面已有的形式：对所有时刻，把 aligned symbol 与网络输出分布求 divergence，再在 时间上求和。
7. [01:16:47]-[01:17:19] 若使用 KL divergence 且目标 one-hot，则 loss 就是全时刻目标符号负对数概率之和，也就是逐时刻 cross entropy 求和。
8. [01:17:25]-[01:18:48] 梯度结构也很简单：对任一时刻的输出向量，只有对应该时刻 目标符号的那个分量会留下非零导数，其值是 $-1 / p(\text{target at } t)$；其余词表分量梯度为 0。
9. [01:18:50]-[01:19:34] 最后老师把整体流程串起来：初始化 alignment，按 alignment 训练模型，用当前模型做 Viterbi alignment 更新，再继续训练；SGD 场景里，对齐与 求导也可以在每个样本的前后向过程中联动完成。

#### 概念、符号与推导
- 顶行递推：因只有同一行前一个节点作为父节点，所以 best parent 固定，best path score 直接乘当前节点概率即可。
- 一般行递推：父节点候选是同一行左侧节点与上一行左侧节点；选 best path score 较 大的那个。
- 回溯：从右下角节点出发，按 best parent 指针逆向追踪到起点，恢复整条最优路径。
- 训练 loss：
  - 先用当前模型和目标 compressed sequence 找到最佳 aligned time-synchronous sequence；
  - 再对每个时刻比较 aligned symbol 与网络输出，求和得到总 divergence。
- 若目标是 one-hot，则逐时刻 KL/cross entropy 化简为 $-\log p(\text{target at } t)$。
- 对输出向量的梯度：除了目标符号对应分量，其余分量为 0；目标分量导数为 $-1 / p(\text{target at } t)$。

#### 例子与课堂提示
- Poll 4 的第三项特意拿“逐列取最大符号”做干扰项，是为了防止学生把 Viterbi 又误听成简单 greedy argmax。
- 老师在这一段明确说“伪代码自己看”，课堂重点不在实现，而在理解它如何与训练闭环对接。
- “先对齐、再求 divergence、再反传”是本段最重要的流程性提示。

   参考答案：前两条正确，第三条错误。

   参考答案：把 alignment 展成 time-synchronous 目标序列，对所有时刻的 divergence 求和。

#### 本段在整讲中的作用
这一段是全讲收束。老师先总结“猜 alignment 再训练”的两种工程落地方式，再指出这种 方法对初始对齐敏感、容易陷入局部最优，最后自然引出下一讲的 CTC：不显式承诺某一个 alignment，而是直接处理全部可能对齐。

#### 教学展开
1. [01:19:31]-[01:20:12] 老师说对齐与训练可以有两种执行方式：
   - 先为整个训练集估计 alignment，再训练模型；
   - 或在 SGD/mini-batch 训练时，对每个样本在 forward 中估计 alignment，在 backward 中直接用它求导。
2. [01:20:15]-[01:20:53] 然后老师指出这一方案的根本弱点：alignment 是猜出来的， 因此方法高度依赖初始 alignment。
3. [01:20:53]-[01:21:00] 如果初始猜测很差，就会导向差的初始模型；差的模型又会给 出差的重估 alignment，从而形成坏循环并陷入 poor local optimum。
4. [01:21:00]-[01:21:13] 因此更好的方向是“without explicit alignment”的训练，也 就是 Connectionist Temporal Classification framework。
5. [01:21:07]-[01:21:29] 老师预告下一讲会讲三件事：CTC、本来 greedy collapse 难 以处理的 repeated symbol separation，以及 CTC decoder。

#### 概念、符号与推导
- 本段没有新公式推导。
- 两种工程策略：全数据先重估 alignment 再训练，或在 SGD 中逐样本即时估计 alignment 并求梯度。
- 方法风险：初始 alignment 误差会经由“坏模型 -> 坏重估对齐 -> 更坏模型”链条被放 大。
- 下一步的替代方案：不显式固定某一个 alignment，而改用 CTC 框架处理训练。

#### 例子与课堂提示
- “poor local optimum” 是本段唯一明确的失败模式提示，说明 Viterbi re-alignment  训练并不是最终答案，只是通向 CTC 的过渡方法。
- 老师提到数据量大时错误可能互相抵消，但核心判断没有变：显式猜 alignment 的方法 本质上仍脆弱。
