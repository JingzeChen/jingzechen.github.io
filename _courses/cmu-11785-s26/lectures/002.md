## 学习目标

## 核心概念与依赖关系
- associationism：把认知理解为通过经验形成联想。
- connectionism：把信息和知识理解为存储在简单单元之间的连接中。
- biological neuron：为计算模型提供结构原型，包括 dendrite、soma、axon、threshold-like firing 直觉。
- McCulloch-Pitts neuron：把神经元建模为布尔阈值逻辑单元，说明“神经元可以计算”。
- Hebbian learning：首次给出“连接如何因经验而变化”的学习直觉，但它不稳定。
- perceptron：把学习从“共同激活就增强”推进到“按误差修正”，并在线性可分条件下保证收敛。
- multi-layer perceptron：通过分层连接突破单个 perceptron 的 XOR 限制，进而成为通用布尔函数机、通用分类器和连续函数逼近器。
- neural network as function：前述所有结构最终服务于同一件事，即把输入映射到输出。

## 关键推导、例子与结论边界
- Hebb rule：$w_{xy} = w_{xy} + \beta xy$。关键边界是它只有增强没有减弱，因此不稳定。
- perceptron update：$w = w + a\,(d(x)-y(x))\,x$。关键改进是以误差驱动学习，而不是只做正向累加。
- 阈值与 bias 的等价改写：把“加权和超过阈值”改写为“先算 affine function，再过 threshold activation”。
- XOR 反例：单个 perceptron 做不到 XOR，但少量 perceptrons 组网后就能做到。
- 五边形/双五边形/六边形例子：说明复杂决策边界可由多条线性边界层层组合。
- 方脉冲逼近连续函数：说明 MLP 不只是分类器，也能近似连续值函数。
- 结论边界：本讲把 MLP 讲成 universal approximator，但 depth 的作用、更加正式的近似论证都被留到下一讲。

## 易错点与待核对项
- 易错点：80 billion 指大脑中 neurons 数量，100 trillion 指 connections 数量。

- 易错点：Hebbian learning “会学”不等于“稳定可用”；它缺少权重减小机制。

## 本段在整讲中的作用

## 教学展开
- [00:32:01-00:33:28] 老师先介绍 Bain 在 1873 年《Mind and Body》中的主张：大脑通过 neurons 之间的连接存储信息，尤其是感知之间、刺激与反应之间的 association。随后用二值化小电路举例：输入与输出都取 0/1，神经元在“所有输入都发火”时发火；于是 A、B 触发 X，B、C 触发 Y，A、C 触发 Z，同一组连接在不同输入模式下产生不同输出模式。
- [00:33:28-00:34:08] 老师再给出强度版本的例子：若输入强度低，X 可能得不到足够累计而不发火，Y 因接收到更多“拷贝”并在持续时间足够时发火；若输入强度高，则 X 与 Y 都会发火。老师据此强调，这已经非常接近现代神经网络的思路，而且提出时间早到 1873 年。
- [00:34:10-00:35:01] 接着老师说 Bain 不仅提出结构，还提出学习机制：当两个 impressions 同时出现或紧密相继时，神经流会找到某种“桥”或“连续处”，从而建立联结。老师明确指出，这几乎就是后面会讲到的 Hebbian learning，只是 Bain 比 Hebb 早了约 75 年。
- [00:35:04-00:36:35] 之后老师讲 Bain 的怀疑与反悔：他的同时代人觉得他在胡说，他自己也逐渐怀疑。1873 年他估计需要 100 万个 neurons 和 50 亿个连接来表示 20 万个 percepts；到 1883 年又担心没有把部分形成的联想计入；到 1903 年索性认定大脑不够大、理论不成立并公开撤回。但老师立刻指出：Bain 后来错了，他早先反而对了，因为现代估计认为大脑约有 800 亿个 neurons 和约 100 万亿个 connections，完全足以支撑这一想法。
- [00:36:37-00:37:29] 老师据此下结论：connectionism 并未死去。今天我们认为大脑确实是一台 connectionist machine；neurons 连接到 neurons，脑的处理能力和信息容量由这些连接决定，现代人工神经网络正是在模拟这种结构。
- [00:37:29-00:39:54] 随后老师转向和传统计算机架构的对比。他先追问普通处理器是什么架构，引出 von Neumann / Princeton 架构以及 Harvard 架构：关键不在变体区别，而在“处理单元”和“存储程序/数据的内存”相互分离。传统机器之所以能轻易做许多不同任务，是因为只要把新程序装进内存即可。
- [00:39:14-00:39:54] 紧接着老师强调 connectionist machine 与之不同：在 connectionist machine 里，程序就在连接中，计算机本身就是程序，程序与记忆都编码在单元之间的连接里。因此若要改程序，就得改机器本身，这也是很少直接做“纯硬件神经网络”的原因；现实中通常是在普通 Harvard/Princeton 机器上模拟 connectionist machine。

## 概念、符号与推导

- [00:52:44-00:54:06] 因此老师引出 Donald Hebb，并简述其经历：从想当小说家、农夫、流浪汉、教师，到最终进入 Harvard 成为心理学家。1949 年《Organization of Behavior》提出：若细胞 A 的 axon 足够接近并反复参与激活细胞 B，那么某种生长过程或代谢变化会让 A 更容易再次激活 B。

- [00:55:13-00:56:07] 在数学层面，老师定义从 neuron x 到 neuron y 的连接权重为 $w_{xy}$，并把 neuron 输出视为 0/1。Hebbian rule 写成：$w_{xy} = w_{xy} + \beta xy$。只有当 $x=1$ 且 $y=1$，即 x 成功触发 y 时，权重才增加。

## 概念、符号与推导
- Hebbian learning 的口语表述：neurons that fire together wire together。[00:54:02-00:54:06]
- 突触层面的直观机制：成功触发后 synaptic knob 会变大，使得同一路径下次更容易成功触发。[00:54:46-00:55:13]
- Hebbian rule：$w_{xy} = w_{xy} + \beta xy$。其中 $w_{xy}$ 是从 x 到 y 的连接权重，x、y 取 0/1，仅在两者同为 1 时增加权重。[00:55:13-00:56:07]
- 不稳定性来源：规则只有正向增长项，没有负反馈或归一化项，因此权重会无界增大。[00:56:09-00:56:58]
- perceptron 单元：接收多个输入，做加权求和，与阈值 $t$ 比较，超过则输出 1，否则 0。[00:59:59-01:00:37]
- perceptron 学习规则：$w = w + a\,(d(x)-y(x))\,x$，其中 $d(x)$ 是期望输出，$y(x)$ 是实际输出，误差项决定权重增减方向与幅度。[01:01:04-01:01:53]

### 01:01:51-01:11:49

## 本段在整讲中的作用
- 本段把 perceptron learning rule 与 Hebb rule 的区别讲清楚，并从单个 perceptron 的能力边界出发推到多层 perceptron 的必要性，最后再把模型扩展到实值输入与 affine 视角。[01:01:51-01:11:49]
- 它承担两个关键任务：一是解释“为什么 perceptron 比 Hebb 更可用”，二是解释“为什么单个神经元不够，必须组网”。

## 教学展开
- [01:01:51-01:02:30] 老师先回答上一段留下的问题：perceptron rule 与 Hebb rule 的关键差别在于引入了 desired output，并按误差而不是按共同激活本身更新权重。若输出已等于期望值，则权重不再变化；若有误差，才按误差大小调整。这给了系统 negative feedback。
- [01:02:38-01:03:02] 接着老师说明 Rosenblatt 还证明了一个重要结论：若数据 linearly separable，即期望输出为 1 与 0 的两类样本可被一个 hyperplane 分开，则该学习规则保证收敛到一组把两类分开的权重。
- [01:03:05-01:04:19] 然后老师讲历史反噬：Rosenblatt 原本谈的是“大量单元构成的完整模型”可表示任意布尔函数，但媒体和后来很多人把这个能力误投射到单个 perceptron 单元上，甚至出现“会走、会说、会看、会写、会自我复制并有自我意识”的夸张报道。老师说，这种夸大后来导致神经网络研究经费一度枯竭。
- [01:04:26-01:05:19] 为了准确理解单个 perceptron 的能力，老师先展示它如何模拟基本布尔门：合适的权重和阈值配置可以实现 AND、OR、NOT。
- [01:05:26-01:06:00] 但老师随即指出单个 perceptron 的限制：它无法计算 XOR，这说明单个单元不是 universal Boolean machine。
- [01:06:03-01:06:39] 解决办法不是放弃，而是回到“脑是网络而非单个神经元”这个起点。老师给出 3 个 perceptrons 的组网例子：一层做 OR，一层做 “not X or not Y”，最后再做 AND，从而得到 XOR。
- [01:06:22-01:06:39] 在这个结构里，前一层两个中间单元被称为 hidden layer，不是因为它们真的隐形，而是因为我们最终关心的是最后输出单元的输出。
- [01:06:43-01:08:20] 一旦接受 perceptrons 可以分层连接，老师就把结论推到一般情形：任意复杂的布尔函数都可以通过恰当连接的多层 perceptrons 来计算。因此 multi-layer perceptron, MLP, 是 universal Boolean function machine。
- [01:08:20-01:09:21] 不过老师立刻补充，大脑不只处理布尔输入输出，所以还要把 perceptron 推广到实值输入。此时 perceptron 依旧先做加权求和，只是输入和权重都允许为实数；把阈值重写为 bias，就得到“先算 affine function，再过 threshold activation”的视角。
- [01:09:21-01:11:49] 最后老师详细区分 linear 与 affine：若 $\sum_i w_i x_i = 0$，对应穿过原点的 hyperplane；若 $\sum_i w_i x_i + b = 0$，仍是 hyperplane，但不必经过原点。因此多出来的 bias 项就是原阈值的另一种写法。

## 概念、符号与推导
- perceptron 与 Hebb 的差别：Hebb 按共同激活正向累加；perceptron 按误差 $d(x)-y(x)$ 调整，因此可能增加也可能减少权重。[01:01:51-01:02:30]
- linearly separable：输出为 1 与 0 的两类样本可被一个 hyperplane 分开；在此条件下 perceptron learning 保证收敛。[01:02:38-01:03:02]
- 单个 perceptron 能模拟 AND、OR、NOT，但不能模拟 XOR。[01:04:26-01:06:00]
- hidden layer：中间层，其单元输出通常不是最终关心目标，而是服务于最后输出层的组合计算。[01:06:22-01:06:39]
- MLP：把 perceptrons 按层连接得到的网络，能够表示任意复杂布尔函数。[01:06:43-01:08:20]
- perceptron 的 affine 视角：将“加权和超过阈值 $t$”改写为先计算 $z=\sum_i w_i x_i + b$，其中 $b=-t$，再施加 threshold activation。[01:08:54-01:10:25]
- linear 与 affine 的区别：前者定义经过原点的超平面，后者定义一般位置的超平面。[01:11:02-01:11:49]

## 概念、符号与推导
- 实值 perceptron：输入 $x_1,\dots,x_N$ 和权重 $w_1,\dots,w_N$ 为实数，超过阈值则输出 1，否则输出 0。[01:12:28-01:12:59]
- 判别边界：满足“加权和等于阈值”的点集，几何上是一个 hyperplane。[01:12:41-01:12:50]
- 复杂分类边界的组合原则：单个 perceptron 给出线性边界，多层网络用 AND/OR 组合这些边界形成多边形及其并、交等复杂区域。[01:14:07-01:15:45]
- universal classifier：因为任意复杂决策边界都可由足够多的线性边界组合到任意精度，所以 MLP 可用于一般分类任务。[01:16:06-01:17:32]
- 连续函数逼近直觉：两个阈值单元可围出区间 $[T_1,T_2]$ 的脉冲，再将多个脉冲按高度加权求和逼近目标函数；区间越细，逼近越精确。[01:18:45-01:20:07]
- neural network as function：给定一个或多个输入，逐层计算并输出一个或多个预测值，这就是 AI 任务的统一描述。[01:21:14-01:21:47]
