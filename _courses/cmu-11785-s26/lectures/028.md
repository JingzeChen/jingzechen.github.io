## 学习目标
- 理解 Hopfield network 的结构约束、局部翻转规则与对称权重为何是后续收敛分析的前提。
- 能复述从局部翻转、全局量单调变化到能量递减与有限步收敛的证明链条。
- 理解 Hopfield net 作为 content-addressable memory 的含义，以及稳定模式、镜像模式、false memories 的来源。
- 掌握单模式与多模式 Hebbian learning 的构造、容量局限、parasitic patterns 与经典 $0.14N$ 结论。
- 能概括基于能量优化的改进训练思路：降低目标模式能量、抬高目标邻域中的坏谷，并理解 valley 与 down-valley 近似的作用。

## 需要的先修知识
- 前馈网络、阈值单元与 recurrent / loopy dynamics 的基本直觉，因为老师不断把 Hopfield net 与 feedforward net、RNN 和共享参数的深层网络互相类比。
- 向量内积、二次型、矩阵对称性与外积，因为能量函数、Hebbian 规则和梯度更新都建立在这些表示上。
- 基本优化与梯度下降概念，因为后半讲把“记忆哪些模式”重新写成最小化与最大化能量的目标函数问题。
- 基础物理类比直觉会有帮助，因为老师用 spin glass、dipole、外部磁场和能量地形解释网络收敛与局部极小值。

## 老师的教学主线
老师先把本讲放在课程最后两讲与 2024 年诺奖的背景里，先讲 John Hopfield 的网络，下一讲再讲 Geoffrey Hinton 的扩展。随后他从“把前馈网络的输出重新送回输入”开始，引入对称二值 loopy network，并用局部 field 与翻转规则定义 Hopfield net 的动态。接着，他先证明这种局部翻转不会无限持续：每一步都会让某个全局量单调增加，而该量又有上界，于是网络会在有限步内停下。

在此基础上，老师把单调量改写成能量函数，并借 spin glass 类比说明 Hopfield net 为什么天然是一个会滑向局部低谷的动力系统。由此，网络的稳定模式被重新解释成 content-addressable memory 的记忆项：从残缺或受噪声污染的状态出发，系统会被吸回最近的完整模式。再往后，课堂重点转到“怎样让网络记住我们指定的模式”。老师先区分 stationary 与 stable，再给出单模式 Hebbian learning，随后指出多模式平均 Hebbian 会遇到容量上限与 parasitic patterns。最后他把问题重新写成目标模式低能量、非目标模式高能量的优化任务，进一步把“反记忆全部非目标模式”的不可行目标一步步收缩成只抬高目标模式附近坏谷的近似梯度训练程序。

## 核心概念与依赖关系
- Hopfield network 的结构定义是整讲起点：神经元输出取 $\pm 1$，局部更新由 field 决定，权重矩阵满足对称性。
- 局部翻转规则先导出“某个量单调增加”，再被改写成“能量单调下降”，所以收敛性证明先于能量视角出现。
- 能量地形与 spin glass 类比共同把网络从“分类器”改写成“动力系统”，这一步才使 content-addressable memory 的解释成立。
- 记忆模式必须同时满足 stationarity 与 stability；只有不变而不抗扰动的状态，不能被当作可靠记忆。
- 单模式 Hebbian learning 通过 $w_{ij}=y_i y_j$ 让目标模式成为 stationary，进一步通过最低能量论证使其稳定。
- 多模式 Hebbian 只是“对目标模式做正更新”的一半，因此会带来容量上限与 parasitic patterns，并不能精确实现“只记住该记住的模式”。
- 后半讲的优化视角把训练目标写成“拉低目标模式、抬高非目标模式”的能量设计问题，再逐步近似成只针对重要 valley 或目标邻域做负更新。

## 关键推导、例子与结论边界
- 收敛证明的关键分成两步：先看单个神经元翻转前后 $y^- f$ 与 $y^+ f$ 的变化，再把局部变化累加成带有上界的全局量，从而证明有限步终止。
- 能量定义 $E=-\frac{1}{2}\sum_j y_j\,field_j$ 与矩阵形式 $E=-\frac{1}{2}\sum_{i,j} w_{ij} y_i y_j$，把上一段的单调量重写成更熟悉的“每步能量递减”。
- spin glass、dipole 与外部磁场类比说明：Hopfield net 的权重、偏置和翻转，不是临时数学技巧，而是直接对应物理系统沿局部低能量态演化的机制。
- Bugs Bunny、Chip and Dale、penguin / Joker / Earth 这些例子说明 content-addressable memory 的本质不是识别语义，而是从初始状态滑入最近吸引盆。
- 单模式 Hebbian 的核心推导是 $w_{ij}=y_i y_j$ 使每个神经元的 field 与自身取值同号，因此目标模式 stationary；再由能量最小性推出 stability。
- 多模式 Hebbian 的经典结论是随机模式容量约为 $0.14N$，且存在召回误差与 parasitic patterns；老师也明确提醒这只是 Hopfield 原始规则的局限，不是所有可能权重设计的绝对极限。
- 讲末的梯度视角给出更一般的训练原则，但对所有 $2^N$ 非目标模式做负更新不可行，所以最终程序必须依赖 valley 抽样与邻域近似，而不是全局精确优化。

## 易错点与待核对项
- 不要把 Hopfield net 仅理解成“多了回边的 MLP”；老师真正强调的是它变成了一个会持续演化直到局部稳定的动力系统。
- 不要把“停止翻转”和“稳定记忆”混为一谈；stationary 只是必要条件，stable 才说明受小扰动后会回到原模式。
- 不要把 content-addressable memory 误解为“可从权重矩阵直接读出所有记忆”；阈值非线性和离散状态空间会制造额外低谷与伪记忆。
- 不要把 Hebbian learning 当成完整最优解；老师明确指出它只做了“学习目标模式”这一半，没有对非目标模式做反向抑制。
- 关于自连接、若干能量常数项、$-0.5 * n * n - 1$ 这类口述数值，以及 $1.06^N$ 所对应的精确定理命题，若需论文级引用仍应回看录音与课件。[需回听]

- 00:04:20-00:05:17，对照 [课件: lecture_25_Hopfield_S26.pdf p.3-p.4]，老师先回顾“目前为止看到的都是 feedforward structures”，再追问如果把输出重新喂回输入会怎样，于是得到 loopy network，并提醒这和可变长度递归的 recurrent neural network 很像。
- 00:05:17-00:06:10，对照 [p.4-p.6]，老师规定本讲讨论的具体网络：每个神经元都是阈值单元，输出只能取 +1 或 -1；每个神经元接收所有其他神经元的输入，也把输出送给所有其他神经元；再额外要求权重矩阵对称，令 $W_{ij}=W_{ji}$，这就是 Hopfield network。
- 00:06:12-00:08:53，对照 [p.7-p.9]，老师解释运行机制。每个神经元先接收一个 field，也就是由所有输入形成的 affine term；如果当前输出与 field 同号，就不变；若异号，就翻转。老师把它口头写成：当输出与 field 的乘积为负时，神经元从 $Y$ 翻到 $-Y$。
- 00:08:53-00:10:01，老师强调一旦某个神经元翻转，它对其他神经元 field 的贡献也会改变，所以其他位置也可能跟着翻，这就是“回路”真正带来的连锁演化。

概念、符号与推导：
- Hopfield network 的结构约束：
  - 神经元输出为二值：$+1$ 或 $-1$。
  - 全连接到其他神经元，但不在本段明说自连接是否保留；后文默认不考虑自连接。[需回听]
  - 权重对称：$W_{ij}=W_{ji}$。
- field：老师把每个神经元接收到的 affine term 称为 field，对应 [p.7-p.9] 中“weighted sum of other neurons' outputs”。
- 翻转规则：
  - 若当前输出和 field 同号，输出不变。
  - 若当前输出和 field 异号，输出翻转。
  - 等价表述：若当前输出与 field 的乘积为负，则 $Y \rightarrow -Y$；若乘积为正，则保持不变。
- 本段尚未进入正式能量函数推导，重点只是把结构约束和局部更新规则定义清楚。

例子与课堂提示：
- [课件: p.3-p.4] 的对比图把“前馈网络”与“把输出送回输入的网络”并置，服务于知识点：Hopfield net 不是在原有 MLP 上多加几条边，而是把信息流改成持续回灌的动态系统。
- 老师把 loopy net 类比成“可变长度递归的 recurrent neural network”，服务于知识点：帮助学生用已有 RNN 经验理解“重复应用同一组权重”的动态图景。
- [课件: p.7-p.9] 的翻转说明强调：单个节点的局部一致性修正，会立即改变别处的局部场。这是后面必须引入全局量来证明不会无限振荡的根源。
- 00:06:31-00:07:04 老师故意让学生“接管剩余课堂”，是在提示：到这一步为止，网络定义已经足够具体，后续行为应该能由课程前面学过的感知机和递归直觉自行推出。

本段掌握检查：
1. 本讲在课程结尾处分别把哪两位研究者放在今天和下节课的中心位置？
答案：今天是 John Hopfield；下节课是 Geoffrey Hinton 对 Hopfield network 的扩展。
2. Hopfield network 与前面见过的 feedforward network 最核心的结构差异是什么？
答案：输出会反馈到输入，网络形成回路，因此输入一次后系统会持续演化而不是单向传播到输出即停止。
3. 本讲约定的神经元输出取值是什么？
答案：每个神经元都是阈值单元，输出只能是 $+1$ 或 $-1$。
4. 为什么老师强调网络是对称的？
答案：因为令 $W_{ij}=W_{ji}$ 后，一些关键数学性质才成立，后面关于能量与收敛的分析依赖这个对称性。
5. 神经元何时翻转？
答案：当它当前输出的符号与该位置 field 的符号相反时翻转；等价地说，输出与 field 的乘积为负时翻转。

### 002 00:10:00-00:19:47

本段在整讲中的作用：
- 本段承接上一段的“回路导致连锁翻转”，先说明这种演化表面上可能无穷持续，再通过局部量和全局量的递增关系给出“不会永远翻”的证明思路。
- 这一步为后面把递增量改写成能量递减、再引出稳定记忆提供了严格基础。

教学展开：
- 00:10:00-00:11:31，对照 [课件: lecture_25_Hopfield_S26.pdf p.10-p.17]，老师先让学生看一组网络演化示例：一个神经元翻转会改变其他神经元的 field，继而触发新的翻转，甚至让先前翻过的神经元再次翻回，因此表面上会一直“back and forth”。
- 00:11:44-00:12:09，老师抛出关键问题：这种行为会不会永远持续。答案是否定的，而且“有办法证明”。
- 00:12:13-00:15:19，对照 [p.18-p.19]，老师固定某个神经元，定义它在响应前后的输出分别为 $y^-$ 和 $y^+$，field 记为 $f$。若 $y^- f > 0$，说明输出与 field 同号，因此不翻转，$y^+=y^-$，于是 $y^+f-y^-f=0$。若 $y^- f < 0$，说明异号，神经元翻转，$y^+=-y^-$，于是 $y^+f-y^-f=2y^+f$；而翻转后的 $y^+$ 已与 $f$ 同号，所以该项严格为正。
- 00:15:19-00:16:24，老师总结：神经元若不翻，相关乘积不变；若翻，则这个乘积一定增加。也就是说，每次局部翻转都把某个量往上推。
- 00:16:26-00:19:43，对照 [p.20-p.21]，老师把这个局部量扩展成跨所有节点的总和：field 由所有加权输入和偏置组成，所以全局量本质上是所有 $W_{ij}Y_iY_j$ 与 $B_iY_i$ 的求和。每次网络演化，该值至少增加一个正的有限量；同时由于所有 field、权重、偏置都有限，这个全局量又有有限上界。因此“上界 ÷ 最小正增量”给出一个有限步数，说明网络必在有限步内停止演化。

概念、符号与推导：
- 记号定义：
  - $y^-$：第 $i$ 个神经元响应当前 field 之前的输出。
  - $y^+$：第 $i$ 个神经元响应当前 field 之后的输出。
  - $f$：该神经元在当前时刻看到的 field。
- 局部两种情况：
  - 若 $y^-f>0$，则不翻转，$y^+=y^-$，因此 $y^+f-y^-f=0$。
  - 若 $y^-f<0$，则翻转，$y^+=-y^-$，因此 $y^+f-y^-f=2y^+f$，且该值为正。
- 老师关心的全局量是“所有神经元的输出与各自 field 乘积之和”，口述中把它写成由两部分构成：
  - 所有神经元对之间的 $W_{ij}Y_iY_j$ 求和。
  - 偏置项 $B_iY_i$ 求和。
- 结论链条：
  - 每次翻转都会让该全局量增加。
  - 增量存在正下界，因为 field、权重、偏置都有限且不是全零网络。
  - 全局量存在上界，因为所有 field 都有限。
  - 因而总翻转次数有限，网络不可能无限演化。

例子与课堂提示：
- [课件: p.10-p.16] 用红边表示 $+1$、蓝边表示 $-1$，黄点表示 $-1$、黑点表示 $+1$，服务于知识点：把“符号不一致导致翻转”的抽象规则变成可观察的动态图。

概念、符号与推导：
- 连续能量与二值约束：
  - 连续形式的 $E=-0.5\,Y^T W Y$ 被老师描述为 concave quadratic。
  - 但真实 Hopfield 状态只能落在超立方体角点，因为每个分量只允许 $\pm1$。
- 记忆的两个条件：
  - Stationarity：处在该模式时不会自发改变。
  - Stability：稍加扰动后会回到该模式。
  - 结论：stationarity 是必要条件，但不足；stable 才是记忆真正需要的条件。
- Hebbian learning（单模式版本）：
  - 设目标模式为 $Y$，分量为 $y_i$。
  - 取 $w_{ij}=y_i y_j$。
  - 则对任一神经元，field 的符号与 $y_i$ 同号，因为 $\sum_j y_j^2$ 为正。
  - 因而神经元不翻转，目标模式 stationary。
