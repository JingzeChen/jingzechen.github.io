## 学习目标

- 理解为什么 full batch 更新计算代价高，以及 incremental updates 为什么可能更快。
- 理解 SGD 的核心机制、随机化要求与收敛所需的学习率衰减条件。
- 区分 expected divergence、empirical risk、sample loss、mini-batch loss 之间的关系。
- 掌握 mini-batch 为什么在现代训练中成为主流折中方案。
- 理解 momentum、Nesterov、RMSProp、Adam 分别在“平滑梯度趋势”和“按方向调节学习率”上的作用。

## 需要的先修知识

- 经验风险最小化与训练集/总体分布的区别。
- 反向传播与梯度下降的基本更新式。
- 方差、期望、无偏估计、独立同分布样本平均的方差缩减。
- 凸优化与非凸优化的基本收敛概念。

## 老师的教学主线

- 先回顾训练神经网络的总框架，指出 full batch 更新虽然直接最小化总 loss，但每步太贵。
- 再提出 incremental update / SGD：更频繁地更新、更快地吸收样本信息，但也更容易抖动。
- 随后问两个根本问题：它什么时候收敛，为什么会高方差。
- 在此基础上引入 mini-batch 作为计算与方差之间的折中。
- 最后回到 trend / adaptive optimizers，用 momentum、Nesterov、RMSProp、Adam 平滑或重缩放更新，进一步改善收敛。

## 核心概念与依赖关系

- batch update：一次更新前看全量训练集，直接优化经验风险，但计算昂贵。
- SGD：一次看一个样本，更新频繁，但样本级估计方差大。
- mini-batch：一次看一个小批量样本，在效率与方差之间折中。
- empirical risk：训练样本上的平均 divergence，是 expected divergence 的无偏估计。
- 方差缩减规律：样本平均的方差随样本数按 $1/n$ 下降，因此 mini-batch 会比 SGD 稳定。
- momentum / Nesterov：利用一阶趋势平滑梯度方向。
- RMSProp：利用平方导数的运行平均按方向缩放学习率。
- Adam：把 momentum 与 RMSProp 组合起来，同时利用一阶与二阶统计量。

## 关键推导、例子与结论边界

- SGD 收敛条件：$\sum_k \eta_k = \infty$ 与 $\sum_k \eta_k^2 < \infty$。
- 典型步长：$\eta_k \propto 1/k$ 满足上述两条。
- empirical risk 与 mini-batch loss 的无偏性是“统计期望意义”上的结论，不保证某次具体训练一定最小化真实 expected divergence。
- SGD 高方差的来源不是“有偏”，而是每次只看一个样本，无法用平均效应消掉采样噪声。
- mini-batch 的价值在于：仍保留频繁更新，同时让方差按 $1/B$ 缩小。
- momentum 解决的是“梯度方向抖动”，RMSProp 解决的是“不同方向应有不同学习率”，Adam 同时处理两者。

## 易错点与待核对项

- 不要把“无偏估计”误解成“单次训练必然正确”。
- 不要把“SGD 更快”理解成“最终误差一定更低”；本讲示例明确指出它可能更快但停在更差解。
- 不要把 momentum 与 RMSProp 混为一谈；前者平滑一阶趋势，后者按二阶矩调整学习率。
- 不要把 mini-batch 仅理解为“为了并行硬件”；它在统计上也通过 $1/B$ 降低方差。

## 概念、符号与推导

- 本段无公式推导。
- 经验风险最小化：训练目标是在训练集上最小化总误差；老师把它作为整门训练主线的正式名称。
- batch update：一次参数更新前，需要对全部训练样本做 forward pass、backward pass，并对所有样本导数求平均后才更新。
- incremental update 的直觉前提：如果只在一个位置局部修正，步子必须小，否则局部修正会把别处“顶出来”。

## 本段在整讲中的作用

这一段把上一段的“单手捏橡皮泥”直觉正式变成 incremental update 的训练程序，并进一步说明为什么样本顺序必须随机化。它直接给出 SGD 的核心操作方式、epoch 概念，以及“数据越相似，增量更新越占优”的第一层解释。

## 教学展开

- [00:11:27] 老师正式接住上一段的类比：不再试图一次把函数在所有点上都修正，而是一次只修正一个训练点。
- [00:11:39] 每次随机挑一个训练点，按该点误差方向微调函数；因为这种局部改动会影响其他位置，所以每次调整都要保持很小。
- [00:12:15] 虽然每一步只顾一个点，但当所有训练点都被处理过后，整个函数也被整体调整过了，而且累计调整量可能比一次 batch update 更大。
- [00:12:37] 老师给出伪代码直觉：遍历训练数据，对每个训练点立刻更新权重。
- [00:13:02] 定义 epoch：对整个训练集的一次完整遍历叫一个 epoch；若训练集有 t 个样本，则一个 epoch 会产生 t 次参数更新。
- [00:13:49] 老师指出这种方法有 caveats，并构造一个八个点、左右各四个点、函数形状近似抛物线的示例。
- [00:14:06] 若先连续处理左侧四个点，它们都会要求把左边压低，于是右边会鼓起来；接着再处理右侧点，又会把左边顶起来。
- [00:14:40] 因此，如果按固定顺序扫数据，更新会在左右之间来回打架，出现 cyclic behavior。
- [00:15:04] 解决办法是随机化样本顺序：每次不要把同侧样本连在一起处理，而是在不同位置间随机切换，让修正更容易互相抵消并走向收敛。
- [00:15:39] 伪代码层面的实现方式很直接：每个 epoch 内先对训练数据做随机排列，因此 epoch 与 epoch 之间的数据访问顺序不同。
- [00:16:08] 老师据此给出术语：按随机顺序逐个呈现训练实例的梯度下降，叫 stochastic gradient descent。
- [00:16:31] “gradient descent”强调仍然是在做梯度下降；“stochastic”强调训练样本是随机顺序出现的。
- [00:16:42] 老师强调 SGD 不是神经网络专属技巧，而是经验风险最小化问题中的通用优化算法。
- [00:17:05] 随后老师开始回答“为什么 incremental updates 会更有效”的问题，先给一个极端但容易理解的情形。
- [00:17:22] 极端情形是所有训练点完全相同；这时总体损失的梯度就是所有单样本梯度的平均，而这些梯度彼此相同。
- [00:18:38] 因而，处理全部样本求平均梯度，与只看一个样本得到的梯度没有区别。
- [00:19:11] 在这种情况下，batch update 处理完 t 个样本只能做 1 次小更新；而 SGD 每处理一个样本就做 1 次更新，同样算力下能做 t 次更新。
- [00:20:16] 老师进一步放松条件：即便训练样本不完全相同，只要彼此很相似，这种“同算力下更多次有效修正”的优势仍然大体成立。
- [00:20:52] 当数据越来越多样、越来越分散时，SGD 相对 batch 的这种优势会下降，但不会完全消失。

## 概念、符号与推导

- epoch：对全部训练数据的一次完整遍历。若训练集有 t 个样本，则 1 个 epoch 产生 t 次更新。
- SGD：按随机顺序逐个呈现训练实例，并在每个实例后立刻做一次梯度更新。
- 本段没有正式公式推导，但给出一个关键比较：
  - batch update：处理完 t 个样本后做 1 次更新。
  - incremental / SGD：处理 t 个样本时做 t 次更新。
- “为什么可能更有效”的第一层解释：若样本高度相似，则每个单样本梯度近似指向同一方向，于是多次小更新比一次平均后更新更积极。

## 例子与课堂提示

- [00:13:49] “左右各四个点、函数近似抛物线”的例子，服务于说明固定顺序处理样本会导致左右来回拉扯，出现周期振荡。
- [00:15:04] 随机打乱样本顺序的建议，服务于避免 cyclic behavior，是 SGD 能工作的重要工程条件。
- [00:17:22] “所有训练点完全相同”的极端例子，服务于解释为何同样算力下，SGD 可以用更多次更新换取更大的累计修正。
- [00:20:16] 老师提示不要把极端例子当作唯一适用场景：只要数据“clumpy”而非完全一致，结论仍部分成立。

## 概念、符号与推导

- 记号：
  - $W_0$：初始参数；
  - $W^{\ast}$：最优参数；
  - $\eta_k$：第 $k$ 次迭代的学习率。
- 收敛的两个充分条件（Robbins and Munro 1951，课件 p.58）：
  - $\sum_k \eta_k = \infty$：保证参数空间最终“可被走遍”，不至于总步长有限而永远走不到远处的解。
  - $\sum_k \eta_k^2 < \infty$：保证步长整体在缩小，不会一直大幅震荡。
- 典型满足条件的序列：$\eta_k \propto 1/k$。
  - 因为 $\sum 1/k$ 发散；
  - 但 $\sum 1/k^2$ 收敛。
- 收敛结论：
  - convex loss 下，SGD 收敛到最优解；
  - non-convex loss 下，SGD 至少可收敛到局部极小。（课件 p.58）

## 概念、符号与推导

- 目标函数区分：
  - expected divergence：对整个输入空间的真实期望风险；
  - empirical risk / loss：训练样本上的平均 divergence。（课件 p.67-69）
- 无偏性结论：
  - $E[\mathrm{Loss}(W)] = E[\mathrm{div}(f(X;W), g(X))]$；
  - 所以经验风险是 expected divergence 的无偏估计。（课件 p.68-69）
- 方差结论：
  - 若样本独立同分布，则样本平均的方差满足 $\mathrm{var}(\text{average}) = \frac{1}{n}\mathrm{var}(X)$；
  - 套到经验风险上，就是 $\mathrm{var}(\mathrm{Loss}) \propto 1/n$。（课件 p.70）
- 对 SGD 的推论：
  - 单样本损失的期望仍无偏；
  - 但因为相当于 $n=1$，所以方差最大。（课件 p.71-73）

## 概念、符号与推导

- 记号：$B$ 表示 mini-batch size。
- mini-batch update：每次使用一个随机选出的、大小为 $B$ 的样本子集来估计梯度并更新参数。（课件 p.88-89）
- 无偏性：mini-batch loss 的期望仍等于 expected divergence，因此仍是无偏估计。（课件 p.90-91）
- 方差：$\mathrm{var}(\text{mini-batch loss}) \propto 1/B$。（课件 p.92）
- 极端情形：
  - $B=1$ 时退化为 SGD；
  - $B=N$ 时接近 full batch。
- 实践结论：通过选合适的 $B$，可以在“低方差”和“低计算延迟更新”之间取得折中。

## 教学展开

- [01:01:19] 老师先回答“损失函数何时会在迭代间变化”：在 online training、SGD、mini-batch 中，每次迭代看到的训练实例集合不同，因此 loss 本身也在变。
- [01:01:39] 这意味着即便参数站在同一位置，不同迭代也可能得到完全不同的梯度；所以与 full batch 相比，这些方法更需要处理“趋势和平滑”问题。
- [01:02:20] 老师指出：由于 loss surface 本来就会随位置改变梯度，而在线/小批量训练又额外让 loss 本身抖动，所以 momentum 在这里比 batch descent 中更重要。（课件 p.114-118）
- [01:02:48] 随后进入回顾：momentum 如何做？核心是同时决定“怎样计算导数的历史趋势”和“怎样更新参数”。
- [01:03:20] 老师回忆标准 momentum：维护一个梯度修正的 running average；当前步长等于之前平均步长的缩放版本加上当前负梯度修正。（课件 p.102-106, p.115）
- [01:04:16] 这种方法的效果是：梯度在某方向上持续同号时，累计步子会变长；若梯度在某方向上不断翻转，历史平均会把它压小。
- [01:04:21] 老师用经典等高线图回顾：vanilla gradient descent 在狭长谷地中会左右摆动，而 momentum 会压制摆动并更顺滑地下坡。（课件 p.102, p.107）
- [01:04:54] 接着老师追问 momentum 的改进版是什么，答案是 Nesterov’s accelerated gradient。
- [01:05:37] 老师先重述普通 momentum 的顺序：先在当前位置算梯度并走一步，再叠加上一轮历史步长的缩放版。

- [01:07:07] 因而新修正项可以理解为“历史步长的外推”加上“在外推位置计算出的新梯度步”。
- [01:08:04] 老师再用 Hinton 的图做比较：普通 momentum 可能会冲到较远位置，而 Nesterov 因为先前瞻再修正，能更快逼近最优点。（课件 p.113）

## 概念、符号与推导

- 本段主要回顾趋势法的更新规则，符号与含义如下：
  - $\Delta W^{(k)}$：第 $k$ 次迭代的参数修正；
  - 当前修正方向由负梯度给出；
  - momentum 用历史修正的运行平均替代“只看当前梯度”。（课件 p.102-106）
- momentum 的核心思想：
  - 若某方向梯度长期一致，则运行平均增强该方向步长；
  - 若某方向梯度频繁翻转，则运行平均削弱该方向步长。
- Nesterov 的核心变化：
  - 普通 momentum：先在当前位置算梯度，再加历史步长；
  - Nesterov：先沿历史步长外推，再在外推位置算梯度。（课件 p.108-112, p.118）
- 本段没有把全部公式逐项写全，但讲清了顺序差异就是 Nesterov 的本质推导点。

- [01:04:21] 狭长谷地中的等高线图，服务于直观理解 momentum 为什么能抑制左右摆动。（课件 p.102, p.107）
- [01:06:03] “先迈出历史步再看梯度”的讲法，服务于把 Nesterov 与普通 momentum 的差别说得极为具体。

## 本段在整讲中的作用

## 教学展开

- [01:09:41] 老师回到标准 gradient descent 更新式，指出除了参数 $W$ 本身之外，更新里其实还有两个可控项：梯度与学习率。（课件 p.119-121）
- [01:10:18] momentum 只是在平滑“梯度项”，学习率项本身并没有变；于是老师提出“另一个项怎么办”。
- [01:10:58] 老师给出三段梯度序列，指出它们在水平方向平均起来差不多，但竖直方向的摆动幅度非常不同。
- [01:11:31] 因而不同方向其实应该有不同学习率：摆动越大的方向越不可信，学习率应更低；运动更稳定的方向学习率可更高。（课件 p.122-123）
- [01:12:47] 老师追问“如何判断哪个方向该更小”，学生答到与二次量有关，老师据此引入平方导数与均方导数的记号。

- [01:13:40] 关键直觉是：总运动大的方向应降学习率，总运动小的方向应升学习率。
- [01:14:26] 实现方式是维护平方导数的运行平均，并把学习率按其 RMS 值的倒数来缩放；为避免分母为零，还要加一个很小的 $\epsilon$。（课件 p.125-127）
- [01:15:50] 老师把这种方法命名为 RMSProp，并解释名字来源：若导数恒定，则 RMS 值与导数大小相消，效果很像 Rprop。（课件 p.126）
- [01:16:25] 老师反复强调 RMSProp 的核心不是“追着最新值跑”，而是“在摆动大的方向不太相信它，因此自动把该方向学习率调低”。
- [01:17:29] 接着老师回到总更新式：RMSProp 修的是学习率项，momentum 修的是梯度趋势项。
- [01:17:43] 于是最自然的下一步就是把二者合起来，得到 Adam：本质上就是 RMSProp with momentum。（课件 p.128-130）
- [01:18:05] Adam 同时维护一阶矩的运行平均与二阶矩的运行平均，再用前者做更新方向、用后者的 RMS 做归一化。（课件 p.130-132）
- [01:18:41] 老师还解释了 Adam 里看起来“有点 hacky”的早期校正项：因为初始时运行平均容易过小，若不做修正，前期更新会几乎停滞。
- [01:19:53] 所以分母里那类 $1-\gamma^k$ 风格的项，是为了让早期估计不要被初始化偏置压扁；随着 $k$ 增大，这个修正会逐渐失效，算法回到普通运行平均形式。（课件 p.131-132）
- [01:20:35] 老师最后补充：AdaGrad、AdaDelta、AdamW 等都属于同一主题的变体，但共享的基本原则不变。（课件 p.133）

## 概念、符号与推导

- 标准更新式包含两类核心量：
  - 梯度项；
  - 学习率项。（课件 p.119）
- RMSProp 的构造：（课件 p.124-127）
  - 对每个参数维护平方导数的运行平均；
  - 记平方导数的运行平均为该方向“总运动”的估计；
  - 用其 RMS（均方根）值缩放学习率；
  - 更新形如“学习率除以 RMS 再乘当前梯度”，并在分母加 $\epsilon$ 防止除零。
- Adam 的构造：（课件 p.128-132）
  - 同时维护一阶矩（导数均值）的运行平均；
  - 同时维护二阶矩（平方导数均值）的运行平均；
  - 用一阶矩给方向，用二阶矩 RMS 归一化步长；
  - 用早期偏置修正项避免初始运行平均过小导致更新停滞。
- 本段保留老师给出的推导层级：
  - 先从“不同方向应有不同学习率”出发；
  - 再用平方导数衡量摆动大小；
  - 最后把学习率按 RMS 缩放，并与 momentum 结合成 Adam。
