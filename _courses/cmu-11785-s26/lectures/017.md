## 学习目标
- 理解本讲研究的是“输入输出保持顺序、但不时间同步”的 sequence-to-sequence 模型，并知道为什么语音识别属于这一类。
- 理解三条训练线索之间的关系：给定对齐直接训练、Viterbi 式猜对齐再训练、对所有可能对齐取期望训练。
- 掌握 alpha、beta-hat、beta、gamma 的定义、方向与各自承担的计算任务。
- 理解 blank 如何消除重复字符歧义，并能说明 blank 对训练图与 trellis 连接规则的影响。
- 理解 greedy decode、理论最优 decode 与 beam/pruning 之间的关系与取舍。

## 需要的先修知识
- RNN / LSTM 的基本递推机制，因为老师用“概率向量只经隐藏状态传播”解释前后图分解。
- 负对数概率、KL 散度与常规 backpropagation，因为已知对齐训练从这些概念直接起步。
- 动态规划与图上递推的基本直觉，因为 forward-backward 与 beam search 都依赖“局部累计到全局”的思路。

## 老师的教学主线
老师先用语音识别、机器翻译、对话系统和问答系统区分两类 seq2seq：一类像语音识别，输入输出顺序一致，尽管不时间同步，却仍可对齐；另一类像机器翻译和对话，不保证逐位置对应。本讲只保留第一类。随后他回顾：若训练数据给了输出序列的时间对齐，就可以把标签扩成时间同步序列，直接最小化逐时刻目标符号对数概率的负和；若没有对齐，上节课曾提过 Viterbi 式“先猜对齐再训练”，但它依赖初始对齐，容易掉入差的局部最优。因此本讲转向“对所有对齐取期望”的训练视角。

在这个视角下，老师先把 reduced graph 中“经过某节点的路径总概率”拆成前向部分与后向部分，定义 alpha、beta-hat、beta，再把它们归一化成节点后验 gamma，最终得到 $-\sum \gamma \log y$ 的训练目标，以及对完整输出概率向量的简洁导数公式。之后他指出：即便训练问题这样解决了，greedy decode 仍然无法分辨重复字符，于是引入不可见 blank，重新定义压缩规则与 trellis 的 skip 连接。把这些规则加回 forward-backward 与梯度计算后，Connectionist Temporal Classification 的完整训练框架成立。最后老师回到推断：greedy 仍是单路径最优而非序列总概率最优，因此理论上要对所有候选压缩序列做搜索；实际中则通过 pruning / beam width 只保留 top few 候选，使解码变得可计算。

## 核心概念与依赖关系
- order-aligned but not time synchronous：这是本讲所有训练与解码推导的前提。只有在输入输出顺序一致时，才能把输出序列与输入时间轴构成 trellis 并谈论对齐。
- 已知对齐训练：它提供了最基本的目标函数和梯度结构，也是理解“未知对齐但对所有路径求期望”时的参照系。
- all-alignments 训练：它把“单条最佳路径”替换成“所有路径上的期望损失”，由此需要节点后验权重。
- alpha / beta / gamma：先用 alpha 表示到达节点的路径总概率，再用 beta 表示从节点继续到终点的路径总概率，最后把两者的乘积按列归一化成 gamma 作为节点后验。
- blank：它不改变“前向、后向、后验、梯度”这条主链，而是改变“哪些路径压缩后等价于同一可见输出”，因此会改变 trellis 的状态连接。
- optimal decode vs greedy decode：前者比较压缩序列跨所有对齐的总概率，后者只选最大时间同步路径；beam/pruning 是把前者做成近似可运行算法的工程手段。

## 关键推导、例子与结论边界
- 已知对齐时，损失是逐时刻目标符号对数概率的负和，输出向量梯度除目标分量外全为 0，目标分量呈 $-1/p$ 结构。
- 未知对齐时，把训练目标改成所有可能对齐的期望损失，再借助“路径经过节点的后验概率”把它改写成对所有节点的 $-\gamma \log y$ 求和。
- 前向递推的核心是“父节点 alpha 之和乘当前节点概率”，后向递推的核心是“当前节点概率乘子节点 beta-hat 之和”，节点后验 gamma 则是 alpha-beta 乘积的列归一化。
- 对完整输出向量求导时，老师明确保留 $\gamma / y$ 项，忽略显式的 $(\partial \gamma / \partial y) \log y$ 项，并把该结果解释为 maximum likelihood 形式。
- `red/read` 例子说明没有 blank 时重复字符无法区分；`E D D E` 说明相同相邻字符之间 blank 是必需的；`red/Ted` 说明单条路径概率峰值不等于压缩序列总概率峰值。
- 结论边界：老师给出了理论正确的 CTC 解码目标与 pruning 思路，但把完整长伪代码留到 slides 与作业，没有在课堂上继续展开实现细节。

## 易错点与待核对项
- 不要把“单条 best alignment”误当成稳定训练目标；老师明确指出其对初始对齐敏感，容易落入局部最优。
- 不要把 alpha-beta 乘积直接当作节点后验；它还必须按列归一化成 gamma。
- 不要把 blank 理解成“没有预测任何东西”；它是词表中的真实符号，只是在最终压缩后不可见。
- 不要忘记 skip 连接的判断规则：只有当隔两格的符号与当前不同，扩展图里才有第三个父节点/子节点。
- 不要把 greedy decode 当成理论最优；它只是在 CTC blank 机制下常常表现不错。
- 多处字幕存在术语和下标误写，正式引用时应按时间戳回听核对。[需回听]

### 001 00:00:05-00:10:02
本段在整讲中的作用：这一段先把本讲放回“循环神经网络与 sequence-to-sequence 模型”系列中，说明今天聚焦的是“输入输出保持顺序、但不按时间同步”的 seq2seq 场景，并回顾上节课已经讲过的“给定对齐时如何训练”与“未给定对齐时先猜对齐”的思路，最后把问题推进到“不要只押一个对齐，而要考虑所有可能对齐”。

教学展开：老师先提醒今天课程较长，并要求同学在提问时尽快回应。随后他说明本讲继续讲 RNN 中的 sequence-to-sequence 模型：输入是一个序列 $X_1\ldots X_n$，输出是另一个序列 $Y_1\ldots Y_m$，两者长度不要求相同。接着他用语音识别、机器翻译、对话系统、问答系统举例，说明“序列进，序列出”是共同结构，但输入输出之间未必有逐位置对应。之后老师区分两类问题。第一类像语音识别，输入输出虽然不时间同步，但顺序保持一致，因此可以做对齐；第二类像机器翻译，输入顺序改变后输出仍可能正确，因此不存在一一对应。再往下，他明确本讲只看第一类，也就是“order synchronous but not time synchronous”的情况，并把语音识别当作主例子。在此基础上，老师回顾此前留下的两个问题：一是这种模型怎样做推断，二是怎样训练。关于训练，如果训练数据给了输出序列及其对齐时刻，那么做法很直接：把目标序列扩展成和输入同长度的时间同步序列，再把总散度写成逐时刻散度之和；若逐时刻用 KL 散度，总体目标就是逐时刻目标符号对数概率的负和。老师进一步回顾其梯度结论：对某个时刻的输出向量求导时，除了目标符号所在分量外，其余分量都是 0，而目标分量给出 $-1/p$ 形式的导数。最后他转向“没有给对齐”的情况，先回顾上一讲提过的 Viterbi/迭代猜对齐办法：初始化一个对齐，用它训练模型，再用模型重新估计对齐并反复迭代。通过课堂投票与追问，他指出这类方法严重依赖初始对齐，容易把训练拖入很差的局部最优，于是引出替代思路：不要在每一轮只选一个对齐，而是考虑所有可能对齐。为此老师重新回到“如何从 reduced probability table 中得到对齐”的图示，提醒大家：从左上到右下的每条路径都是一个对齐，而先前只是取了最可能的那一条。

概念、符号与推导：sequence-to-sequence 模型的输入序列为 $X_1\ldots X_n$，输出序列为 $Y_1\ldots Y_m$，一般只要求“序列到序列”，不要求 $n=m$。老师把语音识别归入 order synchronous but not time synchronous：输入与输出保持顺序一致，但一个输出符号不一定对应固定时长。对非 order-aligned 的 seq2seq，如机器翻译、对话系统和问答系统，本讲不继续展开。已知对齐时的训练目标是：把目标输出扩成时间同步序列后，总散度写成逐时刻散度之和；老师口述为“逐时刻 KL 散度之和”，等价写成目标符号对数概率的负和。对某一时刻输出向量求导时，只有该时刻目标符号对应分量非零，其值为 $-1 / P(\text{target at } t)$。未知对齐时的第一种方案，是先猜一个对齐，训练后重新估计对齐，再迭代更新。本段没有给出新的完整公式推导，重点是回顾前序训练目标，并把问题转向“所有可能对齐”。

例子与课堂提示：机器翻译例子 “I ate an apple” 对到德语时，老师强调词与词之间并非一一对应，尤其 “ate” 会拆到两个输出成分上，用来说明不能把所有 seq2seq 都当成逐位置对齐问题。对话系统例子 “My screen is blank” 对应 “Please check if your computer is plugged in.”，用来说明有些任务中输出甚至看起来不像输入的逐段重排。语音识别例子则反复被用来强调：这是本讲真正处理的场景，因为语音和输出 phone/word 序列至少保持顺序一致。课堂投票中，老师确认 Viterbi training 会显式估计每个训练样本的对齐，而且每次迭代都要重新估计；这个投票服务于说明“先猜对齐再训练”的机制。老师特别提醒该方法的风险在于“初始猜测不好时会迅速陷入差的局部最优”，这是后面转向“对所有对齐取期望”的直接动机。

本段掌握检查：1. 老师为什么把语音识别和机器翻译分成两类 seq2seq 问题？参考答案：因为语音识别中输入和输出顺序一致、可以对齐，而机器翻译中输入输出不必保持逐位置对应，甚至重排后仍可能正确。2. 已知对齐时，训练目标在老师口中是怎样写的？参考答案：先把目标序列扩成时间同步序列，再把总散度写成逐时刻 KL 散度之和，也就是目标符号对数概率的负和。3. 已知对齐时，对某个时刻输出向量求导有什么结构？参考答案：除了该时刻目标符号对应分量外，其余分量都是 0；目标分量是 $-1/p$。4. “先猜对齐再训练”的主要问题是什么？参考答案：它高度依赖初始对齐；初始对齐差时，训练出的模型和重新估计的对齐都会差，容易落入局部最优。5. 本段结尾把问题推进到了哪里？参考答案：从“只取最可能的一条对齐路径”推进到“考虑所有可能对齐”。

待核对项：[00:04:52]-[00:04:56] 字幕中的 “callback library divergence” 应为老师在回顾 KL / cross-entropy 一类目标，具体措辞需回听。[00:09:55]-[00:10:00] 结尾处句子被截断，只能确认老师准备继续讨论“用最可能对齐计算 divergence”的问题设置。[需回听]

### 002 00:10:00-00:19:58
本段在整讲中的作用：这一段正式把训练目标从“只依赖单一最佳对齐”改成“对所有可能对齐取期望”，并给出后续 forward-backward 计算所需的关键量：某时刻某节点被随机对齐路径经过的后验权重。

教学展开：老师先接上前面的 reduced graph，指出“只选最可能的一条对齐路径”在训练早期可能非常不可靠，特别是模型初始化很差时。然后他请同学提出替代方案：可以按概率随机采样一条对齐，也可以对所有对齐求平均；老师明确说更稳健的是“average across all alignments”。接着他回到单个对齐的损失定义：若一条对齐给定，则其 divergence 是沿该对齐路径逐时刻对数概率的负和。要把它推广到所有对齐，只需用“该对齐本身的后验概率”对每条路径的 negative log probability 加权，于是总体目标就是“alignment 的 negative log probability 的期望值”。老师随后利用“期望是线性算子”把外层期望推进求和号内，得到新的解释：在每个时刻，不再只看单个节点，而是对该时刻所有可能节点的对数概率做加权平均。这个加权不是普通平均，权重恰好是“随机抽取一条对齐路径时，它经过该节点的概率”。最后老师把注意力集中到这个权重如何计算。他先说明，这个权重与“穿过该节点的所有路径总概率”成正比。然后把经过节点的整张图拆成前半段与后半段：前半段是到该节点为止的所有路径，后半段是从该节点之后到终点的所有路径。虽然一开始写成“前半段概率乘以后半段在前半段条件下的概率”，但老师立即说明，由于 RNN 在给定输入后，输出概率是通过隐藏状态递推出来的，而“这个时刻到底对齐到哪个符号”不会再反馈去影响后面的输出概率，所以图的两部分在这里可以视为条件独立，为后面定义前向量和后向量做准备。

概念、符号与推导：单个对齐的 divergence，被老师回顾为沿对齐路径逐时刻求 $-\log$ 概率的和。新的训练目标是对所有可能对齐的 divergence 取期望。其线性化步骤是：先写成“所有对齐的 negative log probability 的期望”；再利用期望的线性性，把期望移入逐时刻求和；最后在每个时刻，对所有节点的对数概率做加权平均。节点权重是“随机选一条对齐路径时，该路径经过这个节点的概率”，它与“所有经过该节点的路径总概率”成正比。图分解思想是：经过某节点的总路径概率可拆成“到该节点的前半图概率”与“从该节点之后到终点的后半图概率”的乘积；老师强调后半图不受该节点被对齐到哪个标签的反馈影响，因为 RNN 的递推只经过隐藏状态。本段没有把最终递推式完全写全，但已经把 forward/backward 的概率分解思路铺好。

例子与课堂提示：老师用“在横轴上列出所有对齐、纵轴上画出各自概率”的想象图，说明“总是拿最高的一条”其实等价于总是从分布中挑出最大概率样本，用来帮助同学理解为什么单路径训练不稳健。他还补充说，可以随机按分布采样一条对齐，但“对所有对齐取平均”更稳健；这是工程上和统计上都更可靠的建议。课堂投票的结论是：without alignment 的训练确实是对所有对齐的 divergence 求平均，而且正因为如此，不需要显式估计唯一的对齐路径。关于条件独立的解释，老师特别提醒：后续时刻的概率向量来自隐藏状态，而不是来自“当前时刻被配到了哪个符号”，这为把蓝色图和红色图乘起来提供了直觉依据。

### 003 00:19:55-00:29:54
本段在整讲中的作用：这一段开始把前面“前半图乘后半图”的想法落实成可计算的 forward 概率与 backward 概率，并先完整推出 forward recursion，为随后求节点后验和总体序列概率打基础。

教学展开：老师先承接上一段的条件独立结论，明确说经过某节点的整张图概率，可以写成“到该节点为止的红色部分概率”乘上“从该节点之后开始的蓝色部分概率”。他把前者记作 forward probability $\alpha_{t,r}$，表示“在时刻 $t$ 到达第 $r$ 个符号节点的所有路径总概率”；把后者记作 backward probability $\beta$，表示“从该节点之后继续到终点的部分图概率”。随后老师集中解释如何计算 $\alpha_{t,r}$。他强调：要到达某个节点，只能来自它的父节点。在当前图示中，这个节点只有两个父节点，所以到达它的所有路径，可以拆成“先到第一个父节点再转移过来”的所有路径，加上“先到第二个父节点再转移过来”的所有路径。于是某节点的 alpha 就是所有父节点 alpha 之和，再乘当前节点的节点概率。老师先用具体例子说明：某个 $e$ 节点的 alpha 等于上一时刻到 $b$ 的 alpha 乘该节点概率，加上上一时刻到 $e$ 的 alpha 乘该节点概率。然后他把它推广成一般规则：$\alpha_{t,r}$ 是该节点所有父节点 alpha 的和，再乘本节点概率。接下来他把这个公式变成算法步骤。初始化时，从最左列开始：第一个可达节点的 alpha 就是该节点自身概率，不允许出现在图里的节点 alpha 为 0。之后按列从左到右推进；在每一列里，对每个节点先把父节点 alpha 相加，再乘节点概率得到当前 alpha。一直推进到最右下节点为止。最后老师解释这个终点 alpha 的意义：最右下节点的 alpha，不是 1，而是“这个压缩符号序列在所有可能对齐上的总概率”。这是后面训练和解码都会反复使用的关键量。段末他再把视角拉回到原始分解式，指出前向部分已经算出来，接下来要算从当前节点到终点的后向部分，并先提出一个技术处理：为了避免“后向部分不包含当前节点”带来的麻烦，他先定义包含当前节点的 $\hat\beta$，之后再除以节点概率得到真正的 beta。

概念、符号与推导：forward probability $\alpha_{t,r}$ 表示从 source 出发，在时刻 $t$ 到达第 $r$ 行节点的所有路径总概率。一般 forward 递推为 $\alpha_{t,r} = (\sum_{p \in \mathrm{Parents}(t,r)} \alpha_p) \cdot y_{t,r}$。在老师当前示例中，每个节点有两个父节点，因此口头公式是 $\alpha_{t,r} = (\alpha_{t-1,r-1} + \alpha_{t-1,r}) \cdot y_{t,r}$。初始化时，首列中可作为起点的节点 alpha 等于该节点概率；不允许出现的节点 alpha 为 0。终点 alpha 的意义是：右下终点的 alpha 等于给定压缩符号序列在所有对齐上的总概率，而不是常数 1。$\hat\beta_{t,r}$ 是老师为处理“不含当前节点的后向图”而引入的中间量，定义为“从当前节点出发并包含当前节点”的到终点总概率。

例子与课堂提示：老师反复追问“某个节点的所有路径总概率是什么”，逼同学把“到某个节点的路径总概率”与 alpha 符号绑定起来，这个提问服务于让递推关系从图上直接读出来。“只有两个父节点”的图上例子，是为了让大家先接受“分情况枚举父节点”这一步，再推广到对所有父节点求和。他特别提醒：终点 alpha 不是 1，因为输入上可以对应许多不同的输出符号序列；当前终点 alpha 只表示“这个特定符号序列”的概率。对 beta 的处理里，老师明确说“先把当前节点也算进去，再除掉节点概率”，这是为了减少后向公式书写时的烦琐。

本段掌握检查：1. $\alpha_{t,r}$ 在本讲里表示什么？参考答案：表示从源点出发，在时刻 $t$ 到达第 $r$ 个节点的所有路径总概率。2. 为什么某个节点的 alpha 要对所有父节点求和？参考答案：因为任何到达该节点的路径，最后一步一定来自某个父节点，所以总概率是所有父来源路径概率之和，再乘本节点概率。3. 初始化时哪些节点的 alpha 会是 0？参考答案：图结构不允许作为起点的那些节点 alpha 为 0。4. 最右下节点的 alpha 代表什么？参考答案：代表该压缩符号序列在所有可能对齐上的总概率。5. 为什么老师又定义了 $\hat\beta$？参考答案：因为他想先计算“包含当前节点”的后向总概率，再通过除以节点概率得到真正不包含当前节点的 beta。

### 004 00:29:51-00:39:48
本段在整讲中的作用：这一段把上一段留下的后向量补全，进一步得到标准化后的节点后验 $\gamma$，从而把“所有对齐的期望损失”写成一个可以直接用于训练的逐时刻、逐节点求和公式。

教学展开：老师先解释真正的 beta 如何从 $\hat\beta$ 得到：既然后向中间量是“包含当前节点”的从该点到终点总概率，那么把它除以当前节点概率，就得到“不含当前节点”的 beta。之后他开始推导 $\hat\beta$ 的递推。他指出，从某个节点到终点，在当前例子里只有两种走法：先走到第一个子节点，再从那个子节点到终点；或者先走到第二个子节点，再从第二个子节点到终点。所以当前节点的 $\hat\beta$，就是当前节点概率乘以“所有子节点 $\hat\beta$ 之和”。在图上例子里，某个 $e$ 节点的 $\hat\beta$ 就等于该节点概率乘上下一时刻两个子节点的 $\hat\beta$ 之和。然后老师把它整理成 backward algorithm：从最右边开始初始化，右下终点节点的 $\hat\beta$ 就是节点自身概率，不可能作为终点的节点 $\hat\beta$ 为 0；随后按列向左回退，在每一列中，对每个节点把其所有子节点的 $\hat\beta$ 相加，再乘本节点概率。最后再把每个节点的 $\hat\beta$ 除以节点概率，得到真正的 beta。有了 alpha 和 beta，老师回到前面的目标量：经过某节点的所有路径总概率就是 $\alpha_{t,r}\beta_{t,r}$。但他马上提醒，这个量在同一列所有节点上加起来，不会等于 1，而是等于“该压缩符号序列整体的概率”。训练时真正需要的是“在给定这条压缩符号序列的前提下，随机一条对齐路径经过某节点的后验概率”，因此还要在列内做归一化。归一化后得到的量被老师记作 gamma：某节点的 gamma 等于该节点 alpha 与 beta 的乘积，再除以该列所有 alpha-beta 乘积的和。最后，老师把整段推导代回总体目标：总 divergence 就是对所有时刻、该时刻所有节点，累加“节点后验 gamma 乘该节点的对数概率”，外面再带一个负号。到这里，“不显式固定单一对齐”的训练损失公式就成形了。

概念、符号与推导：$\hat\beta_{t,r}$ 表示从当前节点出发、包含当前节点，到终点的所有路径总概率。backward 递推是 $\hat\beta_{t,r} = y_{t,r} \cdot \sum_{c \in \mathrm{Children}(t,r)} \hat\beta_c$。真正的 backward probability 是 $\beta_{t,r} = \hat\beta_{t,r} / y_{t,r}$。经过节点的路径总概率是 $\alpha_{t,r}\beta_{t,r}$。列归一化后的后验是 $\gamma_{t,r} = \frac{\alpha_{t,r}\beta_{t,r}}{\sum_{r'} \alpha_{t,r'}\beta_{t,r'}}$。最终损失写法则是：divergence 对所有时刻、所有节点的 $-\gamma_{t,r}\log y_{t,r}$ 求和。

例子与课堂提示：老师先在局部图里问“从这里到 sink 的所有路径总概率是什么”，再把答案逐个替换成各节点的 $\hat\beta$，帮助同学从图到公式过渡。他特别强调“alpha 乘 beta 不会自动和为 1”，因为它们的列和对应的是整个目标符号序列的概率，而不是条件在该序列上的节点后验。有同学提到 softmax，老师借此说明此处需要做的其实就是“按列归一化”，服务于把路径总概率转成真正的后验权重。段末老师说 “we have a formula”，说明这一节的重点不是再举例，而是把训练所需的数学量完整闭合起来。

本段掌握检查：1. $\hat\beta$ 与 beta 的差别是什么？参考答案：$\hat\beta$ 包含当前节点的概率，beta 不包含；两者关系是 beta 等于 $\hat\beta$ 除以当前节点概率。2. backward 递推为什么要对所有子节点求和？参考答案：因为从当前节点到终点的任何路径，第一步一定走向某个子节点，所以总概率是所有子分支概率之和，再乘当前节点概率。3. 为什么 $\alpha\beta$ 还需要归一化？参考答案：因为同一列所有节点的 $\alpha\beta$ 之和是整个目标序列的概率，不是节点后验；要得到后验必须再除以列和。4. gamma 表示什么？参考答案：表示在给定目标压缩符号序列时，随机一条对齐路径经过某节点的后验概率。5. 这一段最后把 divergence 写成了什么形式？参考答案：写成对所有时刻、所有节点的 $-\gamma \log y$ 累加。

### 005 00:39:49-00:49:48
本段在整讲中的作用：这一段把“对 reduced graph 的期望损失”真正接回 RNN 的输出层梯度，说明怎样从 gamma 得到对每个时刻完整词表概率向量的导数，并给出无对齐训练的整体流程，随后自然过渡到 CTC 中“重复字符无法区分”的解码问题。

教学展开：老师先用第三次投票的结论开场：forward-backward 算法计算的是“压缩序列中每个符号在输入上的对齐后验”，而这些后验正是计算“所有对齐期望 divergence”所必需的。接着他提醒，虽然 divergence 是在 reduced graph 上写出来的，但反向传播真正需要的是“对 RNN 在每个时刻输出的完整概率向量求导”。随后老师逐步分析这个导数的结构。对于不在压缩序列里的词表符号，导数显然为 0。对于出现在 reduced graph 某列中的符号，导数来自该列对应节点的项。如果某个符号只在这一列出现一次，例如 B 或 F，那么只会收到一个节点贡献；如果像 E 那样在同一列对应多个节点，那么这些贡献需要相加。在此基础上，老师把单个节点项写成 $\gamma_{t,r}\log y_{t,l}$ 的形式，并用乘法求导法则拆成两部分：一部分是相对容易的 $\gamma / y$，另一部分是 $\partial \gamma / \partial y$ 乘上 $\log y$。他直言后一项 “hideous”，因为 gamma 本身也依赖于输出概率 $y$。工程处理上，老师说“先把这项扔掉”，并补充这样做可以得到 maximum likelihood 形式，而且从数学上是正确的。于是最终导数变得非常简洁：对任意时刻、任意词表符号，其导数等于该符号概率的负倒数，再乘同一时刻所有标记了该符号的节点 gamma 之和。接着老师把这个导数塞回训练流程：输入先经过网络得到各时刻词表概率向量；根据压缩符号序列构造 reduced graph；在图上做 forward 和 backward 得到 alpha、beta；再得到 gamma；由 gamma 计算对输出概率向量的导数；最后用常规 backpropagation 回传并按 batch 更新参数。段末老师把 “story so far” 再收束一次：到这里，能够处理 time-asynchronous 输出的 seq2seq 训练已经建立起来，但当前 greedy decoding 仍然默认“每个时刻都有一个可见符号并把相邻重复折叠”，这就会在重复字符上出问题，下一段要解决的正是这个缺口。

概念、符号与推导：完整输出向量梯度具有稀疏结构，对不在压缩序列中的符号，导数为 0。若某词表符号在同一列对应多个节点，则该符号的导数要把这些节点的贡献相加。单节点项的求导拆分为 $\frac{\partial (\gamma \log y)}{\partial y} = \gamma / y + (\partial \gamma / \partial y) \log y$。老师在工程推导中舍弃第二项 $(\partial \gamma / \partial y) \log y$，保留 maximum likelihood 形式。最终导数写为 $\frac{\partial \mathrm{DIV}}{\partial y_{t,l}} = -\frac{1}{y_{t,l}} \sum_{r: \text{node}(t,r)=l} \gamma_{t,r}$。训练流水线则是：RNN 前向得到每个时刻的词表概率向量；依据压缩标签序列构造 reduced graph；forward/backward 得到 alpha、beta；用 alpha、beta 算 gamma；用 gamma 算输出层导数；再用常规反向传播更新参数。

例子与课堂提示：老师用同一列里 B、E、F 的例子说明：B 和 F 各只有一个节点贡献，而 E 会因为在图里出现两次而需要把两处 gamma 贡献相加。“hideous” 那一项的处理是一个明确的课堂提示：老师不是说它不存在，而是说工程上直接忽略，并给出“仍然对应最大似然”的解释。老师连续几次确认大家是否跟上，说明这一段难点不在 graph 定义，而在“从 reduced graph 的节点量回到完整词表向量导数”。结尾再次提到 greedy decode 会合并相邻符号，这个过渡提示了下一节为何必须引入新机制来区分重复字符。

### 008 01:09:37-01:19:37
本段在整讲中的作用：这一段从“greedy 不是最优”推进到“什么才是最优 CTC 解码”，并给出理论上正确但会指数爆炸的搜索方案，最后以 pruning/beam 的方式说明课堂标题中的“beam search”是怎样进入 CTC 解码的。

教学展开：老师先承接上一段，指出 blank 让 greedy decode 在实践中常常不错，因为 blank 大多数时候概率最高、可见符号主要出现在边界处；但这不改变 greedy 的次优本质。真正想做的是：给定输入，找到概率最高的 order-aligned 压缩符号序列，而不是只找概率最高的时间同步路径。为了说明怎样计算这个目标，老师回到前面 trellis 上的终点 alpha：某个压缩序列对应 trellis 的右下 alpha，正好就是该压缩序列在所有可能对齐上的总概率。因此理论上要做最优解码，就得对每一个可能的压缩符号序列都构造 trellis、算出末端 alpha，再挑最大的那个。第五次投票之后，老师确认这就是 decoding 的真正目标：找到给定输入下概率最大的 compressed sequence；等价地说，就是找到“最终 alpha 最大”的符号序列。随后他承认直接枚举所有序列不现实，于是提出把所有可能序列组织成一棵 “semi tree”。为方便说明，他只保留两个可见符号 $s_1$ 与 $s_2$，blank 仍然隐含存在。树的每个节点都表示一条完整符号序列，从根到该节点的路径就是该序列本身。接着老师说明扩展规则：若当前末尾是 $s_1$，可以直接接 $s_2$；若想再接 $s_1$，就必须先插 blank；对 $s_2$ 也同理。这样不断往下扩展，整棵树就枚举了该小词表下所有可能的输出序列。他再把这棵树竖着画出来，并沿时间展开成 trellis。此时每一行不再只代表某个局部标签位置，而是代表一条唯一的完整符号序列。输入逐时刻到来时，可以在这张巨大的 trellis 上继续跑 forward algorithm，维护所有节点的 alpha。最后老师讲解如何从这个理论解码器落到可执行算法。对于某个候选序列，若它可以“以自身结束”或“以自身后跟 blank 结束”，那么其总概率要把这两个 alpha 加起来。问题在于：随着时间推进，树会迅速指数膨胀。于是他给出实际做法：每个时刻只保留 alpha 最大的前若干个活动节点，再只扩展这些节点；这个保留宽度就是 beam width。最终在最后时刻，再根据保留下来的候选中哪个序列的 alpha 最大来输出结果。老师说明：这就是理论正确解码器加 pruning 的版本；剪枝会带来次优风险，但由于 CTC 分数在符号终止点附近更尖锐，pruning 的损伤通常可控。段末他说 slides 里有较长的伪代码，但因为作业里会实现，这里课堂上跳过。
