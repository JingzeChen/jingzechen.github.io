## 学习目标
- 说明本讲在 CNN 系列中的位置：前半段快速回顾卷积层、池化层、重采样与端到端 CNN，主体聚焦卷积层与池化层的反向传播；upsampling / downsampling 的反传明确留到下一讲。
- 掌握从最终平坦 MLP 的常规 backprop 出发，如何把梯度 reshape 回卷积部分最后一层，再继续传过卷积层与池化层。
- 掌握卷积层两类关键梯度：输入 maps 的梯度如何改写成“补零后的输出导数图与翻转 filter 的卷积”，filters 的梯度如何改写成“输入图与输出导数图的卷积型求和”。
- 掌握 max pooling 与 mean pooling 的反向分配规则，并理解为什么两者在窗口重叠时都必须使用 plus equals 进行累加。

## 需要的先修知识
- 已经掌握 CNN 的基本前向结构：卷积层先算 affine map，再做逐元素激活得到 activation map；池化层逐 map 扫描；最终输出 flatten 后送入 MLP。
- 已经掌握普通 MLP 的训练流程：定义单样本 divergence、训练集平均 loss，并用梯度下降最小化参数损失。
- 已经掌握链式法则，尤其是当 $y=f(z)$ 时，能够从 $\frac{\partial Div}{\partial y}$ 写出 $\frac{\partial Div}{\partial z}=\frac{\partial Div}{\partial y}f'(z)$。
- 能够跟踪卷积中的索引与尺寸关系，包括输入 maps 数、filters 数、filter channels 数、前向输出尺寸 $m-k+1$ 等基本约束。

## 核心概念与依赖关系
- 一个卷积层的单个输出 map 对应一个 filter；单个 filter 的 channels 数等于输入 maps 数；filters 的数量等于输出 maps 数。
- 卷积层前向可写成两阶段：先得到 affine map $z$，再逐元素施加激活函数得到 activation map $y$。
- 最终平坦 MLP 的输入只是卷积部分最后一层输出 maps 的展开表示，因此其反传梯度可以折回原来的 map 形状。
- 卷积层输入梯度的依赖关系是：某个输入元素会落入多个卷积窗口，因此会影响所有相关输出位置，反向时必须把这些路径全部累加。
- 卷积层 filter 梯度的依赖关系是：固定一个 filter 元素后，它会随着 filter 扫描参与该输出 affine map 的每个位置计算，因此其梯度要对该输出 map 的所有位置求和。
- 池化层反传的依赖关系是：max pooling 只把梯度送回前向最大值位置，mean pooling 把梯度均匀分回整个窗口；若窗口重叠，同一输入元素可能接收多个输出位置的贡献。

## 关键推导、例子与结论边界
- 激活层的局部反传规则是

  $\frac{\partial Div}{\partial z(l,m,x,y)}=\frac{\partial Div}{\partial y(l,m,x,y)}f'(z(l,m,x,y))$

- 对卷积层输入梯度，老师先固定某个输入元素，推出

  $z_{x',y'} \mathrel{+}= y_{x,y}\, w_{x-x',y-y'}$

  以及

  $\frac{\partial z_{x',y'}}{\partial y_{x,y}} = w_{x-x',y-y'}$

  再把它改写成“补零后的输出导数图与翻转 filter 的卷积，并对所有输出 maps 求和”。
- 对卷积层 filter 梯度，老师固定某个 filter 元素，推出

  $\frac{\partial z_{x,y}}{\partial w_{i,j}}=y_{x+i,y+j}$

  以及

  $\frac{\partial Div}{\partial w_{i,j}}=\sum_{x,y} \frac{\partial Div}{\partial z_{x,y}}\cdot y_{x+i,y+j}$

  并强调这里不需要翻转 filter。
- 输入梯度的尺寸检查边界是：若前向输入尺寸为 $m$、filter 尺寸为 $k$、输出尺寸为 $m-k+1$，则反向必须先在输出导数图四周补 $k-1$ 个零，卷积后结果才会恢复到尺寸 $m$；若前向用过 zero padding，最后还要裁掉 pad 区域。
- 池化层的例子边界是：max pooling 的赢家通吃规则依赖前向保存 argmax；mean pooling 的均匀分配规则来自把平均写成每个元素都乘 $1/k^2$ 的线性组合；本讲没有展开 upsampling / downsampling 的反向传播。

## 易错点与待核对项
- 容易混淆的结构关系：单个 filter 的 channels 数由输入 maps 数决定，filters 的数量由输出 maps 数决定。
- 容易记错的卷积层反传区别：求输入梯度时要翻转 filter，求 filter 梯度时不翻转。
- 容易漏掉的实现细节：单个输入元素会影响多个输出位置；pooling 窗口也可能重叠，所以卷积层输入梯度、max pooling 反传、mean pooling 反传都可能需要 plus equals 累加而不能覆盖。

#### 概念、符号与推导
- CNN 的分层扫描直觉：低层扫描原始输入，高层扫描低层 maps，最终由决策层输出类别。[课件 p.3]
- 卷积层两阶段：
  1. 计算 affine map；
  2. 对 affine map 做逐元素激活得到 activation map。[课件 p.5-p.6]
- 通道/滤波器关系：
  1. 输出 maps 的数量 = filters 的数量；
  2. 单个 filter 的 channels 数 = 输入 maps 数。
- 本段给出的卷积公式为：[课件 p.7-p.14]

  $z_{l,n,x,y}=\sum_m\sum_i\sum_j w^l_{m,n,i,j}\,y_{l-1,m,x+i,y+j}+b_l(n)$

  课件注明使用 0-based indexing。
- 池化定义：
  1. max pooling 在窗口内选最大值；
  2. mean pooling 在窗口内求均值。
- 重采样定义：
  1. downsampling 每隔 $S-1$ 行/列丢弃一次；
  2. upsampling 在相邻元素间插入 $S-1$ 行/列零。

#### 概念、符号与推导
- 已知量：所有输出 activation 元素的梯度 $\partial Div/\partial y(l,m,x,y)$。
- 第一步链式法则：

  $\frac{\partial Div}{\partial z(l,m,x,y)}=\frac{\partial Div}{\partial y(l,m,x,y)}f'(z(l,m,x,y))$

- 目标一：给定所有输出 affine 元素的梯度，求输入 map 的梯度。
- 依赖结构：
  1. 第 $m$ 个输入 channel 会影响所有输出 affine maps；
  2. 它对第 $n$ 个输出 map 的影响，是通过第 $n$ 个 filter 的第 $m$ 个 channel 发生的。
- 因而某个输入 map 的梯度应写成“对所有输出 maps、所有相关位置”的求和：

  $\frac{\partial Div}{\partial Y_{l-1,m}}=\sum_n \sum_{x',y'} \frac{\partial Div}{\partial z(l,n,x',y')}\cdot \frac{\partial z(l,n,x',y')}{\partial Y_{l-1,m}}$

  本段只建立这个求和框架，尚未把第二项的具体形式完全展开。
- 关键前提：单个输入元素不会只影响一个输出位置，而是会随着 filter 的扫描影响多个输出位置，因此梯度必须汇总所有这些路径。

#### 本段在整讲中的作用

#### 教学展开
- [00:39:51] 老师把上一段公式代入具体例子 $y_{2,2}$：
  $\partial Div/\partial y_{2,2}$ 由多个输出位置的导数与相应权重相乘后相加。
- [00:40:23] 他逐项口算：
  1. 来自 $z_{0,0}$ 的项乘 $w_{2,2}$；
  2. 来自 $z_{1,0}$ 的项乘 $w_{1,2}$；
  3. 来自 $z_{2,0}$ 的项乘相应权重；
  4. 再加上 $z_{0,1}, z_{1,1}, z_{2,1}$ 等项。
- [00:41:27] 然后老师问学生“看出图形关系了吗”，学生回答 rotated，老师进一步纠正成 flipped：这里不是任意旋转，而是上下、左右同时翻转 filter。
- [00:41:47] 新的几何解释是：为了求 $y_{2,2}$ 的梯度，把 filter 左右翻转、上下翻转，使翻转后 filter 的 $(0,0)$ 元素对准导数图中的 $(2,2)$ 位置，再对覆盖区域做内积。
- [00:42:41] 于是推广为任意 $y_{x,y}$：把翻转后的 filter 的 $(0,0)$ 元素放到导数图的 $(x,y)$ 上，对覆盖区域求内积。
- [00:43:36] 接着老师说明为什么还要 zero padding：若原输入图尺寸为 $m$，filter 尺寸为 $k$，前向输出尺寸是 $m-k+1$；要让反向求出的输入梯度重新回到尺寸 $m$，就必须先把输出导数图在四周各补 $k-1$ 行/列零。
- [00:44:23] 补零后尺寸从 $m-k+1$ 变成 $m+k-1$，再与 $k\times k$ 的翻转 filter 卷积，输出尺寸重新变回 $m$。
- [00:45:27] 老师把这总结成一条必须记住的规则：任何过程输入是什么尺寸，divergence 对该输入的梯度就必须恢复成同样尺寸。
- [00:46:17] 最终算法：
  1. 取某个输出 Z map 的导数图；
  2. 在四周补 $k-1$ 零；
  3. 取对应 filter channel 并上下左右翻转；
  4. 做卷积；
  5. 得到该 Z map 对某个输入 channel 梯度的贡献；
  6. 再对所有 Z maps 的贡献求和。
- [00:49:19] 老师补充：如果前向时输入图本来就做过 zero padding，那么反向得到的会是“补零后输入”的梯度，最后还要把 pad 区域裁掉，只保留原输入区域的梯度。

#### 概念、符号与推导
- 单个输入元素梯度的展开式可重写为“导数图与翻转 filter 的内积”。
- filter 翻转规则：左右翻转一次、上下翻转一次，即相当于 180 度翻转，而不是仅交换索引名称。
- 尺寸推导：
  1. 前向：若输入尺寸为 $m$，filter 尺寸为 $k$，则输出尺寸为 $m-k+1$；
  2. 反向先补零：$(m-k+1)+2(k-1)=m+k-1$；
  3. 再与 $k\times k$ filter 卷积：$(m+k-1)-k+1=m$。
- 因而输入梯度的算法形式为：

  $\frac{\partial Div}{\partial Y_{l-1,m}} = \sum_n \text{conv}\Big(\text{pad}_{k-1}\big(\frac{\partial Div}{\partial Z_{l,n}}\big),\; \text{flip}(W_{l,m,n})\Big)$

#### 概念、符号与推导
- max pooling 反向规则：若某输入位置是前向窗口中被选中的最大值位置，则它接收该输出位置的全部梯度；否则接收 0。
- 记作分段形式：

  $\frac{\partial Div}{\partial y_{k,l}} = \begin{cases}
  \frac{\partial Div}{\partial u_{i,j}}, & (k,l)=pidx(i,j)\\
  0, & \text{otherwise}
  \end{cases}$

  其中 $pidx(i,j)$ 是前向 max pooling 保存的最大值位置。
- mean pooling 反向规则：若窗口大小为 $k\times k$，则单个输出梯度均匀分配到窗口内每个输入元素：

  $\frac{\partial Div}{\partial y_{a,b}} \mathrel{+}= \frac{1}{k^2}\frac{\partial Div}{\partial u_{i,j}}$

  1. 卷积层输入梯度：翻转/转置后的 filter 与输出导数图卷积；
  2. 卷积层 filter 梯度：输入图与输出导数图卷积；
  3. 池化层梯度：把输出梯度重新分配给实际贡献的输入元素。
