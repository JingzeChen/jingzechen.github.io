## 核心概念与依赖关系

- 深度学习课程价值定位：现代 AI 的核心技术背景，决定了课程的高投入定位。
- 先修能力 -> implementation-heavy 课程方式：因为课程要求从零实现、实验和 debug，所以 Python、基础 ML、线代和微积分是直接前提。
- Lecture -> Quiz：lecture 和 slides 决定 quiz 的覆盖范围，且 attendance 会影响成绩。
- Lecture/Recitation/Bootcamp -> Homework：lecture 讲概念，recitation 与 bootcamp 把概念转成具体实现，homework 再把实现能力推到可评分产出。
- Homework Part 1 -> Homework Part 2：Part 1 训练从零造组件，Part 2 在真实数据集上用这些能力解决复杂问题。
- Study group / TA mentor / Piazza -> 持续支持系统：它们共同负责解答、纠偏、跟踪进度和防止学生掉队。
- Homework / Quiz / Project / Attendance -> Mastery-based evaluation：老师希望通过理解、应用和创造力的组合来判断学生是否真正掌握课程内容。
- Integrity rules -> 所有学习活动：无论是 quiz、homework 还是 project，协作都必须停在允许的边界内。
