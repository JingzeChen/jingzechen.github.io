## 学习目标
- 回顾 CNN 中卷积层、池化层的既有反向传播规则，并把它们接到完整训练流程里。
- 掌握 downsampling、upsampling、整步长与分数步长卷积/池化的 backward 处理方式，尤其是“保存前向尺寸以处理边界”这一实现要求。
- 理解老师用来统一反传推导的方法：先写前向代码，再按依赖关系倒着写导数。
- 区分 shift invariance、rotation/scaling invariance 与工程上常用的数据增强方案，理解显式变换滤波器族为何理论可行但代价过高。
- 说明 CNN 如何从分类扩展到定位、bounding box 预测与 pose estimation 等多任务输出。
- 认识 depthwise convolution、receptive field、数据增强与 LeNet/AlexNet/ResNet 等历史脉络在 CNN 发展中的作用。

## 需要的先修知识
- 已掌握上一讲卷积层反传的两个核心子问题：已知某层仿射图导数时，如何求前一层输入通道的导数，以及如何求卷积滤波器各通道的导数。
- 熟悉链式法则与激活层反传，能从 $d\mathrm{Div}/dy$ 写出 $d\mathrm{Div}/dz = (d\mathrm{Div}/dy)f'(z)$。
- 知道 CNN 是共享参数模型，可把同一组滤波器理解为在不同位置扫描输入的相同子网络。
- 了解基本卷积、池化、展平、MLP/softmax 分类流程，以及 shift invariance 与 jitter sensitivity 的基本直觉。

## 老师的教学主线
- 先快速回顾：用“cat / hello”式模式检测和完整训练图景把 CNN 的定位重新落在共享参数与反向传播上。
- 再补重采样反传：先讲 max/mean pooling backward，再讲 downsampling 与 upsampling 的对偶关系、边界条件和 stride 分解视角。
- 接着统一方法：从 $z = wx,\ y = \sigma(z)$ 出发，说明任何能写成前向代码的运算都能按依赖关系倒着写 backward，再把这一方法套回卷积循环。
- 然后扩任务与不变性：从 shift invariance 推到 rotation/scaling invariance，解释显式变换滤波器族与数据增强的取舍，再过渡到分类 head 加位置 head 的 multitask 定位。
- 最后讲模型变体与历史：用 depthwise convolution、receptive field、训练问题、数据增强和 LeNet 到 ResNet 的演化，把 CNN 的工程成熟过程收束起来。

## 核心概念与依赖关系
- 激活图与仿射图：$Y^{(l)}$ 依赖 $Z^{(l)}$，因此反传必须先从 $dY$ 回到 $dZ$。
- 卷积层反传：$dZ$ 继续分流为“对前一层输入通道的导数”和“对当前滤波器的导数”，对应零填充导数图与翻转滤波器卷积，以及输入通道与 $dL/dZ$ 的卷积。
- 池化层反传：max pooling 只把梯度传回 argmax 位置，mean pooling 把梯度按 $1/K^2$ 均匀分配到 $K\times K$ 窗口；窗口重叠时都需要累加。
- 重采样层反传：downsampling 把保留位置的梯度复制回原图、被删位置梯度设为 0；upsampling 只把真实复制位置的梯度取回输入，前向插入的 0 不回传梯度。
- stride 与分数 stride：stride 大于 1 的卷积/池化可视为普通操作后接 downsampling；stride 小于 1 可视为先 upsampling 再做普通卷积。
- 变换不变性与数据增强：理论上可枚举并应用变换后的滤波器族，工程上通常改用数据增强以避免计算和通道数爆炸。
- 多任务定位：共享卷积特征后接分类 head 与位置 head，同一结构还可推广到 pose estimation。
- depthwise convolution 与 receptive field：前者通过保留逐通道卷积结果并重新加权来换取参数效率，后者解释不同层神经元到底在响应什么模式。

## 关键推导、例子与结论边界
- 关键推导 1：已知 $d\mathrm{Div}/dy$ 时，先逐元素写出 $d\mathrm{Div}/dz = (d\mathrm{Div}/dy)f'(z)$，这是后续所有卷积与代码级反传的入口。
- 关键推导 2：对 $z = wx,\ y = \sigma(z)$，必须先求 $dL/dz$，再求 $dL/dw = (dL/dz)x$ 与 $dL/dx = (dL/dz)w$；老师用它说明“先看依赖，再写 backward”。
- 关键推导 3：卷积循环的 backward 不需要另起一套神秘数学，仍是把前向里的乘法、加法、激活按相反依赖顺序传播并在对应位置累加。
- 关键例子：花瓣轻微位移说明 pooling 用于降低 jitter sensitivity；“3 个滤波器、10 个输入通道”量化了标准卷积的计算代价；Yaser Sheikh 的骨架演示说明 CNN 可从分类扩展到姿态估计；LeNet/AlexNet/ResNet 链条展示 CNN 架构与性能如何快速演化。
- 结论边界 1：downsampling backward 与 upsampling、upsampling backward 与 downsampling 只是“忽略边界时的对偶”，真正实现仍必须保留前向输入尺寸。
- 结论边界 2：并列最大值、次梯度、板书索引图示等内容在 transcript 中保留不完整，笔记只能维持老师口头层面的结论，不能额外补数学细节。
- 结论边界 3：显式变换滤波器族理论可行，但老师明确将其评价为工程上过于昂贵，因此课堂结论停留在“知道其思想与代价”，不把它当默认实用方案。

## 易错点与待核对项
- max pooling 和 mean pooling 反传里都不能把重叠窗口的梯度写成覆盖赋值，必须累加；老师还用旧版 PyTorch 的 bug 提醒过这一点。
- 不能把“概念上互逆”误写成“代码上完全相同”：上采样/下采样 backward 都受边界与前向尺寸约束。
- 不能把整数索引网格上的分数 stride 直接理解为“半个像素移动”，课堂采用的是“先上采样，再做普通卷积”的离散实现解释。
- CNN 天然获得的是近似平移不变，不是自动的旋转、缩放、反射不变；后者若显式建模，需要枚举离散变换集合。
- depthwise convolution 的优势是参数量、计算量与中间激活量更小，但老师也明确承认它的表达能力通常不如完整卷积。

#### 概念、符号与推导
- $Y^{(l)}$：第 $l$ 层激活图；$Z^{(l)}$：第 $l$ 层仿射组合图；老师在课件 p.8 明确区分了二者。
- 已知 $\frac{d\mathrm{Div}}{d y(l,m,x,y)}$ 时，按链式法则得到
  $\frac{d\mathrm{Div}}{d z(l,m,x,y)} = \frac{d\mathrm{Div}}{d y(l,m,x,y)} f'(z(l,m,x,y))$。
- 卷积层反传的两类核心对象：
  1. 对前一层输入通道的导数：把输出侧的导数图零填充，再与翻转后的相应滤波器通道做卷积。
  2. 对滤波器的导数：把输入通道与当前仿射图导数做卷积，得到滤波器各通道的梯度。
- 本段没有新增公式推导，重点是把前一讲已经得到的推导重新压缩成可执行的规则清单。

### 00:10:45-00:20:44

#### 本段在整讲中的作用
这一段完成了对池化层反向传播的系统回顾，并把话题自然推进到下采样层的反传。它既是前面卷积层反传回顾的补足，也是后面重采样层反传的入口。提示文件附带课件 p.11-12，但这两页仍是卷积滤波器导数；本段口头主线实际集中在 max/mean pooling 与下采样导数的直觉。

#### 教学展开
- 老师先用“花瓣轻微左右移动，仍应识别为同一朵花”解释 jitter sensitivity：特征不该对窗口内很小的位置抖动过度敏感，因此需要池化在一个小邻域内做聚合。
- 对 max pooling，前向过程不是“抽象地取最大值”，而是“先找到最大元素所在位置，再把该元素复制到输出”。因此反向传播时，只有那个被复制的输入位置真正影响输出，其余位置导数为 0；输出侧的导数会直接拷回最大值所在的位置。
- 老师特别追问伪代码里为什么必须写 `+=` 而不是 `=`。原因是相邻池化窗口可能重叠，同一个输入位置可能被多个窗口选为最大值，所以导数必须累加。老师还举了一个实现提醒：旧版 PyTorch 在 max pool 反传里曾把这里写成赋值而不是累加，在窗口重叠时会出错。
- 对 mean pooling，前向是窗口平均；反向时，输出位置的导数要均匀分配给窗口内所有输入位置。老师先用 $2\times 2$ 窗口举例，说每个元素都乘 $1/4$ 参与均值，因此反向时每个元素也分到同样大小的四分之一导数；再推广到 $K\times K$ 窗口，每个位置得到 $1/K^2$ 倍的导数。
- 随后老师处理两个补充问题：若 max pooling 出现并列最大值，则这些并列元素在微扰时都会影响输出，因此梯度会复制给这些元素；而许多早期模型会故意让池化窗口不重叠，这样 `+=` 的作用在实现上不明显，但规则仍应写对。
- 第一轮课堂投票给出两个判断题，老师确认答案都为 True：max pooling 只把导数传回窗口内最大值位置；mean pooling 会把导数均匀分配到整个窗口。
- 最后老师开始过渡到 downsampling：如果前向时一个元素被直接丢弃，它对输出没有贡献，那么它对损失的导数就是 0；如果某个元素只是被原样复制到输出，那么它的导数就等于对应输出位置的导数。这为下一段完整推导下采样反传做铺垫。

#### 概念、符号与推导
- max pooling 反传规则：对每个输出位置，只把导数传给前向时被选中的最大值位置；其余位置导数为 0。
- 若池化窗口重叠，则同一输入位置可能接收来自多个输出位置的导数，因此实现上必须累加。
- mean pooling 反传规则：若窗口大小为 $K\times K$，则每个窗口内输入位置得到
  $\frac{1}{K^2}\frac{dL}{dy_{\text{out}}}$。

#### 本段在整讲中的作用
这一段完整讲清下采样与上采样的 backward 规则，是本讲新增反传机制的核心技术段。

#### 教学展开
- 老师先给出一个总规则：任何变量的梯度张量都必须与该变量本身同形。因此，下采样层输入的梯度图必须与下采样前的输入图一样大。
- 对下采样层，反向传播的第一步是分配一个与原输入同尺寸的梯度图。前向时被“涂黑、删掉、屏蔽”的位置不影响输出，因此这些位置的梯度直接设为 0；前向时被原样复制到输出的位置，反向时梯度也原样复制回来。
- 老师随后总结：如果忽略边界问题，下采样的反向传播看起来就是上采样。也就是说，downsampling 的 backward 几乎就是 upsampling，只是边界处会有模糊性。
- 接着老师讲上采样层。前向时，上采样会在相邻元素之间插入 $S-1$ 行和 $S-1$ 列 0。那些人工插入的 0 不是输入的函数，所以反向时，这些输出位置的导数不会回流到任何输入元素，应该直接丢弃。
- 与此相对，前向时那些被直接复制过来的“有效位置”仍与输入一一对应，因此它们的导数会原样复制回输入。老师总结为：upsampling 的 backward 看起来就是 downsampling。
- 对两个方向，老师都强调唯一的麻烦是边界。是否需要最后一行、最后一列，不能从输出本身唯一恢复，必须记住前向时的输入尺寸；只要把尺寸记住，边界就能处理。
- 最后老师把结论推广到 stride：实际实现中通常不会先做完整卷积/池化再显式做 downsampling，而是直接用 stride 大于 1 的卷积或池化。但为了推导和实现反传，更简单的思路是把“stride 卷积”看成“stride 1 卷积 + downsampling”，先穿过下采样，再穿过普通卷积。

#### 概念、符号与推导
- 梯度尺寸规则：损失对变量的梯度张量尺寸与变量本身一致。
- downsampling backward：删掉的位置梯度为 0，复制过的位置把输出梯度复制回去。
- upsampling backward：人工插入 0 的位置不回传梯度，只把有效位置的梯度抽取回输入。

#### 例子与课堂提示
- 老师用“最终一列/最终一行是否该存在”的例子说明边界模糊：不同大小的输入在下采样后可能给出相同输出，所以 backward 不能只看输出，必须记住前向输入尺寸。
- 对上采样，老师反复强调“这些 0 只是硬塞进去的，不是由任何输入算出来的”，这是判断某个梯度是否应回传的最直接方法。
- “literal 复制到正确位置”是老师对代码实现的总结，提示这部分实现并不难，关键是索引和尺寸记录。

参考答案：因为梯度张量与变量本身同形。
