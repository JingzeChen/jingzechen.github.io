## 学习目标
- 识别本讲真正要解决的是“无顺序同步、无逐词对齐保证”的 sequence-to-sequence 建模，而不是一般的固定窗口语言建模。
- 把 language model detour 与后半段的 translation model 连起来，理解 decoder 为什么就是 conditional language model。
- 讲清 one-hot、projection、embedding、recurrent LM、encoder、decoder、greedy、random sampling、beam search、训练时目标前缀输入之间的因果链。
- 能指出 simple translation model 的优势、使用条件和最后暴露出的单一 hidden representation 过载问题。

## 需要的先修知识
- recurrent neural network、LSTM、softmax、backpropagation 的基本工作方式。
- 序列条件概率连乘、one-hot 向量、词表、类别分布采样等基础概念。
- 对上次课 CTC 与 beam search 的位置有印象即可：它们属于“有顺序对应”的 seq2seq。
- 理解“模型输出的是分布，不是直接输出一个最终句子”这一常识。

## 老师的教学主线
- 先回顾上次课，把本讲定位到“无顺序对应的 seq2seq”，并通过自动生成代码/数学文本/Wikipedia 页把问题拐到 language modeling。
- 再从 next symbol prediction 出发，搭起 one-hot、固定历史模型、embedding、recurrent language model 的基础概念。
- 然后回到 seq2seq，先给出最朴素 delayed 模型，再通过 “a/an” 反例升级成 self-referencing encoder-decoder。
- 接着把 decoder 的逐步概率上升为整句解码目标，说明 greedy 的局限、beam search 的必要和非最优性。
- 最后讲训练为何要把目标前缀送入 decoder，展示翻译、对话、图像描述、视频描述等应用，并把“单一 hidden representation 过载”留到下一讲。

## 核心概念与依赖关系
- seq2seq 是总问题；本讲只处理不要求顺序同步或逐词对齐的那一类。
- language model 是过渡桥梁：先学“根据前缀预测下一个词”，再把它条件化在输入表示上，形成 decoder。
- one-hot 的优点是“不引先验关系”，缺点是高维稀疏；projection 把它压到低维形成 embedding。
- recurrent LM 允许用“全部过去”来预测下一个词，为 decoder 的时序建模提供范式。
- encoder 把输入序列压成表示；decoder 把这个表示当作条件，结合已生成前缀逐词输出。
- inference 的目标是整句概率最大，因此不能把“每步局部最优”误当成“全局最优”。
- training 时把目标前缀送入 decoder，是为了让每一步都有可对齐的监督，而不是让错误前缀把训练过程拖偏。

## 关键推导、例子与结论边界
- one-hot 的关键性质是所有词等长、任意两个不同词向量等距，老师口头给出距离为 $\sqrt{2}$；这解释了 why one-hot，而不是二进制紧凑编码。
- embedding 的关键关系是 $P \times W$，对 one-hot 而言等价于从投影矩阵取一列；因此 embedding 可以理解为“共享线性层下的词列向量”。
- 整句输出概率的关键关系是把每一步条件概率乘到 `<eos>`；因此 decoding 目标天然是全序列搜索，而不是逐步独立决策。
- “he nose / he knows” 的例子说明 greedy 可以被局部更大概率误导；beam search 是务实近似，但理论上仍可能剪掉最优路径。
- simple translation model 的结论边界是：它能统一处理翻译、对话、图像描述等条件生成任务，但把整段输入压到一个 hidden representation 中可能过载。

## 易错点与待核对项
- 不要把 language model 误解成“只会局部猜下一个词”；老师反复强调它真正建模的是完整词序列概率。
- 不要把 one-hot 的高维稀疏直接理解成“应该避免 one-hot”；老师先用它保证无先验，再靠 projection 学语义结构。
- 不要把 decoder 当普通 LM；这里它始终是对 encoder 表示条件化的 conditional LM。
- 不要把 greedy 当成寻找最可能句子的可靠算法；beam search 更好但也不是理论最优。
- 待核对点主要在德语/法语词串、人名和最后一句结束语的字幕失真处；这些不影响主链路，但影响逐字引用精度。

## 掌握标准
- 能完整说出从 one-hot 到 embedding、从 LM 到 conditional LM、从 delayed seq2seq 到 self-referencing encoder-decoder 的演化链。
- 能解释为什么 `<sos>/<eos>` 必须显式加入词表，以及为什么训练与推理阶段 decoder 的输入不同。
- 能用自己的话重述 greedy 为什么失败、beam search 为什么必要、beam search 为什么仍不保证全局最优。
- 能从老师给出的例子中指出本讲统一结构可覆盖翻译、语音识别、对话、图像描述、视频描述。
- 能指出 simple model 的下节课问题：整个输入被压成单一 hidden representation，负担过重。

00:01:20-00:11:19
本段在整讲中的作用：老师先把本讲放回 recurrent networks / sequence-to-sequence models 的课程链条里，回顾上周讲过的 CTC beam search 代表的是“输入输出存在顺序对应”的 seq2seq；而本讲与下节课要处理的是另一类任务，即输入序列和输出序列之间没有必要保持时间同步，也不保证逐词或逐位置对应。这里的功能不是直接上模型，而是先重新定义问题边界，并把后面会用到的 language modeling detour 合法化。
教学展开：老师先点名上次课主题是 CTC beam search，然后把它放进更大的“一个序列进去、另一个序列出来”的总问题里。接着按顺序举例：speech recognition、machine translation、dialog、question answering，说明输入输出甚至可以不是同一种数据类型，长度也未必相同。随后他区分上周那类“如果把输入顺序打乱，输出也会跟着同样打乱”的任务，与本讲关注的“无顺序对应”任务。为让差异具体化，他先用 “I ate an apple → Ich habe einen apfel gegessen” 说明翻译里没有逐词顺序同步，再用 “My screen is blank → Can you check if your computer is plugged in?” 说明输出甚至可以表面上与输入词面弱相关。最后，老师在真正进入翻译模型前先拐去讲 language modeling，展示 Andre Karpati 生成的 Linux 风格代码、数学论文样式文本和 Wikipedia 样式页面，强调这些并不是现代复杂大模型，而只是几层 LSTM 以 generative mode 运行的结果，因此问题变成“这种模型在做什么”。
概念、符号与推导：本段主要搭问题框架，没有正式公式。重要概念有两类 seq2seq：一类有顺序对应，一类无顺序对应；本讲处理后者。language modeling 在这里先被作为后续生成问题的入口，而不是独立主题。
例子与课堂提示：speech recognition、machine translation、dialog、question answering 服务于说明 seq2seq 的广义性；“I ate an apple → Ich habe einen apfel gegessen” 和 “My screen is blank → 请检查是否插电” 服务于解释“无顺序同步”；自动生成代码、数学文本、Wikipedia 页面服务于说明简单 LSTM 已能学出明显结构感。
本段掌握检查：上次课的代表性主题是 CTC beam search；本讲新问题是无顺序对应的 seq2seq；自动生成示例被老师描述为用几层 LSTM 盲生成出来。
待核对项：德语发音字幕多处失真，应以课件给出的书面词串为准；Andre Karpati 展示页细节若要逐字引用需回听。

00:11:17-00:21:15
本段在整讲中的作用：老师把“模型到底在做什么”落到 next symbol prediction 上，并从词表示、训练样本构造与 one-hot 几何性质入手，为 embedding 和更完整的 language model 搭底。
教学展开：他先追问前面自动生成系统究竟完成了什么操作，答案是 next symbol prediction。接着解释，为了让计算机处理词或字符，需要固定词表或字符表顺序，并把每个词/字符表示成 one-hot 向量。随后他提出具体任务：给定前面的词，预测下一个词。用 “four score and seven years ?” 说明任务，再用 “she sells sea shells at the seashore” 展示如何用滑动窗口把一句话切成多个训练样本。然后他指出 one-hot 的高维浪费：十万词词表意味着十万维向量。接下来老师不是立刻否定 one-hot，而是先回答“为什么不用更紧凑的二进制编码”：因为 one-hot 让所有词等长、任意两个词等距，不会人为假设哪个词更重要、哪个词彼此更接近。最后才指出它的缺点是极高维、极稀疏、只占据空间里极少的有效点，于是自然引出低维投影。
概念、符号与推导：one-hot 是固定词表下只有一位为 1 的向量；固定历史模型是用前 n 个词预测下一个词；任意两个不同 one-hot 向量之间的距离在老师口头解释里为 $\sqrt{2}$。没有更长公式推导，但 one-hot 的“等长、等距、不引先验”是这里最重要的性质总结。
例子与课堂提示：“AARDVARK / AARON” 例子说明 one-hot 编码方式；“she sells sea shells ...” 说明训练样本切分方式；老师追问“为什么不用二进制编码”是本段最关键提示，说明 one-hot 的价值在无先验而不在紧凑。
本段掌握检查：language model 的底层操作是 next symbol prediction；one-hot 通过固定词表顺序定义；一句训练语句能切出多个样本；不同 one-hot 的距离一致；one-hot 虽浪费空间，但不预设词间关系。
待核对项：个别维度数字和学生名字字幕存在噪声，但不影响推理链。

<div id="section-03" class="course-note-section-anchor" aria-hidden="true">&nbsp;</div>

00:21:12-00:31:10
本段在整讲中的作用：承接 one-hot 稀疏问题，正式定义 projection/embedding，并说明语言模型既可以是固定窗口 TDNN，也可以是基于 recurrence 的全历史模型。
教学展开：老师先说明真正进入模型的不是 one-hot 本身，而是 $P \times W$。因为 $W$ 是 one-hot，所以这等价于从矩阵 $P$ 中取出一个列向量；这个低维列向量就是该词的 embedding。随后他回到固定历史模型，把它叫作 time delay neural network：例如用前四词预测下一词，常见隐藏激活是 tanh，输出是 softmax。接着他补充 soft bag of words 和 skip-gram 等替代方法，强调这些方法的共同目标都是学习投影矩阵 $P$。再往后，他用 Mikolov 2013 的国家-首都、man/woman/king/queen 例子说明，学出来的 embedding 空间会携带语义结构。然后老师小结：language model 真正建模的是整个词序列概率，只是通常拆成 next token prediction；embedding 是 one-hot 经过低维投影后的新表示。最后老师指出，如果真正想根据“全部过去”预测下一个词，那么 recurrence 才是自然选择，于是过渡到 LSTM/RNN language model。
概念、符号与推导：关键关系是 $P \times W$；由于 $W$ 为 one-hot，这个乘法等价于抽取矩阵的一列。TDNN 只看固定历史；RNN/LSTM 则在每个时刻计算“给定此前全部词后，下一个词的条件概率”，老师口头举例为像 $P(W_7\mid W_1\ldots W_6)$ 这样的量。这里没有长推导，但条件概率与投影关系都已具备。
例子与课堂提示：国家-首都位移和 king/queen 例子用来说明 embedding 可携带语义；poll 1 的四个判断题则把“one-hot 不引先验”和“embedding 不能自动表示词表外新词”这两个边界钉牢。老师从 TDNN 转向 recurrence 本身也是提示：如果目标是建模全部过去，固定窗口只是过渡方案。
本段掌握检查：embedding 就是投影后的低维词表示；TDNN 是固定历史模型；投影矩阵可与语言模型一起训练；RNN 更自然地对应“全部过去”的条件预测。
待核对项：老师曾先口误提到 LSTM 后立刻更正为 TDNN，应以后面的更正为准；论文作者名字幕不稳，但不影响论点。

<div id="section-04" class="course-note-section-anchor" aria-hidden="true">&nbsp;</div>

00:31:09-00:41:07
本段在整讲中的作用：这里开始把 recurrent language model 变成真正的生成系统，补上 `<sos>/<eos>` 边界机制，并首次提出最朴素 delayed seq2seq；同时老师用一个反例指出它还不够好。
教学展开：老师先说生成时会把上一步抽到的词送回模型继续生成。代码生成可能有自然结束点，但钢琴音乐生成未必，所以必须显式定义什么时候结束。于是他把 `<sos>` 和 `<eos>` 加入词表，并用 “four score and eight” 四种写法区分句中片段、句首、句尾和完整句子。之后老师回到本讲核心问题，再次区分有顺序对应与无顺序对应的 seq2seq，然后给出 delayed sequence-to-sequence：先完整处理输入，得到最终 hidden representation，再从该表示出发逐步生成输出直到 `<eos>`。但他很快发现这个版本有缺陷：下一步 hidden state 只依赖前一步 hidden state，不知道上一步实际抽到了哪个词，因此不能根据上一词调整下一步的输出分布。
概念、符号与推导：`<sos>` 和 `<eos>` 是生成任务的显式边界符号；delayed seq2seq 的过程是“先编码完整输入，再逐步解码输出”；其缺陷是输出词本身没有反馈到下一时刻计算中。本段没有板书公式。
例子与课堂提示：代码生成 vs MIDI 生成说明为什么不能假设自然终止；“four score and eight” 的四种写法说明为什么必须显式编码句子边界；“a / an” 反例则成为下一段修模型的关键动机。
本段掌握检查：完整句子必须同时具有 `<sos>` 与 `<eos>`；最朴素 delayed seq2seq 先编码后解码；其问题是已输出词不影响下一步分布。
待核对项：关于“statistically complete”的口头说法字幕残缺；本段末尾提问在下一段才完整展开。

<div id="section-05" class="course-note-section-anchor" aria-hidden="true">&nbsp;</div>

00:41:04-00:51:04
本段在整讲中的作用：老师直接修补上一段的缺陷，给出 delayed self-referencing sequence-to-sequence，也就是本讲核心的 simple translation model，并把 decoder 明确解释为 conditional language model。
教学展开：老师继续用 “a / and” 之后更该接哪类词的反例说明，上一模型之所以错，是因为抽出来的词没有反馈。解决方法就是把输出词作为下一步输入。于是模型变成两部分：encoder 读取输入直到输入端 `<eos>`，把整句信息压成最终 hidden representation；decoder 以该表示与 `<sos>` 为起点，逐步给出输出分布，抽词，再把该词送回模型，直到产生 `<eos>`。老师随后把这个过程再口头走一遍伪代码，并正式命名 encoder 和 decoder。接着他追问“今天前面有没有见过类似结构”，答案是 decoder 本质上就是 language model，只是现在它对输入条件化，因此成了 conditional language model。最后他补充：真正送入网络的仍然不是 one-hot，而是经 projection matrix 压到低维的 embedding；若输入输出语言不同，输入侧与输出侧的投影矩阵可以不同。
概念、符号与推导：关键概念是 self-reference，即时刻 $t$ 的输出词要进入时刻 $t+1$ 的输入；encoder 是提取输入表示的网络，decoder 是以该表示为条件逐词生成输出的 conditional LM。没有额外公式，但递归依赖关系被说清楚了。
例子与课堂提示：“a/an” 反例不仅用于挑错，也用于说明为什么输出必须反馈；“decoder 就是 conditional LM” 是把前面 language model detour 与当前翻译模型真正接上的一句话。
本段掌握检查：输出反馈能修复什么问题；encoder 在哪里结束；decoder 用什么起步；为什么说 decoder 是 conditional language model；不同语言两侧的 projection matrix 可以不同。
待核对项：德语词形与个别术语字幕有噪声，但不影响结构结论。

<div id="section-06" class="course-note-section-anchor" aria-hidden="true">&nbsp;</div>

00:51:01-01:01:00
本段在整讲中的作用：此时模型结构已经齐备，老师把问题提升到 inference 目标层：既然 decoder 每一步给的是概率分布，那么真正想要的是整句最可能输出，而不是局部看起来最好的词。

00:01:20-00:11:19：问，老师为什么先提 CTC beam search 而不是直接进入翻译模型？答，因为他要先把今天的问题放回 seq2seq 的连续教学线上，说明上次讲的是“有顺序对应”的一种，而今天要转到“无顺序对应”的另一种。问，speech recognition 和 machine translation 在这里被并列的原因是什么？答，它们都符合“一个序列进去、一个序列出来”的任务抽象。问，为什么对话系统例子重要？答，因为它说明输出不一定在词面上看起来像输入的重排。问，Karpati 自动生成代码示例在本讲承担什么作用？答，它不是结论，而是把大家从 seq2seq 问题引到 language modeling 的过渡道具。问，本段最值得记住的边界是什么？答，本讲关注的 seq2seq 不能假设输入输出逐词同步或同长。

00:11:17-00:21:15：问，next symbol prediction 在老师口中真正对应什么更大的对象？答，它对应的是整个语言中序列概率分布的增量构造。问，为什么词和字符都要先排固定顺序？答，因为 one-hot 依赖一个确定索引系统，否则同一个词不会有稳定位置。问，滑窗训练样本的意义是什么？答，它把无标注语料直接变成“前 n 个词预测下一个词”的监督对。问，老师为什么坚持 one-hot 而不是紧凑编码？答，因为 one-hot 不预设词之间谁更近、谁更重要。问，本段最关键的几何结论是什么？答，不同 one-hot 向量等距，这为后续“让模型自己学语义结构”留下了干净起点。

00:21:12-00:31:10：问，为什么 $P \times W$ 在这里不是抽象代数，而是具体的“取列”操作？答，因为 $W$ 是 one-hot，矩阵乘法只会保留与那个 1 对应的一列。问，embedding 在本讲中的定义是什么？答，就是 one-hot 词向量被投影到低维后的新表示。问，老师为什么还要讲 soft bag of words 和 skip-gram？答，因为它们说明“学 projection matrix”有多种训练框架，而不只是一种 TDNN。问，Mikolov 例子被引用来证明什么？答，证明低维词向量空间能学出语义关系而不只是压缩维度。问，老师从 TDNN 过渡到 recurrence 的理由是什么？答，如果目标是根据全部过去预测下一个词，固定窗口模型不再自然，RNN/LSTM 才更贴合目标。

00:31:09-00:41:07：问，为什么老师认为仅靠长度或时长截断生成“不统计一致”？答，因为那是外部人为停止，而不是模型内部产生了句终止符。问，`<sos>` 和 `<eos>` 哪个更不可少？答，老师明确说在某些起点明显的场合 `<sos>` 可以省，但 `<eos>` 仍然必须用来停止。问，delayed seq2seq 的优势是什么？答，它先把整个输入看完，再统一生成输出，结构上很直观。问，它的根本缺陷又是什么？答，已输出词不参与下一步状态更新，导致解码器不知道自己刚说了什么。问，`a/an` 反例的重要性是什么？答，它用最简单的语法依赖直接证明“输出不回馈”的模型违反语言生成常识。

00:41:04-00:51:04：问，self-referencing 的“self”具体指谁？答，指 decoder 在生成输出时把自己上一步产出的词重新喂回自己。问，为什么 decoder 的第一个输入不是普通词而是 `<sos>`？答，因为解码器需要一个明确的起点标记来开始生成。问，encoder 的末状态在老师口中起什么作用？答，它“stores all information about the sentence”，是整个输入的压缩表示。问，为什么说 decoder 其实就是之前的 language model？答，因为它同样是根据前缀逐步给出下一词分布，只是现在这个分布还条件化在 encoder 表示上。问，输入侧与输出侧 embedding 是否必须共享？答，不必须；若源语言和目标语言不同，两侧完全可以有不同 projection matrix。

00:51:01-01:01:00：问，老师为什么还要花时间讲“怎样从分布里抽样”？答，因为 decode 流程里“draw a word”是关键操作，必须从黑箱变成可执行步骤。问，整句概率为什么要一直乘到 `<eos>`？答，因为 `<eos>` 是输出序列的一部分，完整句子的概率包含“在该前缀后终止”的概率。问，greedy 表面上看为什么很有诱惑力？答，因为它每一步都拿当前最大值，似乎在“最大化输出”。问，老师怎样推翻这种直觉？答，用 “he nose / he knows” 说明较大局部概率可能破坏未来上下文，从而让整体概率更低。问，本段想让学生最终记住哪句话？答，局部最优词选择不等于全局最优句子选择。

01:00:57-01:10:57：问，随机采样为什么不能作为“最优解码”的答案？答，因为它没有系统地搜索所有高分路径，只是按分布随即挑选。问，全树搜索为什么理论上正确？答，因为它保留了所有可能路径，最终不会错过真正分数最高的完整序列。问，全树搜索为什么实践上不可行？答，因为候选路径数随时间指数爆炸。问，beam search 保留的到底是什么？答，是当前总分最高的前缀路径集合，而不是每个节点处的局部最大词。问，beam search 为什么依然不是理论最优？答，因为剪枝阶段可能已经把真正最优路径删掉了。问，本段训练过渡里最关键的一句是什么？答，decoder 仍然按语言模型方式学，只不过现在是在输入条件下学。

01:10:55-01:20:54：问，老师说的“cheat code”到底在作弊什么？答，它让训练时 decoder 始终吃到正确目标前缀，而不是吃到模型自己还不成熟时乱猜出来的前缀。问，如果不这样做会怎样？答，早期一个错误词就会让后面所有位置与目标序列错位，导致比较和回传都变得困难。问，为什么老师拿句子簇可视化来讲 hidden representation？答，因为他要说明 encoder 学到的不只是词面，而是句级语义与关系。问，对话系统例子在本段有什么作用？答，它说明 encoder-decoder 不只做翻译，也能做条件响应生成。问，图像描述例子又说明了什么？答，只要把 encoder 换成 CNN，decoder 仍可保持 conditional language model 身份。问，simple model 的后续瓶颈是什么？答，单个 hidden representation 在长输入下可能被迫承担过多信息，解码时会逐渐稀释。

01:20:51-01:22:08：问，为什么老师最后还要重说 language model 的定义？答，因为整讲从 seq2seq 绕行到 LM 再回到 conditional LM，他需要在结束前把这条线闭合。问，为什么最后总结里还强调 inference？答，因为结构讲完后，模型真正要做的仍是“给定输入找最可能输出”，这是应用层的最终目标。问，image captioning 和 video captioning 为什么能跟翻译放在同一页总结？答，因为它们都属于“编码某种输入，再用 conditional language model 解码输出序列”的统一机制。问，老师留给下一讲的唯一问题是什么？答，simple model 把整段输入压缩进一个 hidden representation，这个单点瓶颈太重。问，如果学生只能带走一句本讲结论，应该是什么？答，encoder-decoder 的 decoder 本质上是条件语言模型，而 decoding 与 training 都要围绕这个事实展开。
