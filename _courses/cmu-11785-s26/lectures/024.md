## 学习目标
- 理解为什么 diffusion 会在 GAN 不稳、VAE 模糊、flow 受限之后成为主流生成路线。
- 理解 forward fixed noising、reverse learned denoising、reparameterization trick、noise prediction loss 之间的关系。
- 能用 2D spiral toy model 解释 diffusion 如何从高噪时学习全局结构，到低噪时学习局部细节。
- 理解 DDPM 与 DDIM 的关系，知道速度瓶颈来自“模型只会单步去噪”，而不是来自“数学上绝对不能跳步”。
- 理解 score-based SDE 视角、conditional generation 与 classifier-free guidance 的基本作用链条。
- 能说明 FID、IS、precision/recall、latent diffusion 与 ControlNet / DreamBooth / video diffusion 在本讲中的定位。

## 需要的先修知识
- 高斯分布、均值方差、正态噪声叠加等基础概率知识，因为本讲 repeatedly 依赖“Gaussian + Gaussian 仍是 Gaussian”。
- VAE、GAN、flow-based model 的基本直觉，因为老师用它们对比 diffusion 的 trade-off。
- MSE 回归、神经网络去噪与基本生成模型训练流程，因为 diffusion training 被老师直接重述成“预测噪声”的回归问题。
- Markov chain、reparameterization trick、positional encoding 的基本概念，因为 forward chain、one-shot noising 与 noise-level embedding 都要用到它们。
- ODE / SDE 与梯度场的最低限度直觉，因为老师在后半讲把 diffusion 改写成 score-based reverse SDE。

## 老师的教学主线
老师先用判别式与生成式的对比，重新定义“生成模型到底要学什么”，即不是标签边界，而是整个数据分布 $p(X)$ 与其 data manifold。随后她把 diffusion 放回生成模型谱系中，比较 GAN、VAE、flow 和 diffusion 的优缺点，并把 VAE 的 one-step problem 作为动机：一步从纯噪声跨到高分辨率图像分布太难，所以要把生成拆成许多微小去噪步骤。

接下来整讲进入 diffusion 本体。老师先定义 fixed forward process 与 learned reverse process，说明前者通过逐步添加 Gaussian noise 把图像送向标准高斯，后者则一步步把纯噪声拉回真实图像分布。然后她用 Markov chain 与 reparameterization trick 解释为什么 diffusion training 虽然有很多时间步却依然可算，并说明网络在实践中通常通过简单 MSE 去预测被加进去的噪声，而不是直接预测图像。接着她引入 log-scale noise schedule、训练伪代码和 2D spiral toy model，利用噪声嵌入和向量场可视化展示模型如何从 coarse-to-fine 地恢复数据流形。

后半讲老师把 intuition 推向两条更高阶的解释。第一条是几何与采样线：预测噪声等价于指向数据流形，DDPM 逐步去噪但慢，DDIM 则依靠对 $x_0$ 的显式估计来实现更大的 informed jumps。第二条是连续时间线：把离散 diffusion 改写为 score-based reverse SDE，说明噪声预测、score estimation 与 reverse SDE 只是同一模型的不同数学视角。在此基础上，她再转入应用与系统层：先讲 conditional generation 与 classifier-free guidance，再讲如何评估模型质量，为什么 latent diffusion 解决了像素空间扩散过慢的问题，最后用 ControlNet、DreamBooth 与 video diffusion 说明扩散模型如何从“会生成图像”走向“可控、可编辑、可落地”的现代生成系统。

## 核心概念与依赖关系
- 判别式 vs 生成式：老师用 $X\to Y$ 与 $p(X)$ 的对比界定了 diffusion 要解决的不是分类，而是数据分布学习。
- data manifold：训练数据被视为高维空间中的结构化区域；从噪声走回 manifold 是整讲统一几何图景。
- one-step problem：VAE 一步从噪声到图像的生成负担过重，直接促成“many small steps”这一 diffusion 设计。
- forward / reverse process：forward 是 fixed Gaussian corruption，reverse 是 learned denoising chain；两者一起构成 diffusion 的基本机械结构。
- reparameterization trick：依赖高斯闭合性，把任意深度的 noising 从顺序 $O(T)$ 采样改成 direct $O(1)$ 采样，使训练可行。
- noise prediction objective：老师把 reverse learning 压缩为预测 $\epsilon$ 的 MSE，这又与 score estimation 在数学上相连。
- noise schedule：$\sigma$ 不只是噪声强度，还决定训练覆盖哪些难度层次，并影响模型学到 global structure 还是 fine details。
- toy model / vector field：2D spiral 让“高噪学整体、低噪学局部”的多尺度行为可视化。
- DDPM vs DDIM：前者严格逐步采样，后者借助 predicted $x_0$ 执行 larger informed jumps，因此大幅加速。
- ODE / SDE / score：连续时间视角下，drift 决定确定性流，diffusion term 决定随机扩散；score 提供朝向高概率区域的方向，避免直接处理正规化常数。
- conditional generation / CFG：把无条件采样 $p(X)$ 收缩到条件采样 $p(X\mid Y)$，而 CFG 用同一模型的 conditional / unconditional 两个分支完成引导。
- metrics / latent diffusion / applications：评估指标负责判断“像不像真数据、够不够多样”；latent diffusion 负责把计算移出像素空间；ControlNet、DreamBooth、video diffusion 展示可控生成的落地方向。

## 关键推导、例子与结论边界
- 判别式模型学 decision boundary，生成式模型学整分布 $p(X)$；“画一只新猫”而不是“判断猫狗”是本讲所有后续设计的出发点。
- VAE 的 one-step jump 会平均高频细节，导致模糊样本；diffusion 的核心反论是把一次大跨越拆成上千个小步骤。
- forward process 是 Markov chain，且每一步都加 Gaussian noise；正因为高斯叠加后仍是高斯，老师才能把多步 noising 变成 one-shot closed form，从 $O(T)$ 训练降到 $O(1)$ 采样任意噪声层。
- true reverse $q(x_{t-1}\mid x_t)$ 难直接求，因此用 $p_\theta$ 近似；在实践里老师把训练目标写成简单的噪声预测 MSE。
- 训练中的 noise schedule 从 $\sigma_{\min}=0.01$ 到 $\sigma_{\max}=100$，通常取 100 到 1000 个离散噪声级别，并常在 $\log \sigma$ 空间均匀采样，以平衡高噪与低噪训练覆盖。
- 2D spiral 例子说明：高噪时向量场指向整体均值，中噪时开始看出螺旋弯曲，低噪时则精确指向最近的 manifold 部位。
- 几何视角下，预测噪声等价于给出回到数据流形的方向；噪声还会把原本尖锐不可微的距离地形平滑化，使 denoising direction 可学习。
- DDPM 慢，不是因为数学上绝对不能跳步，而是因为模型只学会 one-step reverse；DDIM 则通过 predicted $x_0$、方向项和随机项重写采样更新，在 $\sigma_t=0$ 时可退化成 deterministic process。
- 连续时间视角下，老师把 ODE 与 SDE 区分为“只有 drift”与“drift 加 diffusion term”；score function 则通过 $\nabla \log p(x)$ 给出通向高概率数据区的方向，并自动消去难算的正规化常数。
- conditional generation 中，classifier guidance 需要额外 classifier；CFG 通过随机丢弃 10% 到 20% 的条件标签，让同一模型同时学会 conditional 与 unconditional generation。
- 指标部分的课堂边界是高层解释而非正式定义：FID 看分布距离且越低越好，IS 看清晰与多样，precision / recall 分别看真实性与覆盖度。
- latent diffusion 的结论边界也很明确：VAE 只负责压缩与保留感知相关语义，真正的生成 heavy lift 仍由 diffusion 完成。

## 易错点与待核对项
- 不要把 diffusion 理解成“前向和后向都要学习”；老师明确说 forward 是 fixed、reverse 才是 learned。
- 不要把高斯噪声只当成工程噪声源；它同时提供 closed-form noising、平滑几何地形和可近似高斯的 reverse step。
- 不要把 DDIM 的加速误解为“用更小的网络”或“训练更快”；本讲明确说它快在 intelligent timestep skipping。
- 不要把 CFG 理解成纯推断技巧；如果训练时从不 drop condition，模型就学不会 unconditional branch，也就做不出 CFG。
- 不要把 latent diffusion 理解为“VAE 负责生成，diffusion 负责修修补补”；老师反过来说，VAE 只负责压缩到合适 latent，diffusion 负责 generation heavy lifting。
- 多个公式在字幕中缺失根号、上下标或常数，例如 closed-form noising、DDIM update、reverse SDE；正式引用时应回看 slide 或视频板书。[需回听]

## 概念、符号与推导
本段的核心符号只有任务层面的 $X$、$Y$ 与 $p(X)$。老师把判别式模型概括为“给定输入预测标签”，把生成式模型概括为“学习数据分布本身”。data manifold 指训练数据在高维空间中聚集形成的结构区域；从高斯噪声到流形的映射，是后续 diffusion、VAE、flow 和 GAN 共同面对的生成问题表述。本段无公式推导。

### 002 00:09:57-00:19:55
## 本段在整讲中的作用
这一段完成“为什么 diffusion 值得学”的核心论证。老师按 GAN、VAE、flow、diffusion 的顺序比较生成路线，随后把 VAE 的 one-step problem 作为直接靶子，引出“把大跳跃拆成很多小去噪步骤”的 diffusion 直觉，并正式交代 forward / reverse 的基本设定。

## 教学展开
老师先接上上一段未说完的 GAN，对其评价是效果好时很惊艳，但训练不稳定且容易 mode collapse。随后她回顾上一讲讲过的 VAE：数据先经 encoder 压到 latent code，再由 decoder 重建；训练稳定，但样本常常发糊。再往下是 flow-based model：同一个可逆变换既能把数据送到噪声，也能把噪声送回数据，优势是 exact likelihood，但代价是架构被 invertibility 严格约束。比较完三类方法后，老师说 diffusion 采取的是“完全不同的赌注”：不是靠单个 latent code 一步生成，而是构造一条从 clean data 到 pure noise 的长链，并学习一步一步把它反过来。这样虽然更慢，却同时绕开了 GAN 的不稳、VAE 的模糊和 flow 的结构约束，因此成为当前主流。

接着老师把镜头拉回 VAE 的 one-step problem。她说，从高斯噪声一步跨到高分辨率图像分布，差距太大，decoder 必须“一次跳过整个鸿沟”，结果往往只能平均自己的猜测，丢失高频细节，于是产出 blurry、low-quality images。diffusion 的核心洞见恰好相反：不要 jump the gap，而是搭一段 staircase，把生成拆成上千个 tiny, easy-to-learn denoising steps。老师现场提问“如果重设系统，你会怎么让 decoder 的工作更容易”，同学回答“lots of steps”，这就是她要的答案。随后她把 diffusion 与 hierarchical VAE 对比，指出它有三个更具体的设计选择：所有 latent 变量和原图同维；forward process 只负责加噪，不需要学习；reverse process 只学习如何去噪；同时可以使用成百上千个步骤。

在 [00:16:34] 之后，老师把直觉连到物理扩散。她用 Brownian motion 和“把一滴墨水滴进水里”的比喻说明：$t=0$ 时是有结构的浓墨，随着时间推移会扩散成均匀混合状态，这个终态就像 pure noise。diffusion model 问的问题就是：能不能把这件事反过来学回来？历史上她提到 2015 年 Sohl-Dickstein 等人给出概念雏形，但真正把它做大的是 Ho et al. 2020 的 DDPM，因为他们把“学反过程”重述成“预测加进去的噪声”。段末老师给出 forward / reverse 的最基本角色划分：forward fixed、不学习，从 clean image 出发逐步加高斯噪声直到近似标准高斯；reverse 才是学习对象，它从纯噪声出发，一步步走回真实图像分布。

## 概念、符号与推导
本段出现的关键符号是 $x_0$、$x_t$ 以及“从结构化数据分布到标准高斯”的 forward chain。one-step problem 指 VAE decoder 需要一次性把纯噪声映射到复杂图像分布，因此容易平均化、变模糊。diffusion 的三项设计选择是：latent 与原图同维、forward 只加噪且固定、reverse 只去噪且可使用很多步。老师把 forward 解释为“逐步 destroy structure”，把 reverse 解释为“学习 undo that destruction”。本段没有展开完整公式推导，重点是问题设定和建模取舍。

## 例子与课堂提示

## 教学展开
老师先从图示出发解释 forward process：从 $x_0$ 开始，每一步只在前一状态上叠加一点点 Gaussian noise，于是 $x_1$ 比 $x_0$ 更噪，$x_2$ 又比 $x_1$ 更噪，一直走到几乎纯噪声。这里最重要的词是 “only depends on the previous step”，所以这是一条 Markov chain，写作 $q(x_t\mid x_{t-1})$。然后她提醒大家想起 reparameterization trick，并说明如果逐步把 $x_1,x_2,\ldots,x_{500}$ 全部算出来，复杂度是 $O(T)$，训练会很慢。

## 教学展开
老师先从 data manifold 继续往下讲。她说 denoiser 的工作，就是面对任意 off-manifold point，判断哪一个方向能把它带回真实数据表面。若直接把这个方向理解成“到最近数据点的距离函数梯度”，数学上很干净，但真实 distance function 在 manifold 折弯处会出现 sharp edges 和 corners，处处不可微，神经网络很难直接学。这里噪声的作用就不只是训练技巧了：当你以某个噪声级别 $\sigma$ 腐蚀数据时，等价于把那张尖锐的距离地形图做平滑，sharp edges 被磨圆，整个 landscape 变得可微。老师说底部 theorem 正是在说明：这个平滑函数的梯度，正比于最优噪声预测器，也就是我们训练得到的 $\epsilon$。于是“predict noise” 与 “point toward the data surface” 成了同一件事。

在这层几何解释之后，老师进入 sampling。现在模型已经学会在每一步给出局部去噪方向，生成时就从 pure noise 出发，逐步从 $x_t$ 走到 $x_{t-1}$，一点点把 sample 拉回数据流形。她强调这依然是 probabilistic process：每一步不只是减掉模型预测的噪声，还会按 $\sigma_t$ 再注入一小点 Gaussian noise，以保持探索性、避免卡死。问题也因此暴露出来：如果严格按 DDPM 的 Markov chain 逐步执行，而训练时又用了上千时间步，那么 sampling 就必须顺序跑完几百到几千步，单张图像生成可能要几分钟，这就是 early diffusion 的 speed problem。

接着老师解释为什么 DDIM 能快。她先澄清：瓶颈不在于“Markov chain 理论上不允许跨步”，真正的问题是 DDPM 的模型只被训练成执行 one-step denoising，因此没有学会 $x_t\to x_{t-k}$ 的多步反过程。DDIM 的 insight 是把采样改写成 non-Markovian update，不再死守单步转移。老师把更新式拆成三部分：第一项是根据当前 noisy sample 与预测噪声反推出的 predicted $x_0$，这相当于每一步都先估计最终目的地；第二项是保持当前噪声水平一致的方向项，用来平滑地沿轨迹前进；第三项是按 $\sigma_t$ 缩放的随机噪声。当 $\sigma_t=0$ 时，第三项完全消失，过程变成 deterministic，这正是 DDIM 的特殊情形，也让 interpolation、inversion 等 latent-space 操作变得有意义。老师最后给出直观收益：因为每一步都锚定了对 $x_0$ 的估计，可以安全跳过大量中间时间步，例如从 1000 步减少到 50 步，同时保持可比质量。

## 概念、符号与推导
本段的几何核心是“平滑距离函数的梯度与最优噪声预测器成正比”。sampling 端的关键量是 predicted $x_0$、保持轨迹一致的方向项，以及按 $\sigma_t$ 缩放的随机噪声项。老师把 DDPM 与 DDIM 的差别讲成“local one-step denoising”与“允许 larger informed jumps”的区别；当 $\sigma_t=0$ 时，DDIM 进入 deterministic special case。本段没有把所有公式完整板书到字幕里，但三项分解和各项意义是明确口述的。

## 例子与课堂提示
“噪声把不可微的尖角地形磨圆”是本段最重要的几何类比。老师还把 DDIM 的速度提升说成“不是 trick，而是更 informed update rule 的直接结果”，这能防止把 DDIM 理解成单纯工程剪枝。她强调 predicted $x_0$ 是关键 move，因为它让模型不再 blind 地一步步摸索，而是每一步都朝着估计终点校正方向。

## 本段在整讲中的作用

## 教学展开
老师先借 Poll 3 收束上一段，确认 DDIM 更快是因为能“intelligently skip timesteps”。随后她说如果想真正理解 diffusion 的底层数学，就要把 staircase 式离散步骤换成 slide 式的连续演化。于是她不再谈 step 50、step 100，而改成谈任意连续时间 $t$ 上的数据分布 $p_t(x)$。有了这个连续视角，就能写出 reverse stochastic differential equation，从而把“从噪声生成数据”视为一条受随机微分方程控制的逆向轨迹。

为了让这件事不太抽象，老师先对比 ODE 和 SDE。她把式子里的 drift term 解释为 deterministic part，也就是 ordinary differential equation；一旦再加上 stochasticity，也就是 diffusion term，这个过程就从确定性流变成扩散过程。她在板书上画了两条从初始分布到数据分布的路径：ODE 对应一条平滑、确定的流，这里她口头把它连到 flow matching；SDE 则对应一条带随机抖动的路径，这就是 diffusion model。老师反复强调，这两者都在做“把一个分布逐步变到另一个分布”，区别只在于是否显式包含随机扩散项。

随后老师引入 score function。她说在很多生成模型里，我们真正关心的是概率密度 $p(x)$，但复杂分布常常带有难以计算的 normalizing constant $Z$。若直接取 $\nabla_x \log p(x)$，这个烦人的常数会消失，留下的就是 score function。score 告诉我们“哪一个方向通向更高概率的数据区域”，而无需显式解出 $Z$。在 diffusion 里，这一点尤其关键，因为老师指出：训练网络预测加到图像上的噪声，等价于训练它去估计这个 score。于是到 [01:08:43] 之后，reverse SDE 的 drift term 就可以不再只是把样本往原点推，而是通过 score modification 把样本拉向高密度数据区域。段末她用图像化语言总结：我们从 pure noise 开始，沿着 learned score vector field 一路下滑到真实图像流形，这就是连续时间版 diffusion 的生成过程。

## 概念、符号与推导
本段的连续时间对象是边缘分布 $p_t(x)$。老师把 ODE 部分称为 drift term，把额外随机部分称为 diffusion term；有后者时就是 SDE，没有后者时就是确定性的 flow。score function 写作对 $\log p(x)$ 的梯度，其意义是指向更高概率区域。关键推论是：噪声预测与 score estimation 数学等价，因此把 learned score 代入 reverse SDE 后，reverse drift 就能把样本从 noise side 拉回 data manifold。本段字幕没有保留完整 SDE 公式排版，但概念与作用链条是清楚的。

## 本段在整讲中的作用

## 教学展开
老师先把 reverse SDE 再收束一次：score 像一个 vector field 或 compass，持续给出“朝数据走”的方向，因此从 Gaussian noise 出发，沿 learned score 反复更新，就能 principled 地流回真实图像流形。紧接着她切向一个完全不同但更应用导向的问题：到目前为止大家掌握的是 unconditional diffusion，它只能“从帽子里变出一张随机高质量图片”，但现实里人们想要的是控制，比如“画一只宠物”还不够，要能指定“山间落日”或其他 prompt。这意味着采样目标要从 $p(X)$ 换成条件分布 $p(X\mid Y)$。

在条件生成部分，老师先给出两条路线。早期方法是 classifier guidance：单独训练一个 classifier，再用它对 noisy image 的梯度告诉 diffusion“怎样更像目标类别”。老师把它解释成“classifier 看着噪声图，说往这个方向更像 dog”，然后再用 guidance scale $\gamma$ 放大或缩小这份建议。它有效，但问题是要维护两个模型，而且 noisy classifier 在高噪阶段容易不稳定。主流做法是 classifier-free guidance。这里不再另训分类器，而是训练同一个扩散模型同时学 conditional 与 unconditional 两件事：大部分训练样本带 class label 或文本条件，小约 10% 到 20% 的样本则故意把条件丢掉，换成 dummy / empty label。这样模型既学会“生成猫”，也学会“生成任意东西”。推断时再把 conditional prediction 与 unconditional prediction 做向量外推，把 sample 从“随便什么都行”的方向推向“更符合 prompt”的方向。老师追问“为什么一定要 drop labels”，并明确回答：如果从不丢条件，模型就永远学不会 unconditional branch，也就做不出 CFG 所需的对比校正。

接下来老师用 OpenAI GLIDE 的图像样例说明 CFG 的效果：无 guidance 时图像大体正确，但更平、更糊；有 guidance 时颜色更鲜明、边缘更清楚、prompt adherence 更强。她进一步给出一个经验解释：CFG 像 low-temperature sampling。增大 guidance scale $\gamma$ 相当于 sharpen 概率分布，把模型推向更高密度、也往往主观质量更高的样本。她把这概括成“用一个坏版本的自己来引导一个好版本的自己”，即 predictor-corrector 机制。随后话题转向模型评估。老师快速列出三类指标：FID 比较生成图像分布与真实图像分布，越低越好；Inception Score 同时看清晰度和多样性；precision 看“生成图像像不像真的”，recall 看“模型是否覆盖了整个数据集，而不是只记住几个容易样本”。

最后老师过渡到 latent diffusion 的动机：早期 diffusion 慢，是因为直接在 pixel space 上对高分辨率图像跑几百上千步。解决方案是先用 VAE 把图像压到更小、更致密的 latent space，例如从大分辨率压到 $64\times64$ 网格，再在这个 latent space 里做 diffusion。老师说这样不仅更快，而且往往画质还更好，因为模型不再把容量浪费在“不可见的 pixel noise”上。段末她给出蓝图：encoder 压缩到 latent，U-Net 在 latent 中做 denoising，decoder 再把 latent 放大回高分辨率图像。

## 概念、符号与推导
这一段的重要概率对象是从无条件分布 $p(X)$ 转到条件分布 $p(X\mid Y)$。classifier guidance 通过额外分类器提供关于 noisy image 的条件梯度，再由 guidance scale $\gamma$ 调强弱；classifier-free guidance 则通过同一模型的 conditional / unconditional 两个预测分支做向量外推。老师把 CFG 的训练技巧明确成“随机丢弃 10% 到 20% 的条件标签”。评估指标部分没有公式，只给出含义：FID 看分布接近度，IS 看清晰度与多样性，precision/recall 分别看真实性与覆盖度。latent diffusion 的结构则是 encoder → latent-space denoiser → decoder。

## 教学展开
老师先围绕 latent diffusion 回答一个自然疑问：既然 VAE reconstruction 常常发糊，为什么这里还敢先压缩再生成？她的回答是，latent diffusion 中 VAE 的职责不是负责最终生成高质量图像，而是以“受控且符合人类感知”的方式丢掉不重要的像素级细节，同时保留 semantic 与 visual structure，把图像映射到 compact、meaningful 的 latent space。真正负责 heavy lifting 的仍然是 diffusion，它在 latent space 中学习生成过程，然后再交给 decoder 回到高分辨率图像。

随后老师在只剩一两分钟的情况下快速扫过应用。第一类是 fine-grained control。普通文本 prompt 只能给语义控制，无法保证结构；ControlNet 的办法是在主 denoiser 旁边增加并行网络，让模型额外接收 edge map、depth map、pose skeleton 这类 structural input，从而把“站着的人”进一步约束成“这个人以这一姿态站在这一位置”。第二类是 image editing / personalization。DreamBooth 通过只用三到五张某个特定 subject 的照片，微调模型的一小部分，并把这个身份绑定到一个 rare token 上，于是之后就能在模型懂得的任何上下文里生成这个特定主体。第三类是 video generation。老师把它概括成“image diffusion 加上第三个维度”，这个额外维度就是时间；VAE 不再只压缩空间，还要压缩时空联合表示。主要挑战是 temporal consistency，要避免物体在连续帧之间 drift 或 flicker。她同时提醒，计算代价会大得多，但底层 framework 仍然是同一套 diffusion 思路。

在正式结束前，老师给出三条总结。第一，many small steps beat one big jump，所以 diffusion 能在 VAE struggle 的地方成功；第二，forward process 是 fixed 的，reverse process 才是 learned 的，训练目标归根到底就是预测噪声的简单 MSE；第三，denoising、score estimation 与 reverse SDE 只是同一模型的三种不同视角。随后她感谢听众，并说 lecture 虽 tough 但希望大家抓住主线。最后的 Q&A 又回到 latent diffusion：学生追问“如果先经 VAE 编码，diffusion 的输出是不是还停留在那个 latent space 里”；老师再次强调 VAE 擅长压缩到 latent space，而 diffusion 负责 generation heavy lift，系统仍然需要 decoder 把 latent 还原到输入空间，否则就仍困在压缩表示中。

## 本段掌握检查
1. 老师为什么认为 latent diffusion 中使用 VAE 是可以接受的？参考答案：因为 VAE 只负责以感知一致的方式压缩并保留语义结构，不承担最终生成质量，真正的生成重任在 diffusion。
2. ControlNet 相比普通文本条件多了什么控制能力？参考答案：多了 edge、depth、pose 等结构条件，能把内容控制推进到空间布局与姿态层面。
3. DreamBooth 解决的是什么问题？参考答案：用极少量样本让预训练模型记住某个具体主体，并在任意上下文里再生成它。
4. 视频扩散比图像扩散多出的核心维度与挑战是什么？参考答案：多出时间维，核心挑战是 temporal consistency，避免跨帧漂移和闪烁。
5. 老师最后留下的三条总复习是什么？参考答案：小步优于大跳；forward 固定而 reverse 学习；denoising、score estimation 与 reverse SDE 是同一模型的不同视角。
