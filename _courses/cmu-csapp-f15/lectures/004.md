## 教学路径与依赖

### 1. 先建立 fractional binary（`00:00:01-00:06:59`）

从 $2^k$ 位权出发，计算有限二进制小数，观察移位与 $1-\epsilon$，再用 $x/2^k$ 条件和固定 binary point 的范围/精度冲突提出 floating point 的必要性。[课件: 04-float.pptx p.3] [课件: 04-float.pptx p.4] [课件: 04-float.pptx p.5] [课件: 04-float.pptx p.6]

### 2. 再定义 IEEE 754 编码骨架（`00:06:59-00:19:47`）

先说明统一标准的动机，再定义

$$
v=(-1)^sM2^E
$$

与 `s | exp | frac`。随后只处理 normalized values：biased exponent、implied leading 1、single/double 字段宽度，并以 `15213.0` 完成一次完整编码。[课件: 04-float.pptx p.8] [课件: 04-float.pptx p.9] [课件: 04-float.pptx p.10] [课件: 04-float.pptx p.11] [课件: 04-float.pptx p.12]

### 3. 用特殊 `exp` 补齐数值系统（`00:19:47-00:29:37`）

`exp=0` 取消 implied 1，得到 signed zero 与接近 0 的 denorm；`exp` 全 1 再由 `frac` 是否为 0 区分 infinity 与 NaN。老师把所有类别放到概念数轴后，建议用 tiny format 穷举理解。[课件: 04-float.pptx p.13] [课件: 04-float.pptx p.14] [课件: 04-float.pptx p.15] [课件: 04-float.pptx p.17]

### 4. 用 tiny format 验证边界与 spacing（`00:29:37-00:40:35`）

8-bit format 把 $0,1/512,\ldots,7/512,8/512,9/512$ 连续算出，说明 denorm 到 norm 无间距突变；6-bit 数轴进一步展示 fixed exponent 内等距、指数每增 1 间距翻倍。随后归纳 bit encoding 的比较便利及 sign/$-0$/NaN 例外。[课件: 04-float.pptx p.18] [课件: 04-float.pptx p.19] [课件: 04-float.pptx p.20] [课件: 04-float.pptx p.21]

### 5. 从表示转向 rounding（`00:40:35-00:54:35`）

先建立

$$
x+_fy=Round(x+y),\qquad x\times_fy=Round(x\times y),
$$

再比较四种模式。十进制例子先把“最近”和“exact tie”分开，二进制例子再把 halfway 识别为 `100...`，覆盖 tie 向上与 tie 向下。[课件: 04-float.pptx p.23] [课件: 04-float.pptx p.24] [课件: 04-float.pptx p.25] [课件: 04-float.pptx p.26]

### 6. 把 rounding 放回乘法与加法（`00:54:35-00:59:33`）

乘法组合 sign/significand/exponent 后 normalize 和 round；加法先对齐 binary points，再做 signed addition、normalize 和 round。大动态范围让小量在对齐/舍入时消失，从而破坏 associativity。[课件: 04-float.pptx p.27] [课件: 04-float.pptx p.28] [课件: 04-float.pptx p.29]

### 7. 用代数反例划清“float 与 real”的边界（`00:59:33-01:02:38`）

老师依次讨论 addition 与 multiplication 的代数性质，用 $10^{20}$ 例子展示重关联引发 overflow，用 `infinity-infinity` 展示 distributivity 失效，再用地震模拟经验说明实际风险取决于数据动态范围和计算顺序。[课件: 04-float.pptx p.29] [课件: 04-float.pptx p.30]

### 8. 最后落到 C conversions 与 puzzles（`01:02:38-01:11:22`）

按 `floating -> int`、`int -> double`、`int -> float` 的顺序建立截断、精确与舍入规则；再逐题检查 widening/narrowing 往返、双重取负、integer division、monotonicity、平方和 non-associativity。[课件: 04-float.pptx p.32] [课件: 04-float.pptx p.33] [课件: 04-float.pptx p.34]

## 关键推导与课堂例子

### 1. Fractional binary 的统一计算

$$
1011.101_2
=2^3+2^1+2^0+2^{-1}+2^{-3}
=11.625.
$$

有限 $n$ 位全 1 小数为

$$
0.\underbrace{11\ldots1}_{n}{}_2
=\sum_{i=1}^{n}2^{-i}
=1-2^{-n}.
$$

因此 finite binary fraction 必为 $x/2^k$；$1/3$、$1/5$、$1/10$ 需要循环展开。[课件: 04-float.pptx p.5] [课件: 04-float.pptx p.6]

### 2. IEEE 754 的分类表

| `exp` | `frac` | 类别 | $E$ | $M$ |
| --- | --- | --- | --- | --- |
| neither all 0 nor all 1 | 任意 | normalized | $Exp-Bias$ | $1.frac_2$ |
| all 0 | all 0 | $\pm0$ | $1-Bias$ | 0 |
| all 0 | nonzero | denormalized | $1-Bias$ | $0.frac_2$ |
| all 1 | all 0 | $\pm\infty$ | n/a | n/a |
| all 1 | nonzero | NaN | n/a | n/a |

其中

$$
Bias=2^{k-1}-1.
$$

Single 的 bias 为 127，normalized $E\in[-126,127]$；double 的 bias 为 1023，normalized $E\in[-1022,1023]$。[课件: 04-float.pptx p.11] [课件: 04-float.pptx p.13] [课件: 04-float.pptx p.14]

### 3. `15213.0` 的完整编码

$$
15213_{10}=11101101101101_2
=1.1101101101101_2\times2^{13}.
$$

$$
Exp=13+127=140=10001100_2.
$$

```text
0 10001100 11011011011010000000000
```

[课件: 04-float.pptx p.12]

### 4. Tiny format 的平滑边界

对 `1/4/3` 位的 8-bit format，$Bias=7$。正数端点按编码顺序为：[课件: 04-float.pptx p.17] [课件: 04-float.pptx p.18]

$$
0,\frac1{512},\ldots,\frac7{512},\frac8{512},\frac9{512},\ldots,240,+\infty.
$$

最大 denorm：

$$
\frac78\times2^{-6}=\frac7{512}.
$$

最小 norm：

$$
1\times2^{-6}=\frac8{512}.
$$

两者与 denorm 内部间距同为 $1/512$。

### 5. Spacing 公式

`frac` 有 $f$ 位时：

$$
\Delta_{denorm}=2^{1-Bias-f},
$$

$$
\Delta_E=2^{E-f}.
$$

所以 $E$ 每增加 1，$\Delta$ 翻倍；在最小 normalized exponent $E=1-Bias$ 处，两公式相等。[课件: 04-float.pptx p.19] [课件: 04-float.pptx p.20]

### 6. Round-to-nearest-even

只有 exact halfway 才看最低保留 digit/bit 的奇偶：[课件: 04-float.pptx p.25] [课件: 04-float.pptx p.26]

| 精确值 | 目标精度 | 结果 | 原因 |
| --- | --- | --- | --- |
| $7.8949999$ | 百分位 | $7.89$ | 小于 half |
| $7.8950001$ | 百分位 | $7.90$ | 大于 half |
| $7.8950000$ | 百分位 | $7.90$ | tie，选 even 0 |
| $7.8850000$ | 百分位 | $7.88$ | tie，选 even 8 |
| $10.11100_2$ | 两位小数 | $11.00_2$ | tie，截断结果 odd，向上 |
| $10.10100_2$ | 两位小数 | $10.10_2$ | tie，截断结果 even，向下 |

### 7. Floating-point operations

乘法：[课件: 04-float.pptx p.27]

$$
s=s_1\oplus s_2,\qquad M=M_1M_2,\qquad E=E_1+E_2.
$$

若 $M\ge2$ 则右移并增加 $E$，之后检查 overflow 并 round。

加法：[课件: 04-float.pptx p.28]

```text
align smaller exponent -> signed add -> normalize -> overflow check -> round
```

### 8. 代数反例

加法不结合：[课件: 04-float.pptx p.29]

$$
(3.14+_f10^{10})-_f10^{10}=0,
$$

$$
3.14+_f(10^{10}-_f10^{10})=3.14.
$$

乘法不结合：[课件: 04-float.pptx p.30]

$$
(10^{20}\times_f10^{20})\times_f10^{-20}=\infty,
$$

$$
10^{20}\times_f(10^{20}\times_f10^{-20})=10^{20}.
$$

不满足分配律：[课件: 04-float.pptx p.30]

$$
10^{20}\times_f(10^{20}-_f10^{20})=0,
$$

$$
(10^{20}\times_f10^{20})-_f(10^{20}\times_f10^{20})=NaN.
$$

### 9. C conversions 与 puzzles

| 转换 | 课堂规则 |
| --- | --- |
| `float/double -> int` | 丢弃 fractional part，toward zero；out-of-range/NaN 不由普通规则定义 |
| `int -> double` | 当整数不超过 53-bit word size 时精确 |
| `int -> float` | 可能按当前模式舍入 |

[课件: 04-float.pptx p.32]

Puzzles 的主结论：[课件: 04-float.pptx p.33]

| Expression | 是否总成立 | 原因摘要 |
| --- | --- | --- |
| `x == (int)(float)x` | 否 | `int -> float` 可能丢低位 |
| `x == (int)(double)x` | 是，课堂 32-bit `int` 前提 | double 精确容纳 |
| `f == (float)(double)f` | 是，排除 NaN | widening 后可回到原 float |
| `d == (double)(float)d` | 否 | narrowing 可能舍入 |
| `f == -(-f)` | 是，排除 NaN | 两次切换 sign |
| `2/3 == 2/3.0` | 否 | integer division 0 vs floating division |
| `d < 0 -> d*2 < 0` | 是，排除 NaN | overflow 也到 $-\infty$ |
| `d > f -> -f > -d` | 是，排除 NaN | 取负反转顺序 |
| `d*d >= 0` | 是，排除 NaN | finite/zero/$+\infty$ 均非负 |
| `(d+f)-d == f` | 否 | 中间舍入、非结合性 |

## 常见误区与陷阱

- 把 binary point 右侧第一位误当成 $2^0$，而不是 $2^{-1}$。
- 认为十进制有限小数必有有限二进制展开；$1/10$ 是课堂反例。[课件: 04-float.pptx p.6]
- 把 `exp` bit field、$Exp$ unsigned value 和 $E$ actual exponent 混成一个对象。
- 把 raw single `exp` 端点 $0,255$ 代入 normalized 公式，误得 $E\in[-127,128]$；实际 normalized 范围是 $[-126,127]$。[课件: 04-float.pptx p.11]
- 在 denorm 中仍补 implied leading 1；denorm 使用 $M=0.frac_2$。[课件: 04-float.pptx p.13]
- 把 $-0$ 与 $+0$ 说成同一 bit pattern，或忽略其在除法符号中的作用。
- 认为 infinity 参与任何运算仍是 infinity；$\infty-\infty$ 与 $\infty\times0$ 是 NaN。[课件: 04-float.pptx p.14]
- 无条件把 floating-point bit pattern 当 unsigned integer 比较，忽略 sign、negative zero 和 NaN。[课件: 04-float.pptx p.21]
- 看到被丢弃首位为 1 就一律进位；还必须判断 suffix 是大于还是等于 `100...`。
- 在非 tie 情形也强求结果最低位为 even；even 只是 exact halfway 的 tie-break。
- 把 round down 当成 truncation；对负数，toward $-\infty$ 与 toward zero 不同。[课件: 04-float.pptx p.24]
- 浮点加法未对齐 exponent 就直接相加 significands。[课件: 04-float.pptx p.28]
- 由 commutativity 错推 associativity 或 distributivity，允许 compiler 任意重排。[课件: 04-float.pptx p.29] [课件: 04-float.pptx p.30]
- 把一次 single-precision 科学模拟未遇到问题推广为所有数据范围都安全。
- 认为 `float/double -> int` 使用 nearest-even，或忽视 out-of-range/NaN 的边界。[课件: 04-float.pptx p.32]
- 认为 narrowing 后再 widening 能恢复原 bits。
- 在 `2/3 == 2/3.0` 中以为 comparison 会让左侧重新执行 floating division。
- 忘记 puzzles 明确排除 `f`、`d` 为 NaN 的情况。[课件: 04-float.pptx p.33]

## 推荐复习顺序

1. **先练第 1 节的位权与分数。** 若不能稳定计算 $1011.101_2$、$1-\epsilon$ 和循环二进制，后面的 `frac` 与 rounding 会失去基础。
2. **连续复习第 2、3 节的分类规则。** 先写 normalized，再写 denorm/zero/infinity/NaN；每次都明确 `exp`、$Exp$、$E$，不要只背 bit pattern。
3. **手算第 4 节 tiny format。** 从 0 开始列到 $9/512$，再算 1 附近和 240；这是检查规则是否真正理解的最快方法。
4. **单独训练第 5、6 节 rounding。** 先判断 `< half / = half / > half`，只有 `= half` 才看 even；然后再放回 multiplication/addition。
5. **复习第 6、7 节的代数反例。** 每一步都写出中间 rounding、infinity 或 NaN，不能只背“不结合”。
6. **最后做第 7、8 节 C puzzles。** 先标 operand types 和 conversion direction，再判断 precision、special values 与题设假设。
7. **集中检查所有 `[需回听 ...]`。** 重点是 raw/normalized exponent 端点、$10^{10}/10^{20}$ 的 ASR、PowerPoint crash 缺口和最后的 C 类型追问。

## 全讲快速自测

1. **问：为什么 normalized single 的 `frac` 有 23 bits，却通常有 24 bits precision？**  
   **答：** Normalized $M=1.frac_2$，leading 1 由规则隐含，不占字段。

2. **问：Denorm 为什么同时改 $M$ 与 $E$ 的规则？**  
   **答：** Leading 0 允许趋近 0；$E=1-Bias$ 让最大 denorm 与最小 norm 保持同一间距。

3. **问：Nearest-even 最容易误用在哪里？**  
   **答：** 只有 discarded part 恰在 halfway 才看保留 LSB 的奇偶；小于或大于 halfway 都直接选最近值。

4. **问：浮点加法非结合性的直接机制是什么？**  
   **答：** 不同括号改变中间对齐与舍入；小量可能先被大数吞掉，也可能在大数先相消后保留。

5. **问：判断 C cast 往返能否恢复原值的统一方法是什么？**  
   **答：** 看第一次转换的目标格式能否精确容纳源值；一旦 narrowing 舍入或截断，后续 widening 不能恢复信息。

## 教学展开

### 1. 从十进制小数类比二进制小数（`00:00:11-00:01:57`）

老师把 floating point 定位为计算机表示实数的方法，然后从 `3.14` 这样的十进制小数过渡到 binary point。二进制点左侧从右到左的位权为 $2^0,2^1,2^2,\ldots$，右侧从左到右的位权为 $2^{-1},2^{-2},2^{-3},\ldots$。[课件: 04-float.pptx p.3] [课件: 04-float.pptx p.4]

若有限二进制串写成

$$
b_i b_{i-1}\cdots b_0.b_{-1}b_{-2}\cdots b_{-j},
$$

则其值为

$$
\sum_{k=-j}^{i} b_k 2^k,\qquad b_k\in\{0,1\}.
$$

例如课件开头的 $1011.101_2$ 可逐位展开为

$$
\begin{aligned}
1011.101_2
&=1\cdot2^3+0\cdot2^2+1\cdot2^1+1\cdot2^0\\
&\quad+1\cdot2^{-1}+0\cdot2^{-2}+1\cdot2^{-3}\\
&=8+0+2+1+\frac12+0+\frac18\\
&=11\frac58=11.625.
\end{aligned}
$$

这与十进制位置记数法没有结构差异，只有基数从 10 变成 2。[课件: 04-float.pptx p.3] [课件: 04-float.pptx p.4]

### 2. 三个带分数例子（`00:02:05-00:03:47`）

老师按从整数部分到小数部分的顺序展开三个例子：[课件: 04-float.pptx p.5]

1. $5\frac34$：

   $$
   101.11_2=4+1+\frac12+\frac14=5\frac34.
   $$

2. $2\frac78$：

   $$
   10.111_2=2+\frac12+\frac14+\frac18
   =2+\frac{4+2+1}{8}=2\frac78.
   $$

3. $1\frac7{16}$：

   $$
   1.0111_2=1+\frac14+\frac18+\frac1{16}
   =1+\frac{4+2+1}{16}=1\frac7{16}.
   $$

这些例子既练习位权，也为后面把 `frac` 字段解释成二进制小数作准备。

### 3. 移位与 $1-\epsilon$（`00:03:47-00:04:59`）

保持所有位不变而把二进制点向右移动一位，相当于每个位权都乘以 2；向左移动一位则相当于每个位权都除以 2。因此，无符号二进制小数满足“左移一位乘 2、右移一位除 2”的位权关系。[课件: 04-float.pptx p.5]

对二进制点后恰有 $n$ 个 `1` 的数，课堂称它为略小于 1 的 $1-\epsilon$：

$$
\begin{aligned}
0.\underbrace{11\cdots1}_{n\text{ bits}}{}_2
&=2^{-1}+2^{-2}+\cdots+2^{-n}\\
&=1-2^{-n}.
\end{aligned}
$$

因此在这个具体位宽下 $\epsilon=2^{-n}$。$n$ 越大，$\epsilon$ 越小，该数越接近 1；无限级数 $\frac12+\frac14+\frac18+\cdots$ 的极限为 1。[课件: 04-float.pptx p.5]

### 4. 有限二进制表示的第一个局限（`00:04:59-00:05:40`）

有限二进制小数的每一项分母都是 2 的幂。通分后，它必定具有

$$
\frac{x}{2^k}
$$

的形式，其中 $x$、$k$ 为整数且 $k\ge 0$。反过来，这类数可以在至多 $k$ 个二进制小数位内表示。因此，有限二进制串只能精确表示这类有理数。[课件: 04-float.pptx p.6]

其他有理数会循环：

$$
\frac13=0.010101\ldots_2,
$$

$$
\frac15=0.001100110011\ldots_2,
$$

$$
\frac1{10}=0.0001100110011\ldots_2.
$$

有限机器只能截取并舍入这些无限展开，所以“十进制看起来有限”不保证“二进制也能精确表示”。[课件: 04-float.pptx p.6]

### 5. 固定二进制点的第二个局限（`00:05:40-00:06:59`）

假设总位数固定。给二进制点右侧更多位，可表达更细的分数间隔，却会减少左侧位数和可覆盖的最大数量级；给左侧更多位可扩大范围，却会牺牲小数精度。这就是固定点表示的范围/精度权衡。[课件: 04-float.pptx p.6]

Floating point 的动机正是让二进制点的位置随指数变化：在有限总位数下，用 significand 保存有效数字，用 exponent 调整尺度，从而覆盖较宽动态范围。这里的 “floating” 指尺度变化，并不表示数值没有规则。

### 6. IEEE 754 统一浮点行为（`00:06:59-00:08:15`）

老师回顾 1985 年以前各厂商格式、舍入和跨机器行为不统一的情况，再引入 IEEE Standard 754。课件强调该标准由数值需求驱动，对 rounding、overflow 和 underflow 给出一致规则，并被主要 CPU 支持。[课件: 04-float.pptx p.8]

这一步的教学结论是：后续分析可以基于一个公开、可预测的表示与运算模型，而不是针对每台机器猜测行为。

### 7. 数值形式与三类字段（`00:08:15-00:09:57`）

IEEE 浮点数按类似科学记数法的形式组织：[课件: 04-float.pptx p.9]

$$
v=(-1)^s M2^E.
$$

- $s$ 是 sign bit：$s=0$ 给出正号，$s=1$ 给出负号。
- $M$ 是 significand，normalized 情况下通常在 $[1,2)$。
- $E$ 是实际指数，用 $2^E$ 调整数量级。
- 物理编码按 `s | exp | frac` 排列；`s` 是最高位。
- `exp` 字段编码 $E$，但字段本身不等于 $E$。
- `frac` 字段编码 $M$，但字段本身不等于 $M$。

最后两点是下一节的关键依赖：读 bit pattern 时不能直接把 `exp` 当实际指数，也不能直接把 `frac` 当完整 significand。[课件: 04-float.pptx p.9]

## 概念、符号与推导

### 二进制小数的统一公式

$$
B=\sum_{k=-j}^{i}b_k2^k.
$$

二进制点不是一个占位 bit，而是说明各 bit 应采用哪一个 $2^k$ 位权。

### 精确可表示条件

对有限二进制小数，最小位权为 $2^{-k}$。把所有项通分到 $2^k$ 后，结果必为 $x/2^k$。边界情况包括：

- 整数对应 $k=0$，当然属于该集合。
- $1/8=2^{-3}$ 可精确表示。
- $1/10$ 的最简分母含因子 5，不是 2 的幂，因此有限二进制位不能精确表示。[课件: 04-float.pptx p.6]

### 浮点抽象的依赖

```text
有限总位数
├─ 固定二进制点 -> 范围与精度只能静态分配
└─ 浮动二进制点
   ├─ M 保存有效数字
   ├─ E 调整尺度
   └─ s 给出符号
```

## 常见误解

- **误解：二进制点后的第一位表示 $2^0$。** 它表示 $2^{-1}=1/2$。
- **误解：所有有理数都能被有限二进制小数精确表示。** 只有能写成 $x/2^k$ 的数可以；其余会循环并需要舍入。
- **误解：小数在十进制中有限，换成二进制也有限。** $0.1_{10}=1/10$ 就是反例。[课件: 04-float.pptx p.6]
- **误解：多放小数位不会付出代价。** 总位数固定时，小数位增加会压缩整数范围。
- **误解：`exp` 就是 $E$，`frac` 就是 $M$。** 两个字段都只是编码；解码规则尚未给出。[课件: 04-float.pptx p.9]
- **误解：浮点数意在精确表示所有实数。** 本讲从一开始就把它放在有限位数约束下；目标是可预测地平衡范围和精度。

# 第 2 节：精度字段、normalized 编码与 `15213.0` 实例

## 教学展开

### 1. Single、double 与 extended 的字段宽度（`00:09:57-00:10:43`）

IEEE 常用的两档精度如下：[课件: 04-float.pptx p.10]

| 类型 | 总位数 | `s` | `exp` | `frac` |
| --- | ---: | ---: | ---: | ---: |
| single precision | 32 | 1 | 8 | 23 |
| double precision | 64 | 1 | 11 | 52 |

课件还列出 Intel-only 的 80-bit extended precision，但老师明确说本讲不再展开。无论精度如何，最高位都是 sign bit，其后依次为 `exp` 和 `frac`。[课件: 04-float.pptx p.9] [课件: 04-float.pptx p.10]

### 2. Normalized value 的判定（`00:10:43-00:11:19`）

当且仅当

```text
exp != 000...0 且 exp != 111...1
```

时，本段采用 normalized 规则。全 0 和全 1 被保留给 denormalized、zero、infinity 和 NaN，不能套用本节公式。[课件: 04-float.pptx p.11]

### 3. Biased exponent：从 `exp` 到 $Exp$ 再到 $E$（`00:11:19-00:14:51`）

设 `exp` 有 $k$ 位：

1. 把 `exp` 当作无符号整数，得到 $Exp$。
2. 计算

   $$
   Bias=2^{k-1}-1.
   $$

3. 对 normalized value 解码：

   $$
   E=Exp-Bias.
   $$

Single precision 中 $k=8$，所以

$$
Bias=2^{8-1}-1=2^7-1=127.
$$

Double precision 中 $k=11$，所以

$$
Bias=2^{11-1}-1=2^{10}-1=1023.
$$

由于 normalized 编码排除两个端点，single 的 $Exp\in[1,254]$，对应 $E\in[-126,127]$；double 的 $Exp\in[1,2046]$，对应 $E\in[-1022,1023]$。[课件: 04-float.pptx p.11]

老师提出“为什么不直接把指数存成 two's complement”。课堂给出的动机是：biased encoding 把较小实际指数映射到较小无符号编码，有助于编码顺序随数值尺度增加。这里先建立直觉；后面比较整段浮点 bit pattern 时仍必须处理 sign、negative zero 和 NaN 等例外，不能把这句话扩大成无条件规则。[课件: 04-float.pptx p.21]

### 4. Implied leading 1：从 `frac` 到 $M$（`00:14:51-00:16:48`）

Normalized value 总能调整二进制点，使 significand 写成

$$
M=1.xxx\ldots x_2,
$$

并把移动量放进 $E$。既然开头必为 `1`，编码时不保存它，只把点右侧的 bits 放入 `frac`。因此若 `frac` 有 $f$ 位，实际有效数有 $f+1$ 位有效二进制精度。[课件: 04-float.pptx p.11]

边界为：

$$
\mathrm{frac}=00\ldots0\Longrightarrow M=1.0,
$$

$$
\mathrm{frac}=11\ldots1\Longrightarrow
M=1+\sum_{i=1}^{f}2^{-i}=2-2^{-f}=2-\epsilon.
$$

所以 normalized significand 满足 $1\le M<2$。隐含位只适用于 normalized case；下一节的 denorm 改用 implied leading 0。

### 5. `15213.0` 的 single-precision 编码（`00:16:48-00:19:28`）

课件选课程号 `15213` 作为完整例子。[课件: 04-float.pptx p.12]

**步骤 1：把十进制整数改写为二进制。**

$$
15213_{10}=11101101101101_2.
$$

逐项验算：

$$
15213=2^{13}+2^{12}+2^{11}+2^9+2^8+2^6+2^5+2^3+2^2+2^0.
$$

**步骤 2：规格化。** 二进制点左移 13 位，同时乘上 $2^{13}$：

$$
11101101101101_2
=1.1101101101101_2\times2^{13}.
$$

因此

$$
M=1.1101101101101_2,\qquad E=13.
$$

**步骤 3：编码 `frac`。** 丢掉必然存在的 leading `1`，保留点后 bits，再补 0 到 23 位：

```text
frac = 11011011011010000000000
```

**步骤 4：编码 `exp`。** 由 $E=Exp-Bias$ 得

$$
Exp=E+Bias=13+127=140.
$$

而

$$
140_{10}=10001100_2.
$$

**步骤 5：确定符号并拼接。** `15213.0` 为正数，所以 $s=0$：

```text
s |   exp    |          frac
0 | 10001100 | 11011011011010000000000
```

代回解码式检查：

$$
(-1)^0\times1.1101101101101_2\times2^{140-127}=15213.
$$

这个例子没有发生舍入：整数的有效 bits 能完整放入 single 的 implicit-1 加 23 个 `frac` bits 中。[课件: 04-float.pptx p.12]

## 概念、符号与推导

### 三个容易混淆的指数对象

| 记号 | 含义 | `15213.0` 中的值 |
| --- | --- | ---: |
| `exp` | 实际存储的 bit field | `10001100` |
| $Exp$ | 把 `exp` 解释成无符号数 | 140 |
| $E$ | 数值公式中的实际指数 | 13 |

关系只在 normalized case 中为

$$
E=Exp-Bias.
$$

### 编码与解码的方向

```text
编码：给定 E -> Exp = E + Bias -> 写成 k-bit exp
解码：读取 exp -> 无符号值 Exp -> E = Exp - Bias
```

把两个方向混在一起，会产生课堂末尾口述中“从 140 减 127 来形成字段”的错句；正确的是用 $13+127$ 得到字段值 140，再在解码时用 $140-127$ 还原 13。[课件: 04-float.pptx p.12]

## 例子与课堂提示

- `100.01` 被规格化为 $1.0001\times2^2$，用于说明移动二进制点必须反向调整指数。
- Implied leading 1 不是额外存储位，而是 normalized 规则允许解码器补回的固定 bit。[课件: 04-float.pptx p.11]
- `15213.0` 把整数二进制、规格化、bias、field concatenation 串成一次完整编码。[课件: 04-float.pptx p.12]

## 常见误解

- **误解：Single 有 7 个 exponent bits。** 它有 8 个；ASR 在 `00:12:03` 误识为 7。[课件: 04-float.pptx p.10]
- **误解：Double 的 bias 是 123.23。** 正确值是 1023。[课件: 04-float.pptx p.11]
- **误解：$Exp$ 可以为 0 或全 1，同时仍按 normalized 解码。** 这两个编码区间已被保留。
- **误解：`frac=0` 代表 $M=0$。** 在 normalized case 中隐含 leading 1，所以它代表 $M=1.0$。
- **误解：规格化会改变数值。** 二进制点移动与 $2^E$ 的调整互相抵消，数值保持不变。
- **误解：整个浮点 bit pattern 总能直接作 unsigned 比较。** Sign、$-0$ 和 NaN 都要求额外处理。[课件: 04-float.pptx p.21]

## 本段掌握检查

1. **问：Single 和 double 的字段宽度各是什么？**  
   **答：** Single 为 `1/8/23`，double 为 `1/11/52`，依次对应 `s/exp/frac`。

2. **问：8-bit `exp=10001100` 对应的 normalized 实际指数是多少？**  
   **答：** $Exp=140$，$E=140-127=13$。

3. **问：为什么 normalized `frac` 不保存开头的 `1`？**  
   **答：** 规格化保证 $M=1.xxx_2$，leading 1 可由规则补回，从而多获得一位有效精度。

4. **问：`frac` 全 1 时为何仍小于 2？**  
   **答：** $M=1+\sum_{i=1}^{f}2^{-i}=2-2^{-f}$，与 2 仍差一个最小小数位权。

5. **问：`15213.0` 的完整 single 编码是什么？**  
   **答：** `0 10001100 11011011011010000000000`。

# 第 3 节：指数端点、denormalized、零、无穷与 NaN

> 时间范围：`00:19:47-00:29:37`  
> 课件范围：[课件: 04-float.pptx p.11] [课件: 04-float.pptx p.13] [课件: 04-float.pptx p.14] [课件: 04-float.pptx p.15] [课件: 04-float.pptx p.16] [课件: 04-float.pptx p.17]

## 本段在整讲中的作用

老师先回到 biased exponent，借学生回答暴露一个关键混淆：$Exp$ 是编码值，$E$ 才是实际指数。随后他解释 normalized 的 implied leading 1 为什么无法覆盖 0 附近，于是引入 `exp=0` 的 denormalized 规则；再用 `exp` 全 1 分出 infinity 与 NaN。段末把所有编码类别放到一条概念数轴上，并提出用 tiny format 穷举所有 bit pattern 的学习方法。[课件: 04-float.pptx p.13] [课件: 04-float.pptx p.14] [课件: 04-float.pptx p.15] [课件: 04-float.pptx p.17]

## 学习目标

- 区分 raw `exp` 编码范围与 normalized 的合法 $Exp/E$ 范围。
- 写出 denormalized value 的 $E$、$M$ 和 $v$。
- 说明为什么 denorm 同时提供 signed zero、接近零的等距数和向 normalized 的平滑过渡。
- 根据 `exp`/`frac` 判断 infinity 与 NaN。
- 比较 floating-point overflow 与 two's-complement modular overflow 的课堂模型。

## 前置知识与依赖

- 依赖第 2 节的 $Bias=2^{k-1}-1$、normalized $E=Exp-Bias$ 与 $M=1.frac$。
- 需要持续区分 bit field `exp`、字段无符号值 $Exp$ 和实际指数 $E$。
- 本段先定义类别；下一节才用 8-bit tiny format 对边界逐值验算。

## 教学展开

### 1. Raw 编码端点不等于 normalized 指数端点（`00:19:47-00:23:23`）

对 single 的 8-bit `exp`，若只看无符号 bit pattern，则

$$
Exp_{raw}\in[0,255].
$$

若机械代入 $E=Exp-127$，形式上会得到 $[-127,128]$。但这两个端点恰好对应 `exp=00000000` 与 `exp=11111111`，已经保留给其他类别，**不是 normalized values**。Normalized 的实际范围是：[课件: 04-float.pptx p.11]

$$
Exp\in[1,254]
$$

$$
E_{min}=1-127=-126,
$$

$$
E_{max}=254-127=127.
$$

老师用“把指数区间整体向上平移 bias”解释 biased encoding：实际指数 0 被映射到 $Exp=Bias$，负指数落在其下，正指数落在其上。课堂口述在这一段混用了 raw 端点与 normalized 端点；边界应以课件定义为准。

### 2. 为什么还需要 denormalized values（`00:23:23-00:24:55`）

Normalized 总有 $M\ge1$。即使指数已经降到 normalized 最小值，固定 leading 1 仍阻止 significand 继续趋向 0。IEEE 因而为 `exp=000...0` 定义 denormalized（denorm）规则：[课件: 04-float.pptx p.13]

$$
E=1-Bias,
$$

$$
M=0.xxx\ldots x_2=\frac{Frac}{2^f},
$$

$$
v=(-1)^sM2^E.
$$

这里的 leading bit 从 normalized 的隐含 `1` 改为隐含 `0`。此外，$E$ 特意使用 $1-Bias$，而不是机械的 $0-Bias$；下一节会验证它让最大 denorm 与最小 norm 之间保持同一间距。

### 3. Signed zero 与最接近 0 的有限数（`00:24:55-00:26:13`）

当 `exp=0` 且 `frac=0` 时，$M=0$，因此无论符号位如何，数值大小都是 0：[课件: 04-float.pptx p.13]

```text
0 000...0 000...0 -> +0
1 000...0 000...0 -> -0
```

这给出两个不同 bit pattern，但课件后面要求数值比较时把 $-0$ 与 $+0$ 视为相等。[课件: 04-float.pptx p.21]

若 `exp=0`、`frac!=0`，则得到最接近 0 的非零数。对固定 $f$，相邻 `Frac` 只差 1，故相邻正 denorm 的间距恒为

$$
\Delta=2^{-f}\cdot2^{1-Bias}=2^{1-Bias-f}.
$$

这就是课件所说的“最接近 0 且等距”；本讲在这里不展开额外硬件机制。[课件: 04-float.pptx p.13]

### 4. `exp` 全 1、`frac` 全 0：infinity（`00:26:13-00:27:19`）

编码规则为：[课件: 04-float.pptx p.14]

```text
exp = 111...1, frac = 000...0
```

$s=0$ 表示 $+\infty$，$s=1$ 表示 $-\infty$。课堂把它作为浮点运算指数溢出后的特殊结果，与 two's-complement 整数绕回表示区间的 modular behavior 对照。

课件给出的除零例子为：

$$
\frac{1.0}{+0.0}=+\infty,
\qquad
\frac{-1.0}{-0.0}=+\infty,
\qquad
\frac{1.0}{-0.0}=-\infty.
$$

符号来自操作数符号组合；不能把“得到 infinity 后一切仍是 infinity”理解为所有后续运算都如此，因为 $\infty-\infty$、$\infty\cdot0$ 会得到 NaN。[课件: 04-float.pptx p.14]

### 5. `exp` 全 1、`frac` 非 0：NaN（`00:27:19-00:27:55`）

```text
exp = 111...1, frac != 000...0 -> NaN
```

NaN（Not-a-Number）用于没有可确定数值结果的情况。课堂口述举出 $\sqrt{-1}$；课件还列出

$$
\infty-\infty
$$

和

$$
\infty\cdot0.
$$

这些不是普通有限数，也不是有序数轴上的一个“最大值”。[课件: 04-float.pptx p.14]

### 6. 全部编码类别的概念顺序（`00:27:55-00:28:39`）

老师用可视化把正负两侧连接起来：[课件: 04-float.pptx p.15]

```text
-infinity ... negative normalized ... negative denorm ... -0/+0
          ... positive denorm ... positive normalized ... +infinity

NaN 不放在普通数值顺序中。
```

从 0 向外，先是等距 denorm，再进入 normalized；越接近 0，可表示值越密。正负零 bit pattern 不同但数值相等，NaN 则需要特殊比较语义。

### 7. 用 tiny format 穷举，而不是只背公式（`00:28:39-00:29:37`）

老师把学习策略与前一讲的 tiny two's-complement system 类比：位数足够小时，可以列出所有编码，直接观察边界和相邻关系。本讲接下来采用 1 个 sign bit、4 个 exponent bits、3 个 fraction bits 的 8-bit IEEE-like format，保留 normalized、denormalized、zero、infinity、NaN 的相同分类，只缩小字段宽度。[课件: 04-float.pptx p.17]

## 概念、符号与推导

### 四类解码规则

| `exp` | `frac` | 类别 | $E$ | $M$ |
| --- | --- | --- | --- | --- |
| neither all 0 nor all 1 | 任意 | normalized | $Exp-Bias$ | $1.frac_2$ |
| all 0 | all 0 | signed zero | $1-Bias$ | $0$ |
| all 0 | nonzero | denormalized | $1-Bias$ | $0.frac_2$ |
| all 1 | all 0 | $\pm\infty$ | n/a | n/a |
| all 1 | nonzero | NaN | n/a | n/a |

[课件: 04-float.pptx p.11] [课件: 04-float.pptx p.13] [课件: 04-float.pptx p.14]

### Single normalized 边界

不能从 raw field 的 $0\ldots255$ 直接得到 normalized 范围。正确推导是：

$$
1\le Exp\le254
$$

$$
-126=1-127\le E\le254-127=127.
$$

## 例子与课堂提示

- Signed zero 说明 sign bit 并不因 magnitude 为 0 而消失。[课件: 04-float.pptx p.13]
- 除以 $+0/-0$ 的例子说明 zero 的符号会影响某些运算结果。[课件: 04-float.pptx p.14]
- $\sqrt{-1}$、$\infty-\infty$、$\infty\cdot0$ 区分“数值太大”与“没有可确定数值”。[课件: 04-float.pptx p.14]
- Tiny format 的目的不是创造另一套标准，而是让 IEEE-like 分类可以被完整枚举。[课件: 04-float.pptx p.17]

## 常见误解

- **误解：Single normalized 的 $E$ 范围是 $[-127,128]$。** 那是把两个特殊 raw `exp` 端点机械代入后的形式结果；实际 normalized 范围是 $[-126,127]$。[课件: 04-float.pptx p.11]
- **误解：Denorm 仍有 implied leading 1。** 它使用 $M=0.frac_2$。[课件: 04-float.pptx p.13]
- **误解：$-0$ 与 $+0$ 的编码相同。** 只有 sign bit 不同；数值比较时才视为相等。
- **误解：Overflow 会像 two's complement 一样绕回小数。** 课堂模型是溢出到带符号 infinity。
- **误解：Infinity 参与任何运算都仍是 infinity。** $\infty-\infty$ 和 $\infty\cdot0$ 是 NaN。[课件: 04-float.pptx p.14]
- **误解：NaN 位于 $+\infty$ 之后。** NaN 不属于普通数值全序。

## 本段掌握检查

1. **问：为什么 single normalized 的最小 $E$ 是 $-126$ 而不是 $-127$？**  
   **答：** $Exp=0$ 保留给 zero/denorm，最小 normalized $Exp=1$，所以 $E=1-127=-126$。

2. **问：Denorm 为什么使用 $E=1-Bias$？**  
   **答：** 它与最小 normalized value 使用同一指数，使两类编码在边界处保持平滑间距。

3. **问：什么 bit pattern 表示 $-0$？**  
   **答：** `s=1`、`exp` 全 0、`frac` 全 0。

4. **问：怎样从 `exp` 全 1 的编码区分 infinity 与 NaN？**  
   **答：** `frac=0` 是带符号 infinity；`frac!=0` 是 NaN。

5. **问：浮点 overflow 与课堂中的 two's-complement overflow 有何不同？**  
   **答：** 浮点溢出到 $\pm\infty$；two's-complement 例子按模绕回有限区间。

# 第 4 节：Tiny floating point、动态范围与数值间距

> 时间范围：`00:29:37-00:39:33`  
> 课件范围：[课件: 04-float.pptx p.17] [课件: 04-float.pptx p.18] [课件: 04-float.pptx p.19] [课件: 04-float.pptx p.20]

## 本段在整讲中的作用

前一节定义了五种编码类别，本段不再增加规则，而是用一个 8-bit IEEE-like format 逐值验证它们。老师从 zero、最小 denorm、最大 denorm 算到最小 normalized value，解释 $E=1-Bias$ 的设计如何消除边界跳洞；随后改用更小的 6-bit format 画数轴，观察“同一指数内等距、指数每增 1 间距加倍、越接近 0 越密”的分布。[课件: 04-float.pptx p.17] [课件: 04-float.pptx p.18] [课件: 04-float.pptx p.19] [课件: 04-float.pptx p.20]

## 学习目标

- 从字段宽度算出 tiny format 的 bias。
- 逐步解码 zero、最小/最大 denorm、最小 norm 和相邻 norm。
- 证明 denorm 到 norm 的边界从 $7/512$ 平滑过渡到 $8/512$。
- 推导固定 exponent 下的相邻数间距。
- 解释为什么 floating-point values 在 0 附近更密、向外逐级变疏。

## 前置知识与依赖

- 依赖第 3 节的分类表以及 normalized/denormalized 两套 $E,M$ 规则。
- 需要能把 3-bit fraction 看成以 8 为分母的二进制小数。
- 本段只枚举 $s=0$ 的正半轴；$s=1$ 给出对称的负值类别。

## 教学展开

### 1. 定义 8-bit IEEE-like format（`00:29:37-00:30:43`）

字段布局为：[课件: 04-float.pptx p.17]

```text
s | exp  | frac
1 | 4 位 | 3 位
```

总计 8 bits。Exponent 位数 $k=4$，所以

$$
Bias=2^{4-1}-1=7.
$$

它不是实际 IEEE single/double，只是字段更小、类别和规则相同的教学模型。固定 $s=0$ 后，`exp | frac` 有 $2^{4+3}=128$ 种组合，可以完整枚举。

### 2. Zero 与最小正 denorm（`00:30:43-00:32:39`）

`0 0000 000` 是 denormalized 类别：

$$
E=1-Bias=1-7=-6,
$$

$$
M=0.000_2=0,
$$

$$
v=0\cdot2^{-6}=0.
$$

因此浮点 $+0$ 与无符号整数 0 都是全 0 bit pattern。[课件: 04-float.pptx p.18]

把 `frac` 增加 1 得 `0 0000 001`：

$$
M=0.001_2=\frac18,
$$

$$
v=\frac18\cdot2^{-6}
=\frac18\cdot\frac1{64}
=\frac1{512}.
$$

它是该 tiny format 的最小正非零数。[课件: 04-float.pptx p.18]

### 3. Denorm 的等距增长与最大值（`00:32:45-00:34:03`）

`0 0000 010` 中

$$
M=0.010_2=\frac14=\frac28,
$$

所以

$$
v=\frac28\cdot\frac1{64}=\frac2{512}.
$$

每把 `Frac` 增加 1，$M$ 增加 $1/8$，而 $E=-6$ 不变，因此数值固定增加

$$
\Delta=\frac18\cdot2^{-6}=\frac1{512}.
$$

最大 denorm 为 `0 0000 111`：

$$
M=0.111_2=\frac78,
$$

$$
v=\frac78\cdot\frac1{64}=\frac7{512}.
$$

[课件: 04-float.pptx p.18]

### 4. 从最大 denorm 平滑进入最小 norm（`00:34:03-00:36:06`）

再把整段编码增加 1，`frac` 从 `111` 回到 `000`，`exp` 从 `0000` 变为 `0001`。它现在是 normalized value：

$$
Exp=1,
$$

$$
E=Exp-Bias=1-7=-6,
$$

$$
M=1.000_2=1=\frac88.
$$

于是

$$
v=1\cdot2^{-6}=\frac1{64}=\frac8{512}.
$$

最大 denorm 是 $7/512$，最小 norm 是 $8/512$，差仍为 $1/512$。这正是 denorm 选择 $E=1-Bias$ 而不是 $-Bias$ 的效果。[课件: 04-float.pptx p.18]

### 5. 同一 exponent 内继续等距（`00:36:06-00:36:49`）

保持 `exp=0001`，把 `frac` 从 `000` 增到 `001`：

$$
M=1.001_2=1+\frac18=\frac98,
$$

$$
v=\frac98\cdot2^{-6}=\frac9{512}.
$$

因此边界附近依次为

$$
\ldots,\frac6{512},\frac7{512},\frac8{512},\frac9{512},\ldots
$$

类别改变了，局部间距没有改变。[课件: 04-float.pptx p.18]

### 6. Bias 的区间直觉（`00:36:49-00:37:58`）

学生询问为何 bias 取 $2^{k-1}-1$。老师用区间平移解释：希望实际指数 0 位于编码范围中部附近，较小的 $Exp$ 对应负指数，较大的 $Exp$ 对应正指数，同时保留全 0 与全 1 两端作特殊编码。

对本例：

$$
Bias=7,
$$

所以 normalized $Exp=1\ldots14$ 映射到

$$
E=-6\ldots7.
$$

这也解释了课件表中最大 normalized 编码 `0 1110 111` 的 $E=7$。[课件: 04-float.pptx p.18]

### 7. Dynamic range 的其余锚点（课件表）

老师没有逐行计算整张表，但课件用以下值标出范围与 1 附近的结构：[课件: 04-float.pptx p.18]

| 编码 | 类别 | 推导 | 值 |
| --- | --- | --- | ---: |
| `0 0110 111` | norm | $M=15/8,E=-1$ | $15/16$ |
| `0 0111 000` | norm | $M=1,E=0$ | $1$ |
| `0 0111 001` | norm | $M=9/8,E=0$ | $9/8$ |
| `0 1110 111` | 最大正 norm | $M=15/8,E=7$ | $240$ |
| `0 1111 000` | special | `exp` 全 1、`frac` 全 0 | $+\infty$ |

例如最大 finite value：

$$
\frac{15}{8}\cdot2^7=\frac{15}{8}\cdot128=15\cdot16=240.
$$

### 8. 数轴分布：同层等距，逐层加倍（`00:37:58-00:39:33`）

课件再用 6-bit IEEE-like format：1 个 sign bit、$e=3$ 个 exponent bits、$f=2$ 个 fraction bits，bias 为

$$
2^{3-1}-1=3.
$$

[课件: 04-float.pptx p.19] [课件: 04-float.pptx p.20]

对 fixed normalized exponent $E$，相邻 `Frac` 差 1，因此

$$
\Delta_E=2^{-f}\cdot2^E=2^{E-f}.
$$

当 $E$ 墠加 1：

$$
\Delta_{E+1}=2^{E+1-f}=2\Delta_E.
$$

所以每个 exponent band 内部等距；走到下一 band 后间距翻倍。反向靠近 0 时，间距逐级减半，图上就表现为 0 周围更密。Denorm 与最小 norm 共享边界间距，避免突然出现一个更大的空洞。[课件: 04-float.pptx p.19] [课件: 04-float.pptx p.20]

## 概念、符号与推导

### 通用间距公式

若 `frac` 有 $f$ 位：

- Denorm 间距：

  $$
  \Delta_{denorm}=2^{1-Bias-f}.
  $$

- 固定 normalized exponent $E$ 的间距：

  $$
  \Delta_E=2^{E-f}.
  $$

- 最小 normalized exponent $E=1-Bias$，因此

  $$
  \Delta_{min\ norm}=2^{1-Bias-f}=\Delta_{denorm}.
  $$

这三步直接证明 denorm/norm 边界平滑。

### Tiny format 的正数边界

```text
0
1/512                 最小正 denorm
...
7/512                 最大 denorm
8/512 = 1/64          最小正 norm
9/512                 下一个 norm
...
15/16 < 1 < 9/8       1 附近
...
240                   最大正 finite norm
+infinity              下一个特殊类别（frac=0）
```

- 6-bit 数轴图不是要记住每个点，而是看出 density 随指数成倍变化。[课件: 04-float.pptx p.19] [课件: 04-float.pptx p.20]

## 常见误解

- **误解：8-bit tiny format 就是某种实际 IEEE 类型。** 它只是保留 IEEE-like 规则的教学模型。
- **误解：`frac=001` 总代表 $1/8$。** Denorm 中 $M=1/8$；normalized 中 $M=1+1/8=9/8$。
- **误解：从 denorm 进入 norm 时指数一定增加。** 字段 `Exp` 增加，但两侧实际 $E$ 都是 $-6$。
- **误解：所有 floating-point values 等距。** 只有同一 exponent band 内等距；$E$ 每增 1，间距翻倍。
- **误解：越接近 0 相对精度越高且规则完全不变。** 图只说明绝对间距更小；denorm 区采用固定间距和不同的 leading-bit 规则。

## 教学展开

### 1. 同一 exponent band 内保持等距（`00:39:33-00:39:45`）

本段从上一节被切开的句子继续：tiny format 中，相同 `exp` 下每把 `frac` 增加 1，数值增加同一个 $\Delta_E$；`exp` 使 $E$ 增加 1 后，间距翻倍。Denorm 与第一组 normalized values 在边界处仍保持相同间距。[课件: 04-float.pptx p.20]

### 2. IEEE 编码的比较便利与必要例外（`00:39:45-00:40:35`，课堂追问 `00:42:31-00:43:22`）

第一个便利是 $+0$ 的 floating-point bit pattern 与 integer zero 一样全为 0。[课件: 04-float.pptx p.21]

老师最初把第二个便利概括为“除 NaN 外可以把 floating-point pattern 当 unsigned integer 比较”。学生随后用 negative infinity 的 sign bit 反驳，老师当场承认还需处理负数。课件给出的完整边界是：[课件: 04-float.pptx p.21]

- 必须先比较 sign bits；负数一侧不能直接沿用正数的 unsigned 顺序。
- 必须把 $-0$ 与 $+0$ 视为相等。
- NaN problematic：其 pattern 看起来可能比普通值大，但普通数值比较不应把它当作最大数。
- 处理这些例外后，denorm 到 normalized、normalized 到 infinity 的编码顺序具有可利用的单调性。

因此这里的结论是 “almost”，不是无条件 bitwise comparison。[课件: 04-float.pptx p.21]

### 3. 浮点运算的核心模型（`00:40:35-00:41:39`）

有限 `frac` bits 不保证两个输入的精确和或积仍能装入目标格式。老师要求采用如下概念模型：[课件: 04-float.pptx p.23]

$$
x+_fy=Round(x+y),
$$

$$
x\cdot_fy=Round(x\cdot y).
$$

右侧 $x+y$ 或 $x\cdot y$ 先按“无限多 bits”得到精确数学结果，再做两类修正：

1. 若 exponent 超出格式范围，可能 overflow。
2. 若 significand 需要的 bits 超过 `frac` precision，按指定模式舍入。

这是推理模型，不是声称硬件必须真的配置无限位寄存器；它允许程序员脱离具体实现分析结果。[课件: 04-float.pptx p.23] [课件: 04-float.pptx p.34]

### 4. IEEE 的四种舍入模式（`00:41:39-00:44:18`）

老师用“舍入到整数美元”比较四种模式：[课件: 04-float.pptx p.24]

| 模式 | $1.40$ | $1.60$ | $1.50$ | $2.50$ | $-1.50$ |
| --- | ---: | ---: | ---: | ---: | ---: |
| toward zero | 1 | 1 | 1 | 2 | -1 |
| down，toward $-\infty$ | 1 | 1 | 1 | 2 | -2 |
| up，toward $+\infty$ | 2 | 2 | 2 | 3 | -1 |
| nearest even（默认） | 1 | 2 | 2 | 2 | -2 |

“Down” 指向数轴的 $-\infty$，不是“绝对值变小”；所以 $-1.50$ 向下得到 $-2$。相反，toward zero 才会得到 $-1$。

IEEE 默认采用 nearest even。老师说其他模式可以在较低层改变，但本讲后续只分析默认模式。[课件: 04-float.pptx p.25]

### 5. Nearest-even 的三分规则（`00:44:18-00:45:37`）

设精确值位于两个相邻可表示值 $L<U$ 之间：

1. 距离 $L$ 更近：选 $L$。
2. 距离 $U$ 更近：选 $U$。
3. 恰好 halfway：选保留位置最低有效 digit 为偶数的那个。

因此 `$1.50` 舍入到偶数整数 2，`$2.50` 也舍入到偶数整数 2；负的 `$-1.50` 在 `-1` 与 `-2` 中选择偶数 `-2`。[课件: 04-float.pptx p.24]

老师给出的统计动机是：若中点情形分布没有方向偏好，ties 有时向上、有时向下，避免“所有 ties 总向同一方向”造成系统性高估或低估。这个理由只解释 tie rule；非中点仍然选择真正较近的一侧。[课件: 04-float.pptx p.25]

### 6. Round to nearest hundredth（`00:46:03-00:49:05`）

目标是保留到百分位。判断时必须看百分位右侧的**全部** digits：[课件: 04-float.pptx p.25]

1. **小于 halfway：**

   $$
   7.8949999\rightarrow7.89.
   $$

   被丢弃部分 `49999...` 小于 `50000...`，所以直接截断。保留末位 `9` 虽为奇数，也不触发 tie-to-even，因为它不是 tie。

2. **大于 halfway：**

   $$
   7.8950001\rightarrow7.90.
   $$

   被丢弃部分大于 `50000...`，所以向较近的上侧值进位。

3. **恰好 halfway，保留末位为奇数：**

   $$
   7.8950000\rightarrow7.90.
   $$

   两侧是 `7.89` 与 `7.90`。`7.89` 的最低保留 digit 为 9（奇），`7.90` 为 0（偶），故选 `7.90`。进位可机械地看成在舍入位置加一个单位并传播 carry。

4. **恰好 halfway，保留末位已为偶数：**

   $$
   7.8850000\rightarrow7.88.
   $$

   两侧是 `7.88` 与 `7.89`，前者最低保留 digit 8 为偶数，因此截断到 `7.88`。

关键不是“逢 5 看奇偶”，而是“被丢弃部分必须恰为 5 后全 0，才看保留末位奇偶”。[课件: 04-float.pptx p.25]

## 概念、符号与推导

### 舍入决策

令目标格式中相邻值为 $L,U$，精确结果为 $r$：

$$
Round(r)=
\begin{cases}
L,&r<(L+U)/2,\\
U,&r>(L+U)/2,\\
\mathrm{LSB\ even},&r=(L+U)/2.
\end{cases}
$$

最后一行表示 exact tie 时选择最低保留 digit 为偶数的一侧；更高位不参与奇偶判定。

### 运算抽象的边界

```text
输入浮点值
  -> 精确数学运算
  -> exponent 是否越界
  -> significand 舍入到目标 precision
  -> 可表示的浮点结果或特殊值
```

- 依赖 normalized significand 范围 $1\le M<2$ 和精确后舍入模型。
- 需要知道异或 `^`：两个 sign bits 不同时结果为负。

## 教学展开

### 1. 舍入必须检查全部 discarded digits（`00:49:17-00:50:18`）

老师先确认：相同 `exp` 的 values 在同一 number-line band 内等距。随后回答另一问题：判断小于、等于还是大于 halfway 时，要考虑舍入位置右侧的完整值。十进制中 exact halfway 是 `5` 后全 0；若后面还有任何非零 digit，就已经大于 halfway，不能当 tie。[课件: 04-float.pptx p.25]

### 2. 二进制中的 even 与 halfway（`00:50:23-00:51:04`）

二进制只有 `0`、`1`：

- 舍入后最低保留 bit 为 `0`，结果为 even。
- 最低保留 bit 为 `1`，结果为 odd。
- 舍入位置右侧恰为 `100..._2`，表示 exact halfway。

若 discarded bits 小于 `100..._2`，向下截断；大于它，向上加一个最低保留位单位；恰好等于它，再看最低保留 bit 的奇偶。[课件: 04-float.pptx p.26]

### 3. 四个数舍入到最近 $1/4$（`00:51:04-00:54:35`）

保留 binary point 右侧两 bits，最小保留单位是 $2^{-2}=1/4$。[课件: 04-float.pptx p.26]

**例 1：$2\frac3{32}$，小于 halfway。**

$$
2\frac3{32}=10.00011_2.
$$

保留 `10.00`，discarded bits 为 `011`：

$$
011_2<100_2.
$$

所以截断：

$$
10.00011_2\rightarrow10.00_2=2.
$$

**例 2：$2\frac3{16}$，大于 halfway。**

$$
2\frac3{16}=10.00110_2.
$$

Discarded bits 为 `110`：

$$
110_2>100_2.
$$

向最低保留位置加 1 个单位：

$$
10.00_2+0.01_2=10.01_2=2\frac14.
$$

**例 3：$2\frac78$，exact tie 且截断结果为 odd。**

$$
2\frac78=10.11100_2.
$$

保留 `10.11`，discarded bits 为 `100`，恰在中点。`10.11` 最低位为 1（odd），因此进位并传播 carry：

$$
10.11_2+0.01_2=11.00_2=3.
$$

**例 4：$2\frac58$，exact tie 且截断结果已为 even。**

$$
2\frac58=10.10100_2.
$$

保留 `10.10`，discarded bits 也是 `100`。最低保留 bit 为 0（even），所以截断：

$$
10.10100_2\rightarrow10.10_2=2\frac12.
$$

四例把算法压缩为：比较 discarded suffix 与 `100...`；向下就截断，向上就在最低保留位加 1 并传播 carry。[课件: 04-float.pptx p.26]

### 4. Floating-point multiplication（`00:54:38-00:55:54`）

对两个 normalized 形式

$$
(-1)^{s_1}M_1 2^{E_1}
$$

与

$$
(-1)^{s_2}M_2 2^{E_2},
$$

精确乘积先写成：[课件: 04-float.pptx p.27]

$$
s=s_1\oplus s_2,
$$

$$
M=M_1M_2,
$$

$$
E=E_1+E_2.
$$

然后修正：

1. 若 $M\ge2$，右移 $M$ 一位并令 $E\leftarrow E+1$，恢复 $1\le M<2$。
2. 若 $E$ 超出范围，overflow。
3. 把 $M$ 舍入到可用 `frac` precision。

课件指出实现中的主要工作是 significand multiplication；本讲不展开 multiplier circuit。[课件: 04-float.pptx p.27]

### 5. Floating-point addition（`00:55:55-00:56:41`）

设 $E_1>E_2$。普通竖式加法要求位权对齐，浮点加法也必须先把 binary points 对齐：[课件: 04-float.pptx p.28]

1. 把较小指数一侧的 $M_2$ 右移 $E_1-E_2$ 位，使两项都以 $2^{E_1}$ 为尺度。
2. 按符号对齐后相加，得到 signed significand $M$，暂取 $E=E_1$。
3. 若 $M\ge2$，右移一位并增加 $E$。
4. 若 $0<M<1$，左移 $k$ 位并减少 $E$，直到规格化；zero/special cases 另按其类别处理。
5. 检查 exponent overflow，再把 $M$ 舍入到目标 `frac` precision。

与乘法相比，加法的关键额外步骤是 **align**。大指数差意味着较小数被右移很多位，其低位可能在最终舍入中完全消失。

### 6. Floats are not reals：加法不满足结合律（`00:56:41-00:59:13`）

老师把本讲重新连接到第一讲的 great reality：浮点运算不是实数运算，但具有明确、可推理的性质。浮点加法是 commutative，却不是 associative；动态范围差异很大时尤其容易看到反例。[课件: 04-float.pptx p.29]

课堂课件使用：

$$
(3.14+10^{10})-10^{10}.
$$

第一步中 $3.14$ 相对 $10^{10}$ 太小，在目标 precision 对齐并舍入后消失：

$$
Round(3.14+10^{10})\approx10^{10},
$$

所以

$$
(3.14+_f10^{10})+_f(-10^{10})=0.
$$

换关联顺序：

$$
3.14+_f(10^{10}+_f(-10^{10}))
=3.14+_f0
=3.14.
$$

两边不同，因此

$$
(x+_fy)+_fz\ne x+_f(y+_fz)
$$

在一般情况下成立。根因不是运算随机，而是每一步都可能舍入。[课件: 04-float.pptx p.29]

## 概念、符号与推导

### Binary nearest-even 决策表

| Discarded suffix | 与 halfway 比较 | 动作 |
| --- | --- | --- |
| `0...` | 小于 | 截断 |
| `1...` 且不为 `100...` | 大于 | 最低保留位加 1 |
| `100...`，保留 LSB 为 0 | 相等、even | 截断 |
| `100...`，保留 LSB 为 1 | 相等、odd | 最低保留位加 1 |

### 乘法与加法的流程差异

```text
乘法：sign XOR -> significands multiply -> exponents add -> normalize -> round
加法：align exponents -> signed significands add -> normalize -> round
```

两者都可能因 exponent 越界而 overflow。[课件: 04-float.pptx p.27] [课件: 04-float.pptx p.28]

## 例子与课堂提示

- $2\frac78$ 与 $2\frac58$ 具有相同 halfway suffix，却因保留 LSB 不同而分别向上、向下。[课件: 04-float.pptx p.26]
- 乘法中 $M_1,M_2\in[1,2)$，所以积可能进入 $[1,4)$；$M\ge2$ 时只需右移并增 exponent。[课件: 04-float.pptx p.27]
- 加法先 align，解释了“小数加到大数上为何消失”。[课件: 04-float.pptx p.28]

## 常见误解

- **误解：二进制中 `1` 就表示应该进位。** 只有完整 discarded suffix 大于 halfway，或恰为 halfway 且保留结果为 odd，才进位。
- **误解：Tie-to-even 看被丢弃位是否偶数。** 它看舍入后最低保留 bit。
- **误解：浮点加法直接把两个 significand 相加。** 必须先对齐 exponent/binary point。
- **误解：Normalization 与 rounding 是同一步。** 先把 $M$ 调回目标范围，再把精度压到可用 `frac` bits。
- **误解：浮点加法不交换。** 课件结论是 commutative，但不 associative。[课件: 04-float.pptx p.29]
- **误解：代数上重排总能让程序更快且结果不变。** 每个中间结果的舍入位置可能改变最终答案。

## 本段掌握检查

1. **问：二进制 discarded suffix 何时表示 exact halfway？**

## 教学展开

### 1. 浮点加法保留什么、失去什么（`00:59:13-00:59:33`）

老师接上上一节的性质表：[课件: 04-float.pptx p.29]

| 性质 | 课堂结论 | 边界 |
| --- | --- | --- |
| 封闭性 | 基本成立 | 结果可能是 infinity 或 NaN |
| 交换律 | 成立 | NaN 比较等特殊语义另论 |
| 结合律 | 不成立 | 中间舍入或 overflow 会改变结果 |
| 加法单位元 0 | 成立 | 普通数值语义下 |
| 加法逆元 | 几乎成立 | infinity 与 NaN 例外 |
| 单调性 | 几乎成立 | infinity 与 NaN 需要排除 |

因此浮点数不是 Abelian group 的完整实现；“规则不完全等同于实数”也不等于“没有规则”。

### 2. 浮点乘法性质与非结合反例（`00:59:33-01:00:46`）

乘法一般封闭到 IEEE 的有限值/特殊值集合，并满足 commutativity，但不满足 associativity，也不对浮点加法满足 distributivity；1 是乘法单位元，单调性在排除 infinity/NaN 后基本保留。[课件: 04-float.pptx p.30]

课件的重关联反例为：

$$
(10^{20}\cdot_f10^{20})\cdot_f10^{-20}.
$$

第一步 overflow：

$$
10^{20}\cdot_f10^{20}=+\infty,
$$

于是

$$
+\infty\cdot_f10^{-20}=+\infty.
$$

改变关联顺序：

$$
10^{20}\cdot_f(10^{20}\cdot_f10^{-20}).
$$

括号内约为 1，因此结果约为

$$
10^{20}\cdot_f1=10^{20}.
$$

两种中间结果分别经历 overflow 和数量级抵消，最终不同。[课件: 04-float.pptx p.30]

### 3. 不满足分配律（课件与同一讲解序列）

课件给出：[课件: 04-float.pptx p.30]

$$
10^{20}\cdot_f(10^{20}-_f10^{20})=10^{20}\cdot_f0=0.
$$

若形式上展开：

$$
(10^{20}\cdot_f10^{20})-_f(10^{20}\cdot_f10^{20})
=+\infty-_f+\infty
=NaN.
$$

所以浮点运算不能直接套用实数的 distributive rewrite。该差异来自中间 overflow 和特殊值，不是符号代数本身发生变化。

### 4. 地震模拟经验：风险由动态范围决定（`01:00:46-01:02:38`）

老师讲到自己用 finite elements 和 single-precision floating point 模拟 Southern California earthquake ground motion。团队无法保证每次完全相同的运算顺序，却没有在该项目中遇到明显的 associativity 问题；他的经验解释是相邻地面状态变化较平滑，数据没有频繁出现课堂反例那样极端的数量级混合。

他把这与可能具有更大 dynamic range 的非自然或 financial data 对照，并给出程序员层面的结论：

1. 了解数据可能覆盖的数量级。
2. 知道重关联或改变求和顺序可能改变末位乃至结果。
3. 不把一次项目“没有出问题”推广成 floating point 等同实数的保证。

这是一段应用经验，不是“自然现象永远适合 single precision”的定理。

### 5. C 提供的两档 floating-point type（`01:02:38-01:03:27`）

C 在本讲模型中保证：[课件: 04-float.pptx p.32]

```c
float   // IEEE single precision
double  // IEEE double precision
```

老师把它与先前 `int`/`unsigned` cast 对比：后者在课堂模型中可只改变同一 bit pattern 的解释；`int`、`float`、`double` 之间转换则会生成目标格式的新 bit representation，可能伴随 truncation 或 rounding。[课件: 04-float.pptx p.32]

### 6. `double/float -> int`（`01:03:27-01:05:41`）

课件给出的规则是：[课件: 04-float.pptx p.32]

- 丢弃 fractional part，效果类似 rounding toward zero。
- 若原值超出目标整数范围或为 NaN，结果不由该规则定义；课件注明常见表现是设置为 `TMin`。

这里的截断不是 nearest-even。Transcript 在 PowerPoint crash 前围绕 23/52 fraction bits 进行了一段自我修正；最终应以课件的范围前提与 toward-zero 规则为准，不能推出“任何 float 转 int 都不会丢信息”。

### 7. `int -> double` 与 `int -> float`（`01:05:41-01:06:59`）

**`int -> double`：** 当整数 word size 不超过 double 的 53-bit 有效精度时可精确转换。对课堂的 32-bit `int`，所有值都能完整放入 double significand：[课件: 04-float.pptx p.32]

$$
(double)x
$$

不需要丢失整数低位。

**`int -> float`：** Float 只有 24 位有效精度（implicit leading 1 加 23 个 `frac` bits），32-bit `int` 的某些值需要更多有效 bits，因此按当前 rounding mode 舍入。[课件: 04-float.pptx p.32]

两者继续服从同一个抽象：先取整数的精确值，再把它装入目标 floating-point precision。

### 8. Puzzles 1-5：用 precision 包含关系判断（`01:06:59-01:09:00`）

设 `int x`、`float f`、`double d`，并按课件假设 `f`、`d` 不是 NaN。[课件: 04-float.pptx p.33]

1. **`x == (int)(float)x`：不总成立。**

   `int -> float` 可能舍掉低位；再转回 `int` 无法恢复。例如只需选择一个需要超过 24 个有效 binary digits 的课堂 32-bit integer，就可能失败。老师在此只要求说明信息损失，不给具体反例值。

2. **`x == (int)(double)x`：在课堂 32-bit `int` 前提下成立。**

   `int -> double` 精确，值仍在原 `int` 范围，转回得到 $x$。[课件: 04-float.pptx p.32]

3. **`f == (float)(double)f`：成立。**

   Every single-precision finite/infinite value 可嵌入更宽的 double precision；转回 float 没有丢掉原来不存在的 bits。NaN 已由题设排除。

4. **`d == (double)(float)d`：不总成立。**

   `double -> float` 可能舍入；转回 double 只能精确表示那个已舍入的 float，不能恢复原 double。

5. **`f == -(-f)`：成立。**

   课堂解释为两次切换 sign bit，回到原编码/数值；NaN 已由题设排除。[课件: 04-float.pptx p.33]

## 概念、符号与推导

### Precision 包含关系

在本讲所用 32-bit `int`、single、double 模型中：

```text
32-bit int 的所有值 -> double：精确
32-bit int 的所有值 -> float：不保证精确

```

[课件: 04-float.pptx p.32] [课件: 04-float.pptx p.33]

### 代数规则的程序含义

```text
Commutative: 可交换两个操作数
Associative: 可改变括号/求值树
Distributive: 可在乘法与加减之间展开或提取因子
```

## 常见误解

- **误解：乘法可交换，所以也可任意重加括号。** Commutativity 与 associativity 是不同性质。
- **误解：分配律展开只是语法变化。** 它会改变中间 overflow/rounding，甚至把 0 变成 NaN。[课件: 04-float.pptx p.30]
- **误解：老师的地震模拟没出问题，single precision 就适合所有科学计算。** 该段只报告一个动态范围较平滑的项目经验。
- **误解：Floating-to-int 使用 nearest-even。** 它截断 fractional part，类似 toward zero。[课件: 04-float.pptx p.32]

- **误解：更宽类型转回窄类型后再转宽可恢复原值。** 一旦第一次 narrowing 舍入，信息已经丢失。

## 本段掌握检查

1. **问：浮点乘法为什么不 associative？**  
   **答：** 不同关联顺序产生不同中间舍入或 overflow；课堂例子一侧先得到 infinity，另一侧先约成 1。

2. **问：分配律反例的两侧为何分别是 0 与 NaN？**  
   **答：** 括号内先相减得到 0；展开后两个乘积先 overflow 为 infinity，再做 `infinity-infinity` 得 NaN。

3. **问：`float/double -> int` 怎样处理 fractional part？**  
   **答：** 截断，效果类似 toward zero；超范围或 NaN 不适用这一普通规则。

4. **问：为什么 32-bit `int -> double -> int` 能往返？**  
   **答：** Double 有 53-bit 有效精度，能精确承载课堂 32-bit `int` 的全部值。

5. **问：为什么 `double -> float -> double` 不保证回到原值？**  
   **答：** 第一步可能把 53-bit precision 压到 float 的 24-bit precision 并舍入，第二步不能恢复丢失 bits。

## 教学展开

### 1. `2/3 == 2/3.0`：不成立（`01:09:08-01:09:21`）

左侧两个 operands 都是整数，课堂结果为 integer division：

$$
2/3=0.
$$

右侧 `3.0` 使表达式执行 floating-point division，得到最接近 $2/3$ 的浮点表示：

$$
2/3.0\approx0.666\ldots.
$$

所以

```c
2/3 == 2/3.0
```

为 false。这里的重点不是 $2/3$ 能否被精确二进制表示，而是左侧在进入 floating-point comparison 前已经由 integer division 得到 0。[课件: 04-float.pptx p.33]

### 2. `d < 0.0 => d*2 < 0.0`：课堂判断为成立（`01:09:21-01:09:47`）

在 $d$ 非 NaN 且严格小于 0 的前提下，乘以正数 2 保持负号。老师特别检查 overflow 边界：若 magnitude 翻倍后超出有限范围，结果为 $-\infty$，而

$$
-\infty<0.
$$

若结果仍有限，它也保持负值；因此课件给出的 implication 成立。[课件: 04-float.pptx p.33]

### 3. `d > f => -f > -d`：课堂判断为成立（`01:09:47-01:10:29`）

这使用前面总结的 monotonicity：对非 NaN 数值，取负会反转严格不等号：

$$
d>f\Longrightarrow -d<-f,
$$

等价写成

$$
-f>-d.
$$

学生随后追问表达式中的某一中间量究竟是 `float` 还是 `double`。老师先给出猜测，随即明确说需要查 C guide，因此这段课不能作为精确类型规则的依据。[需回听 01:09:59] 题目的课堂结论仍来自非 NaN 条件下的顺序反转。[课件: 04-float.pptx p.33]

### 4. `d*d >= 0.0`：课堂判断为成立（`01:10:29-01:10:45`）

题设排除了 NaN。对 finite $d$，两个相同符号相乘得到非负结果；很小的结果即使舍入到 zero，也满足 $0\ge0$；很大的 magnitude 若 overflow，则得到 $+\infty$，同样满足比较。若 $d$ 本来是 infinity，平方仍是 positive infinity。因此：[课件: 04-float.pptx p.33]

$$
d\cdot d\ge0.
$$

这个结论依赖“不是 NaN”。若把题设丢掉，就不能把 NaN 的 comparison 当作普通非负判断。

### 5. `(d+f)-d == f`：不总成立（`01:10:45-01:10:52`）

实数代数会把左侧重写为 $f$，但浮点每一步都有舍入：

$$
(d+_ff)-_fd
$$

不保证等于

$$
(d-_fd)+_ff=f.
$$

当 $\lvert d\rvert$ 远大于 $\lvert f\rvert$ 时，第一步 `d+f` 可能舍掉 $f$：

$$
Round(d+f)=d,
$$

于是

$$
(d+_ff)-_fd=d-_fd=0\ne f
$$

（取任意课堂意义下非零且足够小的 $f$）。这正是前面 associativity 反例的 C expression 版本。[课件: 04-float.pptx p.29] [课件: 04-float.pptx p.33]

### 6. 总结：不是 reals，但可预测（`01:10:52-01:11:22`）

老师最后强调：[课件: 04-float.pptx p.34]

1. IEEE floating point 表示 $M\cdot2^E$ 形式的数，并有清晰数学性质。
2. 运算可以按“perfect precision 后 rounded”推理，而不依赖具体硬件微结构。
3. 它不等于 real arithmetic，会违反 associativity 和 distributivity。
4. 这些差异限制 compiler 的代数重排，也要求 numerical application programmers 理解数据范围和舍入。

Transcript 一度说 “not associative or commutative”，紧接着改成 “not associative”。前面课件已经明确 addition 与 multiplication 均 commutative；最终结论应是 **commutative，但不 associative，且 multiplication 不对 addition distributive**。[课件: 04-float.pptx p.29] [课件: 04-float.pptx p.30] [课件: 04-float.pptx p.34]

## 概念、符号与推导

### 本段五题的依赖图

```text
2/3 vs 2/3.0
  -> operand types determine integer or floating division

d < 0 -> d*2 < 0
  -> positive scaling + signed infinity on overflow

d > f -> -f > -d
  -> monotonicity/order reversal under negation

d*d >= 0
  -> sign multiplication + NaN excluded

(d+f)-d == f
  -> false because intermediate rounding breaks associativity
```

### 全讲统一运算模型

$$
x\circ_f y=Round(x\circ y),
$$

其中 $\circ$ 是课堂讨论的加法或乘法。该模型解释了为什么每个单独步骤可预测，而多个步骤仍可能不满足实数代数重写。[课件: 04-float.pptx p.23] [课件: 04-float.pptx p.34]

## 例子与课堂提示

- `2/3` 与 `2/3.0` 用一个 `.0` 展示 operand types 会先改变运算，再影响 comparison。[课件: 04-float.pptx p.33]
- `d*2` 的 overflow 边界说明 infinity 不是此命题的反例。
- `d*d` 的成立依赖题设排除 NaN，不能删掉假设后照搬答案。
- `(d+f)-d` 是最贴近实际代码的 non-associativity 检查。[课件: 04-float.pptx p.33]

## 常见误解

- **误解：Comparison 会先把 `2/3` 按浮点重新计算。** Integer division 已先得到 0，之后的类型转换不能恢复余数。
- **误解：负数 overflow 会绕成正数。** 本讲浮点模型溢出到带符号 infinity；这不同于 two's-complement modular overflow。
- **误解：所有涉及 NaN 的平方仍满足 `>= 0`。** 题设明确排除 NaN，不能把结论外推。[课件: 04-float.pptx p.33]
- **误解：`(d+f)-d` 可由符号代数直接消去 `d`。** 两步浮点运算之间已经发生舍入。
- **误解：浮点加法和乘法都不 commutative。** 老师最后立即纠正口误；课件结论是 commutative，但不 associative。[课件: 04-float.pptx p.29] [课件: 04-float.pptx p.30]

## 本段掌握检查

1. **问：为什么 `2/3 == 2/3.0` 为 false？**  
   **答：** 左侧 integer division 得 0，右侧 floating division 得约 $0.666\ldots$。

2. **问：`d<0` 时 `d*2` overflow 会不会推翻结果仍小于 0？**  
   **答：** 不会；课堂模型中它 overflow 到 $-\infty$，仍小于 0。

3. **问：`d>f` 为什么推出 `-f>-d`？**  
   **答：** 对非 NaN 数值，取负会反转严格不等号。

4. **问：`d*d>=0` 依赖哪个显式假设？**  
   **答：** `d` 不是 NaN；有限结果、zero 或 positive infinity 都非负。

5. **问：为什么 `(d+f)-d` 不保证等于 `f`？**  
   **答：** 若 $d$ 远大于 $f$，`d+f` 的中间舍入会先丢掉 $f$，再减 $d$ 得 0。
